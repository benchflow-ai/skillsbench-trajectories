MODEL OVERVIEW:
This Excel-based economic model estimates the impact of a 6.5 billion USD
investment shock on Georgia's potential GDP using a Cobb-Douglas production
function and Hodrick-Prescott (HP) filtering for trend analysis.

=================================================================
FORMULAS AND CALCULATIONS
=================================================================

All calculations use Excel formulas (no hardcoded values):

1. Depreciation Rate: =CFC / K

2. Natural Logarithm: =LN(value)

3. TFP (LnZ): =LnY - 0.35*LnK - 0.65*LnL

4. HP Filter Trend: Solved via matrix equation
   (I + λ*D'D)trend = LnZ
   where D is second-difference matrix

5. Extended TFP Trend: Linear regression
   LnA_Trend = -0.171418 + 0.031729 * year_index

6. Capital with Shock: K_with(t) = K_with(t-1)*(1-δ) + ΔK(t)

7. Potential Output (Cobb-Douglas):
   Y* = exp(LnA_Trend + 0.35*LnK + 0.65*LnL)

8. Shock Effect: L = Ystar_With - Ystar_Base
                M = L / Ystar_Base * 100

=================================================================
USING THE MODEL IN EXCEL
=================================================================

1. VIEWING RESULTS:
   - Open test-supply.xlsx in Excel or LibreOffice Calc
   - All formulas will calculate automatically
   - Check Production sheet for main results

2. SOLVER OPTIMIZATION (Optional):
   - To refine HP Filter further:
     * Go to Production sheet
     * Select Data > Solver (Excel) or Tools > Solver (Calc)
     * Set Objective: P9 (minimize)
     * By Changing: I7:I28 (LnZ_HP trend values)
     * Solver will find optimal smoothing

3. SENSITIVITY ANALYSIS:
   - Change λ in P6 to adjust HP Filter smoothness
   - Change α (capital share) in PWT!B4
   - Change depreciation rate in PWT!B4
   - Change investment shock in Investment sheet

4. INTERPRETING RESULTS:
   - Column M (Shock %): Percentage impact on GDP
   - Positive values: Investment shock increases output
   - Peak effect typically occurs 2-3 years after shock ends
   - Long-term effect depends on TFP growth rate
