# Build Failure Analysis

## Root Cause
The build fails because `agentops/__init__.py` unconditionally imports `LangchainCallbackHandler` and `AsyncLangchainCallbackHandler` from `langchain_callback_handler.py` (line 12).

The `langchain_callback_handler.py` module requires `langchain_core` package:
```python
from langchain_core.agents import AgentFinish, AgentAction
```

However, `langchain_core` is listed as an OPTIONAL dependency in `pyproject.toml`:
```toml
[project.optional-dependencies]
langchain = [
    "langchain>=0.0.354"
]
```

This means when users install the package without the `langchain` extras (i.e., `pip install agentops` instead of `pip install agentops[langchain]`), the import fails with:
```
ModuleNotFoundError: No module named 'langchain_core'
```

## Error Location
- File: `agentops/__init__.py`
- Line: 12
- Code: `from .langchain_callback_handler import LangchainCallbackHandler, AsyncLangchainCallbackHandler`

## Proposed Fix
Make the langchain imports conditional by using a try/except block. If langchain_core is not available, set the handlers to None or skip the import entirely.

The fix will:
1. Wrap the langchain import in a try/except block
2. Only expose the langchain handlers if langchain_core is installed
3. Allow the core package to work without the optional langchain dependency
