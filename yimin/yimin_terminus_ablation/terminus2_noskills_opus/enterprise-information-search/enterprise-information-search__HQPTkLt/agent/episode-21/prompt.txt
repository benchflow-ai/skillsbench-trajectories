# Enterprise Data Retrieval Skill

## Overview
This skill covers techniques for retrieving information from enterprise JSON data files containing Slack messages and product information.

## Data Structure
Enterprise data typically includes:
- **Product files**: JSON files containing Slack channel messages with user IDs, timestamps, and text
- **Metadata files**: Employee information, customer data, team structures

## Key Patterns

### 1. Loading JSON Data
```python
import json

with open('data.json', 'r') as f:
    data = json.load(f)
```

### 2. Searching Slack Messages
```python
def search_messages(data, keyword):
    results = []
    for item in data.get('slack', []):
        message = item.get('Message', {}).get('User', {})
        text = message.get('text', '')
        if keyword.lower() in text.lower():
            results.append({
                'userId': message.get('userId'),
                'text': text,
                'timestamp': message.get('timestamp')
            })
        # Also check thread replies
        for reply in item.get('ThreadReplies', []):
            reply_text = reply.get('text', '')
            if keyword.lower() in reply_text.lower():
                results.append({
                    'userId': reply.get('userId'),
                    'text': reply_text
                })
    return results
```

### 3. Extracting URLs from Text
```python
import re

def extract_urls(text):
    url_pattern = r'https?://[^\s>|]+'
    return re.findall(url_pattern, text)
```

### 4. Finding Employee IDs
```python
def extract_employee_ids(text):
    eid_pattern = r'eid_[a-f0-9]+'
    return re.findall(eid_pattern, text)
```

## Best Practices
- Always check both main messages and thread replies
- Use case-insensitive search for keywords
- Extract unique IDs to avoid duplicates
- Handle missing keys gracefully with .get()
