BUILD FAILURE ANALYSIS
======================

Repository: google/auto
Primary Error: Could not find artifact com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar

ROOT CAUSE:
-----------
The build is failing because multiple modules use the 'compile-testing' library as a test dependency,
which has a system-scoped dependency on com.sun:tools:jar with version ${java.version} and systemPath ${toolsjar}.

In Java 8 and earlier, tools.jar contained compiler APIs and was located at ${java.home}/../lib/tools.jar.
Starting with Java 9, tools.jar was removed and its contents were integrated into the JDK as modules.

The build is running with Java 11 (version 11.0.27), which doesn't have tools.jar, causing Maven to fail
when trying to resolve the dependency.

AFFECTED FILES:
---------------
- common/pom.xml: Uses compile-testing version 0.7 as a test dependency
- factory/pom.xml: Uses compile-testing version 0.8 as a test dependency  
- service/pom.xml: Uses compile-testing version 0.6 as a test dependency
- value/pom.xml: Uses compile-testing version 0.6 as a test dependency

All versions of compile-testing (0.6, 0.7, 0.8) have a hard dependency on tools.jar via system scope.

SOLUTION IMPLEMENTED:
--------------------
1. Added exclusions for the com.sun:tools dependency in all four modules
2. For common module: upgraded to compile-testing 0.12 (more compatible with Java 11)
3. For other modules: kept existing versions but excluded tools.jar
4. This allows the code to compile on Java 11 where compiler APIs are available as modules

FIXES APPLIED:
--------------
patch_1.diff - Updates common/pom.xml:
  - Upgrades compile-testing from 0.7 to 0.12
  - Adds exclusion for com.sun:tools dependency

patch_2.diff - Updates factory/pom.xml:
  - Adds exclusion for com.sun:tools dependency from compile-testing 0.8

patch_3.diff - Updates service/pom.xml:
  - Adds exclusion for com.sun:tools dependency from compile-testing 0.6

patch_4.diff - Updates value/pom.xml:
  - Adds exclusion for com.sun:tools dependency from compile-testing 0.6

RESULTS:
--------
The tools.jar dependency resolution error has been FIXED in all modules.

ADDITIONAL ISSUES DISCOVERED:
-----------------------------
1. Test compilation failures in common module due to Truth library API changes
   - Tests can be skipped with -Dmaven.test.skip=true
   - Or test code needs updating for newer Truth API

2. Main code compilation failure in factory module:
   - Error: cannot find symbol javax.annotation.Generated
   - This is a separate Java 9+ migration issue where Generated moved to javax.annotation.processing
   - Would need a separate fix to update imports or add appropriate dependencies

The primary tools.jar build error has been successfully resolved with the four patches.
