=== Summary of CVE-2025-32433 Fix ===

Vulnerability: Erlang/OTP SSH server allowed processing of SSH connection
protocol messages (channel open, exec requests, etc.) BEFORE authentication
was completed, allowing unauthenticated remote command execution.

Fix Location: /app/workspace/otp_src_27.3.2/lib/ssh/src/ssh_connection_handler.erl

Fix Description:
- Added authentication state check before processing connection protocol messages
- When connection messages arrive before authentication is complete:
  * The server now sends SSH_DISCONNECT_PROTOCOL_ERROR
  * The connection is terminated immediately
- Normal SSH behavior is maintained for authenticated connections

Affected Message Types (now protected):
  - ssh_msg_global_request
  - ssh_msg_request_success/failure
  - ssh_msg_channel_open/open_confirmation/open_failure
  - ssh_msg_channel_window_adjust
  - ssh_msg_channel_data/extended_data
  - ssh_msg_channel_eof/close
  - ssh_msg_channel_request (includes exec commands)
  - ssh_msg_channel_success/failure
