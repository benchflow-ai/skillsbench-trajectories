PATCH MECHANISM
================================================================================

The patch adds the following validation to each JavaScript class constructor:

    Preconditions.checkState(config != null && config.isEnabled(), 
                             "JavaScript is disabled");

This ensures:
  ✓ Early validation during Jackson deserialization
  ✓ Prevents instantiation of malicious JavaScript objects
  ✓ Blocks the empty key bypass attack
  ✓ Consistent protection across all JavaScript execution paths
  ✓ No performance impact (validation happens once at deserialization)

================================================================================
SECURITY IMPROVEMENTS
================================================================================

Before Patch (Vulnerable):
  1. Attacker sends malicious JavaScript filter to sampler endpoint
  2. Jackson deserializes the filter object (no validation)
  3. Empty key in JSON bypasses the enabled check
  4. Filter object is created successfully
  5. When filter is used, JavaScript code executes with full privileges
  6. Arbitrary code execution achieved

After Patch (Secure):
  1. Attacker sends malicious JavaScript filter to sampler endpoint
  2. Jackson attempts to deserialize the filter object
  3. Constructor validation checks if JavaScript is enabled
  4. If disabled, Preconditions.checkState throws IllegalStateException
  5. Deserialization fails, filter object is never created
  6. Request is rejected before any code execution
