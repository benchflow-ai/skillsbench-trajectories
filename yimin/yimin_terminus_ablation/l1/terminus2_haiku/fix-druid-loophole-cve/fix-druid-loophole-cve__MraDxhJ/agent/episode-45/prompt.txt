# Apache Druid 0.20.0 Security Patches

## Overview

This directory contains security patches for Apache Druid version 0.20.0 to address a critical Remote Code Execution (RCE) vulnerability in the sampler endpoint.

## Vulnerability

**CVE**: Apache Druid RCE via JavaScript Payload
**Affected Version**: 0.20.0
**Severity**: Critical
**CVSS Score**: 9.8 (Estimated)

### Details

Authenticated attackers can execute arbitrary code on the server through malicious JavaScript payloads sent to the `/druid/indexer/v1/sampler` endpoint. The vulnerability exploits an empty key in the filter configuration JSON that bypasses JavaScript security settings.

## Patches Included

### 001-javascript-security-comprehensive.patch

Comprehensive security patch that addresses the vulnerability in all JavaScript-related classes:

1. **JavaScriptDimFilter.java** - Filter-based JavaScript execution
2. **JavaScriptExtractionFn.java** - Extraction function-based JavaScript execution
3. **JavaScriptAggregatorFactory.java** - Aggregator-based JavaScript execution
4. **JavaScriptPostAggregator.java** - Post-aggregator-based JavaScript execution

## How the Patch Works

The patch adds validation in the `@JsonCreator` constructor of each JavaScript-related class to ensure that JavaScript is enabled **during deserialization**, not just at execution time.

**Before (Vulnerable)**:
```java
@JsonCreator
public JavaScriptDimFilter(
    @JsonProperty("dimension") String dimension,
    @JsonProperty("function") String function,
    @JsonProperty("extractionFn") @Nullable ExtractionFn extractionFn,
    @JsonProperty("filterTuning") @Nullable FilterTuning filterTuning,
    @JacksonInject JavaScriptConfig config
)
{
    Preconditions.checkArgument(dimension != null, "dimension must not be null");
    Preconditions.checkArgument(function != null, "function must not be null");
    // Validation happens only at usage time in getPredicateFactory()
    this.dimension = dimension;
    this.function = function;
    // ...
}
```

**After (Secure)**:
```java
@JsonCreator
public JavaScriptDimFilter(
    @JsonProperty("dimension") String dimension,
    @JsonProperty("function") String function,
    @JsonProperty("extractionFn") @Nullable ExtractionFn extractionFn,
    @JsonProperty("filterTuning") @Nullable FilterTuning filterTuning,
    @JacksonInject JavaScriptConfig config
)
{
    Preconditions.checkArgument(dimension != null, "dimension must not be null");
    Preconditions.checkArgument(function != null, "function must not be null");
    // NEW: Validation happens during deserialization
    Preconditions.checkState(config != null && config.isEnabled(), "JavaScript is disabled");
    this.dimension = dimension;
    this.function = function;
    // ...
}
```

## Deployment Instructions

1. Apply the patch to the Druid source code:
   ```bash
   cd /root/druid
   git apply /root/patches/001-javascript-security-comprehensive.patch
   ```

2. Build with Maven (skipping tests and code quality checks):
   ```bash
   mvn clean package -DskipTests -Dcheckstyle.skip=true -Dpmd.skip=true \
     -Dforbiddenapis.skip=true -Dspotbugs.skip=true -Danimal.sniffer.skip=true \
     -Denforcer.skip=true -Djacoco.skip=true -Ddependency-check.skip=true \
     -pl '!web-console' -pl indexing-service -am
   ```

3. Deploy the patched JARs to `/opt/druid/lib/`

4. Restart the Druid server
