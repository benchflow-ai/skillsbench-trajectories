### 3. **LongestSessionPerJob.java** (Complete Implementation)
A Flink streaming job that:

**Key Components:**
- **TaskEventSource**: Reads gzipped task event CSV files
- **JobEventSource**: Reads gzipped job event CSV files
- **StageTracker**: KeyedProcessFunction that identifies stages and finds the longest
- **StageState**: Maintains per-job state including:
  - `lastSubmitTime`: Timestamp of last SUBMIT event
  - `currentStageSize`: Number of tasks in current stage
  - `longestStageSize`: Maximum stage size found so far

**Algorithm:**
1. Filters task events for SUBMIT events (eventType == 0)
2. Filters job events for FINISH events (eventType == 4)
3. For each SUBMIT event:
   - If gap since last SUBMIT > 10 minutes (600,000,000 microseconds): End current stage, start new one
   - Otherwise: Continue current stage, increment task count
4. When job finishes (FINISH event): Output (jobId, longestStageSize)
5. Output format: `(jobId,taskCount)` written to file

**Features:**
- Handles gzipped CSV file parsing
- Processes timestamps in microseconds
- Uses Flink's keyed state for efficient per-job tracking
- Correctly counts resubmitted tasks as separate submissions
- Outputs results in the required tuple format

The implementation is ready for compilation and deployment on Apache Flink.
