- A stage ends when there's a 10-minute gap with no SUBMIT events

**Processing:**

2. Read and filter job events for FINISH events (eventType=4)
3. Merge streams and re-key by jobId
4. Use StageTracker to identify stages and track longest
5. Output (jobId, longestStageSize) when job finishes
