### Algorithm:

**Stage Definition:**
- A stage is a period of SUBMIT events (eventType=0) that occur close together in event time
- A stage ends when there's a 10-minute (600,000,000 microsecond) gap with no SUBMIT events

**Processing:**
1. Filter task events for SUBMIT events (eventType=0)
2. Filter job events for FINISH events (eventType=4)
3. For each SUBMIT event:
   - If gap since last SUBMIT > 10 minutes: End current stage, start new one
   - Otherwise: Continue current stage, increment task count
4. When job finishes: Output (jobId, longestStageSize)

**Output Format:**
- `(jobId,taskCount)` - One line per job
- Example: `(6251812952,45)`
