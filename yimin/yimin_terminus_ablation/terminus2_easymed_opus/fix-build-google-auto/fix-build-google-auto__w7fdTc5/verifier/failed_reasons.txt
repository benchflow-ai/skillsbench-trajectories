# Build Failure Analysis for google/auto

## Root Causes

### Issue 1: tools.jar dependency (Java 9+ incompatibility)
The build fails because the project depends on `com.google.testing.compile:compile-testing` 
library versions 0.6 and 0.7, which have a system-scoped dependency on `com.sun:tools:jar` 
(tools.jar). This file existed in Java 8 and earlier at `${java.home}/../lib/tools.jar`, 
but was removed in Java 9+ when the compiler API was moved into JDK modules.

### Issue 2: javax.annotation.Generated (Java 9+ incompatibility)
The value module uses `javax.annotation.Generated` annotation which was part of the JDK
in Java 8 but was removed in Java 9+ (moved to javax.annotation.processing.Generated).
This requires adding an explicit dependency on javax.annotation-api.

## Error Messages
- common module: "Could not find artifact com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar"
- value module: Same tools.jar error, plus "cannot find symbol: class Generated in package javax.annotation"

## Affected Files and Fixes

### Fix 1: common/pom.xml (patch_1.diff)
- Changed compile-testing version from 0.7 to 0.15
- Version 0.15 removes the tools.jar dependency and supports Java 9+

### Fix 2: value/pom.xml (patch_2.diff)
- Changed compile-testing version from 0.6 to 0.15
- Version 0.15 removes the tools.jar dependency and supports Java 9+

### Fix 3: value/pom.xml (patch_3.diff)
- Added javax.annotation-api dependency version 1.3.2
- Provides javax.annotation.Generated class for Java 9+ compatibility

## Verification
After applying all patches, both common and value modules compile successfully.
