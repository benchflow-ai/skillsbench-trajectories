### Problem 1: Unconditional import of optional dependency

**File:** `agentops/__init__.py` (line 12)

**Error:**
```
ModuleNotFoundError: No module named 'langchain_core'
```

**Root Cause:**
The `agentops/__init__.py` file unconditionally imports `LangchainCallbackHandler` and `AsyncLangchainCallbackHandler` from `langchain_callback_handler.py`. However, `langchain` is listed as an *optional* dependency in `pyproject.toml` under `[project.optional-dependencies]`.

**Fix (patch_1.diff):**
Make the langchain import conditional using a try/except block:
```python
try:
    from .langchain_callback_handler import LangchainCallbackHandler, AsyncLangchainCallbackHandler
except ImportError:
    LangchainCallbackHandler = None
    AsyncLangchainCallbackHandler = None
```

### Problem 3: Singleton pattern prevents re-initialization

**File:** `agentops/helpers.py` (lines 15-22)

**Error:**
Tests fail because the singleton pattern caches the Client instance and returns it for all subsequent calls, ignoring new parameters. This causes issues when tests run sequentially.

**Fix (patch_3.diff + patch_1.diff):**
1. Add a `clear()` method to the singleton pattern in helpers.py
2. Call `Client.clear()` in the `init()` function before creating a new Client

```python
# In helpers.py
def singleton(class_):
    instances = {}

    def clear():
        instances.clear()

    def getinstance(*args, **kwargs):
        if class_ not in instances:
            instances[class_] = class_(*args, **kwargs)
        return instances[class_]

    getinstance.clear = clear

    return getinstance
```

```python
# In __init__.py init() function
Client.clear()
c = Client(api_key=api_key, ...)
```
