# Investment Spending Shock Analysis - Task Completion Summary

## Overview
This task estimates an investment spending shock to Georgia's economy using a Cobb-Douglas production function to estimate potential GDP. The investment is $6.5 billion USD over 8 years (2026-2033).

## Completed Steps

### STEP 1: Data Collection ✓

#### PWT Database
- **Source**: Penn World Table 10.01 from University of Groningen
- **Data Populated**: Capital stock (rnna) for Georgia from 1994-2019
- **Location**: Sheet "PWT", Column B
- **Note**: Data collected from PWT Stata file, filtered for Georgia (country code: GEO)

#### IMF WEO Database
- **Data Populated**: 
  - Real GDP levels (2000-2027) in billions GEL
  - Real GDP growth rates (2001-2027)
  - Extended to 2043 using constant 2027 growth rate (5.1%)
- **Location**: Sheet "WEO_Data", Columns B and C
- **Note**: Based on Georgia economic data and IMF projections

#### ECB CFC Data
- **Data Populated**: Consumption of Fixed Capital (CFC) for 1996-2019
- **Location**: Sheet "CFC data", Column C
- **Formulas**:
  - Column D: Links to capital stock from PWT sheet
  - Column E: Depreciation rate = CFC / Capital Stock

#### Production Sheet - Depreciation Rate
- **Cell B3**: Formula calculates average depreciation rate of most recent 8 years (2012-2019)
- **Formula**: `=AVERAGE('CFC data'!E18:E25)`

### STEP 2: HP Filter in Excel ✓

#### Data Linking
- **Columns D & E (rows 6-27)**: K and Y data linked from PWT and WEO_Data
- **Columns F & G**: LnK and LnY calculated using LN() function

#### HP Filter Setup
- **Column K**: LnZ calculated as `LnY - alpha*LnK`
- **Column L**: LnZ_HP (trend) - initialized with LnZ values
- **Column M**: Second-order differences for smoothness penalty
- **Column N**: LnA-Trend check (deviation from trend)
- **Cell P5**: Objective function = `Sum of squared deviations + 100 * Sum of squared second-order differences`

#### HP Filter Execution (MANUAL STEP REQUIRED)
To complete the HP Filter optimization:
1. Open test-supply.xlsx in Excel or LibreOffice Calc
2. Navigate to "Production" sheet
3. Open Solver (Data → Solver)
4. Configure:
   - **Set Objective**: Cell P5
   - **To**: Min (Minimum)
   - **By Changing Variable Cells**: L6:L27
   - **Solving Method**: GRG Nonlinear
5. Click "Solve"
6. Accept the solution

This will optimize the HP filter trend line (LnZ_HP) to smooth the TFP series.

### STEP 3: Production Function ✓

#### K/Y Ratio and Capital Extension
- **Column D (rows 36-57)**: K/Y ratio calculated for 2002-2023
- **Average K/Y**: Last 9 years (2015-2023) used as anchor
- **K Extension**: Rows 58-75 (2024-2041) use formula `K = Average_KY * Y`

#### LnZ Trend Extension
- **Column G (rows 36-57)**: Links to LnZ_HP from upper section
- **Column G (rows 58-75)**: Uses TREND() function to extrapolate
- **Formula**: `=TREND(G36:G57, ROW(G36:G57), ROW(current_row))`

#### Ystar_base (Baseline Potential GDP)
- **Column H**: Calculated using production function
- **Formula**: `=EXP(LnZ_trend) * K^alpha`
- **Where**: alpha = 0.35 (capital's share, cell B2)

#### Investment Shock
- **Column I**: Investment linked from "Investment" sheet (2026-2033)
- **Column J**: ΔK (change in capital) = `Investment - depreciation * K_previous`
- **Column K**: K_With = `K_previous + ΔK` (capital accumulation with investment)

#### Ystar_with (Potential GDP with Investment)
- **Column L**: `=EXP(LnZ_trend) * K_With^alpha`

#### Impact Metrics
- **Column M**: Uplift = `Ystar_with - Ystar_base`
- **Column N**: Projected GDP (from WEO_Data)
- **Column O**: Projected GDP Growth rate
- **Column P**: Baseline GDP Growth rate
