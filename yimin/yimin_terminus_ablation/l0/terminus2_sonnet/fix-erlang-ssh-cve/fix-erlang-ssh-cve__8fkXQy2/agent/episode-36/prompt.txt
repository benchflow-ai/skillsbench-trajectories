# Erlang/OTP SSH Authentication Bypass - Quick Summary

## Vulnerability Type
**SSH Connection Protocol Message Authentication Bypass**

Attackers can send connection protocol messages (SSH_MSG_GLOBAL_REQUEST, SSH_MSG_CHANNEL_OPEN, etc.) BEFORE authentication to execute arbitrary commands.

## Root Cause
Missing authentication state checks in message dispatch logic.

## Vulnerable File
`/app/workspace/otp_src_27.3.2/lib/ssh/src/ssh_connection_handler.erl`
- **Lines 1161-1177**: Connection protocol message handlers without authentication guards

## Attack Vector
1. Connect to SSH server
2. Complete key exchange (no auth needed)
3. Send `SSH_MSG_GLOBAL_REQUEST` or `SSH_MSG_CHANNEL_REQUEST` with command
4. Server executes command without authentication ❌

## The Fix
Added `when ?CONNECTED(StateName)` guards to all 14 connection protocol message handlers:
- `ssh_msg_global_request`
- `ssh_msg_channel_open`
- `ssh_msg_channel_request`
- And 11 other channel/request message types

Plus added explicit rejection clause that disconnects with protocol error when these messages arrive before authentication.
