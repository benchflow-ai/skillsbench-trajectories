Target: filter_ns
File: /app/ipython/IPython/utils/wildcard.py
Import: from IPython.utils.wildcard import filter_ns
Why: Converts user-provided wildcard patterns into regex by replacing * with .* and ? with a dot, then compiles and matches against namespace keys. No escaping of other regex metacharacters, so patterns containing characters like +, {, }, |, (, ) are passed directly to re.compile. This creates potential for ReDoS (regex denial of service) or unexpected regex behavior with adversarial patterns.
Input type: str (name_pattern parameter)
Example usage:
    ns = {"foo": 1, "bar": 2, "baz": 3}
    result = filter_ns(ns, "b*")
    # Returns: {"bar": 2, "baz": 3}
