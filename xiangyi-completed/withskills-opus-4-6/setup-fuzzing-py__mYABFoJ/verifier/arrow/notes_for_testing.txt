Library: Arrow (Better dates & times for Python)
Location: /app/arrow/arrow/
Version: dynamic (see /app/arrow/arrow/_version.py)
Dependencies: python-dateutil>=2.7.0, tzdata (or backports.zoneinfo)

This document identifies functions in the Arrow library that are good candidates
for fuzz testing. The focus is on functions that accept user-controlled input
(strings, numbers, tuples, dicts) and perform parsing, validation, conversion,
or normalization operations.

--------------------------------------------------------------------------------
1.1  arrow.parser.DateTimeParser.parse_iso(datetime_string, normalize_whitespace)
--------------------------------------------------------------------------------
File: /app/arrow/arrow/parser.py (line 252)
Class: DateTimeParser
Method: parse_iso

WHY THIS IS A GOOD FUZZ TARGET:
  - Primary ISO 8601 parsing entry point for the entire library.
  - Accepts arbitrary user strings and attempts to match them against 16+
    date format patterns using regex.
  - Contains complex branching logic: space vs T divider detection, time
    component extraction, timezone suffix detection, basic vs extended format.
  - Calls _parse_multiformat() which iterates over many format strings and
    calls parse() for each one. This creates a large attack surface.
  - Uses re.split() and regex matching on untrusted input.
  - Could trigger ReDoS (Regular Expression Denial of Service) with crafted
    inputs due to multiple regex patterns applied sequentially.

INPUT TYPE: str (datetime_string), bool (normalize_whitespace)

ACCEPTABLE EXCEPTIONS:
  - arrow.parser.ParserError -- expected for unparseable strings
  - arrow.parser.ParserMatchError -- expected for format mismatches

SUSPICIOUS EXCEPTIONS (indicate bugs):
  - TypeError, AttributeError -- indicate missing None checks
  - ValueError from datetime constructor -- indicates insufficient validation
    of parsed numeric values (e.g., month=13, day=32)
  - OverflowError -- indicates unbounded numeric values
  - re.error -- indicates regex construction issues
  - RecursionError -- indicates infinite recursion
  - Any uncaught exception not in the ParserError hierarchy

HOW TO CALL:
  from arrow.parser import DateTimeParser
  parser = DateTimeParser()
  result = parser.parse_iso(fuzz_string)
  result = parser.parse_iso(fuzz_string, normalize_whitespace=True)

MINIMAL SETUP: None beyond import. DateTimeParser() uses default "en-us" locale.

1.2  arrow.parser.DateTimeParser.parse(datetime_string, fmt, normalize_whitespace)
--------------------------------------------------------------------------------
File: /app/arrow/arrow/parser.py (line 373)
Class: DateTimeParser
Method: parse

WHY THIS IS A GOOD FUZZ TARGET:
  - General-purpose parsing with user-supplied format strings.
  - Both the datetime_string AND the fmt can be user-controlled.
  - Internally calls _generate_pattern_re(fmt) which builds a regex from
    the format string -- crafted format strings could produce pathological
    regex patterns.
  - The fmt parameter can also be a list of format strings, multiplying
    the attack surface.
  - After regex matching, _parse_token() converts matched groups into
    integer values -- edge cases in numeric conversion are possible.
  - _build_datetime() assembles the final datetime from parsed parts,
    with complex logic for weekdates, day_of_year, am/pm, midnight handling,
    and microsecond rounding.

INPUT TYPE: str (datetime_string), str or List[str] (fmt), bool (normalize_whitespace)

ACCEPTABLE EXCEPTIONS:
  - arrow.parser.ParserError
  - arrow.parser.ParserMatchError
  - re.error (caught and re-raised as ParserMatchError)

SUSPICIOUS EXCEPTIONS:
  - ValueError from datetime() constructor (insufficient validation)
  - OverflowError (unbounded int conversion)
  - IndexError (missing list elements)
  - TypeError
  - KeyError from _input_re_map lookup (partially handled but could leak)

HOW TO CALL:
  from arrow.parser import DateTimeParser
  parser = DateTimeParser()
  result = parser.parse(fuzz_date_string, fuzz_format_string)
  result = parser.parse(fuzz_date_string, [fuzz_fmt1, fuzz_fmt2])

1.3  arrow.parser.TzinfoParser.parse(tzinfo_string)
--------------------------------------------------------------------------------
File: /app/arrow/arrow/parser.py (line 894)
Class: TzinfoParser
Method: parse (classmethod)

WHY THIS IS A GOOD FUZZ TARGET:
  - Parses timezone strings from user input.
  - Handles multiple formats: "local", "utc"/"UTC"/"Z", ISO offset like
    "+05:30" or "-0800", and named timezones like "US/Pacific".
  - Uses regex matching (_TZINFO_RE) on the input string.
  - Falls through to ZoneInfo(tzinfo_string) for named timezones, which
    could have edge cases with unusual timezone database entries.
  - Could be called with any string the user provides.

INPUT TYPE: str

ACCEPTABLE EXCEPTIONS:
  - arrow.parser.ParserError

SUSPICIOUS EXCEPTIONS:
  - OverflowError (from timedelta with huge seconds values)
  - ValueError (from timedelta or timezone construction)
  - KeyError (from ZoneInfo lookup)
  - Any exception not caught by the try/except around ZoneInfo

HOW TO CALL:
  from arrow.parser import TzinfoParser
  result = TzinfoParser.parse(fuzz_string)

1.4  arrow.factory.ArrowFactory.get(*args, **kwargs)
--------------------------------------------------------------------------------
File: /app/arrow/arrow/factory.py (line 85)
Class: ArrowFactory
Method: get

WHY THIS IS A GOOD FUZZ TARGET:
  - THE primary public API entry point for the entire library.
  - Accepts an enormous variety of input types: None, Arrow, datetime, date,
    struct_time, tzinfo, int, float, Decimal, str, Tuple[int,int,int].
  - When given a string, delegates to DateTimeParser.parse_iso().
  - When given two strings, delegates to DateTimeParser.parse().
  - When given a number, calls is_timestamp() and Arrow.fromtimestamp().
  - When given a tuple, calls iso_to_gregorian().
  - The kwargs can include locale (str), tzinfo, normalize_whitespace.
  - Complex dispatching logic based on argument count and types creates
    many code paths to explore.
  - Most user-facing code calls arrow.get() which delegates here.

INPUT TYPES: highly polymorphic -- str, int, float, tuple, and combinations

ACCEPTABLE EXCEPTIONS:
  - TypeError (for unsupported argument types -- by design)
  - arrow.parser.ParserError (for unparseable strings)
  - ValueError (for invalid timestamps)
  - OverflowError (for extremely large timestamps)

SUSPICIOUS EXCEPTIONS:
  - AttributeError (indicates None-safety issues)
  - IndexError
  - Any uncaught exception that propagates from lower layers

HOW TO CALL:
  import arrow
  # Single string:
  arrow.get(fuzz_string)
  # String + format:
  arrow.get(fuzz_string, fuzz_format)
  # Numeric timestamp:
  arrow.get(fuzz_number)
  # ISO calendar tuple:
  arrow.get((fuzz_year, fuzz_week, fuzz_day))
  # With kwargs:
  arrow.get(fuzz_string, locale=fuzz_locale, normalize_whitespace=True)

MINIMAL SETUP: Just `import arrow`.

2.3  arrow.arrow.Arrow.dehumanize(input_string, locale)
--------------------------------------------------------------------------------
File: /app/arrow/arrow/arrow.py (line 1344)
Class: Arrow
Method: dehumanize

WHY THIS IS A GOOD FUZZ TARGET:
  - Parses natural language relative time strings like "2 days ago" or
    "in 5 seconds".
  - Builds regex patterns dynamically from locale-specific format strings
    using str.format(r"\d+") -- this is a regex injection vector if locale
    data contains special characters.
  - Iterates over all timeframe units in a locale, building and searching
    regex patterns against the input string.
  - Sign detection uses separate regex patterns for past/future.
  - Complex interaction between locale data and user input.
  - The locale parameter itself can be fuzzed.

INPUT TYPE: str (input_string), str (locale)
ACCEPTABLE: ValueError (no match, unsupported locale)
SUSPICIOUS: re.error (from malformed patterns), TypeError, KeyError,
            IndexError, infinite loops from pathological regex

HOW TO CALL:
  import arrow
  arw = arrow.utcnow()
  arw.dehumanize(fuzz_string)
  arw.dehumanize(fuzz_string, locale="en_us")

MINIMAL SETUP: Need an Arrow object first. `arrow.utcnow()` is sufficient.

2.4  arrow.formatter.DateTimeFormatter.format(dt, fmt)
--------------------------------------------------------------------------------
File: /app/arrow/arrow/formatter.py (line 37)
Class: DateTimeFormatter
Method: format

WHY: The fmt parameter is a user-controlled format string. The method uses
regex substitution (_FORMAT_RE.sub) with a lambda that calls _format_token().
While the datetime object is typically well-formed, crafted format strings
could trigger edge cases in token processing. The format string supports
bracket-escaped literal sequences like [text], which are parsed and reinserted.

INPUT TYPE: datetime (dt), str (fmt)
ACCEPTABLE: None expected for well-formed datetime input
SUSPICIOUS: AttributeError, TypeError, IndexError from format token processing

HOW TO CALL:

  from datetime import datetime, timezone
  fmt = DateTimeFormatter()
  fmt.format(datetime.now(timezone.utc), fuzz_format_string)

================================================================================
4. RECOMMENDED FUZZING STRATEGIES
================================================================================

STRATEGY A: String parsing focus (highest value)
  - Fuzz parse_iso() with arbitrary strings, including:
    * Valid ISO 8601 strings with mutations
    * Strings with unusual Unicode characters
    * Very long strings (potential ReDoS)
    * Strings with embedded null bytes
    * Strings with multiple T separators or spaces
    * Strings with timezone offset edge cases (+99:99, -00:00)

STRATEGY B: Format string fuzzing
  - Fuzz parse(string, fmt) with both parameters:
    * Random format tokens (YYYY, MM, DD, etc.) in unusual combinations
    * Repeated tokens (YYYYYYYY)
    * Bracket-escaped sections with special regex chars
    * Format strings that produce ambiguous regex patterns

STRATEGY C: Numeric input fuzzing
  - Fuzz fromtimestamp() and normalize_timestamp() with:
    * Boundary values around MAX_TIMESTAMP, MAX_TIMESTAMP_MS, MAX_TIMESTAMP_US
    * Negative timestamps near datetime.min
    * NaN, Inf, -Inf
    * Very large integers
    * String representations of numbers

STRATEGY D: Timezone string fuzzing
  - Fuzz TzinfoParser.parse() with:
    * Valid timezone names with mutations
    * Offset strings with extreme values
    * Unicode timezone names
    * Empty strings

STRATEGY E: Dehumanize fuzzing
  - Fuzz dehumanize() with:
    * Combinations of time unit words
    * Numbers with many digits
    * Mixed languages
    * Strings designed to trigger regex catastrophic backtracking

5. COMBINED FUZZ DRIVER SKETCH

import arrow
from arrow.parser import DateTimeParser, TzinfoParser, ParserError
from arrow.util import normalize_timestamp, iso_to_gregorian, is_timestamp

def fuzz_parse_iso(data: bytes):
    try:
        s = data.decode("utf-8", errors="replace")
        parser = DateTimeParser()
        parser.parse_iso(s)
    except (ParserError, ValueError, TypeError, OverflowError):
        pass  # expected

def fuzz_parse_with_format(data: bytes):
    try:
        s = data.decode("utf-8", errors="replace")
        mid = len(s) // 2
        date_str, fmt_str = s[:mid], s[mid:]
        parser = DateTimeParser()
        parser.parse(date_str, fmt_str)
    except (ParserError, ValueError, TypeError, OverflowError, re.error):
        pass  # expected

def fuzz_tz_parse(data: bytes):
    try:
        s = data.decode("utf-8", errors="replace")
        TzinfoParser.parse(s)
    except (ParserError, ValueError, TypeError):
        pass  # expected

def fuzz_arrow_get(data: bytes):
    try:
        s = data.decode("utf-8", errors="replace")
        arrow.get(s)
    except (ParserError, ValueError, TypeError, OverflowError):
        pass  # expected

def fuzz_dehumanize(data: bytes):
    try:
        s = data.decode("utf-8", errors="replace")
        arw = arrow.Arrow(2021, 1, 1)
        arw.dehumanize(s)
    except (ValueError, TypeError, OverflowError):
        pass  # expected

def fuzz_normalize_timestamp(data: bytes):
    try:
        if len(data) < 8:
            return
        import struct
        val = struct.unpack("d", data[:8])[0]
        normalize_timestamp(val)
    except (ValueError, OverflowError, struct.error):
        pass  # expected
