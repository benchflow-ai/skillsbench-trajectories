ERROR 1: com.sun:tools:jar system dependency resolution failure
--------------------------------------------------------------
Type: Build configuration / dependency resolution
Affected Modules: common, service, factory, value (all 4 modules)

Root Cause:
  The compile-testing library (versions 0.6, 0.7, 0.8) used as a test dependency
  in all modules declares a system-scoped transitive dependency on com.sun:tools:jar
  with systemPath=${toolsjar} pointing to ${java.home}/../lib/tools.jar.

  On Java 11, tools.jar does not exist. It was removed in Java 9 when the JDK was
  modularized. The compiler API classes that were in tools.jar were moved to the
  java.compiler module.

  Maven fails to resolve this system-scoped dependency because the file
  /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar does not exist.

Error Message:
  Could not resolve dependencies for project com.google.auto:auto-common:jar:1.0-SNAPSHOT:
  Could not find artifact com.sun:tools:jar:11.0.27 at specified path
  /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar

Fix:
  Add <exclusion> for com.sun:tools in the compile-testing dependency declaration
  in each module POM (common/pom.xml, service/pom.xml, factory/pom.xml, value/pom.xml).
  On Java 11, the javax.tools and javax.lang.model APIs are available from the
  java.compiler module without needing tools.jar.

Files to modify:
  - common/pom.xml  (compile-testing 0.7)
  - service/pom.xml (compile-testing 0.6)
  - factory/pom.xml (compile-testing 0.8)
  - value/pom.xml   (compile-testing 0.6)


ERROR 2: javax.annotation.Generated class not found
----------------------------------------------------
Type: Source code incompatibility with Java 11
Affected Modules: factory, value

Root Cause:
  The javax.annotation.Generated annotation was part of the java.xml.ws.annotation
  module in Java 9, which was deprecated in Java 9 and removed entirely in Java 11.
  In Java 9+, a replacement annotation was added at javax.annotation.processing.Generated
  (part of the java.compiler module).

  Three source files import javax.annotation.Generated which does not exist in Java 11.

    symbol: class Generated, location: package javax.annotation
  value/src/main/java/.../AutoValueProcessor.java:[51,24] cannot find symbol
    symbol: class Generated, location: package javax.annotation

  in all three affected files. Also update the string literal in FactoryWriter.java line 60
  that emits the import into generated source code.
