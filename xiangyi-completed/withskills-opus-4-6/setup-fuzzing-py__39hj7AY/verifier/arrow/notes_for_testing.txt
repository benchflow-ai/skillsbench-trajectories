FUZZ TARGET 1: DateTimeParser.parse_iso()
================================================================================

Module: arrow.parser
Class: DateTimeParser
Method: parse_iso(datetime_string: str, normalize_whitespace: bool = False) -> datetime
File: /app/arrow/arrow/parser.py
Line: 252

Description:
  Parses a datetime string in ISO 8601-like format. This is the core parsing
  function called when a user passes a single string to arrow.get().

Input:
  - datetime_string: arbitrary str (primary fuzz input)
  - normalize_whitespace: bool (toggle between True/False)

Expected Exceptions (non-bugs):
  - arrow.parser.ParserError
  - arrow.parser.ParserMatchError

Setup:
  from arrow.parser import DateTimeParser, ParserError, ParserMatchError
  parser = DateTimeParser()

Fuzz Driver Sketch:
  def fuzz_parse_iso(data: bytes):
      try:
          s = data.decode("utf-8", errors="replace")
          parser = DateTimeParser()
          parser.parse_iso(s)
      except (ParserError, ParserMatchError, ValueError, OverflowError):
          pass

Edge Cases to Target:
  - Strings with multiple spaces, tabs, newlines
  - Strings with T divider but invalid time components
  - Very long digit sequences
  - Mixed separators (-, /, .)
  - Timezone offsets with extreme values (+99:99)
  - Week date formats (W notation)
  - Ordinal date formats (YYYY-DDD)
  - Subsecond values with many decimal places
  - Hour value 24 (midnight end of day)
  - Negative timestamps
  - Empty string, single character strings
  - Strings with null bytes or control characters

================================================================================
FUZZ TARGET 2: DateTimeParser.parse()
================================================================================

Module: arrow.parser
Class: DateTimeParser
Method: parse(datetime_string: str, fmt: Union[List[str], str], normalize_whitespace: bool = False) -> datetime
File: /app/arrow/arrow/parser.py
Line: 373

Description:
  Parses a datetime string using a user-specified format string (or list of
  format strings). The format string is converted to a regex pattern using
  token substitution. Both inputs are user-controlled, which creates a large
  attack surface for regex-related issues and unexpected parsing behavior.

Input:
  - datetime_string: arbitrary str (fuzz input 1)
  - fmt: arbitrary str or list of str (fuzz input 2)
  - normalize_whitespace: bool

Expected Exceptions (non-bugs):
  - arrow.parser.ParserError
  - arrow.parser.ParserMatchError
  - re.error (caught internally, re-raised as ParserMatchError)

Setup:
  from arrow.parser import DateTimeParser, ParserError, ParserMatchError
  parser = DateTimeParser()

Fuzz Driver Sketch:
  def fuzz_parse(data: bytes):
      try:
          s = data.decode("utf-8", errors="replace")
          # Split fuzz data into datetime string and format string
          if len(s) < 2:
              return
          split_point = len(s) // 2
          datetime_string = s[:split_point]
          fmt = s[split_point:]
          parser = DateTimeParser()
          parser.parse(datetime_string, fmt)
      except (ParserError, ParserMatchError, ValueError, OverflowError, re.error):
          pass

Edge Cases to Target:
  - Format strings with regex special characters: []{}()*+?.\\^$|
  - Format strings with escape brackets: [text]
  - Format strings with repeated tokens: SSSSSSSSSSS
  - Format strings with all token types combined
  - Mismatched token and data combinations
  - Very long format strings
  - Empty format strings
  - Format string list with many entries
  - Format strings generating catastrophic backtracking regex
  - Known regression inputs from issues #854 and #860

Input:
  - tzinfo_string: arbitrary str (primary fuzz input)

Expected Exceptions (non-bugs):
  - arrow.parser.ParserError

Setup:
  from arrow.parser import TzinfoParser, ParserError
  parser = TzinfoParser

Fuzz Driver Sketch:
  def fuzz_tzinfo_parse(data: bytes):
      try:
          s = data.decode("utf-8", errors="replace")
          TzinfoParser.parse(s)
      except (ParserError, ValueError, OverflowError):
          pass

Edge Cases to Target:
  - Offset strings with extreme hour/minute values
  - Strings starting with "(UTC" but malformed
  - Very long timezone name strings
  - Timezone names with special characters
  - Strings like "Z", "z", "utc", "UTC", "local"
  - Partial ISO offset strings: "+", "-", "+0", "-1"
  - Strings that look like timezone names but are not valid
  - Empty string
  - Strings with unicode characters

FUZZ TARGET 4: Arrow.dehumanize()
================================================================================

Module: arrow.arrow
Class: Arrow
Method: dehumanize(input_string: str, locale: str = "en_us") -> Arrow
File: /app/arrow/arrow/arrow.py
Line: 1344

Description:
  Parses humanized relative time strings (e.g., "2 days ago", "in a month")
  back into Arrow objects. Uses locale-specific patterns to match time units
  and determines direction (past/future). Constructs regex patterns dynamically
  from locale data and searches the input string for matches.

Input:
  - input_string: arbitrary str (primary fuzz input)
  - locale: str (can test with different locale values from DEHUMANIZE_LOCALES)

Expected Exceptions (non-bugs):
  - ValueError (invalid input, unsupported locale)

Setup:
  import arrow
  arw = arrow.Arrow(2023, 1, 15, 12, 0, 0)

Fuzz Driver Sketch:
  def fuzz_dehumanize(data: bytes):
      try:
          s = data.decode("utf-8", errors="replace")
          arw = arrow.Arrow(2023, 1, 15, 12, 0, 0)
          arw.dehumanize(s, locale="en_us")
      except (ValueError, OverflowError, KeyError):
          pass

Extended Fuzz Driver (with locale variation):
  LOCALES = ["en_us", "fr", "de", "ja", "zh", "es", "ru", "pl"]
  def fuzz_dehumanize_locales(data: bytes):
      try:
          s = data.decode("utf-8", errors="replace")
          if len(s) < 2:
              return
          locale_idx = data[0] % len(LOCALES)
          input_str = s[1:]
          arw = arrow.Arrow(2023, 1, 15, 12, 0, 0)
          arw.dehumanize(input_str, locale=LOCALES[locale_idx])
      except (ValueError, OverflowError, KeyError):
          pass

Edge Cases to Target:
  - Strings with numeric values but no time unit words
  - Strings with extremely large numbers ("999999999 seconds ago")
  - Strings matching both past and future patterns
  - Strings with overlapping locale patterns
  - Empty strings
  - Strings with only whitespace
  - Strings containing regex special characters
  - Strings with mixed locale words

FUZZ TARGET 5: ArrowFactory.get() with string input
================================================================================

Module: arrow.factory
Class: ArrowFactory
Method: get(*args, **kwargs) -> Arrow
File: /app/arrow/arrow/factory.py
Line: 85

Description:
  The main public API entry point (arrow.get()). Accepts many input types.
  When called with a single string argument, it dispatches to parse_iso().
  When called with two string arguments, it dispatches to parse(). This
  function integrates parsing, timezone handling, and locale processing.

Input:
  - args[0]: arbitrary str (primary fuzz input - datetime string)
  - args[1]: optional str (format string, for two-arg form)
  - locale: str keyword argument
  - tzinfo: optional timezone expression
  - normalize_whitespace: bool

Expected Exceptions (non-bugs):
  - arrow.parser.ParserError
  - arrow.parser.ParserMatchError
  - TypeError
  - ValueError
  - OverflowError

Setup:
  import arrow

Fuzz Driver Sketch (single string):
  def fuzz_arrow_get_single(data: bytes):
      try:
          s = data.decode("utf-8", errors="replace")
          arrow.get(s)
      except (arrow.ParserError, TypeError, ValueError, OverflowError):
          pass

Fuzz Driver Sketch (string + format):
  def fuzz_arrow_get_with_format(data: bytes):
      try:
          s = data.decode("utf-8", errors="replace")
          if len(s) < 2:
              return
          split_point = len(s) // 2
          datetime_string = s[:split_point]
          fmt = s[split_point:]
          arrow.get(datetime_string, fmt)
      except (arrow.ParserError, TypeError, ValueError, OverflowError):
          pass

Fuzz Driver Sketch (with normalize_whitespace):
  def fuzz_arrow_get_normalize(data: bytes):
      try:
          s = data.decode("utf-8", errors="replace")
          arrow.get(s, normalize_whitespace=True)
      except (arrow.ParserError, TypeError, ValueError, OverflowError):
          pass

Edge Cases to Target:
  - All edge cases from Targets 1-3 (since this dispatches to those parsers)
  - Numeric strings that could be interpreted as timestamps
  - Strings that look like ISO dates but have extra content
  - Very large numeric values (timestamp overflow)
  - Strings with timezone suffixes
  - Unicode datetime strings

================================================================================
COMMON NOTES FOR ALL FUZZ TARGETS
================================================================================

Import Path:
  import arrow
  from arrow.parser import DateTimeParser, TzinfoParser, ParserError, ParserMatchError

Installation:
  pip install arrow
  # or from source: pip install -e /app/arrow

Known Previous Fuzzer Findings:
  - Issue #860: ParserMatchError regression - no match group for token
    Input: fmt=b"[|\x1f\xb9\x03\x00\x00\x00\x00:-yI:][\x01yI:yI:I", payload=b""
  - Issue #854: regex module error
    Input: fmt=b"struct n[X+,N-M)MMXdMM]<", payload=b""

General Guidance:
  - All parse functions should only raise ParserError/ParserMatchError/ValueError
    on malformed input, not crash or hang
  - Watch for: ReDoS (catastrophic backtracking), uncaught exceptions,
    assertion errors, infinite loops, memory exhaustion
  - The library uses re module extensively; format strings are converted to
    regex patterns, creating potential for regex injection
  - Timestamp normalization handles very large numbers; watch for overflow
  - Locale-dependent code paths vary significantly; test multiple locales
