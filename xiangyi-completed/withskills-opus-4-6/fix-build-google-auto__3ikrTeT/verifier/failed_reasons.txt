ERROR 1: Missing com.sun:tools dependency (build configuration)
--------------------------------------------------------------
Message: "Could not resolve dependencies for project
com.google.auto:auto-common:jar:1.0-SNAPSHOT: Could not find artifact
com.sun:tools:jar:11.0.27 at specified path
/usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar"

Root Cause: The compile-testing library (test dependency in all 4 modules)
declares a transitive system-scoped dependency on com.sun:tools, which
resolves to ${java.home}/../lib/tools.jar. In Java 9+, tools.jar was
removed -- those classes are now part of the standard JDK modules. The
system-scoped dependency fails to resolve because the file does not exist.

Additionally, the root pom.xml defines profiles that set a ${toolsjar}
property pointing to tools.jar, which also doesn't exist on Java 11+.

Affected files:
  - common/pom.xml (compile-testing:0.7)
  - service/pom.xml (compile-testing:0.6)
  - factory/pom.xml (compile-testing:0.8)
  - value/pom.xml (compile-testing:0.6)
  - pom.xml (root - toolsjar profiles)

Fix: Add <exclusions> for com.sun:tools in each compile-testing dependency,
and add a java9-plus-profile to the root pom.xml that sets toolsjar to a
dummy value.


ERROR 2: javax.annotation.Generated not found (source code)
------------------------------------------------------------
Message: "cannot find symbol - symbol: class Generated - location: package
javax.annotation"

Root Cause: In Java 9, javax.annotation.Generated was deprecated. In Java
11, the java.xml.ws.annotation module (which contained this class) was
removed entirely. Three source files import javax.annotation.Generated
directly, which fails to compile on Java 11.

Affected files:
  - factory/src/main/java/.../FactoryWriter.java (line 39: import, line 85: usage)
  - value/src/main/java/.../AutoValueProcessor.java (line 51: import, line 457: usage)
  - value/src/main/java/.../AutoAnnotationProcessor.java (line 36: import, lines 169, 375: usage)

Fix: Remove the direct import of javax.annotation.Generated and replace
class references with string-based lookups:
  - FactoryWriter.java: Use string "Generated" instead of Generated.class
    in emitAnnotation() call (import is already emitted as a string)
  - AutoValueProcessor.java: Replace Generated.class.getName() with the
    string literal "javax.annotation.Generated"
  - AutoAnnotationProcessor.java: Add a generatedTypeMirror() helper method
    that looks up the class by string name and returns null when not found,
    then use null checks at usage sites
