The build fails because ALL tests (5 test files) cannot be collected by pytest
due to a single critical import error in the source code. The import chain is:

  test_*.py -> import agentops -> agentops/__init__.py (line 12) ->
  agentops/langchain_callback_handler.py (line 8) ->
  from langchain.callbacks.base import BaseCallbackHandler, AsyncCallbackHandler
  -> ModuleNotFoundError: No module named 'langchain.callbacks'

This is the PRIMARY and BLOCKING error. All other issues are secondary.

================================================================================
ERROR #1 (CRITICAL) - Broken Import in langchain_callback_handler.py
================================================================================

File: agentops/langchain_callback_handler.py
Line: 8
Code: from langchain.callbacks.base import BaseCallbackHandler, AsyncCallbackHandler

Problem: The module path `langchain.callbacks.base` no longer exists in modern
versions of langchain. The `BaseCallbackHandler` and `AsyncCallbackHandler`
classes have been moved to `langchain_core.callbacks.base`.

Impact: This prevents the entire `agentops` package from being imported, which
causes ALL 5 test files to fail during collection.

Fix: Change the import to:
  from langchain_core.callbacks.base import BaseCallbackHandler, AsyncCallbackHandler

This is consistent with the other imports in the same file (lines 5-7) which
already correctly use `langchain_core`:
  - from langchain_core.agents import AgentFinish, AgentAction
  - from langchain_core.documents import Document
  - from langchain_core.outputs import ChatGenerationChunk, GenerationChunk, LLMResult

================================================================================
ERROR #2 (HIGH) - Conditional attribute access in client.py
================================================================================

File: agentops/client.py
Lines: 99-101 (initialization), 371-372 (usage)

Problem: `self.llm_tracker` is only created when `instrument_llm_calls=True`
(lines 99-101), but `stop_instrumenting()` (line 372) accesses it
unconditionally. If a Client is created with `instrument_llm_calls=False`,
calling `stop_instrumenting()` crashes with:
  AttributeError: 'Client' object has no attribute 'llm_tracker'

Fix: Add a guard check in `stop_instrumenting()`:
  def stop_instrumenting(self):
      if hasattr(self, 'llm_tracker'):
          self.llm_tracker.stop_instrumenting()
