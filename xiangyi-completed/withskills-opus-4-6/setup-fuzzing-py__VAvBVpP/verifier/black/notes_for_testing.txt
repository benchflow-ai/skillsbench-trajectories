1. PRIMARY FUZZ TARGET: black.format_str()
================================================================================

File: /app/black/src/black/__init__.py
Signature:
    def format_str(
        src_contents: str,
        *,
        mode: Mode,
        lines: Collection[tuple[int, int]] = ()
    ) -> str

Description:
    The main public API for formatting Python source code as a string.
    This is THE most important fuzz target. It accepts arbitrary string input,
    parses it via lib2to3, performs multiple transformation passes (line
    generation, string normalization, bracket handling, comment processing),
    and returns the formatted output. It also calls _format_str_once() twice
    if the first pass changed the code (to handle trailing comma interactions).

Input type: str (Python source code as a string)

Why it is a good fuzz target:
    - Primary entry point that exercises the full formatting pipeline
    - Accepts arbitrary user-provided strings
    - Exercises the parser (lib2to3_parse), line generator, string transformers,
      bracket handling, comment handling, and numeric normalization
    - Complex control flow with many edge cases
    - The existing fuzz script (scripts/fuzz.py) already targets this function
    - Can expose crashes, infinite loops, and equivalence violations

Mode configuration to vary:
    Mode(
        target_versions: set[TargetVersion] = set(),  # e.g., {TargetVersion.PY310}
        line_length: int = 88,                         # try 0, 1, 10, 88, 200
        string_normalization: bool = True,
        is_pyi: bool = False,
        is_ipynb: bool = False,
        skip_source_first_line: bool = False,
        magic_trailing_comma: bool = True,
        preview: bool = False,                         # enables preview features
        unstable: bool = False,                        # enables ALL preview features
        python_cell_magics: set[str] = set(),
        enabled_features: set[Preview] = set(),
    )

Acceptable exceptions:
    - black.parsing.InvalidInput: raised when input is not valid Python syntax.
      This is EXPECTED for malformed input.
    - black.report.NothingChanged: raised when the code is already formatted.
      This is EXPECTED and harmless.
    - TokenError (from blib2to3.pgen2.tokenize): raised for tokenization failures
      on invalid input. EXPECTED.
    - IndentationError: for malformed indentation. EXPECTED.

Suspicious/unexpected exceptions:
    - AssertionError: may indicate an internal logic error in Black
    - black.parsing.ASTSafetyError: means Black produced code that is not
      AST-equivalent to the input. This is a REAL BUG (when fast=False).
    - IndexError, KeyError, AttributeError, TypeError: indicate internal errors
    - RecursionError: may indicate pathological input causing deep recursion
    - MemoryError: may indicate pathological input causing excessive memory use
    - Any crash/segfault: critical bugs

2. SECONDARY FUZZ TARGET: black.format_file_contents()
================================================================================

File: /app/black/src/black/__init__.py
Signature:
    def format_file_contents(
        src_contents: str,
        *,
        fast: bool,
        mode: Mode,
        lines: Collection[tuple[int, int]] = (),
    ) -> FileContent

Description:
    Reformats contents of a file and returns new contents. Wraps format_str()
    and additionally performs AST safety checks (assert_equivalent and
    assert_stable) when fast=False. Also handles Jupyter notebook formatting
    when mode.is_ipynb is True.

Input type: str (Python source code or JSON for ipynb)

Why it is a good fuzz target:
    - When fast=False, exercises the AST safety checking logic which compares
      the ASTs of original and formatted code -- a common source of bugs
    - When mode.is_ipynb=True, exercises the JSON-based Jupyter notebook parsing
      which is a separate complex code path
    - Raises NothingChanged when input == output (expected)

Acceptable exceptions:
    - NothingChanged: expected when code is already formatted
    - InvalidInput: for unparseable Python
    - JSONDecodeError: when is_ipynb=True and input is not valid JSON

Suspicious exceptions:
    - ASTSafetyError: Black produced non-equivalent code (BUG)
    - AssertionError from assert_stable: Black is not idempotent (BUG)

3. FUZZ TARGET: black.parsing.lib2to3_parse()
================================================================================

File: /app/black/src/black/parsing.py
Signature:
    def lib2to3_parse(
        src_txt: str,
        target_versions: Collection[TargetVersion] = ()
    ) -> Node

Description:
    Parses a Python source string into a lib2to3 concrete syntax tree (CST).
    This is the core parser that Black uses. It tries multiple grammar variants
    (Python 3.0-3.6, 3.7-3.9, 3.10+ with soft keywords) and returns the first
    successful parse.

Input type: str (Python source code)

Why it is a good fuzz target:
    - The parser is a complex state machine from blib2to3 (fork of lib2to3)
    - Parser bugs could cause crashes, infinite loops, or incorrect trees
    - Exercises the tokenizer (blib2to3.pgen2.tokenize) and parser (blib2to3.pgen2.parse)
    - Uses multiple grammar variants, each potentially with different bugs

Acceptable exceptions:
    - InvalidInput: for code that cannot be parsed by any grammar
    - TokenError: for tokenization failures

Suspicious exceptions:
    - Any exception other than InvalidInput/TokenError
    - Infinite loops or excessive memory usage

================================================================================
COMPOSITE FUZZ STRATEGY (RECOMMENDED)
================================================================================

The most effective fuzzing strategy combines format_str() with various Mode
configurations, similar to what scripts/fuzz.py already does. Here is the
recommended approach:

1. Generate random syntactically-valid Python source code
2. Call black.format_str(src, mode=mode) with varied Mode settings
3. If formatting succeeds:
   a. Call black.assert_equivalent(src, result) to check AST equivalence
   b. Call black.assert_stable(src, result, mode=mode) to check idempotency
4. Catch and categorize exceptions:
   - InvalidInput, NothingChanged, TokenError -> EXPECTED (skip)
   - ASTSafetyError, AssertionError -> REAL BUG (report)
   - Any other exception -> POTENTIAL BUG (report)

Additional considerations:
- The existing scripts/fuzz.py uses Hypothesis with hypothesmith for
  grammar-based source generation, which is a solid approach
- For coverage-guided fuzzing, use Atheris (integrated in scripts/fuzz.py)
- Vary line_length (especially small values like 1, 2) to stress line-splitting
- Use preview=True and unstable=True to test experimental features
- Test with is_pyi=True for type stub specific behavior
- Test with skip_source_first_line=True for script header handling
- Test with magic_trailing_comma=False to exercise alternative formatting paths
- Feed inputs containing: f-strings, multi-line strings, decorators, match
  statements, walrus operators, type annotations, async/await, *args/**kwargs,
  nested data structures, unicode identifiers, backslash continuations

MODE CONFIGURATION REFERENCE
================================================================================

File: /app/black/src/black/mode.py

class TargetVersion(Enum):
    PY33=3, PY34=4, PY35=5, PY36=6, PY37=7, PY38=8,
    PY39=9, PY310=10, PY311=11, PY312=12, PY313=13, PY314=14

class Preview(Enum):
    string_processing
    hug_parens_with_braces_and_square_brackets
    wrap_long_dict_values_in_parens
    multiline_string_handling
    always_one_newline_after_import
    fix_fmt_skip_in_one_liners
    standardize_type_comments
    wrap_comprehension_in
    remove_parens_around_except_types
    normalize_cr_newlines
    fix_module_docstring_detection
    fix_type_expansion_split
    remove_parens_from_assignment_lhs

UNSTABLE_FEATURES: set[Preview] = {
    Preview.string_processing,
    Preview.hug_parens_with_braces_and_square_brackets,
}

@dataclass
class Mode:
    target_versions: set[TargetVersion]    # default: set()
    line_length: int                        # default: 88
    string_normalization: bool              # default: True
    is_pyi: bool                            # default: False
    is_ipynb: bool                          # default: False
    skip_source_first_line: bool            # default: False
    magic_trailing_comma: bool              # default: True
    python_cell_magics: set[str]            # default: set()
    preview: bool                           # default: False
    unstable: bool                          # default: False
    enabled_features: set[Preview]          # default: set()
