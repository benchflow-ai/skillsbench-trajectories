1. INPUT TRANSFORMATION (HIGHEST PRIORITY)
===========================================================================

1a. TransformerManager.transform_cell()
    File: /app/ipython/IPython/core/inputtransformer2.py
    Signature: def transform_cell(self, cell: str) -> str

    WHY FUZZ: This is the primary entry point for all IPython input
    transformation. It takes raw user input and converts IPython-specific
    syntax (magic commands, shell escapes, help queries) into valid Python.
    It chains together cleanup transforms, line transforms, and token
    transforms. Complex string processing with regex and tokenization makes
    it an ideal fuzz target.

    INPUT TYPE: str (arbitrary cell content, can be multiline)

    SETUP: Create a TransformerManager instance (no args needed).
        from IPython.core.inputtransformer2 import TransformerManager
        tm = TransformerManager()

    ACCEPTABLE EXCEPTIONS:
        - SyntaxError (invalid Python/IPython syntax is expected)
        - RuntimeError("Input transformation still changing after 500
          iterations") -- indicates infinite loop protection triggered
        - tokenize.TokenError (malformed token input)

    SUSPICIOUS EXCEPTIONS:
        - MemoryError, RecursionError (potential DoS)
        - IndexError, KeyError (indicates boundary issues in parsing)
        - Any unhandled exception from inner transform steps


1b. TransformerManager.check_complete()
    File: /app/ipython/IPython/core/inputtransformer2.py
    Signature: def check_complete(self, cell: str) -> tuple[str, int|None]

    WHY FUZZ: Used to determine whether a block of code is ready to
    execute or needs more input. Returns ('complete', None),
    ('incomplete', indent), or ('invalid', None). Involves tokenization,
    all cleanup/line/token transforms, bracket matching, and codeop
    compilation. Highly complex control flow.

    INPUT TYPE: str (arbitrary cell content, can be multiline)

    SETUP: Same as transform_cell.

    ACCEPTABLE EXCEPTIONS:
        - SyntaxError (caught internally, returns 'invalid')
        - tokenize.TokenError (caught internally)

    SUSPICIOUS EXCEPTIONS:
        - RecursionError, MemoryError
        - IndexError (e.g., accessing tokens_by_line[-1] with empty list)
        - RuntimeError from infinite transform loop
        - Any uncaught exception


1c. make_tokens_by_line()
    File: /app/ipython/IPython/core/inputtransformer2.py
    Signature: def make_tokens_by_line(lines: List[str]) -> List[List[Any]]

    WHY FUZZ: Core tokenization function that groups tokens by logical
    line, tracking parenthesis levels. Directly wraps Python's tokenizer
    and must handle malformed inputs gracefully.

    INPUT TYPE: List[str] (lines of code, should have line endings)

    ACCEPTABLE EXCEPTIONS:
        - tokenize.TokenError (caught internally)

    SUSPICIOUS EXCEPTIONS:
        - IndexError, any uncaught exception


1d. cell_magic()
    File: /app/ipython/IPython/core/inputtransformer2.py
    Signature: def cell_magic(lines: List[str]) -> List[str]

    WHY FUZZ: Transforms cell magic syntax (lines starting with %%) into
    get_ipython().run_cell_magic() calls. Uses string partitioning and
    regex matching.

    INPUT TYPE: List[str] (lines of code)

    ACCEPTABLE EXCEPTIONS: None expected; should always return a list.
    SUSPICIOUS EXCEPTIONS: Any exception.


1e. EscapedCommand.transform() / find()
    File: /app/ipython/IPython/core/inputtransformer2.py
    Class: EscapedCommand (inherits TokenTransformBase)
    Signatures:
        @classmethod find(cls, tokens_by_line) -> Optional[EscapedCommand]
        def transform(self, lines: List[str]) -> List[str]

    WHY FUZZ: Handles all escaped commands: %magic, !shell, ?help, ??help,
    ,autocall, ;autocall, /autocall. The transform() calls into the tr{}
    dispatch dictionary which includes _tr_help, _tr_magic, _tr_quote,
    _tr_quote2, _tr_paren -- each doing string manipulation.

    INPUT TYPE: List[str] for transform; List[List[TokenInfo]] for find.

    ACCEPTABLE EXCEPTIONS:
        - SyntaxError (from _tr_paren when no callable name follows /)

    SUSPICIOUS EXCEPTIONS: IndexError, KeyError, AttributeError


1f. MagicAssign.transform() and SystemAssign.transform()
    File: /app/ipython/IPython/core/inputtransformer2.py
    Signatures:
        def transform(self, lines: List[str]) -> List[str]

    WHY FUZZ: Handle assignments from magics (a = %foo) and system
    commands (a = !foo). Involves find_end_of_continued_line() and
    assemble_continued_line() which do index-based line manipulation.

    INPUT TYPE: List[str]

    SUSPICIOUS EXCEPTIONS: IndexError (from line access), AssertionError


1g. HelpEnd.transform()
    File: /app/ipython/IPython/core/inputtransformer2.py
    Class: HelpEnd
    Signature: def transform(self, lines: List[str]) -> List[str]

    WHY FUZZ: Handles help syntax (obj? and obj??). Uses regex
    _help_end_re to parse and can raise SyntaxError.

    INPUT TYPE: List[str]

    ACCEPTABLE EXCEPTIONS: SyntaxError
    SUSPICIOUS EXCEPTIONS: IndexError, AttributeError

3. GUARDED EVAL (HIGH PRIORITY)
===========================================================================

3a. guarded_eval()
    File: /app/ipython/IPython/core/guarded_eval.py
    Signature: def guarded_eval(code: str, context: EvaluationContext)

    WHY FUZZ: This is a security-critical function that evaluates Python
    code under restricted evaluation policies. It parses arbitrary Python
    expressions using ast.parse() and then walks the AST with eval_node().
    Bugs here could lead to sandbox escapes.

    INPUT TYPE: str (Python expression), EvaluationContext

    SETUP:
        from IPython.core.guarded_eval import (
            guarded_eval, EvaluationContext, GuardRejection
        )
        # Test with various policies:
        context = EvaluationContext(locals={}, globals={}, evaluation="limited")
        # Also try: "minimal", "forbidden", "unsafe"

    ACCEPTABLE EXCEPTIONS:
        - GuardRejection (guard correctly rejects)
        - SyntaxError (from ast.parse on invalid code)
        - NameError (name not found in context)
        - TypeError, ValueError (from operations on types)

    SUSPICIOUS EXCEPTIONS:
        - Any code execution side effects (file access, network, etc.)
        - RecursionError (deeply nested AST)
        - MemoryError
        - SystemExit, KeyboardInterrupt (should not be raised)


3b. eval_node()
    File: /app/ipython/IPython/core/guarded_eval.py
    Signature: def eval_node(node: Union[ast.AST, None], context: EvaluationContext)

    WHY FUZZ: The core AST walker for guarded_eval. Handles all Python
    AST node types: BinOp, Compare, Call, Subscript, Attribute, Name, etc.
    Very complex switch-case logic. Fuzz via guarded_eval() which calls
    this after parsing.

    INPUT TYPE: ast.AST node, EvaluationContext

    Same exception notes as guarded_eval.

    INPUT TYPE: str

    SUSPICIOUS EXCEPTIONS: Any other exception

DEPENDENCIES NEEDED
===========================================================================

Core dependencies (install with pip):
    pip install ipython

For running the code being fuzzed:
    - Python 3.10+
    - traitlets
    - pygments
    - decorator

Optional (for full completer fuzzing):
    - jedi

No dependencies needed for the pure parsing/transformation functions
(items 1-4, 7, 8, 11, 12) -- they mostly use Python stdlib modules
(re, tokenize, ast, textwrap, shlex).

===========================================================================
RECOMMENDED FUZZING STRATEGY
===========================================================================

TIER 1 (Start here - highest value, standalone functions):
    1. TransformerManager.transform_cell(cell: str)
    2. TransformerManager.check_complete(cell: str)
    3. guarded_eval(code: str, context) -- with "limited" policy
    4. split_user_input(line: str)
    5. token_at_cursor(cell: str, cursor_pos: int)

TIER 2 (High value, slightly more setup):
    6. make_tokens_by_line(lines: List[str])
    7. match_dict_keys(keys, prefix, delims)
    8. arg_split(s: str, posix=False, strict=True)
    9. MagicArgumentParser.parse_argstring(argstring: str)
    10. source_to_unicode(txt: bytes)

TIER 3 (Medium value, simpler functions):
    11. cell_magic(lines: List[str])
    12. strip_email_quotes(text: str)
    13. DollarFormatter.parse(fmt_string: str)
    14. filter_ns(ns, name_pattern: str)
    15. Parser.format2(raw: str)

INPUT GENERATION HINTS:
    - For transform_cell/check_complete: Mix valid Python with IPython
      syntax (%magic, !shell, ?help, %%cell_magic), include multiline
      strings, continuations (\\), mixed indentation, unicode, and
      edge cases like empty lines, lines with only whitespace, very
      long lines.
    - For guarded_eval: Focus on Python expressions with attribute
      access (a.b.c), subscript access (a[0]), function calls (f()),
      binary/unary operations, and nested combinations.
    - For split_user_input: Lines starting with !, !!, ?, ??, %, %%,
      ,, ;, / and combinations with unicode identifiers.
    - For token_at_cursor: Vary cursor_pos from 0 to len(cell)+1,
      including multiline input.
    - For match_dict_keys: Use mix of str, bytes, int, float, tuple
      keys with various prefix strings including quotes and numbers.
