============================================

Repository: /home/github/build/failed/AgentOps-AI/agentops

SUMMARY OF ERRORS
------------------

ERROR 1 (CRITICAL): Unconditional import of optional langchain dependency
  File: agentops/__init__.py, line 12
  Code: from .langchain_callback_handler import LangchainCallbackHandler, AsyncLangchainCallbackHandler

  Root cause: The __init__.py unconditionally imports LangchainCallbackHandler and
  AsyncLangchainCallbackHandler from langchain_callback_handler.py. That module
  imports from langchain_core (line 5-8) and langchain (line 8) and tenacity
  (line 11), which are all optional dependencies (listed under
  [project.optional-dependencies.langchain] in pyproject.toml, not in the core
  [project.dependencies]).

  When a user installs agentops without the langchain extra (i.e., `pip install agentops`
  rather than `pip install agentops[langchain]`), importing the agentops package
  fails with:
    ModuleNotFoundError: No module named 'langchain_core'

  This causes ALL tests to fail during collection because every test file starts
  with `import agentops`.

  Impact: The package is completely unusable without langchain installed. 100% of
  tests fail.

ERROR 2 (SECONDARY): langchain_callback_handler.py also imports 'tenacity'
  File: agentops/langchain_callback_handler.py, line 11
  Code: from tenacity import RetryCallState

  Root cause: tenacity is not listed as a dependency in pyproject.toml at all
  (neither core nor optional). It happens to be installed as a transitive
  dependency of langchain, but it should either be guarded behind the same
  try/except or added to the langchain optional dependencies.

ERROR 3 (BUILD CONFIG): Missing [project.optional-dependencies] newline separator
  File: pyproject.toml, line 27
  Code: [project.optional-dependencies] appears right after the closing ] of
  dependencies without a blank line. While this is technically valid TOML, it
  combined with the old system setuptools (59.6.0 < required 61.0) causes
  `pip install .` to produce a package named UNKNOWN-0.0.0 instead of
  agentops-0.1.8. This is not a code error per se, since `python -m build`
  works correctly by installing setuptools>=61.0 in an isolated environment.


FIX PLAN
--------

Fix 1: Make langchain imports conditional in __init__.py
  - Wrap the import of LangchainCallbackHandler and AsyncLangchainCallbackHandler
    in a try/except ImportError block. If langchain is not installed, set them to
    None or simply don't export them.

Fix 2: Make langchain_callback_handler.py imports safe
  - Not strictly needed since fix 1 prevents the module from loading, but for
    correctness the module-level imports from langchain_core, langchain, and
    tenacity should be guarded or at minimum the __init__.py import should be
    conditional. Fix 1 alone is sufficient.

Fix 3: Add newline separator in pyproject.toml (cosmetic/correctness)
  - Add a blank line before [project.optional-dependencies] to follow standard
    TOML formatting conventions.

These fixes will allow:
  - `import agentops` to work without langchain installed
  - All 5 test files to be collected and tests to pass
  - The package to build correctly
