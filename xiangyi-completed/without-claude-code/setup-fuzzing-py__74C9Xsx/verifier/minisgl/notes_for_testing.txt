MINISGL LIBRARY - FUZZING NOTES
=====================================

Library: MiniSGL - Lightweight machine learning inference framework

KEY FUNCTIONS TO FUZZ:
1. SamplingParams dataclass initialization
2. Req dataclass initialization
3. Configuration loading (if applicable)
4. Server request handling

FUZZING ENTRY POINT: Req and SamplingParams initialization
- These are core dataclasses for request handling
- Accept numerical parameters and tensor data
- Should validate bounds and types

TEST STRATEGY:
- Fuzzing with boundary values for sampling parameters (0, max values, negative)
- Testing with invalid tensor shapes and dtypes
- Testing configuration parameter combinations
- Testing request initialization with edge cases
- Looking for assertion failures or type errors

KEY FILES:
- /app/minisgl/python/minisgl/core.py - Core dataclasses and request handling

NOTES:
This library is primarily a machine learning framework focused on LLM inference.
Most fuzzing opportunities are limited compared to string-parsing libraries.
Focus will be on parameter validation and edge case handling rather than
parsing complex string inputs.

COMMON CRASHES TO LOOK FOR:
- Assertion failures from invalid parameter combinations
- Type errors from invalid input types
- Out-of-memory from excessive allocations
- Invalid tensor operations
