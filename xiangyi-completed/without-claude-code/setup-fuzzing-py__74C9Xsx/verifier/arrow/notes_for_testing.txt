ARROW LIBRARY - FUZZING NOTES
=====================================

Library: Arrow - Date/Time parsing and manipulation

KEY FUNCTIONS TO FUZZ:
1. arrow.get(string) - Parse ISO 8601-like datetime strings
2. DateTimeParser.parse(string, format) - Parse datetime with custom format
3. DateTimeParser.parse_iso(string) - Parse ISO 8601 datetime
4. TzinfoParser.parse(string) - Parse timezone information
5. DateTimeParser._parse_token() - Token parsing

FUZZING ENTRY POINT: arrow.get()
- This is the main public API for parsing datetime strings
- Accepts various input formats
- Should handle edge cases, malformed inputs, boundary cases

TEST STRATEGY:
- Fuzzing string inputs with various datetime formats
- Testing timezone parsing
- Testing format string parsing with regex patterns
- Looking for ReDoS (Regular Expression Denial of Service) vulnerabilities
- Testing edge cases: empty strings, very long strings, special characters
- Testing with malformed dates/times

KEY FILES:
- /app/arrow/arrow/parser.py - Core parsing logic
- /app/arrow/arrow/factory.py - Factory method (ArrowFactory.get)

COMMON CRASHES TO LOOK FOR:
- Stack overflow from deep nesting or regex backtracking
- Memory exhaustion from format string expansion
- Segmentation faults from timezone parsing
