UJSON LIBRARY - FUZZING NOTES
=====================================

Library: UltraJSON (ujson) - Fast JSON parsing and encoding

KEY FUNCTIONS TO FUZZ:
1. ujson.decode(string) / ujson.loads(string) - Parse JSON string to Python object
2. ujson.encode(obj, **kwargs) / ujson.dumps(obj, **kwargs) - Serialize object to JSON string

FUZZING ENTRY POINT: ujson.decode()
- This is the main public API for JSON parsing
- Accepts raw JSON strings
- Should handle malformed JSON, edge cases, boundary inputs

TEST STRATEGY:
- Fuzzing with malformed JSON inputs
- Testing unterminated strings, arrays, objects
- Testing invalid escape sequences
- Testing Unicode handling (various encodings and special chars)
- Testing deep nesting levels (arrays, objects)
- Testing with large numbers and scientific notation
- Testing special float values (NaN, Infinity, -Infinity)
- Testing with very long strings
- Fuzzing ujson.encode() with various Python objects
- Testing encode options: encode_html_chars, escape_forward_slashes, ensure_ascii
- Testing circular references if supported
- Testing custom object handling

KEY FILES:
- /app/ujson/src/ujson/ - C extension implementation
- Focus on decode/loads functions

COMMON CRASHES TO LOOK FOR:
- Buffer overflows from malformed input
- Stack overflow from deep nesting
- Memory exhaustion from large allocations
- Invalid memory access from escape sequence handling
- Segmentation faults from Unicode processing
