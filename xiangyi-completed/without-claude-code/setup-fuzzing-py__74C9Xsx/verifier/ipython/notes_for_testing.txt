IPYTHON LIBRARY - FUZZING NOTES
=====================================

Library: IPython - Interactive Python shell

KEY FUNCTIONS TO FUZZ:
1. CachingCompiler.ast_parse(src, filename, symbol) - Code compilation with flags
2. cell_magic(lines) - Parse cell magic commands
3. PromptStripper.__call__(lines) - Strip prompt patterns
4. _find_assign_op(tokens) - Find assignment operators
5. _parse_tokens(buf, pre_whitespace) - Token parsing for completion
6. Completer methods - Code completion matching

FUZZING ENTRY POINT: CachingCompiler.ast_parse()
- This is a core API for parsing Python code with compiler flags
- Accepts raw Python source code
- Should handle edge cases, invalid syntax, special prompt patterns

TEST STRATEGY:
- Fuzzing with syntactically invalid Python code
- Testing with various IPython prompt patterns (>>>, In[n]:, etc.)
- Testing cell magic command parsing with % and %% prefixes
- Testing tokenization and bracket matching
- Testing assignment operator detection with various syntax
- Testing with special characters and Unicode
- Testing with very long input lines and deeply nested structures

KEY FILES:
- /app/ipython/IPython/core/compilerop.py - Compiler and AST parsing
- /app/ipython/IPython/core/inputtransformer2.py - Input transformation and magic parsing
- /app/ipython/IPython/core/completer.py - Code completion

COMMON CRASHES TO LOOK FOR:
- Stack overflow from deep nesting
- Memory exhaustion from token parsing
- Infinite loops in prompt stripping regex
- ReDoS (Regular Expression Denial of Service) in prompt patterns
- Crashes in tokenization with malformed syntax
