BLACK LIBRARY - FUZZING NOTES
=====================================

Library: Black - Python code formatter

KEY FUNCTIONS TO FUZZ:
1. format_str(src_contents, mode) - Main formatting function
2. lib2to3_parse(src_txt, target_versions) - Parse Python code to AST
3. parse_ast(src) - Parse with standard library AST
4. format_file_contents(src_contents, mode) - Format file contents
5. format_ipynb_string(src, mode) - Format Jupyter notebooks

FUZZING ENTRY POINT: format_str()
- This is the main public API for formatting Python code
- Accepts raw Python source code as string
- Should handle syntactically invalid code, edge cases, boundary inputs

TEST STRATEGY:
- Fuzzing with syntactically invalid/malformed Python code
- Testing with edge-case valid Python syntax
- Testing bracket matching and nesting
- Testing comment handling with special characters
- Testing string normalization with various escape sequences
- Testing with very long lines and deeply nested structures
- Testing Jupyter notebook JSON format handling

KEY FILES:
- /app/black/src/black/__init__.py - Main formatting functions
- /app/black/src/black/parsing.py - Python AST parsing
- /app/black/src/black/linegen.py - Line generation logic

COMMON CRASHES TO LOOK FOR:
- Stack overflow from deep nesting
- Memory exhaustion from large inputs
- Infinite loops in bracket matching
- Crashes in lib2to3 or standard AST parser
- Unicode/encoding issues
