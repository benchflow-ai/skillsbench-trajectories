MINISGL LIBRARY - FUZZING ANALYSIS REPORT
==========================================

LIBRARY OVERVIEW
================
Mini-SGLang is a lightweight LLM inference framework (~5,000 lines of Python code).
It handles tokenization, request scheduling, batch processing, and message serialization.

Dependencies:
- torch, transformers (LLM inference)
- msgpack, json (serialization)
- fastapi, uvicorn (API server)
- pydantic (request validation)
- pyzmq (distributed messaging)

KEY FUNCTIONS FOR FUZZING
==========================

1. MESSAGE SERIALIZATION/DESERIALIZATION (CRITICAL)
----------------------------------------------------
File: python/minisgl/message/utils.py

serialize_type(obj)
- Serializes objects to dict/JSON format
- Handles torch.Tensor (converts to numpy bytes)
- Handles dict, list, tuple recursively

deserialize_type(cls_map, data)
- Deserializes from dict back to objects
- Uses type names to reconstruct objects via globals()
- Converts bytes back to torch.Tensor via numpy
- FUZZ: Type confusion attacks, missing classes, malformed tensor data

2. REQUEST PARSING - API SERVER (HIGH PRIORITY)
------------------------------------------------
File: python/minisgl/server/api_server.py

Pydantic Models:
- GenerateRequest: prompt (str), max_tokens (int), ignore_eos (bool)
- Message: role (Literal), content (str)
- OpenAICompletionRequest: Complex model with prompt/messages, sampling params

Endpoints:
- generate(req: GenerateRequest) - POST /generate
- v1_completions(req: OpenAICompletionRequest) - POST /v1/chat/completions

FUZZ: Missing fields, invalid sampling parameters, type confusion

3. TOKENIZATION (HIGH PRIORITY)
--------------------------------
File: python/minisgl/tokenizer/tokenize.py

TokenizeManager.tokenize(msgs: List[TokenizeMsg])
- Accepts text as str OR List[Dict[str, str]] (chat template)
- Calls tokenizer.apply_chat_template() for list input
- Calls tokenizer.encode() for string input
- FUZZ: Invalid chat template dicts, extremely long strings

4. DETOKENIZATION (MEDIUM PRIORITY)
------------------------------------
File: python/minisgl/tokenizer/detokenize.py

DetokenizeManager.detokenize(msgs: List[DetokenizeMsg])
- Processes token IDs and rebuilds strings
- Handles CJK character detection
- FUZZ: Invalid token IDs (negative, overflow), unicode edge cases

5. ARGUMENT PARSING (MEDIUM PRIORITY)
--------------------------------------
File: python/minisgl/server/args.py

parse_args(args: List[str], run_shell: bool)
- Uses argparse to parse command-line arguments
- String conversions: model_path, dtype
- Integer conversions: ports, tensor-parallel-size
- FUZZ: Path traversal, invalid enum choices, type conversion edge cases

6. CORE DATA STRUCTURES (MEDIUM PRIORITY)
------------------------------------------
File: python/minisgl/core.py

SamplingParams dataclass:
- temperature (float), top_k (int), top_p (float)
- ignore_eos (bool), max_tokens (int)
- FUZZ: Invalid parameter combinations, extreme values

FUZZING RECOMMENDATIONS
=======================

1. HIGH PRIORITY:
   - API request JSON parsing (GenerateRequest, OpenAICompletionRequest)
   - Serialization/deserialization cycles
   - Tokenization with malformed inputs

2. ATTACK SURFACE:
   - Type Safety: Ensure deserialization cannot create arbitrary objects
   - Bounds Checking: Validate max_tokens, sequence lengths

   - Numeric Stability: Test NaN, inf, extreme values

3. INPUT CATEGORIES:
   - Malformed JSON

   - Invalid sampling parameters
   - Type mismatches
   - Extreme values
