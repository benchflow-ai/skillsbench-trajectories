UJSON LIBRARY - FUZZING ANALYSIS REPORT
========================================

LIBRARY OVERVIEW
================
UltraJSON is a fast JSON encoder/decoder written as a Python C extension.
The library is in MAINTENANCE-ONLY MODE due to architectural issues.

Main Components:
- Main Python Interface: src/ujson/python/ujson.c
- JSON Decoder: src/ujson/python/JSONtoObj.c
- JSON Encoder: src/ujson/python/objToJSON.c
- Core C Library: src/ujson/lib/ (ultrajson.h, ultrajsondec.c, ultrajsonenc.c)

Module Version: ujson.__version__
Custom Exception: ujson.JSONDecodeError (extends ValueError)

KEY FUNCTIONS FOR FUZZING
==========================

PRIMARY FUNCTIONS (Critical for Testing)
-----------------------------------------

1. ujson.loads(obj, **kwargs) / ujson.decode()
   MAIN DECODE FUNCTION
   Input: JSON string, bytes, or bytearray
   Output: Python object (dict, list, float, int, bool, None)
   Threat Surface: Parses JSON strings from untrusted input

2. ujson.dumps(obj, **kwargs) / ujson.encode()
   MAIN ENCODE FUNCTION
   Input: Python object (arbitrary data structures)
   Output: JSON string
   Key Parameters:
   - ensure_ascii (bool): Default True - escape non-ASCII chars
   - encode_html_chars (bool): Default False - encode <, >, &
   - escape_forward_slashes (bool): Default True - escape /
   - indent (int): Default 0 - indentation level
   - sort_keys (bool): Sort object keys
   - allow_nan (bool): Default True - allow NaN/Infinity
   - reject_bytes (bool): Default False - raise TypeError on bytes

3. ujson.load(file, **kwargs)
   FILE DECODE FUNCTION
   Input: File-like object with read() method

4. ujson.dump(obj, file, **kwargs)
   FILE ENCODE FUNCTION
   Input: Python object and file

CRITICAL INPUT HANDLING PATHS
==============================

JSON PARSING (Decoder Focus):
- String parsing with UTF-8/UTF-16/UTF-32 conversion
- Numeric parsing (integers, floats, special values)
- Special values: null, true, false, NaN, Infinity, -Infinity
- Object/dictionary parsing with string key validation
- Array/list parsing
- Recursion depth checking (MAX_OBJECT_DEPTH = 1024)
- Escape sequence handling (\u, \n, \r, \t, \/, \\, etc.)

JSON ENCODING (Encoder Focus):
- Python object type detection and serialization
- String encoding with HTML character escaping
- Numeric encoding (int, float, Decimal)
- Collection iteration (lists, dicts, tuples)
- Recursion depth checking (MAX_RECURSION_DEPTH = 1024)

RECURSION AND COMPLEXITY LIMITS
================================
- JSON_MAX_RECURSION_DEPTH = 1024 (Encoder max nesting)
- JSON_MAX_OBJECT_DEPTH = 1024 (Decoder max nesting)
- JSON_MAX_STACK_BUFFER_SIZE = 1024
- JSON_DOUBLE_MAX_DECIMALS = 15

FUZZING RECOMMENDATIONS
=======================

1. HIGH PRIORITY (memory safety, parsing correctness):
   - JSON string decoding with malformed/edge-case input
   - Deeply nested structures (approach recursion limits)
   - Large numeric values and scientific notation
   - Unicode/UTF-8 handling in strings
   - Escape sequence combinations
   - Special float values (NaN, Infinity)
   - Invalid UTF-8 and surrogate sequences

2. MEDIUM PRIORITY (encoding edge cases):
   - HTML character escaping combinations
   - Forward slash escaping modes
   - Indentation with deep nesting
   - Decimal and large integer encoding
   - Sort_keys behavior with various key types

3. INPUT CATEGORIES:
   - Malformed JSON strings
   - Very large/small numbers
   - Deeply nested objects/arrays
   - Unicode edge cases
   - Control characters
   - Empty objects/arrays
   - Mixed type collections

SECURITY NOTES
===============
The library is in MAINTENANCE-ONLY MODE due to:
- "UltraJSON's architecture is fundamentally ill-suited to making changes
   without risk of introducing new security vulnerabilities"
- Focus on: Buffer overflows, off-by-one errors, stack overflow from recursion
