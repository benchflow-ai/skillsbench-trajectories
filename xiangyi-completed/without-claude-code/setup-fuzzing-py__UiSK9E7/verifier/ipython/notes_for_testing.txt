IPYTHON LIBRARY - FUZZING ANALYSIS REPORT
==========================================

LIBRARY OVERVIEW
================
IPython is an enhanced interactive Python shell with:
- Magic commands and system shell integration
- Input transformation pipeline
- Code completion and inspection
- Notebook integration

Dependencies:
- decorator, jedi, pygments, prompt_toolkit, stack_data, traitlets
- Python Requirements: >= 3.11

KEY FUNCTIONS FOR FUZZING
==========================

1. INPUT TRANSFORMATION PIPELINE
---------------------------------
File: IPython/core/inputtransformer2.py

TransformerManager.transform_cell(cell: str) -> str
- Main orchestrator for input transformations
- Transforms user input before execution

Key Token-based Transformers:
- PromptStripper: Removes Python/IPython prompts
- MagicAssign: Transforms magic assignments (a = %foo)
- SystemAssign: Transforms system assignments (a = !cmd)
- EscapedCommand: Transforms escaped commands (%magic, !system, /paren)
- HelpEnd: Transforms help syntax (obj?, obj??)

Escape Character Definitions:
- % (ESC_MAGIC) - Line magic
- %% (ESC_MAGIC2) - Cell magic
- ! (ESC_SHELL) - System command
- !! (ESC_SH_CAP) - System command with output capture
- ? / ?? (ESC_HELP/ESC_HELP2) - Help/Detailed help
- , (ESC_QUOTE) - Quote arguments
- ; (ESC_QUOTE2) - Quote all args as string
- / (ESC_PAREN) - Call with rest as args

2. USER INPUT SPLITTING
------------------------
File: IPython/core/splitinput.py

split_user_input(line, pattern)
- Splits input into components: (pre, esc, ifun, the_rest)
- Uses regex pattern matching

3. MAGIC COMMAND HANDLING
--------------------------
File: IPython/core/magic.py

parse_options(arg_str, opt_str, *long_opts, **kw)
- Parses magic command options using getopt

File: IPython/core/magic_arguments.py

parse_argstring(magic_func, argstring, partial=False)
- Parses magic arguments using argparse internally

4. STRING/ARGUMENT PARSING
---------------------------
File: IPython/utils/_process_common.py

arg_split(s, posix=False, strict=True)
- Splits command-line arguments using shlex
- Handles unclosed quotes gracefully when strict=False

5. CODE EXECUTION
------------------
File: IPython/core/interactiveshell.py

InteractiveShell.run_cell(raw_cell, store_history)
- Main execution entry point
- Calls: transform_cell(), transform_ast(), run_ast_nodes()

InteractiveShell.run_line_magic(magic_name, line)
- Executes line magic commands

InteractiveShell.run_cell_magic(magic_name, line, cell)
- Executes cell magic commands

FUZZING RECOMMENDATIONS
=======================

1. HIGH PRIORITY TARGETS:
   - TransformerManager.transform_cell() - Core transformation
   - split_user_input() - Input line parsing
   - arg_split() - Argument parsing
   - parse_options() / parse_argstring() - Option parsing

2. ATTACK SURFACE:
   - Magic Commands: %magic, %%cellmagic parsing
   - System Commands: !shell, !!capture parsing
   - Help Syntax: obj?, obj??, %magic?
   - Continued Lines: Backslash line continuation
   - String Escapes: Quote handling in arg_split
   - Bracket/Paren Matching: Nested structures, unbalanced delimiters

3. INPUT CATEGORIES:
   - Various escape sequences
   - Incomplete magics
   - Malformed syntax
   - Unclosed quotes
   - Special characters
   - Unicode and control characters
