BLACK LIBRARY - FUZZING ANALYSIS REPORT
========================================

LIBRARY OVERVIEW
================
Black is "The uncompromising code formatter" for Python. It's a production-grade tool that:
- Parses Python source code using lib2to3
- Reformats code according to configurable rules
- Validates code equivalence before and after formatting
- Supports Jupyter notebooks, .pyi stub files, and multiple Python versions

Key Dependencies:
- click (CLI framework)
- lib2to3 (Python parser)
- pathspec (path matching)
- mypy_extensions (type hints)
- Optional: jupyter/ipython, tokenize-rt

Python Version: Requires Python 3.10+

KEY FUNCTIONS FOR FUZZING
==========================

PRIMARY PARSING & FORMATTING PIPELINE
--------------------------------------

1. format_str(src_contents: str, *, mode: Mode) -> str
   File: src/black/__init__.py
   CRITICAL TARGET - Main public API for code formatting
   Takes arbitrary Python source code string as input
   Returns formatted code string

2. lib2to3_parse(src_txt: str, target_versions: Collection[TargetVersion] = ()) -> Node
   File: src/black/parsing.py
   CRITICAL TARGET - Direct Python parser interface
   Attempts to parse source code with multiple Python grammar versions
   Raises InvalidInput exception on parse failures

3. format_file_contents(src_contents: str, *, fast: bool, mode: Mode) -> FileContent
   File: src/black/__init__.py
   Wrapper with additional safety checks
   Routes to format_ipynb_string() for notebook processing

STRING PROCESSING & NORMALIZATION
----------------------------------

4. normalize_string_quotes(s: str) -> str
   File: src/black/strings.py
   Normalizes string quote styles
   Handles raw strings, f-strings, byte strings, multi-line strings

5. normalize_fstring_quotes(s: str, quote_style: str) -> str
   File: src/black/strings.py
   Specialized processing for f-strings
   Complex nested expressions

NOTEBOOK HANDLING
-----------------

6. format_ipynb_string(src_contents: str, *, fast: bool, mode: Mode) -> FileContent
   File: src/black/__init__.py
   Processes Jupyter notebook JSON format
   Calls json.loads() on input to parse notebook structure

VALIDATION & EQUIVALENCE CHECKING
----------------------------------

7. assert_equivalent(src: str, dst: str) -> None
   File: src/black/__init__.py
   Verifies AST equivalence before and after formatting
   Find cases where formatting changes semantics

8. assert_stable(src: str, dst: str, mode: Mode) -> None
   File: src/black/__init__.py
   Checks idempotency: formatting same code twice gives same result
   Find code that formats unstably

FUZZING RECOMMENDATIONS
=======================

1. HIGH-PRIORITY TARGETS:
   - format_str() - Main entry point, processes all Python code
   - lib2to3_parse() - Core parser, lowest-level input processing
   - format_ipynb_string() - JSON parsing + code formatting combined

2. INPUT MUTATION IDEAS:
   - Valid Python with edge-case syntax (walrus operators, match statements)
   - Strings with unusual quotes, escapes, and f-string nesting
   - Comments with special directives (# fmt: off/on, # noqa)
   - Deeply nested structures (functions, classes, brackets)
   - Jupyter notebooks with malformed JSON/cells
   - Code with mixed whitespace (tabs vs spaces)
   - Unicode identifiers and escape sequences

3. REGRESSION TESTING:
   - Monitor for crashes in lib2to3_parse()
   - Check assert_equivalent() failures (semantic changes)
   - Check assert_stable() failures (idempotency breaks)
