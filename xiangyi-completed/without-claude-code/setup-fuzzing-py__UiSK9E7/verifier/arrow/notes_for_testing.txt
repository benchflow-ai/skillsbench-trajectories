ARROW LIBRARY - FUZZING ANALYSIS REPORT
========================================

LIBRARY OVERVIEW
================
Arrow is a Python library for better dates and times handling. It provides utilities for:
- Creating and manipulating datetime objects
- Parsing datetime strings from various formats
- Formatting datetime objects
- Converting between timezones
- Humanizing dates

Core Dependencies:
- python-dateutil>=2.7.0
- backports.zoneinfo (Python 3.8 support)
- tzdata (timezone information)

MODULE STRUCTURE
================
Main Modules:
- arrow/__init__.py: Public API exports
- arrow/api.py: Module-level functions (get, now, utcnow)
- arrow/factory.py: ArrowFactory class for object construction
- arrow/parser.py: DateTimeParser - core parsing logic
- arrow/formatter.py: DateTimeFormatter - output formatting
- arrow/arrow.py: Arrow class - main datetime wrapper

KEY FUNCTIONS FOR FUZZING
==========================

HIGHEST PRIORITY - String Parsing Functions
--------------------------------------------

1. DateTimeParser.parse_iso(datetime_string, normalize_whitespace=False)
   File: arrow/parser.py
   Risk: HIGH - Parses ISO 8601-like datetime strings
   Input: String containing date/time in various ISO formats
   Formats accepted: YYYY-MM-DD, YYYYMMDD, YYYY/MM/DD, YYYY.MM.DD, YYYY-MM, ISO weekdate, time components

2. DateTimeParser.parse(datetime_string, fmt, normalize_whitespace=False)
   File: arrow/parser.py
   Risk: HIGH - Parses datetime strings with custom format strings
   Input: String + format string (or list of format strings)
   Key Tokens: YYYY, YY, MM, M, DD, D, HH, H, mm, m, ss, s, S, X, x, ZZZ, ZZ, Z, MMMM, MMM, a, A, W

3. TzinfoParser.parse(tzinfo_string)
   File: arrow/parser.py
   Risk: MEDIUM - Parses timezone information strings
   Input formats: "local", "utc", "UTC", "Z", ISO offset, IANA timezone names

HIGH PRIORITY - Factory Functions
----------------------------------

4. ArrowFactory.get(*args, **kwargs)
   File: arrow/factory.py
   Risk: HIGH - Main entry point for Arrow object creation
   Supports multiple input types:
   - None (current UTC time)
   - Timestamps (int/float to datetime conversion)
   - Arrow objects (copying)
   - datetime/date objects
   - tzinfo objects
   - Strings (via parse_iso or custom format)

5. arrow.get(*args, **kwargs)
   File: arrow/api.py
   Risk: HIGH - Module-level API function wrapping ArrowFactory.get

FUZZING RECOMMENDATIONS
=======================

1. PRIMARY TARGETS:
   - DateTimeParser.parse_iso() with malformed ISO strings
   - DateTimeParser.parse() with format + string combinations
   - ArrowFactory.get() with various input types
   - TzinfoParser.parse() with malformed timezone strings

2. INPUT CATEGORIES TO TEST:
   - Dates: Valid/invalid ranges, leap years, day-of-year edge cases
   - Times: 24-hour edge cases (23:59:59, 24:00:00), microseconds
   - Timezones: Valid IANA names, ISO offsets, special cases (UTC, local)
   - Weekdates: ISO week dates with edge case weeks (52/53)
   - Timestamps: Epoch, negative, very large, floating-point precision
   - Formats: All format tokens, combinations, escape sequences

3. FUZZING ANGLES:
   - Boundary values (year, month, day ranges)
   - Timezone offset extremes
   - Invalid format tokens
   - Unicode and special characters in strings
   - Whitespace variations
   - Empty strings and None values
