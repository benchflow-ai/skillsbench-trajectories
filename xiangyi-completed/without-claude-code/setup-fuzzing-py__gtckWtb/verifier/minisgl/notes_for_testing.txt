MiniSGL Library - Testing Notes
================================

Library Overview:
- MiniSGL appears to be a machine learning/LLM inference library
- Uses PyTorch, Transformers for model handling
- Includes server components (FastAPI, uvicorn)
- Message passing (msgpack, pyzmq)
- Main components: engine, models, server, scheduler

Key Functions to Fuzz:
1. Message parsing/serialization (msgpack usage)
   - Binary message deserialization
   - Potential buffer overflow, type confusion
   - Malformed msgpack data

2. Server endpoints (FastAPI routes)
   - HTTP request handling
   - JSON/msgpack payloads
   - API parameter validation

3. Model input processing
   - Text tokenization
   - Input validation for transformers
   - Large/malformed text inputs

4. Configuration parsing
   - Model config loading
   - Parameter validation

5. Scheduler/queue management
   - Request queue handling
   - Resource allocation logic

Fuzzing Strategy:
- Fuzz msgpack serialized messages
- HTTP API endpoints with malformed requests
- Very long text inputs for model processing
- Malformed model configurations
- Invalid parameter combinations
- Binary data edge cases
- Unicode, special characters in text inputs
- Large batch sizes, memory exhaustion attempts

Dependencies:
- torch
- transformers>=4.56.0,<=4.57.3
- msgpack
- fastapi
- uvicorn
- pyzmq
- accelerate
- sgl_kernel>=0.3.17.post1
