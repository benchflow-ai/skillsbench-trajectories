UltraJSON (ujson) Library - Testing Notes
==========================================

Library Overview:
- UltraJSON is an ultra-fast JSON encoder/decoder for Python
- Written in C for performance (ujson.c, objToJSON.c, JSONtoObj.c)
- Drop-in replacement for standard json module
- Main functions: ujson.dumps(), ujson.loads()

Key Functions to Fuzz:
1. ujson.loads(json_string) - Parse JSON string to Python object
   - C-based parser, potential for buffer overflows
   - Integer overflow in size calculations
   - Stack overflow with deeply nested structures
   - Unicode handling vulnerabilities
   - Very high priority target due to C implementation

2. ujson.dumps(obj) - Serialize Python object to JSON string
   - Object traversal and serialization
   - Circular reference handling
   - Very large objects
   - Special float values (NaN, Inf)

3. ujson.decode() - Alias for loads()
   - Same vulnerabilities as loads()

4. ujson.encode() - Alias for dumps()
   - Same vulnerabilities as dumps()

Fuzzing Strategy:
- Malformed JSON strings (unclosed brackets, quotes)
- Deeply nested JSON (arrays/objects 1000+ levels deep)
- Very long strings (megabytes of data)
- Unicode edge cases (surrogate pairs, invalid UTF-8)
- Large integers (beyond 64-bit range)
- Special numeric values (NaN, Infinity, very large/small floats)
- Escaped characters edge cases (\uXXXX, \n, \t, etc.)
- Mixed valid/invalid JSON structures
- Null bytes in strings
- Memory exhaustion attempts (huge arrays/objects)

PRIORITY: This is the HIGHEST priority target due to:
- C implementation = memory safety issues possible
- Parsing untrusted input
- History of JSON parser vulnerabilities

Dependencies:
- Python 3.x
- C compiler (for building extension)
- No external Python dependencies
