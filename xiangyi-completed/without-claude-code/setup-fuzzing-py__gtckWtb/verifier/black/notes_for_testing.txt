Black Library - Testing Notes
==============================

Library Overview:
- Black is an uncompromising Python code formatter
- Parses Python code and reformats it according to strict rules
- Uses lib2to3 for parsing Python syntax
- Main entry point: black.format_str(), black.format_file_contents()

Key Functions to Fuzz:
1. black.format_str(src_contents, mode=Mode) - Main formatting function
   - Takes Python source code as string input
   - Parses and reformats code
   - Vulnerable to malformed Python syntax, edge cases

2. black.parsing.lib2to3_parse() - Parse Python source code
   - Uses lib2to3 parser
   - Handles various Python versions (3.10+)
   - Good target for syntax edge cases

3. black.parsing.parse_ast() - Parse to AST
   - Alternative parsing using ast module
   - Error handling for invalid syntax

4. black.format_file_contents() - Format with safety checks
   - Includes stability and equivalence checking
   - Multiple passes of formatting

5. black.format_ipynb_string() - Format Jupyter notebooks
   - JSON parsing + Python code formatting
   - Multiple input formats

Fuzzing Strategy:
- Fuzz with various Python syntax patterns
- Malformed Python code (unbalanced brackets, invalid syntax)
- Edge cases: decorators, f-strings, type annotations, match statements
- Very long lines, deeply nested structures
- Unicode characters, special encodings
- Mixed newline types (CR, LF, CRLF)
- Jupyter notebook cell formats
- Configuration edge cases (line length, target versions)
