Arrow Library - Testing Notes
==============================

Library Overview:
- Arrow is a Python library for better date & time handling
- Provides parsing, formatting, and manipulation of datetime objects
- Main entry point: arrow module

Key Functions to Fuzz:
1. arrow.get() - Parse various datetime string formats and return Arrow objects
   - Takes string input with optional format specifiers
   - Handles timestamps, ISO formats, natural language dates
   - Vulnerable to malformed input, edge cases in parsing

2. arrow.parser.DateTimeParser.parse() - Core parsing function
   - Parses datetime strings with format tokens
   - Complex regex-based parsing logic
   - Good candidate for format string fuzzing

3. Arrow.format() - Format datetime objects to strings
   - Takes format string input
   - Uses various format tokens (YYYY, MM, DD, etc.)

4. Arrow.humanize() - Convert datetime to human-readable format
   - String output generation

5. arrow.factory.ArrowFactory - Factory methods for creating Arrow objects
   - Various input types: strings, timestamps, datetime objects

Fuzzing Strategy:
- Fuzz datetime string inputs with various formats
- Malformed date strings (invalid months, days, years)
- Edge cases: leap years, timezone strings, DST transitions
- Format string variations and malformations
- Very long strings, special characters
- Timestamp edge cases (negative, very large values)

Dependencies:
- python-dateutil>=2.7.0
- tzdata (Python 3.9+)
- backports.zoneinfo (Python < 3.9)
