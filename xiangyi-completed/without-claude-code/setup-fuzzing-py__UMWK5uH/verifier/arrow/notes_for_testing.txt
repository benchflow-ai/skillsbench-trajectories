# Arrow Library Fuzz Testing Notes

## Library Overview
Arrow is a Python library that provides a sensible and human-friendly approach to creating,
manipulating, formatting, and converting dates, times, and timestamps. It wraps Python's
datetime with timezone-awareness by default and implements the ISO 8601 standard.

## Dependencies
- python-dateutil>=2.7.0
- tzdata (Python 3.9+)
- atheris (for fuzzing)

## Top Functions to Fuzz Test

### 1. arrow.get() - CRITICAL
Import: arrow.get
Why: Main entry point for parsing user input. Polymorphic function accepting multiple types.
Targets:
- String inputs: various date/time formats, invalid strings, special characters
- Numeric inputs: timestamps (int/float), edge values (0, negative, max/min)
- Mixed inputs: combinations causing type confusion

### 2. arrow.parser.DateTimeParser.parse() - CRITICAL
Import: arrow.parser.DateTimeParser
Method: parse(datetime_string, fmt, normalize_whitespace=False)
Why: Complex token-based parsing with regex generation and format string handling.
Targets:
- Format strings: all token types (YYYY, MM, DD, HH, mm, ss, etc.)
- Datetime strings: malformed dates, boundary dates, special characters
- Whitespace normalization edge cases

### 3. arrow.parser.DateTimeParser.parse_iso() - CRITICAL
Import: arrow.parser.DateTimeParser
Method: parse_iso(datetime_string, normalize_whitespace=False)
Why: ISO 8601 parsing with complex internal format selection and timezone handling.
Targets:
- ISO 8601 variations: basic format, extended format, week dates, ordinal dates
- Time components: missing minutes/seconds, subseconds
- Timezone indicators: Z, +HH:MM, -HH:MM

### 4. arrow.parser.TzinfoParser.parse() - HIGH
Import: arrow.parser.TzinfoParser
Method: parse(tzinfo_string)
Why: Timezone string parsing with fallback to system timezone database.
Targets:
- Timezone names: valid zones, invalid zones, case variations
- Numeric offsets: +05:30, -12:00, edge cases
- Special keywords: "UTC", "local"

### 5. arrow.formatter.DateTimeFormatter.format() - MEDIUM
Import: arrow.formatter.DateTimeFormatter
Method: format(dt, fmt)
Why: Token substitution with locale-dependent output.
Targets:
- Format tokens: all supported tokens with edge values
- Locale-specific: month names, day names, ordinal formats

## Fuzzing Strategy
- Use atheris for libFuzzer integration
- Seed with valid ISO 8601 strings and mutate
- Focus on string inputs to arrow.get()
- Test boundary values for timestamps
