# Black Library Fuzz Testing Notes

## Library Overview
Black is "the uncompromising code formatter" for Python. It parses Python source code,
performs AST transformations, and generates reformatted output. The library processes
arbitrary user input (Python source code strings).

## Dependencies
- click>=8.0.0
- mypy_extensions>=0.4.3
- packaging>=22.0
- pathspec>=0.9.0
- platformdirs>=2
- pytokens>=0.3.0
- tomli>=1.1.0 (Python < 3.11)
- atheris (for fuzzing)

## Top Functions to Fuzz Test

### 1. black.format_str() - CRITICAL
Import: black.format_str
Signature: format_str(src_contents: str, *, mode: Mode) -> str
Location: src/black/__init__.py
Why: Primary public API for formatting Python code. Handles complete formatting pipeline.
Targets:
- Random Python code snippets
- Empty strings, single-character inputs, very long lines
- Different Python version features
- All Mode configurations (preview, unstable, string_normalization)

### 2. black.parsing.lib2to3_parse() - CRITICAL
Import: black.parsing.lib2to3_parse
Signature: lib2to3_parse(src_txt: str, target_versions: Collection[TargetVersion] = ()) -> Node
Location: src/black/parsing.py
Why: Core parsing function that converts string to AST. Tries multiple Python grammars.
Targets:
- Malformed Python syntax
- Mixed Python versions (2.x/3.x hybrids)
- Tokenization edge cases (unterminated strings, bad escapes)
- Unicode and special characters

### 3. black.strings.normalize_string_quotes() - HIGH
Import: black.strings.normalize_string_quotes
Signature: normalize_string_quotes(s: str) -> str
Location: src/black/strings.py
Why: Complex string normalization with regex-based quote conversion.
Targets:
- Strings with various quote combinations (', ", ''', """)
- Raw strings (r"...", rf"...")
- F-strings with embedded expressions
- Unicode escape sequences
- Strings with backslashes and quotes mixed

### 4. black.trans.StringSplitter.do_transform() - HIGH
Import: black.trans.StringSplitter
Location: src/black/trans.py
Why: Most complex transformation logic. Handles line splitting for long strings.
Targets:
- Very long strings (>88 chars, >120 chars)
- F-strings with complex expressions
- Nested quotes in f-string expressions
- Multi-line strings

### 5. black.comments.normalize_fmt_off() - MEDIUM
Import: black.comments.normalize_fmt_off
Location: src/black/comments.py
Why: Processes # fmt: off/on directives that control formatting.
Targets:
- Code with fmt directives
- Nested and overlapping fmt blocks
- Fmt directives in unusual positions

## Fuzzing Strategy
- Use atheris for libFuzzer integration
- Start with valid Python code and mutate
- Test format_str() as main entry point
- Verify idempotency: format_str(format_str(x)) == format_str(x)
- Monitor for infinite loops and performance degradation
