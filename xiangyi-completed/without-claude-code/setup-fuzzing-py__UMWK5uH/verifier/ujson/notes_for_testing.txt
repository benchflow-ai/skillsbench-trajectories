# UltraJSON (ujson) Library Fuzz Testing Notes

## Library Overview
UltraJSON (ujson) is an ultra-fast JSON encoder and decoder written in C with Python bindings.
The library is designed for maximum performance in encoding/decoding JSON data. Note: Library
is in maintenance-only mode due to architectural constraints with security vulnerabilities.

## Dependencies
- No external Python dependencies at runtime
- Uses bundled double-conversion library for numeric conversion
- atheris (for fuzzing)

## Top Functions to Fuzz Test

### 1. ujson.loads() / ujson.decode() - CRITICAL
Import: ujson.loads or ujson.decode
Signature: loads(s: str | bytes | bytearray) -> Any
C Function: JSONToObj() in JSONtoObj.c
Why: Parses JSON strings into Python objects. Primary attack surface.
Targets:
- Multiple input types (str, bytes, bytearray)
- Malformed JSON structures
- Unicode handling and special characters
- Extreme numeric values (NaN, Infinity)
- Deeply nested structures (max depth 1024)
- Buffer overflow attempts
- Invalid escape sequences

### 2. ujson.dumps() / ujson.encode() - CRITICAL
Import: ujson.dumps or ujson.encode
Signature: encode(obj: Any, ensure_ascii: bool = True, encode_html_chars: bool = False,
                  escape_forward_slashes: bool = True, sort_keys: bool = False,
                  indent: int = 0, allow_nan: bool = True, reject_bytes: bool = True,
                  default: Callable | None = None, separators: tuple[str, str] | None = None) -> str
C Function: objToJSON() in objToJSON.c
Why: Encodes arbitrary Python objects to JSON strings. Tests serialization robustness.
Targets:
- Complex nested structures
- All encoding options combinations
- Special types (Decimal, custom __json__ methods)
- Recursion depth handling (max 1024 levels)
- Large inputs and various data types
- Special values (NaN, Infinity, -Infinity)

### 3. ujson.load() / ujson.dump() - HIGH
Import: ujson.load, ujson.dump
Signatures: dump(obj: Any, fp: SupportsWrite[str], ...) -> None
            load(fp: SupportsRead[str | bytes | bytearray]) -> Any
Why: File I/O operations with JSON data. Tests streaming/buffer handling.
Targets:
- File-like object handling
- Large files and streaming
- Truncated/malformed file input
- Error handling edge cases

### 4. Numeric Handling (Internal) - HIGH
Location: ultrajsondec.c, dconv_wrapper.cc
Why: Uses double-conversion library for numeric parsing. Edge cases in float handling.
Targets:
- Extreme float values
- Precision edge cases
- Integer overflow
- Scientific notation edge cases
- Boundary values

### 5. String Escape Handling (Internal) - MEDIUM-HIGH
Location: ultrajsonenc.c, ultrajsondec.c
Why: String encoding with special character handling, surrogate pair processing.
Targets:
- Unicode edge cases
- Surrogate pairs
- Invalid escape sequences
- HTML character escaping
- Forward slash escaping options

## Key Constants
- JSON_MAX_RECURSION_DEPTH: 1024
- JSON_MAX_STACK_BUFFER_SIZE: 1024 bytes

## Fuzzing Strategy
- Use atheris for libFuzzer integration
- Focus on ujson.loads() as primary target
- Test with various encoding option combinations
- Include edge cases from existing test suite
- Monitor for memory safety issues
- Test special values with allow_nan=True/False
