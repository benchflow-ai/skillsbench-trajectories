ujson - Ultra-fast JSON Encoder/Decoder Fuzzing Notes
====================================================

Key Functions for Fuzzing:
1. ujson.loads() - Parse JSON strings
2. ujson.dumps() - Serialize objects to JSON
3. ujson.encode() - Low-level encoding
4. ujson.decode() - Low-level decoding
5. Array/Object parsing - Recursive structure parsing
6. String escaping - Unicode and escape sequence handling

Testing Strategy:
- JSON parsing: malformed JSON, edge cases
- Number parsing: edge case numeric values, infinity, NaN
- String fuzzing: unicode, escape sequences, surrogates
- Nested structures: deeply nested arrays and objects
- Large inputs: memory and performance boundaries
- Invalid UTF-8: malformed byte sequences
- Type coercion: various Python types in dumps()

Dependencies:
- setuptools>=42
- setuptools_scm[toml]>=3.4 (for build)
