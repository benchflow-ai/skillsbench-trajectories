MiniSGL - Structured Generation Language Fuzzing Notes
======================================================

Key Functions for Fuzzing:
1. minisgl.sgl module - SGL program parsing and execution
2. minisgl.language - Language specification parsing
3. minisgl.execution - Program execution engine
4. minisgl.backends - LLM backend interfaces
5. minisgl.constraints - Constraint validation

Testing Strategy:
- Program syntax fuzzing: malformed SGL programs
- Variable binding fuzzing: edge case variable references
- Constraint fuzzing: invalid constraint specifications
- Backend communication: malformed LLM responses
- Token handling: invalid token counts and sequences
- State management: edge cases in execution state
