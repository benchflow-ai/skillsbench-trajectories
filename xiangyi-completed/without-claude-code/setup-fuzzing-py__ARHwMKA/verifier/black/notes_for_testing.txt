Black - Python Code Formatter Fuzzing Notes
=============================================

Key Functions for Fuzzing:
1. black.format_str() - Format Python code strings
2. black.format_file_in_place() - Format Python files
3. blib2to3.pytree parsing - Parse Python code into AST
4. black.lines.Line generation - Generate formatted lines
5. black.normalize_invisible_parens() - Parentheses normalization
6. black.comments module - Comment handling and preservation

Testing Strategy:
- Input fuzzing: malformed Python code, edge cases
- Syntax tree traversal: various AST structures
- Line wrapping: different line lengths and indent levels
- String handling: various string types (f-strings, raw, unicode)
- Comment preservation: edge case comment placements
- Special characters: unicode, escape sequences
