ARROW LIBRARY - FUZZ TESTING ANALYSIS
================================================================================

LIBRARY OVERVIEW
--------------------------------------------------------------------------------
Arrow is a Python library that provides a sensible, human-friendly approach to
creating, manipulating, formatting, and converting dates, times, and timestamps.
It serves as an enhanced replacement for Python's datetime module with better
API design, timezone handling, and human-readable output.

Key features:
- DateTime parsing from various string formats (ISO 8601, custom formats)
- Timezone-aware datetime operations
- Human-readable relative time formatting ("2 hours ago", "in 3 days")
- Dehumanization (parsing human-readable time strings back to datetime)
- Localization support for 60+ languages/dialects
- Format conversion and timestamp handling

================================================================================
KEY MODULES AND THEIR PURPOSES
================================================================================

1. arrow/arrow.py - Core Arrow class
   - Main Arrow datetime wrapper class
   - Provides enhanced datetime functionality
   - Contains: shift(), replace(), to(), format(), humanize(), dehumanize()
   - Key fuzzing targets: dehumanize(), strptime(), fromtimestamp()

2. arrow/parser.py - DateTime parsing engine
   - DateTimeParser class for parsing datetime strings
   - TzinfoParser class for parsing timezone strings
   - Contains complex regex-based parsing logic
   - PRIMARY FUZZING TARGET - handles all string input parsing

3. arrow/factory.py - ArrowFactory for object construction
   - Factory pattern for creating Arrow objects
   - get() method handles multiple input types
   - Delegates to parser for string inputs

4. arrow/formatter.py - DateTime formatting
   - DateTimeFormatter class for output formatting
   - Converts datetime to formatted strings
   - Lower priority for fuzzing (output, not input)

5. arrow/locales.py - Internationalization
   - 60+ locale definitions
   - Month/day names, ordinals, timeframes
   - get_locale() parses locale name strings
   - Secondary fuzzing target for locale name parsing

6. arrow/api.py - Module-level API
   - Convenience functions: get(), now(), utcnow()
   - Thin wrappers around ArrowFactory

7. arrow/util.py - Utility functions
   - is_timestamp(), normalize_timestamp(), validate_ordinal()
   - iso_to_gregorian() - ISO week date conversion

8. arrow/constants.py - Configuration constants
   - MAX_TIMESTAMP values, locale lists, defaults

HIGH PRIORITY - String Parsing Functions
--------------------------------------------------------------------------------

1. DateTimeParser.parse_iso(datetime_string, normalize_whitespace=False)
   Location: /app/arrow/arrow/parser.py
   Signature:
     def parse_iso(self, datetime_string: str, normalize_whitespace: bool = False) -> datetime

   Purpose: Parses ISO 8601-like datetime strings
   Input: Arbitrary datetime string
   Complexity: Complex regex parsing, multiple format attempts

   Example inputs to fuzz:
   - "2021-10-12T14:30:00"
   - "20160413T133656.456289"
   - "2021-10-12 14:30:00+05:00"
   - Invalid/malformed strings

2. DateTimeParser.parse(datetime_string, fmt, normalize_whitespace=False)
   Location: /app/arrow/arrow/parser.py
   Signature:
     def parse(self, datetime_string: str, fmt: Union[List[str], str],
               normalize_whitespace: bool = False) -> datetime

   Purpose: Parses datetime string using specified format
   Input: Datetime string + format string (both can be fuzzed)
   Complexity: Regex generation from format, token parsing

   Example inputs to fuzz:
   - datetime_string: "2021-10-12 14:30:00"
   - fmt: "YYYY-MM-DD HH:mm:ss" or ["MM/DD/YYYY", "YYYY-MM-DD"]

3. TzinfoParser.parse(tzinfo_string)
   Location: /app/arrow/arrow/parser.py
   Signature:
     @classmethod
     def parse(cls, tzinfo_string: str) -> dt_tzinfo

   Purpose: Parses timezone strings
   Input: Timezone expression (e.g., "US/Pacific", "+07:00", "UTC", "local")
   Complexity: Regex matching, ZoneInfo lookup

   Example inputs to fuzz:
   - "America/New_York"
   - "+05:30"
   - "Z"
   - Invalid timezone names

4. Arrow.dehumanize(input_string, locale="en_us")
   Location: /app/arrow/arrow/arrow.py
   Signature:
     def dehumanize(self, input_string: str, locale: str = "en_us") -> "Arrow"

   Purpose: Parses human-readable relative time strings
   Input: Strings like "2 days ago", "in 3 hours"
   Complexity: Locale-specific regex patterns, sign detection

   Example inputs to fuzz:
   - "2 days ago"
   - "in a month"
   - "5 seconds ago"
   - Mixed/malformed human time expressions

5. Arrow.strptime(date_str, fmt, tzinfo=None)
   Location: /app/arrow/arrow/arrow.py
   Signature:
     @classmethod
     def strptime(cls, date_str: str, fmt: str, tzinfo: Optional[TZ_EXPR] = None) -> "Arrow"

   Purpose: Parse date string using strptime format codes
   Input: Date string + format string

   Example inputs to fuzz:
   - date_str: "20-01-2019 15:49:10"

================================================================================
FUZZING RECOMMENDATIONS
================================================================================

1. PRIMARY TARGET: DateTimeParser.parse_iso()
   - Most complex parsing logic
   - Handles arbitrary datetime strings
   - Multiple regex patterns and format attempts
   - High likelihood of edge case bugs

2. SECONDARY TARGET: DateTimeParser.parse()
   - Custom format parsing
   - Both datetime_string and fmt can be fuzzed
   - Format string generates dynamic regex patterns

3. TERTIARY TARGET: TzinfoParser.parse()
   - Timezone string parsing
   - ZoneInfo lookups with potential exceptions

4. ADDITIONAL TARGETS:
   - Arrow.dehumanize() - locale-aware string parsing
   - ArrowFactory.get() - type-flexible input handling

Suggested Fuzz Input Categories:
- Empty strings
- Unicode characters
- Extremely long strings
- Malformed ISO 8601 dates
- Invalid timezone expressions
- Boundary timestamps (very old/future dates)
- Mixed format combinations
- Whitespace variations
- Special regex characters in inputs

import arrow
from arrow.parser import DateTimeParser, TzinfoParser

def fuzz_parse_iso(data: bytes):
    try:
        string = data.decode('utf-8')
        parser = DateTimeParser()
        parser.parse_iso(string)
    except (arrow.parser.ParserError, UnicodeDecodeError, ValueError):
        pass  # Expected exceptions

def fuzz_parse_with_format(data: bytes):
    try:
        parts = data.split(b'\x00', 1)
        if len(parts) == 2:
            string = parts[0].decode('utf-8')
            fmt = parts[1].decode('utf-8')
            parser = DateTimeParser()
            parser.parse(string, fmt)
    except (arrow.parser.ParserError, UnicodeDecodeError, ValueError, re.error):
        pass  # Expected exceptions

def fuzz_timezone_parse(data: bytes):
    try:
        string = data.decode('utf-8')
        TzinfoParser.parse(string)
    except (arrow.parser.ParserError, UnicodeDecodeError):
        pass  # Expected exceptions

def fuzz_dehumanize(data: bytes):
    try:
        string = data.decode('utf-8')
        arw = arrow.utcnow()
        arw.dehumanize(string)
    except (ValueError, UnicodeDecodeError):
        pass  # Expected exceptions

    try:
        string = data.decode('utf-8')
        arrow.get(string)
