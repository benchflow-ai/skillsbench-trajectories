LIBRARY OVERVIEW
================================================================================

IPython is an enhanced interactive Python shell providing:
- Rich interactive computing environment
- Magic commands (% and %%)
- System shell commands (! and !!)
- Help system (? and ??)
- Tab completion with static analysis
- Code transformations and input preprocessing
- History management
- Async/await support at the top level

Version: Requires Python >= 3.11

================================================================================
                              KEY MODULES
================================================================================

1. IPython/core/inputtransformer2.py
   ---------------------------------
   PURPOSE: Transform user input before execution. Handles IPython special
   syntax like %magic, !system, help?, and prompt stripping.

   Key classes:
   - TransformerManager: Main orchestrator for all transformations
   - PromptStripper: Remove input prompts (>>>, In [N]:, etc.)
   - MagicAssign: Transform "a = %magic" assignments
   - SystemAssign: Transform "a = !cmd" assignments
   - EscapedCommand: Handle %magic, !system, /paren, ,quote, ;quote2 escapes
   - HelpEnd: Handle obj? and obj?? help syntax

   Key functions:
   - make_tokens_by_line(lines): Tokenize lines and group by logical line
   - cell_magic(lines): Transform %%cellmagic syntax
   - _make_help_call(target, esc): Create help lookup call

2. IPython/core/prefilter.py
   --------------------------
   PURPOSE: Pre-filter user input lines. Legacy system for checkers/handlers.

   Key classes:
   - PrefilterManager: Main prefilter orchestrator
   - LineInfo: Parse and store info about a single input line
   - PrefilterChecker/PrefilterHandler: Check and handle specific patterns

   Key checkers:
   - MacroChecker, AutoMagicChecker, AutocallChecker, etc.

3. IPython/core/splitinput.py
   --------------------------
   PURPOSE: Split user input into components (whitespace, escape, function, rest)

   Key functions:
   - split_user_input(line, pattern=None): Split line using regex

   Key classes:
   - LineInfo: Store parsed line information

4. IPython/core/magic.py
   ----------------------
   PURPOSE: Magic function framework and registration

   Key classes:
   - MagicsManager: Manage all registered magics
   - Magics: Base class for magic implementations
   - MagicAlias: Alias one magic to another

   Key functions:
   - parse_options(arg_str, opt_str, *long_opts, **kw): Parse magic arguments

5. IPython/core/completer.py
   --------------------------
   PURPOSE: Tab completion system with multiple matchers

   Key classes:
   - Completer: Base completer class
   - IPCompleter: Full IPython completer with all matchers
   - CompletionSplitter: Split line for completion context

   Key functions:
   - rectify_completions(text, completions): Normalize completions

6. IPython/core/interactiveshell.py
   ---------------------------------
   PURPOSE: Main interactive shell - core of IPython

   Key methods:
   - run_cell(raw_cell, ...): Execute a complete cell
   - run_cell_async(raw_cell, ...): Async version
   - run_line_magic(magic_name, line): Execute line magic
   - run_cell_magic(magic_name, line, cell): Execute cell magic
   - transform_cell(raw_cell): Transform input before parsing
   - system(cmd): Execute system command
   - getoutput(cmd): Get output from system command
   - ex(cmd): Execute Python in user namespace
   - ev(expr): Evaluate Python expression

7. IPython/core/guarded_eval.py
   -----------------------------
   PURPOSE: Safe(r) evaluation for completions - guards against side effects

   Key functions:
   - guarded_eval(code, context): Evaluate with restrictions
   - eval_node(node, context): Evaluate AST node with policy

   Key classes:
   - EvaluationPolicy: Define what operations are allowed
   - EvaluationContext: Context for evaluation

8. IPython/core/compilerop.py
   ---------------------------
   PURPOSE: Compile code with caching for better tracebacks

   Key classes:
   - CachingCompiler: Compiler with code caching

   Key methods:
   - ast_parse(source, filename, symbol): Parse to AST
   - cache(transformed_code, number, raw_code): Cache code

9. IPython/core/alias.py
   ----------------------
   PURPOSE: System command aliases

   Key classes:
   - Alias: Callable representing an alias
   - AliasManager: Manage shell aliases

================================================================================
                         FUZZING STRATEGY NOTES
================================================================================

Entry Points for Fuzzing:
1. transform_cell() - Primary entry point for all input transformation
2. check_complete() - For incomplete input detection
3. run_cell() - For full execution path (if testing with mocked execution)
4. parse_options() - For magic argument parsing

Input Categories to Fuzz:
- Magic commands: %magic, %%cellmagic, mixed with Python
- System commands: !cmd, !!cmd, a=!cmd
- Help syntax: obj?, obj??, %magic?
- Escape characters: /, ,, ; at line start
- Prompts: >>>, In [N]:, ...:
- Continuations: backslash line continuations
- Unicode: identifiers, operators, string contents
- Nested constructs: magic inside strings, magic inside magic args
- Incomplete input: unterminated strings, parens, brackets

Edge Cases to Consider:
- Empty input
- Whitespace-only input
- Very long lines/cells
- Deep nesting
- Mixed line endings (\n, \r\n, \r)
- Null bytes and control characters
- Very long identifiers/magic names
- Recursive-looking patterns

Security-Relevant Areas:
- guarded_eval(): Ensure policy restrictions aren't bypassed
- system()/getoutput(): Command injection vectors
- Alias expansion: %s/%l specifier injection
