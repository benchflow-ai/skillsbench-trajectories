IPython Library - Testing Notes
================================

Library Purpose: Enhanced interactive Python shell with rich features

Key Functions for Fuzzing:
---------------------------

1. InteractiveShell.run_cell(raw_cell: str, store_history: bool, silent: bool) -> ExecutionResult
   - Executes IPython cell with code and magic commands
   - Inputs: Code string including %magic and !system commands
   - Test with: malicious commands, shell injection, magic syntax edge cases
   - Location: /app/ipython/IPython/core/interactiveshell.py:3084

2. InteractiveShell.run_cell_magic(magic_name: str, line: str, cell: str)
   - Executes cell magic commands (%%timeit, %%bash, etc.)
   - Inputs: Magic name, arguments, cell body
   - Test with: invalid magic names, malformed arguments
   - Location: /app/ipython/IPython/core/interactiveshell.py:2532

3. IPCompleter.complete(text: str, line_buffer: str, cursor_pos: int) -> Tuple
   - Generates code completions
   - Inputs: Text to complete, line context, cursor position
   - Test with: edge case cursor positions, unusual text patterns
   - Location: /app/ipython/IPython/core/completer.py:3482

4. display(*objs, include: list, exclude: list, metadata: dict)
   - Displays objects with rich formatting
   - Inputs: Python objects, MIME type filters, metadata
   - Test with: malformed MIME types, unusual objects
   - Location: /app/ipython/IPython/core/display_functions.py:85

5. pretty(obj, verbose: bool, max_width: int, max_seq_length: int) -> str
   - Returns pretty-printed string representation
   - Inputs: Any object, formatting parameters
   - Test with: deeply nested objects, circular references
   - Location: /app/ipython/IPython/lib/pretty.py:153

6. Inspector.pinfo(obj, oname: str, detail_level: int)
   - Displays detailed object information (introspection)
   - Inputs: Object to inspect, variable name, detail level
   - Test with: unusual objects, special methods
   - Location: /app/ipython/IPython/core/oinspect.py:813

Fuzzing Strategy:
-----------------
- Focus on run_cell and run_cell_magic for code execution paths
- Test completion with edge case inputs
- Test display/pretty printing with unusual object types
- Look for injection vulnerabilities in magic commands
- Test edge cases in introspection with special objects
