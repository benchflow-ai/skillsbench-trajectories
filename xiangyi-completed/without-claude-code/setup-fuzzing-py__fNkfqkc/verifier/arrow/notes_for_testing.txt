Arrow Library - Testing Notes
==============================

Library Purpose: Date/time manipulation library for Python with user-friendly API

Key Functions for Fuzzing:
---------------------------

1. arrow.get(*args, **kwargs) -> Arrow
   - Universal factory function accepting multiple input types
   - Inputs: timestamps, strings, datetime objects, tuples, format strings
   - Test with: malformed date strings, invalid formats, edge case timestamps
   - Location: /app/arrow/arrow/api.py

2. DateTimeParser.parse(datetime_string: str, fmt: Union[List[str], str]) -> datetime
   - Core parsing engine with custom format tokens (YYYY, MM, DD, HH, mm, ss, ZZ)
   - Inputs: date strings + format string/list
   - Test with: format string injection, invalid tokens, edge cases
   - Location: /app/arrow/arrow/parser.py

3. DateTimeParser.parse_iso(datetime_string: str) -> datetime
   - ISO 8601 format parser
   - Inputs: ISO-formatted datetime strings
   - Test with: malformed ISO strings, timezone variations
   - Location: /app/arrow/arrow/parser.py

4. Arrow.shift(**kwargs) -> Arrow
   - Relative time manipulation
   - Inputs: keyword args with time units (years, months, days, hours, etc.)
   - Test with: extreme values, invalid keys, DST transitions
   - Location: /app/arrow/arrow/arrow.py

5. Arrow.format(fmt: str, locale: str) -> str
   - String formatting with locale support
   - Inputs: format strings, locale identifiers
   - Test with: format string injection, invalid locales
   - Location: /app/arrow/arrow/arrow.py

6. Arrow.humanize(other: Union[Arrow, datetime, None], locale: str) -> str
   - Relative time formatting to human-readable strings
   - Inputs: datetime objects, locale strings
   - Test with: extreme date differences, invalid locales
   - Location: /app/arrow/arrow/arrow.py

Fuzzing Strategy:
-----------------
- Focus on string parsing functions (get, parse, parse_iso)
- Test format string injection and validation
- Test edge cases: leap seconds, DST transitions, timezone boundaries
- Test locale handling with various character encodings
