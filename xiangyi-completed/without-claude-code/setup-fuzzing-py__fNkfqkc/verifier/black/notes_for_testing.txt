Black Library - Testing Notes
==============================

Library Purpose: Python code formatter with opinionated style

Key Functions for Fuzzing:
---------------------------

1. format_str(src_contents: str, *, mode: Mode) -> str
   - Core formatting function - reformats Python code string
   - Inputs: Python code as string, Mode configuration
   - Test with: malformed Python, edge case syntax, deeply nested structures
   - Location: /app/black/src/black/__init__.py:1177

2. format_file_contents(src_contents: str, *, fast: bool, mode: Mode) -> FileContent
   - Reformats file contents with stability/equivalence checks
   - Inputs: File content string, configuration
   - Test with: syntactically valid but semantically unusual code
   - Location: /app/black/src/black/__init__.py:1068

3. format_cell(src: str, *, fast: bool, mode: Mode) -> str
   - Formats Jupyter notebook cells with IPython magic support
   - Inputs: Cell source code with potential magic commands
   - Test with: various magic syntaxes, edge cases with semicolons
   - Location: /app/black/src/black/__init__.py:1096

4. lib2to3_parse(src_txt: str, target_versions: Collection[TargetVersion]) -> Node
   - Parses Python source into AST
   - Inputs: Source code string, target Python versions
   - Test with: invalid syntax, version-specific features
   - Location: /app/black/src/black/parsing.py:55

5. parse_ast(src: str) -> ast.AST
   - Parse Python source using built-in ast module
   - Inputs: Source code string
   - Test with: edge case syntax, encoding issues
   - Location: /app/black/src/black/parsing.py:137

6. assert_equivalent(src: str, dst: str) -> None
   - Verifies AST equivalence between original and formatted code
   - Inputs: Two Python source strings
   - Test with: semantically different code, whitespace variations
   - Location: /app/black/src/black/__init__.py:1581

Fuzzing Strategy:
-----------------
- Focus on parsing functions (lib2to3_parse, parse_ast)
- Test format_str with valid but unusual Python syntax
- Test edge cases: very long lines, deep nesting, complex expressions
- Test mode configurations with various Python versions
- Test for crashes/hangs on pathological inputs
