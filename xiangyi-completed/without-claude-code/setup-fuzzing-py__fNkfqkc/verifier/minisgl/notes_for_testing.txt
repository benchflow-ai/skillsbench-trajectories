MiniSGL Library - Testing Notes
================================

Library Purpose: SGLang runtime library for LLM inference and serving

Key Functions for Fuzzing:
---------------------------

1. TokenizeManager.tokenize(msgs: List[TokenizeMsg]) -> List[torch.Tensor]
   - Batch tokenizes text messages into token ID tensors
   - Inputs: List of messages with text (str or chat format), UIDs, sampling params
   - Test with: malformed text, unusual Unicode, extreme lengths
   - Location: /app/minisgl/python/minisgl/tokenizer/tokenize.py

2. DetokenizeManager.detokenize(msgs: List[DetokenizeMsg]) -> List[str]
   - Batch detokenizes token sequences into strings
   - Inputs: List of messages with UIDs, token IDs, finished flags
   - Test with: invalid token IDs, edge case sequences
   - Location: /app/minisgl/python/minisgl/tokenizer/detokenize.py

3. find_printable_text(text: str) -> str
   - Extracts longest printable substring respecting word boundaries
   - Inputs: Text that may contain incomplete words/tokens
   - Test with: CJK characters, emoji, control characters, mixed encodings
   - Location: /app/minisgl/python/minisgl/tokenizer/detokenize.py

4. _is_chinese_char(cp: int) -> bool
   - Checks if Unicode codepoint is CJK character
   - Inputs: Unicode codepoint (integer)
   - Test with: edge case codepoints, invalid values
   - Location: /app/minisgl/python/minisgl/tokenizer/detokenize.py

5. serialize_type(obj) -> Dict
   - Serializes objects including tensors to dictionaries
   - Inputs: Any object with __dict__ or torch.Tensor
   - Test with: circular references, unusual object types
   - Location: /app/minisgl/python/minisgl/message/utils.py

6. deserialize_type(cls_map: Dict, data: Dict) -> Any
   - Deserializes dictionaries back to objects
   - Inputs: Class mapping and serialized data dict
   - Test with: malformed data, type confusion, missing fields
   - Location: /app/minisgl/python/minisgl/message/utils.py

Fuzzing Strategy:
-----------------
- Focus on tokenization/detokenization with unusual text inputs
- Test text processing with various Unicode categories
- Test serialization with edge case objects and circular references
- Test CJK character detection with boundary codepoints
- Look for crashes with malformed input structures
