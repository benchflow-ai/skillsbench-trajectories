# Build Failure Analysis for google/auto

## Repository Location
/home/travis/build/failed/google/auto

## Build Error Summary
All submodules (common, service, factory, value) fail with the same error:
```
Could not find artifact com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar
```

## Root Cause
The project was designed for Java 6/7/8 where `tools.jar` was a separate file in the JDK.
In Java 9+, `tools.jar` was merged into the JDK core modules and no longer exists as a separate file.

The error originates from:
1. The `compile-testing` dependency (versions 0.6, 0.7, 0.8) used in test scope
2. This library has a system-scoped dependency on `com.sun:tools` with `systemPath=${toolsjar}`
3. The parent POM (`pom.xml`) defines profiles that set `toolsjar` to `${java.home}/../lib/tools.jar`
4. On Java 11, this path doesn't exist because `tools.jar` was removed

Additional issues discovered during fix:
5. `javax.annotation.Generated` class was moved in Java 9+ - factory and value modules use this
6. `truth` library version needs to be updated to match `compile-testing` 0.18 requirements
7. Test code in common module uses deprecated Truth API (`hasMessage` -> `hasMessageThat().isEqualTo`)

## Affected Files
- /home/travis/build/failed/google/auto/pom.xml (parent POM with profiles)
- /home/travis/build/failed/google/auto/common/pom.xml (uses compile-testing 0.7, truth 0.25)
- /home/travis/build/failed/google/auto/service/pom.xml (uses compile-testing 0.6, truth 0.24)
- /home/travis/build/failed/google/auto/factory/pom.xml (uses compile-testing 0.8, truth 0.25)

- /home/travis/build/failed/google/auto/common/src/test/java/com/google/auto/common/AnnotationMirrorsTest.java

## Solution Applied
1. Updated parent POM (pom.xml):
   - Changed Java version from 1.6 to 1.8
   - Added Java 9+ profile with empty toolsjar property

2. Updated compile-testing versions in all child POMs:
   - common/pom.xml: 0.7 -> 0.18
   - service/pom.xml: 0.6 -> 0.18
   - factory/pom.xml: 0.8 -> 0.18
   - value/pom.xml: 0.6 -> 0.18

3. Updated truth versions to match compile-testing 0.18 requirements:
   - common/pom.xml: 0.25 -> 0.44
   - service/pom.xml: 0.24 -> 0.44
   - factory/pom.xml: 0.25 -> 0.44
   - value/pom.xml: 0.25 -> 0.44

4. Added javax.annotation-api dependency for Java 9+ compatibility:
   - factory/pom.xml: added javax.annotation-api 1.3.2
   - value/pom.xml: added javax.annotation-api 1.3.2

5. Fixed test code for new Truth API:
   - AnnotationMirrorsTest.java: hasMessage() -> hasMessageThat().isEqualTo()
