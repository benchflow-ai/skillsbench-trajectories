# Black Library - Fuzz Testing Notes

## Library Overview
Black is a Python code formatter that reformats Python source code to ensure consistent style.
It parses Python code into AST and reformats it according to style rules.

## Critical Functions for Fuzz Testing

### TIER 1 - CRITICAL (Core Formatting)

1. format_str(src_contents, mode) - Main formatting function
   - Module: black.__init__.format_str
   - Input: Python source code string
   - Fuzz: Arbitrary Python code, malformed code, edge cases

2. lib2to3_parse(src_txt, target_versions) - Python AST parsing
   - Module: black.parsing.lib2to3_parse
   - Input: Python source code string
   - Fuzz: Malformed Python, syntax edge cases

3. format_file_contents(src_contents, mode) - Full pipeline
   - Module: black.__init__.format_file_contents
   - Input: File contents string
   - Fuzz: Various Python code patterns

### TIER 2 - HIGH PRIORITY (Key Features)

4. normalize_string_quotes(leaf) - String normalization
   - Module: black.strings.normalize_string_quotes
   - Input: String literal
   - Fuzz: Various quote styles, escape sequences

5. format_cell(src, mode) - Jupyter notebook cell formatting
   - Module: black.__init__.format_cell
   - Input: Jupyter cell code string

6. format_ipynb_string(src_contents, mode) - Jupyter notebook formatting
   - Module: black.__init__.format_ipynb_string
   - Input: JSON notebook string

7. parse_line_ranges(ranges) - Line range parsing
   - Module: black.ranges.parse_line_ranges
   - Input: Sequence of range strings like "1-10"

8. parse_ast(src, filename) - Standard AST parsing
   - Module: black.parsing.parse_ast
   - Input: Python source code string

### TIER 3 - MEDIUM PRIORITY (Supporting Functions)

9. normalize_numeric_literal(leaf) - Numeric literal formatting
   - Module: black.numerics.normalize_numeric_literal
   - Input: Numeric token

10. validate_cell(src) - Notebook cell validation
    - Module: black.handle_ipynb_magics.validate_cell
    - Input: Cell code string

11. assert_equivalent(src, dst) - AST equivalence checking
    - Module: black.__init__.assert_equivalent
    - Input: Two Python source strings

12. normalize_string_prefix(s) - String prefix normalization
    - Module: black.strings.normalize_string_prefix

## Key Input Categories for Fuzzing

### String Inputs:
- Triple-quoted strings
- Raw strings (r"...")
- F-strings (f"...")
- Byte strings (b"...")
- Unicode escapes
- Mixed prefixes (rf"...", br"...")

### Numeric Inputs:
- Hexadecimal numbers
- Scientific notation
- Complex numbers
- Underscores in numbers

### Python Syntax:
- Various Python versions (3.3-3.14)
- New features (match, walrus operator, etc.)
- Deeply nested structures
- Long lines

### Comments:
- fmt: off/on directives
- Type comments
- Docstrings

## Edge Cases to Focus On:
- Empty strings
- Only whitespace
- Deeply nested code
- Very long lines
- Invalid Python syntax
- Unicode identifiers
- Special characters in strings
- Mixed indentation (tabs/spaces)
