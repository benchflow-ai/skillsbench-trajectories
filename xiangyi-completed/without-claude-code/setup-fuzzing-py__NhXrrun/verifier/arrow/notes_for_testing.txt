# Arrow Library - Fuzz Testing Notes

## Library Overview
Arrow is a Python library for date/time manipulation that provides a user-friendly wrapper around Python's datetime.
It parses various date/time string formats, handles timezones, and supports humanization of time differences.

## Critical Functions for Fuzz Testing

### TIER 1 - CRITICAL (Highest Priority)

1. arrow.get(string) - Main entry point, most flexible input, auto-detection
   - Module: arrow.factory.ArrowFactory.get
   - Input: Mixed types (str, int, float, datetime, date, tzinfo, tuple)
   - Fuzz: Arbitrary strings for ISO parsing

2. arrow.parser.DateTimeParser.parse_iso(string) - Complex regex-based parsing
   - Module: arrow.parser.DateTimeParser.parse_iso
   - Input: String (datetime string)
   - Fuzz: Malformed ISO dates, edge cases

3. arrow.parser.DateTimeParser.parse(string, format_string) - Format string parsing
   - Module: arrow.parser.DateTimeParser.parse
   - Input: String (datetime) + String (format)
   - Fuzz: Both parameters with arbitrary strings

4. arrow.parser.TzinfoParser.parse(timezone_string) - Timezone parsing
   - Module: arrow.parser.TzinfoParser.parse
   - Input: String (timezone expression: 'UTC', 'local', '+HH:MM', timezone names)
   - Fuzz: Invalid timezone strings, malformed offsets

### TIER 2 - HIGH PRIORITY

5. Arrow.strptime(string, format) - Python strptime wrapper
   - Input: datetime string + format string

6. Arrow.dehumanize(humanized_string) - Natural language parsing
   - Input: String like "2 days ago", "in 5 seconds"
   - Uses regex, locale-aware

7. Arrow.fromtimestamp(timestamp_value) - Timestamp parsing
   - Input: int/float/str timestamp

8. Arrow.format(format_string) - Format string processing
   - Input: Custom format strings

### TIER 3 - MEDIUM PRIORITY

9. Arrow.span(frame_string) - Time span with bounds validation
10. Arrow.range(frame_string) - Range generation
11. arrow.util functions - Boundary and ordinal validation
12. Arrow.to(timezone_expression) - Timezone conversion

## Key Input Categories for Fuzzing

### String Parameters:
- Datetime strings (various formats)
- Format strings (YYYY, MM, DD, HH, mm, ss, S, Z, ZZ, etc.)
- Timezone names and offsets
- Humanized time expressions
- Locale strings
- Bounds strings ('()', '(]', '[)', '[]')

### Numeric Parameters:
- Timestamps (integers and floats)
- Ordinal values
- Week numbers
- Day values

## Edge Cases to Focus On:
- Empty strings
- Very long strings
- Special characters and Unicode
- Invalid timezone names
- Malformed timestamps
- Out-of-range date values
- DST boundary times
- Leap year/month edge cases
- Format string injection attempts
- Locale-specific month/day names
