# IPython Library - Fuzz Testing Notes

## Library Overview
IPython is an enhanced interactive Python shell with features like magic commands,
input transformation, code completion, and object introspection.

## Critical Functions for Fuzz Testing

### TIER 1 - CRITICAL (Input Transformation & Execution)

1. transform_cell(raw_cell) - Full transformation pipeline
   - Module: IPython.core.interactiveshell.InteractiveShell.transform_cell
   - Input: Raw cell code string
   - Fuzz: Magic syntax, system commands, help syntax

2. run_cell(raw_cell, store_history, silent, shell_futures, cell_id)
   - Module: IPython.core.interactiveshell.InteractiveShell.run_cell
   - Input: Raw Python code + magic commands
   - Fuzz: Arbitrary code, magic combinations

3. guarded_eval(code, context) - Safe expression evaluation
   - Module: IPython.core.guarded_eval.guarded_eval
   - Input: Python expression string
   - Security-critical evaluation for completion

4. TransformerManager.transform_cell(cell) - Core transformation
   - Module: IPython.core.inputtransformer2.TransformerManager.transform_cell
   - Input: Code lines
   - Handles: %magic, %%cell_magic, !system, ?help, ??source

### TIER 2 - HIGH PRIORITY (Magic Commands)

5. run_line_magic(magic_name, line) - Line magic execution
   - Module: IPython.core.interactiveshell.InteractiveShell.run_line_magic
   - Input: Magic name + arguments

6. run_cell_magic(magic_name, line, cell) - Cell magic execution
   - Module: IPython.core.interactiveshell.InteractiveShell.run_cell_magic
   - Input: Magic name + header + body

7. var_expand(cmd, depth) - Variable expansion
   - Module: IPython.core.interactiveshell.InteractiveShell.var_expand
   - Input: Command string with $var syntax
   - Format string-like expansion

8. parse_argstring(magic_func, argstring) - Magic argument parsing
   - Module: IPython.core.magic_arguments.parse_argstring
   - Input: Argument string
   - Uses shlex parsing

9. extract_code_ranges(ranges_str) - Code range parsing
   - Module: IPython.core.magics.code.extract_code_ranges
   - Input: Range specification like "1-10, 20, 30-40"

### TIER 3 - MEDIUM PRIORITY (Completion & Utilities)

10. IPCompleter.complete(text, state) - Code completion
    - Module: IPython.core.completer.IPCompleter.complete
    - Input: Partial code string + position

11. pretty(obj, verbose, max_width, newline, max_seq_length)
    - Module: IPython.lib.pretty.pretty
    - Input: Any Python object
    - Handles recursive structures

12. sx(line, cell) - Shell command execution
    - Module: IPython.core.magics.osm.OSMagics.sx
    - Input: Shell command string

13. has_open_quotes(s) - Quote detection
    - Module: IPython.core.completer.has_open_quotes
    - Input: Code string

14. token_at_cursor(cell, cursor_pos) - Token extraction
    - Module: IPython.utils.tokenutil.token_at_cursor
    - Input: Cell code + position

## Key Input Categories for Fuzzing

### Magic Syntax:
- Line magics: %magic arg1 arg2
- Cell magics: %%magic\ncode
- Magic assignment: x = %magic
- Combined: x = !shell_command
- Help: obj?, obj??

### System Commands:
- !command
- !!command (capture output)
- System command escaping

### Variable Expansion:
- $var, ${var}
- Nested expansions
- Invalid variable names

### Code Transformation:
- Partial statements
- Multi-line strings
- Escape characters
- Unicode identifiers

## Edge Cases to Focus On:
- Empty strings
- Only whitespace
- Unclosed quotes/brackets
- Deeply nested magic combinations
- Invalid magic names
- Shell injection attempts
- Unicode in commands
- Very long input
- Circular object references (for pretty printing)
