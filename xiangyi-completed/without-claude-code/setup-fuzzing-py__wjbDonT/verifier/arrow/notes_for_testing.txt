ARROW - Date/Time Parsing and Manipulation Library

Key Functions for Fuzzing:
1. arrow.get() - Main entry point that parses strings to Arrow objects
   - Takes strings, dates, datetimes, timestamps as input
   - Accepts format strings for parsing
   - Handles multiple input types
   - CRITICAL: Parser can throw ParserError on invalid input

2. Arrow.parse() - Parses date strings with format strings
   - Takes input string and format string
   - Can fail with ParserError

3. DateTimeParser.parse() - Low-level parser
   - Parses datetime strings with regex patterns
   - Handles multiple date formats (RFC2822, RFC3339, etc.)
   - Locale-aware parsing

4. Arrow.format() - Formats Arrow objects to strings
   - Takes format strings
   - Returns formatted date strings

5. Arrow methods: shift, replace, clone - Datetime manipulation
   - Modify datetime components

Fuzzing Strategy:
- Focus on arrow.get() with various string inputs
- Test with special characters, unicode, edge cases
- Test with malformed date strings
- Test timezone-aware strings
- Test with extreme dates
- Test locale-specific parsing
