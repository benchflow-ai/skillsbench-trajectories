UJSON - Ultra Fast JSON Encoder/Decoder (C Extension)

Key Functions for Fuzzing:
1. ujson.loads() - JSON string to Python object
   - Parses JSON strings
   - Can raise JSONDecodeError
   - Must handle invalid JSON

2. ujson.dumps() - Python object to JSON string
   - Serializes Python objects to JSON
   - Handles various data types
   - Can raise TypeError

3. ujson.decode() - Alternative decoder
   - Similar to loads()

4. ujson.encode() - Alternative encoder
   - Similar to dumps()

Fuzzing Strategy:
- Focus on ujson.loads() with malformed JSON
- Test with invalid JSON syntax
- Test with extreme nesting depth
- Test with very large numbers
- Test with unicode and special characters
- Test with control characters
- Test ujson.dumps() with various Python types
- Test with circular references
- Test with extremely large strings
- Edge cases: empty input, whitespace-only, null bytes
