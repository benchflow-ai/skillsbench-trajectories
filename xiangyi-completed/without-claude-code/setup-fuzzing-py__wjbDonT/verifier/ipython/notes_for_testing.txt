IPython - Interactive Python Shell

Key Functions for Fuzzing:
1. IPython.get_ipython() - Get IPython instance
   - Initializes IPython kernel

2. IPython.embed() - Embed interactive shell in code
   - Can be called with user_ns, header, etc.

3. InputSplitter - Parse Python input
   - Handles multi-line input
   - Detects continuation lines

4. IPython.core.interactiveshell - Main interpreter
   - run_cell() - Execute code cells
   - push() - Push variables

5. Syntax validation and AST parsing
   - Parses user input for validity

Fuzzing Strategy:
- Focus on InputSplitter with various code inputs
- Test with incomplete code
- Test with invalid syntax
- Test with magic commands (%magic, !shell)
- Test with special characters and unicode
- Test with extremely long inputs
- Test multiline input handling
