MiniSGL - Small Graph Language/LLM Framework

Key Functions for Fuzzing:
1. minisgl.core - Core framework functions
   - Message handling and routing
   - Model inference

2. minisgl.tokenizer - Tokenization
   - Token encoding/decoding
   - May use external tokenizers

3. minisgl.kernel - Kernel operations
   - Graph execution
   - Model operations

4. minisgl.utils - Utility functions
   - Logging, misc utilities
   - HuggingFace utilities

5. minisgl.engine - Execution engine
   - Pipeline execution
   - Message passing

Fuzzing Strategy:
- Focus on message parsing and handling
- Test with malformed JSON/MessagePack data
- Test tokenizer with various inputs
- Test kernel with various graph definitions
- Test with extreme values in parameters
- Test with unicode and special characters
- Test edge cases in data processing
