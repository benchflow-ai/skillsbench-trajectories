BLACK - Python Code Formatter

Key Functions for Fuzzing:
1. black.format_str() - Main formatting function
   - Takes Python code as string
   - Returns formatted code string
   - Can raise SyntaxError or NothingChanged

2. black.lib2to3_parse() - Parse Python code into AST
   - Uses lib2to3 parser
   - Can raise SyntaxError

3. black.generate_ignored_nodes() - Identifies ignored code sections
   - Processes AST nodes

4. black.get_features_used() - Analyzes code features
   - Detects Python version requirements

5. black.lines module - Line handling and formatting
   - Complex line formatting logic

Fuzzing Strategy:
- Focus on format_str() with various Python code inputs
- Test with syntactically invalid Python
- Test with edge cases: empty strings, very long lines
- Test with unicode and special characters
- Test with nested structures
- Test with comments and docstrings
- Test edge cases in code formatting
