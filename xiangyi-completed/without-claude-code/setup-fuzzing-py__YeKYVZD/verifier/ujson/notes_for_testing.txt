UJSON LIBRARY - TESTING NOTES
==============================

Library Overview:
- UltraJSON is a fast JSON encoder/decoder written in C with Python bindings
- Main functionality: JSON encoding (dumps) and decoding (loads)

Key Functions to Fuzz:
1. ujson.loads() - Parse JSON strings to Python objects
2. ujson.dumps() - Encode Python objects to JSON strings
3. ujson.decode() - Alternative decoding function
4. ujson.encode() - Alternative encoding function

Critical Attack Surfaces:
- JSON string parsing - buffer overflows, malformed JSON
- Numeric parsing - integer overflow, float precision
- String encoding/decoding - Unicode handling, escape sequences
- Nested structure handling - stack overflow with deep nesting

High-Value Fuzzing Targets:
1. ujson.loads(json_string)
   - Malformed JSON (missing quotes, braces, commas)
   - Deeply nested objects/arrays (>1000 levels)
   - Very large numbers (beyond int64 range)
   - Invalid escape sequences
   - Unicode edge cases (surrogates, null bytes)
   - Empty strings, null values

2. ujson.dumps(python_object)
   - Circular references
   - Very large objects
   - Special numeric values (inf, -inf, nan)
   - Non-serializable types

3. Edge cases:
   - Strings with embedded nulls
   - Control characters in strings
   - Very long strings (>1MB)
   - Mixed encoding issues

Expected Input Types:
- JSON strings (for loads)
- Python objects (dict, list, str, int, float, bool, None)
- Options: encode_html_chars, ensure_ascii, etc.

Fuzzing Strategy:
- Focus heavily on ujson.loads() - most critical for security
- Test boundary conditions for numbers
- Test deep nesting (recursion limits)
- Test invalid UTF-8 sequences
- Test escape sequence handling
- Test large inputs (DoS potential)

Known Issues to Test:
- Buffer overflow vulnerabilities (historical issues)
- Integer overflow in numeric parsing
- Stack overflow with deep nesting
