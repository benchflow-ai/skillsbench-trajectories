MINISGL LIBRARY - TESTING NOTES
================================

Library Overview:
- Mini-SGLang is a lightweight LLM inference framework
- Main functionality: model loading, inference, scheduling

Key Functions to Fuzz:
1. Config parsing - YAML/JSON configuration loading
2. Engine initialization - model and tokenizer setup
3. Request handling - input processing and validation
4. Graph operations - computational graph manipulation

Critical Attack Surfaces:
- Configuration file parsing (engine/config.py) - potential injection
- Input tokenization - handling of various text inputs
- Sampling logic (engine/sample.py) - numerical edge cases
- Graph construction (engine/graph.py) - structure validation

High-Value Fuzzing Targets:
1. Configuration parsing (minisgl.engine.config)
   - Malformed YAML/JSON
   - Invalid parameter values
   - Type confusion

2. Engine.generate() - Text generation
   - Unusual input strings
   - Very long inputs
   - Special tokens

3. Graph operations
   - Invalid graph structures
   - Circular dependencies

Expected Input Types:
- Text prompts (strings)
- Configuration dictionaries/files
- Model parameters (floats, ints)
- Tokenizer inputs

Fuzzing Strategy:
- Focus on config parsing and validation
- Test input handling with various encodings
- Test numerical parameters with edge values (NaN, inf, very large)
- Test string inputs with control characters
- Test graph construction with invalid structures
