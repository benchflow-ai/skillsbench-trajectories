BLACK LIBRARY - TESTING NOTES
==============================

Library Overview:
- Black is a Python code formatter
- Main functionality: parsing Python code and reformatting it

Key Functions to Fuzz:
1. black.format_str() - Format Python code from string
2. black.lib2to3_parse() - Parse Python source code to AST
3. black.format_file_contents() - Main formatting logic
4. black.decode_bytes() - Encoding detection and decoding

Critical Attack Surfaces:
- Python code parsing (black/parsing.py) - lib2to3 parser
- AST manipulation - tree transformations
- String encoding/decoding - potential encoding issues
- Regex patterns - format validation

High-Value Fuzzing Targets:
1. black.format_str(src_contents, mode=Mode())
   - Test with malformed Python code
   - Test with deeply nested structures
   - Test with unusual whitespace/encodings

2. black.lib2to3_parse(src_txt)
   - Invalid Python syntax
   - Edge cases in grammar
   - Very large source files

3. black.decode_bytes()
   - Various encodings
   - Malformed byte sequences
   - BOM markers

Expected Input Types:
- Python source code (strings/bytes)
- Configuration objects (Mode)
- File paths
- Encoding names

Fuzzing Strategy:
- Focus on format_str() and parse functions
- Test syntactically invalid Python code
- Test edge cases: very long lines, deep nesting
- Test encoding issues
- Test special Python features (f-strings, async, pattern matching)
