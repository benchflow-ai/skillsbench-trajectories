Library: UltraJSON (ujson) - Ultra Fast JSON Encoder/Decoder
===============================================================

Description:
UltraJSON is an ultra-fast JSON encoder and decoder written in C with Python bindings.
It provides drop-in replacement for Python's standard json module with much better
performance.

Key Modules and Functions for Fuzzing:
---------------------------------------

1. ujson.loads() - JSON string to Python object
   - Main decoding function
   - Parses JSON strings into Python objects
   - HIGHLY FUZZABLE: Complex parsing with edge cases

2. ujson.dumps() - Python object to JSON string
   - Main encoding function
   - Serializes Python objects to JSON
   - FUZZABLE: Object serialization edge cases

3. ujson.decode() - Alias for loads()
   - HIGHLY FUZZABLE: JSON parsing

4. ujson.encode() - Alias for dumps()
   - FUZZABLE: Object encoding

Fuzzing Targets:
----------------
Priority 1: ujson.loads() - JSON parsing is critical security surface
   - Malformed JSON
   - Deeply nested structures
   - Large numbers
   - Unicode edge cases
   - Escape sequences

Priority 2: ujson.dumps() - Encoding edge cases
   - Circular references (should fail gracefully)
   - Special float values (NaN, Inf)
   - Large integers
   - Unusual Unicode

Input Types to Fuzz:
--------------------
For loads():
- Malformed JSON syntax
- Deeply nested objects/arrays
- Very long strings
- Invalid UTF-8 sequences
- Escape sequence edge cases
- Large numeric values
- Truncated input
- Mixed/invalid tokens

For dumps():
- Circular data structures
- Special numeric values
- Large dictionaries
- Complex nested structures
- Objects with custom __repr__
- Non-serializable types

Notes:
------
The README warns that UltraJSON has security vulnerabilities in its architecture.
This makes it an EXCELLENT fuzzing target to find buffer overflows and other
memory safety issues.
