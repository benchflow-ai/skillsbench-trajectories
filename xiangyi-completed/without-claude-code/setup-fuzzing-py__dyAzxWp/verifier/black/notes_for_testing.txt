Library: Black - The Uncompromising Python Code Formatter
===========================================================

Description:
Black is a Python code formatter that automatically formats Python code to conform to
a consistent style. It parses Python source code and reformats it.

Key Modules and Functions for Fuzzing:
---------------------------------------

1. black.format_str() (src/black/__init__.py)
   - Main entry point for formatting Python code as string
   - Takes source code string and mode parameters
   - HIGHLY FUZZABLE: Arbitrary Python code input

2. black.parsing (src/black/parsing.py)
   - lib2to3_parse() - parses Python source using lib2to3
   - parse_ast() - parses to AST
   - FUZZABLE: Source code parsing

3. black.format_file_contents() (src/black/__init__.py)
   - Reformats file contents
   - Includes validation and safety checks
   - HIGHLY FUZZABLE: Complex code transformations

4. black.decode_bytes() (src/black/__init__.py)
   - Decodes bytes with encoding detection
   - Handles different newline types
   - FUZZABLE: Encoding edge cases

5. black.format_ipynb_string() (src/black/__init__.py)
   - Formats Jupyter notebook cells
   - JSON parsing + code formatting
   - FUZZABLE: Combined JSON and Python parsing

6. black.validate_regex() (src/black/__init__.py)
   - Validates and compiles regex patterns
   - FUZZABLE: Regex patterns

Fuzzing Targets:
----------------
Priority 1: format_str() - accepts arbitrary Python source code
Priority 2: format_ipynb_string() - JSON + code parsing
Priority 3: lib2to3_parse() - parser with complex grammar
Priority 4: decode_bytes() - encoding edge cases

Input Types to Fuzz:
--------------------
- Malformed Python syntax
- Deeply nested structures
- Very long lines
- Invalid Unicode/encoding
- Malformed Jupyter notebook JSON
- Edge case AST structures
- Mixed newline types (CRLF, LF, CR)
