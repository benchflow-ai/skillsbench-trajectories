Library: Mini-SGLang - Lightweight LLM Inference Framework
==========================================================

Description:
Mini-SGLang is a compact implementation of SGLang, a high-performance inference
framework for Large Language Models. It's optimized for serving LLM requests with
advanced caching and scheduling.

Key Modules and Functions for Fuzzing:
---------------------------------------

1. minisgl.engine.engine (python/minisgl/engine/engine.py)
   - Main engine for request handling
   - Request processing and scheduling
   - FUZZABLE: Request parsing and validation

2. minisgl.engine.config (python/minisgl/engine/config.py)
   - Configuration parsing
   - Parameter validation
   - FUZZABLE: Config input validation

3. minisgl.message (python/minisgl/message/)
   - Message serialization/deserialization
   - Protocol handling
   - FUZZABLE: Message parsing

4. minisgl.tokenizer (python/minisgl/tokenizer/)
   - Text tokenization
   - Input preprocessing
   - FUZZABLE: Text input handling

5. minisgl.server (python/minisgl/server/)
   - HTTP/API request handling
   - Input validation
   - FUZZABLE: API endpoint inputs

6. minisgl.utils (python/minisgl/utils/)
   - Utility functions for data processing
   - FUZZABLE: Data transformation functions

Fuzzing Targets:
----------------
Priority 1: Request/message parsing
Priority 2: Configuration validation
Priority 3: Tokenizer input handling
Priority 4: Server API inputs

Input Types to Fuzz:
--------------------
- Malformed JSON requests
- Invalid configuration parameters
- Extreme input lengths
- Special characters in text
- Invalid message formats
- Unusual API parameters
- Edge case numeric values
