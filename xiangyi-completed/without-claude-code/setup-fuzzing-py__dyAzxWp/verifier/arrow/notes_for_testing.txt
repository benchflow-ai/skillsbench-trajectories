Library: Arrow - Better dates & times for Python
================================================

Description:
Arrow is a Python library that offers a sensible and human-friendly approach to creating,
manipulating, formatting and converting dates, times and timestamps.

Key Modules and Functions for Fuzzing:
---------------------------------------

1. arrow.parser (arrow/arrow/parser.py)
   - DateTimeParser class - parses various date/time string formats
   - parse() method - main entry point for parsing strings
   - parse_iso() - parses ISO 8601 formatted strings
   - HIGHLY FUZZABLE: String parsing with complex format handling

2. arrow.factory (arrow/arrow/factory.py)
   - ArrowFactory.get() - creates Arrow instances from various inputs
   - Accepts strings, timestamps, datetime objects
   - FUZZABLE: Multiple input types and formats

3. arrow.formatter (arrow/arrow/formatter.py)
   - DateTimeFormatter.format() - formats Arrow objects to strings
   - Handles various format tokens
   - FUZZABLE: Format string processing

4. arrow.arrow (arrow/arrow/arrow.py)
   - Arrow class methods: replace(), shift(), humanize()
   - String representations and conversions
   - FUZZABLE: Date arithmetic and manipulation

Fuzzing Targets:
----------------
Priority 1: arrow.get() - accepts arbitrary string inputs for parsing
Priority 2: Arrow.humanize() - string formatting
Priority 3: DateTimeParser.parse() - complex string parsing logic
Priority 4: Arrow.replace() - parameter validation

Input Types to Fuzz:
--------------------
- Malformed date strings
- Invalid ISO 8601 formats
- Extreme timestamp values
- Invalid format strings
- Mixed encoding strings
- Very long strings
