# Build Failure Analysis for google/auto

## Repository: /home/travis/build/failed/google/auto

## Error 1: tools.jar not found

### Error Description
```
Could not find artifact com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar
```

### Root Cause
The project depends on `compile-testing` library (versions 0.6, 0.7, and 0.8 across different modules). These old versions have an unconditional system-scoped dependency on `com.sun:tools` which points to `tools.jar`.

In Java 8 and earlier, `tools.jar` was located at `$JAVA_HOME/lib/tools.jar` and contained the Java Compiler API and related classes. In Java 9+, this file was removed and its contents were moved into the `jdk.compiler` module.

The project is running on Java 11 where `tools.jar` does not exist, causing the dependency resolution to fail.

### Solution
Upgrade all `compile-testing` dependencies to version 0.18 or later. Starting from version 0.18, the `com.sun:tools` dependency is moved inside Maven profiles that are only activated when `tools.jar` actually exists.

## Error 2: javax.annotation.Generated not found

### Error Description
```
cannot find symbol
  symbol:   class Generated
  location: package javax.annotation
```

### Root Cause
The code uses `javax.annotation.Generated` annotation which was part of the JDK in Java 8, but was deprecated in Java 9 and removed in Java 11. In Java 9+, the annotation was moved to `javax.annotation.processing.Generated`.

### Solution
Add the `javax.annotation-api` dependency to modules that use `javax.annotation.Generated`:
- factory/pom.xml
- value/pom.xml

The `javax.annotation:javax.annotation-api` artifact provides the `javax.annotation.Generated` class for Java 9+.
