     4→
     5→LIBRARY DESCRIPTION
     6→-------------------
     7→IPython (Interactive Python) is an enhanced interactive Python shell that offers
     8→introspection, rich media, shell syntax, tab completion, and history. It is the
     9→kernel behind Jupyter notebooks and provides a command-line interface with
    10→advanced features like magic commands (%command), system shell access (!command),
    11→help queries (?object), and sophisticated code completion.
    12→
    13→The library processes untrusted user input in many forms - code cells, magic
    14→commands, special syntax, and various escape sequences - making it an excellent
    15→candidate for fuzz testing to discover parsing bugs, crashes, and potential
    16→security vulnerabilities.
    17→

    23→1. IPython.core.inputtransformer2.TransformerManager.transform_cell()
    24→--------------------------------------------------------------------------------
    25→Module Path: IPython/core/inputtransformer2.py
    26→Function: TransformerManager.transform_cell(cell: str) -> str
    27→
    28→INPUT TYPE: String (arbitrary Python code with IPython special syntax)
    29→
    30→DESCRIPTION:
    31→The primary entry point for transforming IPython input cells into valid Python
    32→code. This function handles all IPython special syntax including:
    33→- Magic commands (%magic, %%cellmagic)
    34→- System shell commands (!command, !!command)
    35→- Help queries (?object, object?, object??)
    36→- Auto-quoting (,func args -> func("args"))
    37→- Auto-parenthesis (/func args -> func(args))
    38→- Prompt stripping (>>> and In[1]: style prompts)
    39→
    40→WHY FUZZ:
    41→This is the MOST CRITICAL function to fuzz test. It:
    42→- Processes arbitrary user input
    43→- Uses complex regex patterns and tokenization
    44→- Has nested transformation loops with a 500-iteration limit
    45→- Converts special syntax to Python AST calls
    46→- Could have edge cases with malformed escape sequences, unterminated strings,
    47→  deeply nested brackets, or unusual Unicode characters
