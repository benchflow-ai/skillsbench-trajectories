BLACK CODE FORMATTER - FUZZING ANALYSIS
================================================================================

LIBRARY DESCRIPTION
-------------------
Black is "The Uncompromising Code Formatter" for Python. It automatically
reformats Python source code to conform to a consistent style, making code
review faster by producing the smallest diffs possible. The library parses
Python source code, builds an abstract syntax tree, and regenerates the code
with consistent formatting.

Key components:
- Custom Python parser (blib2to3) - a fork of lib2to3 with modern Python support
- Tokenizer using pytokens library
- Line generation and transformation pipeline
- String processing and normalization
- Jupyter notebook (.ipynb) support
- IPython magic command handling

================================================================================
INPUT GENERATION STRATEGIES
================================================================================

For parsing/formatting functions:
- Valid Python code with edge cases (deeply nested, long lines, unusual syntax)
- Invalid Python code (syntax errors at various points)
- Code using all Python version features (f-strings, match statements, etc.)
- Unicode in identifiers and strings
- Very long strings and deeply nested structures
- Code with unusual whitespace and line endings

For string functions:
- All combinations of string prefixes (f, r, b, u, fr, rf, br, rb)
- Strings with all escape sequences
- Strings with Unicode escapes (\uXXXX, \UXXXXXXXX, \N{name})
- Triple-quoted strings with embedded quotes
- Strings with unusual Unicode (control chars, zero-width, combining marks)

For notebook functions:
- Valid Jupyter notebook JSON
- Malformed JSON
- Notebooks with code cells containing IPython magics
- Cells with unusual magic combinations
- Non-Python notebooks

For comment functions:
- Comments with fmt: on/off directives
- Type comments
- Multiple comments on same line
- Comments with unusual characters
