Black Library - Testing Notes
=============================

Library Purpose:
- Python code formatter ("The uncompromising code formatter")
- Parses Python code AST and reformats according to style rules
- Handles configuration from pyproject.toml files

Critical Functions for Fuzzing:
================================

1. format_str(src_contents, mode, lines) - HIGHEST PRIORITY
   Location: /app/black/src/black/__init__.py:1177
   - Main formatting function for Python code strings
   - Parses code using lib2to3
   - AST transformation and line generation

2. lib2to3_parse(src_txt, target_versions)
   Location: /app/black/src/black/parsing.py
   - Parses Python code using lib2to3 grammar
   - Handles multiple Python versions
   - Tokenization and grammar matching

3. parse_ast(src)
   Location: /app/black/src/black/parsing.py
   - AST parsing with version fallback
   - Tries multiple Python interpreters

4. parse_pyproject_toml(path_config)
   Location: /app/black/src/black/files.py
   - TOML configuration file parsing
   - Uses tomllib for parsing

5. normalize_string_quotes(s)
   Location: /app/black/src/black/strings.py
   - Normalizes string quotes (prefers double quotes)
   - Handles escape sequences

6. normalize_fstring_quotes(quote, middles, is_raw_fstring)
   Location: /app/black/src/black/strings.py
   - F-string quote normalization
   - Complex nested string handling

7. normalize_unicode_escape_sequences(leaf)
   Location: /app/black/src/black/strings.py
   - Normalizes Unicode escape sequences

8. format_ipynb_string(src_contents, fast, mode)
   Location: /app/black/src/black/__init__.py:1145
   - Jupyter notebook formatting
   - JSON parsing and cell processing

Input Categories for Fuzzing:
==============================
- Malformed Python code (syntax errors)
- Invalid TOML configuration files
- Edge-case string literals (raw strings, f-strings, unicode)
- Nested f-strings with expressions
- Complex decorators and type annotations
- Large numeric literals with underscores
- Comments with special directives (# fmt: off/on)
- Mixed indentation and whitespace
- Invalid Python version specifiers
- Malformed Jupyter notebooks
- Unicode characters in various contexts
- String escape sequences (\\n, \\u, \\x, \\N)

Key Edge Cases:
===============
- Triple-quoted strings with quotes inside
- F-strings with nested braces and expressions
- Raw f-strings (rf"..." or fr"...")
- Format control comments (# fmt: off/on, # noqa)
- Python 2 vs 3 syntax differences
- Type annotations with complex expressions
- Docstrings with special formatting
- String concatenation and implicit joins
- Backslash line continuations
- AST safety check failures
