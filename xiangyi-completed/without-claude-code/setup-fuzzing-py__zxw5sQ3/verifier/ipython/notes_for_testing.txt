IPython Library - Testing Notes
================================

Library Purpose:
- Interactive Python shell and kernel
- Transforms IPython special syntax into valid Python
- Executes user code with magic commands and system calls

Critical Functions for Fuzzing:
================================

1. InteractiveShell.run_cell(raw_cell) - HIGHEST PRIORITY
   Location: /app/ipython/IPython/core/interactiveshell.py
   - Main entry point for executing IPython cells
   - Handles all special syntax transformations

2. TransformerManager.transform_cell(cell)
   Location: /app/ipython/IPython/core/inputtransformer2.py
   - Transforms IPython syntax to valid Python
   - Handles escape characters (!, ?, %, //, etc.)

3. InteractiveShell.run_line_magic(magic_name, line)
   Location: /app/ipython/IPython/core/interactiveshell.py
   - Executes line magics (%magic args)

4. InteractiveShell.run_cell_magic(magic_name, line, cell)
   Location: /app/ipython/IPython/core/interactiveshell.py
   - Executes cell magics (%%magic)

5. split_user_input(line)
   Location: /app/ipython/IPython/core/splitinput.py
   - Parses input into components (whitespace, escape, function, args)
   - Uses regex pattern matching

6. prefilter_line(line)
   Location: /app/ipython/IPython/core/prefilter.py
   - Dynamic single-line transformations
   - Auto-call detection and handling

IPython Special Syntax:
========================
ESC_SHELL   = '!'     # !ls → system command
ESC_SH_CAP  = '!!'    # !!ls → capture output
ESC_HELP    = '?'     # obj? → help
ESC_HELP2   = '??'    # obj?? → detailed help
ESC_MAGIC   = '%'     # %magic → line magic
ESC_MAGIC2  = '%%'    # %%magic → cell magic
ESC_QUOTE   = ','     # ,func a b → func("a", "b")
ESC_QUOTE2  = ';'     # ;func a b → func("a b")
ESC_PAREN   = '/'     # /func a b → func(a, b)

Input Categories for Fuzzing:
==============================
- Malformed magic commands
- Invalid escape sequences
- System commands with special characters
- Mixed IPython and Python syntax
- Nested magic calls
- Help queries on invalid objects
- Auto-call with complex arguments
- Multi-line cell magics
- Prompt stripping edge cases
- Unicode in commands and magics
- String literals with IPython syntax inside
- Comments with escape characters

Key Edge Cases:
===============
- Magic commands in strings/comments
- Trailing semicolons for output suppression
- Mixed line/cell magics
- System commands with pipes and redirects
- Help syntax (? and ??) in various positions
- Auto-parenthesis with complex expressions
- Multi-line input with continuations
- Escaped escape characters
- Unicode in magic names and arguments
