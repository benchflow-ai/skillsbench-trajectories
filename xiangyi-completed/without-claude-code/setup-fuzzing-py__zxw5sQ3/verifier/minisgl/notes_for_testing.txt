MiniSGL Library - Testing Notes
================================

Library Purpose:
- Lightweight LLM inference framework
- Handles model loading, batch scheduling, and text generation
- Provides OpenAI-compatible API server

Critical Functions for Fuzzing:
================================

1. Scheduler.forward_pass(batch) - HIGHEST PRIORITY
   Location: /app/minisgl/python/minisgl/scheduler/scheduler.py
   - Processes batches of requests
   - Manages KV cache allocation

2. Engine.__init__(config, model_config)
   Location: /app/minisgl/python/minisgl/engine/engine.py
   - Initializes model and GPU resources
   - Loads model weights from HuggingFace

3. SamplingParams.__init__(temperature, top_k, top_p, max_tokens, etc.)
   Location: /app/minisgl/python/minisgl/core.py
   - Validates sampling parameters
   - Temperature, top_k, top_p ranges

4. RadixCacheManager.match_prefix(req)
   Location: /app/minisgl/python/minisgl/kvcache/radix.py
   - Tree-based prefix matching for cache reuse
   - Handles arbitrary input sequences

5. API Server endpoints
   Location: /app/minisgl/python/minisgl/server/api_server.py
   - /completions endpoint (OpenAI-compatible)
   - /chat/completions endpoint
   - JSON request parsing and validation

Input Categories for Fuzzing:
==============================
- Invalid sampling parameters (temperature < 0, top_k < 0, etc.)
- Malformed JSON in API requests
- Extremely long input sequences
- Invalid model paths and configurations
- Tensor parallelism configuration errors
- Memory allocation edge cases
- Invalid token IDs
- Empty or null inputs
- Unicode and special characters in prompts
- Concurrent request handling
- Large batch sizes
- Invalid stop sequences
- Malformed HuggingFace model configs

Key Edge Cases:
===============
- Temperature = 0 (greedy decoding)
- max_tokens = 0 or very large values
- Empty input_ids arrays
- KV cache overflow
- Page allocation failures
- CUDA graph capture edge cases
- Multi-GPU synchronization
- Prefix cache tree depth limits
- Request cancellation during generation
- Streaming response errors
