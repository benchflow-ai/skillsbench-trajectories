Arrow Library - Testing Notes
==============================

Library Purpose:
- Date/time manipulation library for Python
- Parses and formats datetime strings with multiple formats
- Handles timezones, humanization, and locale support

Critical Functions for Fuzzing:
================================

1. arrow.get(string, format) - HIGHEST PRIORITY
   Location: /app/arrow/arrow/factory.py:85
   - Polymorphic input handling (strings, timestamps, dates, etc.)
   - Accepts format strings or lists of formats
   - normalize_whitespace parameter

2. DateTimeParser.parse_iso(datetime_string, normalize_whitespace)
   Location: /app/arrow/arrow/parser.py:252-371
   - Parses ISO 8601 datetime strings
   - Multiple date separators: -, /, .
   - Complex timezone parsing

3. DateTimeParser.parse(datetime_string, fmt, normalize_whitespace)
   Location: /app/arrow/arrow/parser.py:373-439
   - Custom format string parsing
   - 20+ different token types (YYYY, MM, DD, HH, mm, ss, S, X, etc.)
   - Regex-based pattern matching

4. DateTimeParser._build_datetime(parts)
   Location: /app/arrow/arrow/parser.py:695-828
   - Constructs datetime from parsed components
   - Complex logic for day-of-year, weekdate, timestamps
   - AM/PM handling, midnight edge cases

5. Arrow.dehumanize(input_string, locale)
   Location: /app/arrow/arrow/arrow.py:1344-1458
   - Parses humanized time strings ("2 days ago", "in a month")
   - Regex pattern matching with locale support

6. TzinfoParser.parse(tzinfo_string)
   Location: /app/arrow/arrow/parser.py:895-937
   - Parses timezone strings (local, UTC, ISO offsets, named zones)

Input Categories for Fuzzing:
==============================
- Malformed ISO 8601 datetime strings
- Invalid date separators and time dividers
- Boundary values (min/max timestamps, ordinals)
- Invalid timezone strings and offsets
- Format strings with invalid tokens
- Humanized time strings with various locales
- Unicode and special characters in strings
- Hour=24 edge case for midnight
- Subsecond precision and rounding
- Week numbers and day-of-year values

Key Edge Cases:
===============
- MAX_TIMESTAMP boundaries (platform-dependent)
- Hour=24 with non-zero minutes/seconds
- Invalid ISO week dates
- Locale-specific parsing differences
- Escape sequences in format strings
- Multiple timezone representations
