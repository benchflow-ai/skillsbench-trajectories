ARROW LIBRARY - FUZZING NOTES
=============================

Key Modules:
- /app/arrow/arrow/parser.py (DateTimeParser, TzinfoParser)
- /app/arrow/arrow/formatter.py (DateTimeFormatter)
- /app/arrow/arrow/api.py (arrow.get, arrow.now, arrow.utcnow)
- /app/arrow/arrow/arrow.py (Arrow class)

TOP FUZZING TARGETS:
====================

1. HIGHEST PRIORITY:
   - DateTimeParser.parse_iso(string, normalize_whitespace=False)
     * Flexible ISO parsing with multiple format detection
     * Handles timezone info, microseconds
     * Potential for ReDoS in regex patterns

   - DateTimeParser.parse(string, fmt, normalize_whitespace=False)
     * Format string processing with locale handling
     * Supports 25+ token types (YYYY, MM, DD, HH, mm, ss, S, X, x, ZZ, Z, etc)
     * Could crash on invalid format strings

   - arrow.get(*args, **kwargs) / ArrowFactory.get()
     * Multi-type input handling (timestamps, ISO strings, datetime objects, tuples)
     * Wide attack surface with varying argument combinations
     * Parameters: locale, tzinfo, normalize_whitespace

   - DateTimeFormatter.format(dt, fmt)
     * Format string token replacement
     * Regex-based with ~30 format tokens
     * Locale-aware formatting

2. HIGH PRIORITY:
   - DateTimeParser._parse_token(token, value, parts)
     * 25+ token types with different validation rules
     * Parses YYYY, MM, DD, HH, mm, ss, S, X, x, ZZ, Z tokens

   - TzinfoParser.parse(tzinfo_string)
     * Timezone parsing: ISO offsets (+HH:MM), timezone names, special values

   - Arrow.strptime(string, format)
     * Custom format parsing

   - DateTimeParser._build_datetime(parts)
     * Edge cases: midnight, day-of-year, AM/PM conversion
     * Boundary checks for date validity

3. FUZZING STRATEGIES:
   - String inputs: Malformed ISO strings, invalid formats, injection attempts
   - Numeric edge cases: Boundary timestamps (max/min), negative numbers, overflow
   - Timezone strings: Invalid names, malformed offsets, special values
   - Format tokens: Unknown tokens, duplicates, escape sequences
   - Locale handling: Invalid locales, locale-specific names
   - Whitespace normalization: Tabs, newlines, multiple spaces
   - Boundary conditions: Year 1 vs 9999, month 1-12, day 1-31, hour 0-23

Test Input Categories:
- Empty strings
- Very long strings (>10KB)
- Strings with control characters
- Invalid ISO 8601 formats
- Invalid timezone names
- Malformed timestamps
- Extreme numeric values
- Format strings with unknown tokens
- Locale-specific inputs
