BLACK LIBRARY - FUZZING NOTES
==============================

Key Modules:
- /app/black/src/black/__init__.py (Main API)
- /app/black/src/black/parsing.py (lib2to3_parse, parse_ast)
- /app/black/src/black/trans.py (Transformer, token handling)
- /app/black/src/black/lines.py (Line class)
- /app/black/src/black/linegen.py (LineGenerator)

TOP FUZZING TARGETS:
====================

1. HIGHEST PRIORITY:
   - format_str(src_contents: str, *, mode: Mode = None) -> str
     * Main high-level formatting API
     * Accepts arbitrary Python code strings
     * Applies 2-pass formatting for consistency
     * Supports partial formatting with line ranges

   - lib2to3_parse(src_txt: str, target_versions: Set[TargetVersion]) -> Node
     * Parses Python source into lib2to3 AST
     * Multi-grammar support for Python 3.3-3.14
     * Grammar selection affects parsing behavior
     * Potential parse errors, hangs on pathological input

   - assert_equivalent(src: str, dst: str, *, mode: Mode = None) -> None
     * Verifies semantic equivalence of source and formatted code
     * Uses AST comparison
     * Can fail on certain edge cases
     * CPU intensive on complex code

   - get_features_used(src: str, target_versions: Set[TargetVersion]) -> Set[Feature]
     * Identifies Python features used in code
     * Analyzes AST for feature detection
     * Can be slow on large/complex files

   - detect_target_versions(src: str) -> Set[TargetVersion]
     * Auto-detects compatible Python versions
     * Relies on feature detection
     * Edge cases with version conflicts

2. HIGH PRIORITY:
   - format_file_contents(src_contents: str, *, fast: bool, mode: Mode = None) -> str
     * Wraps format_str with file handling
     * Handles both regular Python and Jupyter notebooks

   - parse_ast(src: str) -> ast.Module
     * Parses to standard Python AST
     * Simpler than lib2to3_parse
     * Can fail on syntax errors

   - format_cell(src: str, *, mode: Mode = None) -> str
     * Formats individual Jupyter notebook cells
     * Cell magic handling

   - assert_stable(src: str, dst: str, mode: Mode = None) -> None
     * Verifies formatter idempotency (2-pass consistency)
     * Detects infinite formatting loops

3. FUZZING STRATEGIES:
   - Invalid Python syntax
   - Pathological code structures (deeply nested, extremely long lines)
   - Large files (10MB+)
   - Unicode and special characters
   - Format tokens and string escapes
   - Jupyter magic commands and cell boundaries
   - Comments at edge cases
   - Partial formatting with invalid line ranges
   - Mode configuration combinations
   - Target version conflicts

Test Input Categories:
- Empty strings and whitespace-only code
- Invalid/incomplete Python syntax
- Extremely nested structures (100+ levels)
- Very long single lines (10KB+)
- Unicode in identifiers and strings
- Malformed f-strings and raw strings
- Pathological regex patterns in code
- Binary/bytecode-like content
- Jupyter magic commands (%, %%)
- Code with mixed line endings
- Comments with special formatting
- Invalid target version combinations
