# Build Failure Analysis for google/auto

## Repository: /home/travis/build/failed/google/auto

## Build Error Summary

All submodules (common, factory, service, value) fail to build with two types of errors:

### Error 1: Missing tools.jar dependency
```
Could not resolve dependencies for project: Could not find artifact
com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar
```

### Error 2: Missing javax.annotation.Generated class
```
cannot find symbol
  symbol:   class Generated
  location: package javax.annotation
```

## Root Cause

### Issue 1: tools.jar Dependency
The `com.google.testing.compile:compile-testing` library used in test dependencies
has a transitive dependency on `com.sun:tools:jar`. This dependency expects the
`tools.jar` file that was present in JDK 8 and earlier.

Starting with Java 9 (and the Java Platform Module System), the `tools.jar` file
no longer exists. The classes that were previously in `tools.jar` are now part
of the `jdk.compiler` module and are available directly.

### Issue 2: javax.annotation.Generated class
In Java 9+, the `javax.annotation.Generated` annotation was moved from the
`javax.annotation` package to `javax.annotation.processing.Generated`.

The current environment is using Java 11:
- openjdk version "11.0.27"
- OpenJDK Runtime Environment (build 11.0.27+6-post-Ubuntu-0ubuntu120.04)

## Fix Strategy

### Fix 1: Exclude tools.jar dependency
Add an exclusion for `com.sun:tools` to each `compile-testing` dependency.

### Fix 2: Update Generated import
Change `import javax.annotation.Generated` to `import javax.annotation.processing.Generated`
and update any string literals referencing the import path.
