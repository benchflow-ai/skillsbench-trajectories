# Build Failure Analysis for google/auto

## Repository Location
/home/travis/build/failed/google/auto

## Environment
- Java Version: OpenJDK 11.0.27
- Build System: Maven

## Root Cause Analysis

### Primary Issue: tools.jar Dependency Incompatibility with Java 11+

The build fails with the following error:
```
Could not find artifact com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar
```

#### Explanation:
- In Java 8 and earlier, `tools.jar` was a separate JAR file located in `$JAVA_HOME/lib/tools.jar`
- Starting with Java 9, `tools.jar` was removed and its contents were modularized into the JDK modules
- The project's test dependencies (`compile-testing` library versions 0.6, 0.7, and 0.8) have a hard dependency on `com.sun:tools` with a system scope pointing to the non-existent `tools.jar`

#### Affected Modules:
1. `common/pom.xml` - uses `compile-testing:0.7` (test scope)
2. `value/pom.xml` - uses `compile-testing:0.6` (test scope)
3. `service/pom.xml` - uses `compile-testing:0.6` (test scope)
4. `factory/pom.xml` - uses `compile-testing:0.8` (test scope)

### Secondary Issue: javax.annotation.Generated Not Available in Java 11+

The `javax.annotation.Generated` annotation was removed from the JDK in Java 11 (it was deprecated in Java 9 and removed in Java 11). The code uses this annotation and needs the `javax.annotation-api` library.

#### Affected Modules:
1. `factory/src/main/java/com/google/auto/factory/processor/FactoryWriter.java` - imports `javax.annotation.Generated`
2. `value/src/main/java/com/google/auto/value/processor/AutoAnnotationProcessor.java` - imports `javax.annotation.Generated`
3. `value/src/main/java/com/google/auto/value/processor/AutoValueProcessor.java` - imports `javax.annotation.Generated`

### Tertiary Issue: Java Source/Target Version

The parent pom.xml specifies Java 1.6 as the source and target version:
```xml
<java.version>1.6</java.version>
```

This triggers warnings but is still compilable with Java 11 (though deprecated).

## Applied Fixes

### Fix 1: Update compile-testing dependency versions
Updated the `compile-testing` library to version 0.18, which uses a conditional profile for `tools.jar` that only activates when the file actually exists.

Files modified:
- `common/pom.xml`: Changed `compile-testing` version from `0.7` to `0.18`
- `value/pom.xml`: Changed `compile-testing` version from `0.6` to `0.18`
- `service/pom.xml`: Changed `compile-testing` version from `0.6` to `0.18`
- `factory/pom.xml`: Changed `compile-testing` version from `0.8` to `0.18`

### Fix 2: Update Java version in parent pom.xml
Updated the Java version from 1.6 to 1.8 (the minimum version supported by Java 11 compiler for source/target):

File modified:
- `pom.xml`: Changed `<java.version>1.6</java.version>` to `<java.version>1.8</java.version>`

### Fix 3: Update Truth library versions for compatibility
The `compile-testing:0.18` requires `truth` version 0.42 or later.

Files modified:
- `common/pom.xml`: Updated `truth` from `0.25` to `0.42`
- `value/pom.xml`: Updated `truth` from `0.25` to `0.42`
- `service/pom.xml`: Updated `truth` from `0.24` to `0.42`
- `factory/pom.xml`: Updated `truth` from `0.25` to `0.42`

### Fix 4: Add javax.annotation-api dependency
Added the `javax.annotation-api` library to provide the `javax.annotation.Generated` annotation that was removed in Java 11.

Files modified:
- `factory/pom.xml`: Added `javax.annotation:javax.annotation-api:1.3.2` dependency
- `value/pom.xml`: Added `javax.annotation:javax.annotation-api:1.3.2` dependency
