Build Error Analysis for Google Auto Service
=============================================

ISSUE SUMMARY:
The build fails with: "Could not find artifact com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar"

ROOT CAUSE:
The build fails due to two issues:

1. OBSOLETE JAVA VERSION CONFIGURATION:
   - The auto-parent pom.xml specifies Java 1.6 as the source/target version (line 57-59)
   - It has Maven profiles that expect tools.jar to exist at ${java.home}/../lib/tools.jar (lines 168-186)
   - These profiles try to set a toolsjar property for system dependencies

2. JAVA 11 INCOMPATIBILITY:
   - Java 11 does not include tools.jar in the JDK distribution
   - The functionality was integrated into the jdk.compiler module
   - The system-scoped dependency on com.sun:tools:jar comes from compile-testing:0.6
   - This transitive dependency cannot be resolved because tools.jar no longer exists

TECHNICAL DETAILS:
The dependency tree shows:
- com.google.auto.service:auto-service:jar:1.0-SNAPSHOT
  └─ com.google.testing.compile:compile-testing:jar:0.6:test
     └─ com.sun:tools:jar:11.0.27:system  <-- CANNOT RESOLVE

SOLUTION IMPLEMENTED:
Two complementary fixes are applied:

1. **Update auto-parent pom.xml** (patch_1.diff):
   - Change Java version from 1.6 to 1.8 (more compatible with modern Maven)
   - Remove the "default-profile" that checks for ${java.home}/../lib/tools.jar
   - Keep only the mac-profile for MacOS compatibility (does not block Linux builds)

2. **Exclude tools dependency from compile-testing** (patch_2.diff):
   - Add an exclusion in the compile-testing dependency to exclude com.sun:tools
   - This prevents Maven from trying to resolve the unavailable tools.jar artifact
   - compile-testing 0.6 doesn't actually require tools.jar for runtime functionality

AFFECTED FILES:
1. /home/travis/build/failed/google/auto/pom.xml (auto-parent) - Fixed Java version and removed problematic profile
2. /home/travis/build/failed/google/auto/service/pom.xml - Added exclusion for tools.jar
