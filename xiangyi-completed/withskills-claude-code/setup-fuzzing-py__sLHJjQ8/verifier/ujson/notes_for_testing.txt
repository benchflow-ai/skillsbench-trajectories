# UltraJSON (ujson) Library - Fuzz Testing Notes

## Library Overview
UltraJSON is a fast JSON encoder and decoder written in C with Python bindings.
It aims to be a drop-in replacement for the standard library json module.

## Important Files
1. src/ujson/python/ujson.c - Main Python C extension module
2. src/ujson/python/JSONtoObj.c - JSON decoding (parsing) implementation
3. src/ujson/python/objToJSON.c - JSON encoding implementation
4. src/ujson/lib/ultrajsondec.c - Core JSON decoder in C
5. src/ujson/lib/ultrajsonenc.c - Core JSON encoder in C

## Selected Functions Under Test (FUTs)

### FUT 1: ujson.loads() / ujson.decode()
- Module: ujson (C extension)
- Purpose: Parse JSON string into Python objects
- Input: str or bytes (JSON data)
- Why fuzz: Primary parsing function, handles untrusted input, C implementation
- Oracles: Should not crash, should raise JSONDecodeError for invalid JSON
- Acceptable exceptions: JSONDecodeError, ValueError, TypeError

### FUT 2: ujson.dumps() / ujson.encode()
- Module: ujson (C extension)
- Purpose: Encode Python objects to JSON string
- Input: Any JSON-serializable Python object
- Why fuzz: C implementation, handles various Python types
- Oracles: Should not crash, should raise TypeError for non-serializable objects
- Acceptable exceptions: OverflowError, TypeError

### FUT 3: Round-trip testing (loads(dumps(x)) or dumps(loads(x)))
- Purpose: Verify encoding/decoding consistency
- Why fuzz: Round-trip property is a strong oracle
- Oracles: Round-trip should produce equivalent result

## Recommended Fuzzing Strategy
1. Focus on ujson.loads() as the primary target (accepts string input)
2. Use crash-only oracle (crashes in C code are critical bugs)
3. Also test round-trip property for consistency
4. Generate malformed JSON, edge cases (deep nesting, very large numbers)
5. Test with various encoding options (ensure_ascii, encode_html_chars, indent)

## Seed Corpus Ideas
- Valid JSON: '{"key": "value"}', '[1, 2, 3]', '"string"'
- Numbers: '1e308', '-1e308', '1.7976931348623157e+308'
- Unicode: '"\u0000"', '"\ud834\udd1e"' (surrogate pairs)
- Edge cases: '[]', '{}', 'null', 'true', 'false'
- Malformed JSON: Truncated strings, unmatched brackets, invalid escapes

## Dependencies
- Minimal: Only requires Python and C compiler to build
- No runtime Python dependencies

## Existing Fuzz Infrastructure
The library already has tests/fuzz.py which does random object generation
and tests ujson.dumps(). This can be used as reference for fuzzing strategies.
