# IPython Library - Fuzz Testing Notes

## Library Overview
IPython is an enhanced interactive Python shell. It provides input transformation,
code completion, syntax highlighting, and execution capabilities.

## Important Files
1. IPython/core/inputtransformer2.py - TransformerManager for input transformation
2. IPython/core/guarded_eval.py - Safe evaluation with security policies
3. IPython/core/completer.py - Code completion engine
4. IPython/core/interactiveshell.py - Main interactive shell class

## Selected Functions Under Test (FUTs)

### FUT 1: TransformerManager.transform_cell()
- File: IPython/core/inputtransformer2.py:635-644
- Purpose: Transform cell input (handle magics, prompts, special syntax)
- Input: str (cell)
- Why fuzz: Main input transformation pipeline, handles special IPython syntax
- Oracles: Should not crash, should return transformed string or raise SyntaxError
- Acceptable exceptions: SyntaxError, TokenError

### FUT 2: TransformerManager.check_complete()
- File: IPython/core/inputtransformer2.py:646+
- Purpose: Check if code block is complete or needs continuation
- Input: str (cell)
- Why fuzz: Parses code to determine completeness, complex state machine
- Oracles: Should not crash, should return status tuple
- Acceptable exceptions: None expected (should handle malformed input gracefully)

### FUT 3: guarded_eval()
- File: IPython/core/guarded_eval.py:433-460
- Purpose: Safely evaluate Python expressions with policy restrictions
- Input: str (code), EvaluationContext (context)
- Why fuzz: Security-critical evaluation function, parses and evaluates AST
- Oracles: Should not crash, should raise GuardRejection for forbidden operations
- Acceptable exceptions: GuardRejection, SyntaxError, ValueError

### FUT 4: eval_node()
- File: IPython/core/guarded_eval.py:765+
- Purpose: Evaluate AST node with restrictions
- Input: ast.AST (node), EvaluationContext (context)
- Why fuzz: Core evaluation logic, handles many AST node types
- Oracles: Should not crash, should raise GuardRejection for disallowed operations
- Acceptable exceptions: GuardRejection, TypeError, ValueError

## Recommended Fuzzing Strategy
1. Focus on TransformerManager.transform_cell() as primary target
2. Also fuzz guarded_eval() with minimal evaluation context
3. Use crash-only oracle for transform functions
4. Generate malformed IPython syntax, edge cases

## Seed Corpus Ideas
- IPython magic commands: "%timeit x", "%%bash"
- Shell escapes: "!ls", "!!cat file"
- Help queries: "func?", "func??"
- Valid Python: "x = 1", "def f(): pass"
- Malformed input: Unbalanced brackets, incomplete magics
