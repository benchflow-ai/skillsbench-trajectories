# Arrow Library - Important Functions for Fuzzing

## Overview
Arrow is a Python library for working with dates and times. It provides parsing, formatting, and manipulation of datetime objects.

## Important Files for Fuzzing
1. arrow/parser.py - Contains DateTimeParser and TzinfoParser classes
2. arrow/factory.py - Contains ArrowFactory.get() method for parsing various inputs
3. arrow/formatter.py - Contains DateTimeFormatter for formatting datetimes

## Selected Functions Under Test (FUTs)

### 1. DateTimeParser.parse_iso (parser.py:252)
- **Why this target**: Primary entry point for parsing ISO 8601 datetime strings
- **Input surface**: String input (datetime_string), accepts arbitrary user-provided strings
- **Boundary considerations**: Complex regex-based parsing, handles multiple date formats
- **Complexity**: High - handles multiple ISO 8601 variants, timezones, subseconds
- **Current test gaps**: Fuzz testing can find edge cases not covered by unit tests

**Callable contract**:
- Required imports: `from arrow.parser import DateTimeParser`
- Input: `datetime_string: str`, `normalize_whitespace: bool = False`
- Returns: `datetime` object
- Raises: `ParserError` on invalid input

**Input model**:
- Primary payload type: str (datetime strings)
- Edge classes: malformed dates, extreme values, special characters, unicode, deeply nested brackets

### 2. DateTimeParser.parse (parser.py:373)
- **Why this target**: General parsing with custom format strings
- **Input surface**: Two string inputs - datetime_string and format string
- **Boundary considerations**: Regex pattern generation from format string
- **Complexity**: High - format string is user-controlled and generates regex

**Callable contract**:
- Required imports: `from arrow.parser import DateTimeParser`
- Input: `datetime_string: str`, `fmt: Union[List[str], str]`
- Returns: `datetime` object
- Raises: `ParserMatchError` on no match, `ParserError` on invalid format

### 3. TzinfoParser.parse (parser.py:894)
- **Why this target**: Timezone string parsing
- **Input surface**: Timezone string input
- **Boundary considerations**: Handles various timezone formats (UTC, offsets, named zones)

**Callable contract**:
- Required imports: `from arrow.parser import TzinfoParser`
- Input: `tzinfo_string: str`
- Returns: `tzinfo` object
- Raises: `ParserError` on invalid timezone

### 4. ArrowFactory.get (factory.py:85)
- **Why this target**: Main factory method accepting multiple input types
- **Input surface**: Polymorphic - accepts str, int, float, datetime, date, etc.
- **Boundary considerations**: Type dispatching logic, delegates to parser

## Recommended Fuzzing Approach
1. Focus on `DateTimeParser.parse_iso()` as primary target - single string input, high complexity
2. Use atheris/LibFuzzer for coverage-guided fuzzing
3. Accept ParserError and ParserMatchError as expected exceptions
4. Target crashes, hangs, and unexpected exceptions

## Oracles
- Must-hold: No crashes, no hangs, no memory corruption
- Acceptable exceptions: ParserError, ParserMatchError, ValueError
- Suspicious exceptions: AttributeError, TypeError, KeyError, RecursionError
