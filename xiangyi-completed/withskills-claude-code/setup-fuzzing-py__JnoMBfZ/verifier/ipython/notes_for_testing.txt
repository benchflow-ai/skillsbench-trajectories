# IPython Library - Important Functions for Fuzzing

## Overview
IPython is an interactive computing environment for Python. It includes input transformation, magic command parsing, and code execution.

## Important Files for Fuzzing
1. IPython/core/inputtransformer2.py - Input transformation for magics and special syntax
2. IPython/core/compilerop.py - Code compilation
3. IPython/core/interactiveshell.py - Main interactive shell logic
4. IPython/utils/text.py - Text utilities including parsing

## Selected Functions Under Test (FUTs)

### 1. TransformerManager.transform_cell (IPython/core/inputtransformer2.py)
- **Why this target**: Main entry point for transforming IPython cell input
- **Input surface**: String input (cell) - IPython code with magics, ! commands, etc.
- **Boundary considerations**: Tokenizes and transforms special IPython syntax
- **Complexity**: High - regex-based transformations, tokenization

**Callable contract**:
- Required imports: `from IPython.core.inputtransformer2 import TransformerManager`
- Input: `cell: str`
- Returns: `str` (transformed code)
- Raises: Various exceptions on malformed input

**Input model**:
- Primary payload type: str (IPython cell code)
- Edge classes: Malformed magics (%, %%), system commands (!), help (?), mixed syntax

### 2. check_complete (IPython/core/inputtransformer2.py)
- **Why this target**: Checks if input is complete (useful for REPL)
- **Input surface**: String input (cell)
- **Boundary considerations**: Uses tokenizer to determine completeness

### 3. cell_magic transformer (IPython/core/inputtransformer2.py:115)
- **Why this target**: Transforms cell magics (%%magic)
- **Input surface**: Lines of input starting with %%

## Recommended Fuzzing Approach
1. Focus on TransformerManager.transform_cell() as primary target
2. Use atheris/LibFuzzer for coverage-guided fuzzing
3. Accept SyntaxError, TokenizerError as expected exceptions
4. Target crashes, hangs, and unexpected exceptions

## Oracles
- Must-hold: No crashes, no hangs, no memory corruption
- Acceptable exceptions: SyntaxError, TokenError, IndentationError
- Suspicious exceptions: AttributeError, KeyError, RecursionError
