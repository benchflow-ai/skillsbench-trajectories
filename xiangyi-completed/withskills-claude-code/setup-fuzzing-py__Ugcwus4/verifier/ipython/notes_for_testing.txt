# IPython Library - Fuzz Testing Analysis

## Library Overview
IPython is an interactive Python shell with enhanced features including
magic commands, system shell access, rich display, and notebook support.
The input transformation and parsing components process arbitrary user code.

## Important Files for Fuzzing
1. IPython/core/inputtransformer2.py - Input transformation (HIGH PRIORITY)
2. IPython/core/compilerop.py - Code compilation with caching
3. IPython/core/prefilter.py - Input prefiltering
4. IPython/core/interactiveshell.py - Main shell implementation
5. IPython/utils/tokenutil.py - Token utilities

## Selected Functions Under Test (FUTs)

### 1. TransformerManager.transform_cell (IPython/core/inputtransformer2.py:635)
**Why this target:**
- Primary entry point for transforming user input
- Handles magic commands (%magic, %%cell_magic)
- Handles system commands (!cmd)
- Handles help queries (?obj)
- Complex tokenization and transformation pipeline

**Callable contract:**
- Required imports: from IPython.core.inputtransformer2 import TransformerManager
- Preconditions: cell must be a string
- Determinism: Yes
- External dependencies: None (stateless transformer)

**Input model:**
- Primary payload type: str (IPython cell code)
- Edge cases: empty cells, only whitespace, incomplete syntax
- Special syntax: %magic, !shell, ?help, %%cellmagic

**Oracles:**
- Must-hold: Should not crash on any input
- Acceptable exceptions: SyntaxError (for invalid Python after transform)
- Suspicious exceptions: RuntimeError (transform loop limit), IndexError

### 2. TransformerManager.check_complete (IPython/core/inputtransformer2.py:646)
**Why this target:**
- Determines if input is complete for execution
- Complex tokenization logic
- Edge cases with incomplete code blocks

**Callable contract:**
- Required imports: from IPython.core.inputtransformer2 import TransformerManager
- Preconditions: cell must be a string
- Returns: (status, indent_spaces)

**Input model:**
- Primary payload type: str
- Edge cases: incomplete blocks, trailing backslashes, nested structures

**Oracles:**
- Must-hold: Should not crash
- Acceptable exceptions: None expected
- Must return valid status: 'complete', 'incomplete', or 'invalid'

### 3. cell_magic (IPython/core/inputtransformer2.py:115)
