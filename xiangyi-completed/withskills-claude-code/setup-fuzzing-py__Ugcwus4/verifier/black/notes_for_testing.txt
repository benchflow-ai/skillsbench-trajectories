# Black Library - Fuzz Testing Analysis

## Library Overview
Black is the uncompromising Python code formatter. It parses Python source code
and reformats it according to its style guide. The library processes arbitrary
Python source code, making it a high-value target for fuzzing.

## Important Files for Fuzzing
1. src/black/__init__.py - Main formatting entry points (format_str, format_file_contents)
2. src/black/parsing.py - Python code parsing (lib2to3_parse)
3. src/blib2to3/pgen2/driver.py - Parser driver
4. src/blib2to3/pgen2/tokenize.py - Tokenization
5. src/black/mode.py - Configuration mode

## Selected Functions Under Test (FUTs)

### 1. format_str (src/black/__init__.py:1177)
**Why this target:**
- Primary API for formatting Python code strings
- Accepts arbitrary Python source code
- Complex parsing and transformation pipeline
- High attack surface for malformed inputs

**Callable contract:**
- Required imports: from black import format_str, Mode
- Preconditions: src_contents must be a string
- Determinism: Yes
- External dependencies: None (stateless)

**Input model:**
- Primary payload type: str (Python source code)
- Edge cases: syntax errors, unicode, deeply nested code, very long lines
- Constraints: None - should handle any string

**Oracles:**
- Must-hold: Should not crash on any input
- Acceptable exceptions: InvalidInput (for unparseable code)
- Suspicious exceptions: IndexError, RecursionError, MemoryError, AttributeError

### 2. lib2to3_parse (src/black/parsing.py:55)
**Why this target:**
- Core parsing function that converts source to AST
- Uses lib2to3 grammar-based parser
- Multiple grammar versions for different Python targets
- Parses arbitrary user-provided source

**Callable contract:**
- Required imports: from black.parsing import lib2to3_parse
- Preconditions: src_txt must be a string
- Determinism: Yes

**Input model:**
- Primary payload type: str (Python source code)
- Edge cases: incomplete syntax, mixed encodings, edge Python syntax

**Oracles:**
- Must-hold: Should not crash
- Acceptable exceptions: InvalidInput
- Suspicious exceptions: Any other exception type

### 3. format_file_contents (src/black/__init__.py:1068)
**Why this target:**
- High-level API for formatting file contents
- Includes stability and equivalence checks when fast=False
- Processes both regular Python and Jupyter notebooks

**Callable contract:**
- Required imports: from black import format_file_contents, Mode
- Preconditions: src_contents is string, mode is Mode object
- Determinism: Yes

**Input model:**
- Primary payload type: str
- Mode variations: is_pyi, is_ipynb flags

**Oracles:**
- Must-hold: Should not crash
- Acceptable exceptions: NothingChanged, InvalidInput

### 4. format_ipynb_string (src/black/__init__.py:1145)
**Why this target:**
- Processes Jupyter notebook JSON format
- Complex JSON parsing + Python code formatting
- Multiple attack vectors (JSON + Python)

**Callable contract:**
- Required imports: from black import format_ipynb_string, Mode
- Preconditions: src_contents should be JSON string

**Input model:**
- Primary payload type: str (JSON notebook format)
- Edge cases: malformed JSON, invalid notebook structure

**Oracles:**
- Must-hold: Should not crash on malformed input
- Acceptable exceptions: JSONDecodeError, NothingChanged

## Harness Recommendations
1. Primary target: format_str with default Mode()
2. Use atheris/LibFuzzer for coverage-guided fuzzing
3. Catch and filter InvalidInput exceptions
4. Consider differential testing with Python's ast.parse
