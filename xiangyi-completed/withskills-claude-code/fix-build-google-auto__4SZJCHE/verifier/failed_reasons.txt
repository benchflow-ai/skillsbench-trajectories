BUILD FAILURE ANALYSIS AND RESOLUTION
======================================

Repository: /home/travis/build/failed/google/auto
Build System: Maven
Java Version: OpenJDK 11.0.27

ROOT CAUSES IDENTIFIED:
=======================

1. PRIMARY ISSUE: Missing tools.jar in Java 11
   --------------------------------------------
   Error: "Could not find artifact com.sun:tools:jar:11.0.27 at specified path
          /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar"

   Reason: In Java 9+, the tools.jar file was removed because its classes were
           integrated into the JDK module system. The compile-testing dependency
           (used by auto-common) has a system-scoped dependency on com.sun:tools
           that expects tools.jar to exist.

   Solution: Added a Java 9+ profile to the parent POM that sets the toolsjar
             property to ${java.home}/lib/jrt-fs.jar (which exists in Java 11).
             Also added dependencyManagement to override the tools dependency
             systemPath for all child modules.

2. SECONDARY ISSUE: Missing javax.annotation.Generated class
   ---------------------------------------------------------
   Error: "cannot find symbol: class Generated, location: package javax.annotation"

   Reason: In Java 9+, the javax.annotation.Generated annotation was moved to
           a separate module and is not available on the classpath by default.
           Both auto-factory and auto-value modules use this annotation.

   Solution: Added javax.annotation-api dependency (version 1.3.2) to the factory
             and value modules to provide the Generated annotation.

3. TERTIARY ISSUE: Parent POM version mismatch
   -------------------------------------------
   Reason: Child modules (common, factory, service, value) referenced auto-parent
           version 3, which didn't have the Java 9+ profile fix.

   Solution: Updated all child modules to reference auto-parent version 4-SNAPSHOT
             which contains the fixes.

TECHNICAL DETAILS:
==================
The core issue stems from the transition from Java 8 to Java 11. The codebase
was originally designed for Java 6/8 (source/target 1.6) but is being built
on Java 11. The fixes maintain backward compatibility while enabling the build
to succeed on Java 11 by:

1. Providing an alternative to tools.jar (jrt-fs.jar) for annotation processing
2. Explicitly adding Java EE annotations that were removed from the JDK
3. Using Maven's dependencyManagement to override transitive dependencies

All patches are in standard unified diff format and can be applied using:
  patch -p1 < patch_N.diff
