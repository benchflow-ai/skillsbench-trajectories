MINISGL LIBRARY - FUZZING NOTES
================================

Library Overview:
- Mini-SGLang is an LLM inference framework
- Handles message processing, tokenization, server requests
- Key modules: message/, tokenizer/, server/, engine/

High-Value Fuzzing Targets:
----------------------------

1. minisgl.message.* message handling
   Location: /app/minisgl/python/minisgl/message/
   Why: Processes incoming requests and messages
   Input: JSON/dict message structures
   Risk: Type confusion, injection attacks, DoS
   Test Focus:
   - Malformed JSON messages
   - Large messages (memory exhaustion)
   - Invalid field types
   - Missing required fields
   - Nested message structures

2. minisgl.tokenizer.* tokenization
   Location: /app/minisgl/python/minisgl/tokenizer/
   Why: Tokenizes input text for LLM processing
   Input: Text strings (potentially untrusted user input)
   Risk: Buffer overflow, crashes on invalid Unicode
   Test Focus:
   - Very long strings
   - Invalid UTF-8 sequences
   - Special tokens
   - Control characters
   - Empty strings

3. minisgl.server.* request handling
   Location: /app/minisgl/python/minisgl/server/
   Why: HTTP API endpoint handlers
   Input: HTTP requests with JSON payloads
   Risk: Request parsing bugs, DoS, injection
   Test Focus:
   - Invalid JSON in request body
   - Large request bodies
   - Malformed headers
   - Invalid parameter combinations
   - Rate limiting bypass

4. minisgl.scheduler.* request scheduling
   Location: /app/minisgl/python/minisgl/scheduler/
   Why: Manages request queuing and batching
   Input: Request objects
   Risk: Race conditions, deadlocks, resource exhaustion
   Test Focus:
   - Concurrent requests
   - Very large batch sizes
   - Invalid priority values
   - Request cancellation edge cases

5. minisgl.utils.* utility functions
   Location: /app/minisgl/python/minisgl/utils/
   Why: Various parsing and validation utilities
   Input: Configuration dicts, parameters
   Risk: Validation bypass, type errors
   Test Focus:
   - Invalid configuration values
   - Type mismatches
   - Missing parameters
   - Out of range values

6. minisgl.core.py core functionality
   Location: /app/minisgl/python/minisgl/core.py
   Why: Core engine logic
   Input: Configuration and runtime parameters
   Risk: State corruption, crashes
   Test Focus:
   - Invalid model configurations
   - Resource limit edge cases
   - Concurrent access patterns

Additional Test Considerations:
--------------------------------
- KV cache handling (kvcache/)
- Attention mechanisms (attention/)
- Distributed processing (distributed/)
- Engine state management
- Model loading and validation
- API compatibility with OpenAI format

Oracle Strategies:
------------------
- No crashes on invalid input
- Proper error messages for malformed requests
- Resource limits enforced
- No unauthorized access
- API responses match OpenAI spec
- Thread safety in concurrent scenarios

Dependencies to Install:
------------------------
- torch (PyTorch)
- transformers (HuggingFace)
- fastapi (for server)
- uvicorn (for server)
- Check pyproject.toml for full dependencies
