# IPython Library - Fuzzing Target Notes

## Library Overview
IPython is an enhanced interactive Python shell with advanced features like
magic commands, tab completion, and code transformation. Key fuzzing targets
are the input transformation and safe evaluation systems.

## Important Files for Fuzzing
- IPython/core/inputtransformer2.py (score: 95) - Input transformation and parsing
- IPython/core/guarded_eval.py (score: 95) - Safe code evaluation for completions
- IPython/core/completer.py (score: 85) - Tab completion system
- IPython/core/splitinput.py (score: 80) - Input splitting logic

## Selected Functions Under Test (FUTs)

### FUT 1: TransformerManager.transform_cell()
- File: IPython/core/inputtransformer2.py:635
- Why: Core entry point for transforming user input to valid Python
- Input: cell (str) - raw IPython input
- Harnessability: HIGH
- Input model: IPython cell input with magic commands, system calls, help queries
- Oracles: No crash, proper transformation of valid input
- Edge cases: Malformed magic syntax, nested commands, unusual prompts

### FUT 2: TransformerManager.check_complete()
- File: IPython/core/inputtransformer2.py:646
- Why: Determines if code block is complete/incomplete/invalid
- Input: cell (str) - Python/IPython code
- Harnessability: HIGH
- Input model: Partial or complete code blocks
- Oracles: Returns valid status ('complete', 'incomplete', 'invalid')
- Edge cases: Unclosed brackets, multiline strings, syntax edge cases

### FUT 3: guarded_eval()
- File: IPython/core/guarded_eval.py:433
- Why: Safe evaluation of code strings for completion - security critical
- Input: code (str), context (EvaluationContext)
- Harnessability: MEDIUM (requires context object)
- Input model: Python expressions for evaluation
- Oracles: No crash, GuardRejection for disallowed operations
- Edge cases: Malicious code, attribute access, subscript operations

### FUT 4: cell_magic()
- File: IPython/core/inputtransformer2.py:115
- Why: Transforms %%magic cell commands
- Input: lines (list of str)
- Harnessability: HIGH
- Input model: Lines starting with %%
- Oracles: Proper get_ipython().run_cell_magic() call generation
- Edge cases: Missing magic name, special characters in body

## Recommended Harness Approach
1. Create fuzz driver that calls transform_cell() with fuzzed input
2. Also test check_complete() with fuzzed code blocks
3. For guarded_eval(), create minimal EvaluationContext and test
4. Catch expected exceptions (SyntaxError, RuntimeError, GuardRejection)
5. Any other exceptions indicate bugs

## Seed Corpus Ideas
- Magic commands: "%ls", "%%timeit", "%magic?", "!ls"
- Valid Python: "x = 1", "def f(): pass", "class C: pass"
- Incomplete code: "def f(", "if x:", "[1, 2,"
- System commands: "!echo hello", "!!ls -la"
- Help queries: "print?", "str.format??", "%magic?"
- Prompt examples: ">>> x = 1", "In [1]: x = 1"
- Edge cases: "%%magic\nmultiline\ncontent"
