# Arrow Library - Fuzzing Target Notes

## Library Overview
Arrow is a Python library for working with dates, times, and timestamps.
It provides parsing, formatting, and manipulation of datetime objects.

## Important Files for Fuzzing
- arrow/parser.py (score: 95) - Contains DateTimeParser and TzinfoParser classes
- arrow/factory.py (score: 85) - Contains ArrowFactory with flexible get() method
- arrow/arrow.py (score: 80) - Contains Arrow class with dehumanize() method
- arrow/formatter.py (score: 70) - Contains DateTimeFormatter

## Selected Functions Under Test (FUTs)

### FUT 1: DateTimeParser.parse_iso()
- File: arrow/parser.py:252-371
- Why: Primary entry point for ISO 8601 datetime string parsing
- Input: datetime_string (str), normalize_whitespace (bool)
- Harnessability: HIGH
- Input model: ISO 8601 formatted strings (e.g., "2021-10-12T14:30:00", "2021-10-12 14:30:00+00:00")
- Oracles: No crash, ParserError for invalid input (acceptable)
- Edge cases: Malformed dates, invalid separators, extreme years, invalid timezones

### FUT 2: DateTimeParser.parse()
- File: arrow/parser.py:373-439
- Why: Parses datetime strings with custom format strings
- Input: datetime_string (str), fmt (str or List[str]), normalize_whitespace (bool)
- Harnessability: HIGH
- Input model: Arbitrary strings with format tokens like "YYYY-MM-DD HH:mm:ss"
- Oracles: No crash, ParserMatchError for non-matching input (acceptable)
- Edge cases: Mismatched formats, special characters, locale-specific tokens

### FUT 3: TzinfoParser.parse()
- File: arrow/parser.py:894-937
- Why: Parses timezone strings - boundary function for external timezone data
- Input: tzinfo_string (str)
- Harnessability: HIGH
- Input model: Timezone strings like "UTC", "local", "+05:30", "America/New_York"
- Oracles: No crash, ParserError for invalid timezone (acceptable)
- Edge cases: Invalid timezone names, malformed offsets, edge offset values

### FUT 4: Arrow.dehumanize()
- File: arrow/arrow.py:1344-1481
- Why: Parses humanized relative time strings - complex regex-based parsing
- Input: input_string (str), locale (str)
- Harnessability: MEDIUM (requires Arrow instance)
- Input model: Humanized time strings like "2 days ago", "in 5 minutes"
- Oracles: No crash, ValueError for invalid input (acceptable)
- Edge cases: Unsupported locales, malformed time strings, edge time values

## Recommended Harness Approach
1. Create fuzz driver that calls parse_iso() and parse() with fuzzed strings
2. Catch expected exceptions (ParserError, ParserMatchError, ValueError)
3. Any other exceptions indicate bugs
4. Focus on string parsing functions as they handle untrusted input

## Seed Corpus Ideas
- Valid ISO 8601 dates: "2021-01-01", "2021-12-31T23:59:59.999999+00:00"
- Edge dates: "0001-01-01", "9999-12-31"
- Various formats: "YYYY-MM-DD", "DD/MM/YYYY", "MMMM Do, YYYY"
- Timezone strings: "UTC", "local", "+00:00", "-12:00", "America/New_York"
- Humanized strings: "now", "2 hours ago", "in 3 days"

## Dependencies
- python-dateutil
- backports.zoneinfo (for Python < 3.9)
