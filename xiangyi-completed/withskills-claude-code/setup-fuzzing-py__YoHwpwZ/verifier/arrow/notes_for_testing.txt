ARROW LIBRARY - FUZZING TARGET NOTES
=====================================

## Library Overview
Arrow is a Python library for better dates & times manipulation.
It provides a sensible approach to creating, manipulating, formatting and converting dates, times, and timestamps.

## Important Functions for Fuzzing

### 1. arrow.parser.DateTimeParser.parse()
- **Location**: arrow/parser.py
- **Purpose**: Parses date/time strings into datetime objects
- **Why fuzz**: Handles user-supplied string input with complex parsing logic
- **Input surface**: String inputs with various date/time formats
- **Risks**: Invalid formats, edge cases, unicode issues, extremely long strings
- **Test priority**: HIGH

### 2. arrow.arrow.Arrow.fromdatetime()
- **Location**: arrow/arrow.py
- **Purpose**: Constructs Arrow object from datetime
- **Why fuzz**: Converts between object types with timezone handling
- **Input surface**: datetime objects with various configurations
- **Test priority**: MEDIUM

### 3. arrow.factory.ArrowFactory.get()
- **Location**: arrow/factory.py
- **Purpose**: Flexible factory method accepting strings, timestamps, datetimes
- **Why fuzz**: Multiple input types and format strings
- **Input surface**: Mixed types (str, int, float, datetime) + format strings
- **Risks**: Type confusion, format string injection, invalid combinations
- **Test priority**: HIGH

### 4. arrow.arrow.Arrow.format()
- **Location**: arrow/arrow.py
- **Purpose**: Formats Arrow objects to strings using format tokens
- **Why fuzz**: Format string handling
- **Input surface**: Format string with various tokens
- **Risks**: Invalid format specifiers, buffer overflows in formatting
- **Test priority**: MEDIUM

### 5. arrow.parser.DateTimeParser.parse_iso()
- **Location**: arrow/parser.py
- **Purpose**: ISO 8601 datetime parsing
- **Why fuzz**: Standards-based parsing with strict/lenient modes
- **Input surface**: ISO 8601 formatted strings
- **Risks**: Malformed ISO strings, edge cases
- **Test priority**: HIGH

## Fuzzing Strategy
1. Start with arrow.parser.DateTimeParser.parse() - highest risk, complex parsing
2. Test arrow.factory.ArrowFactory.get() - multiple input types
3. Focus on edge cases: empty strings, very long strings, unicode, special characters
4. Test boundary values: min/max dates, invalid timezones, DST transitions

## Expected Exceptions
- ParserError: Expected for invalid date strings
- ValueError: Expected for out-of-range values
- TypeError: Expected for wrong input types

## Crash-Worthy Issues
- Infinite loops in parsing
- Stack overflow from recursion
- Memory exhaustion from malformed input
- Uncaught exceptions (not ParserError/ValueError)
