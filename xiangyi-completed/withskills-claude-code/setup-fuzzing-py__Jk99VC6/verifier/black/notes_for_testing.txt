Black Library - Fuzzing Target Analysis

PRIMARY TARGETS (Highest Priority):

1. lib2to3_parse() [CRITICAL]
   File: /app/black/src/black/parsing.py:55-102
   Complexity: High - Core parsing function, handles multiple grammar versions
   Input Surface: Arbitrary Python source strings with variable line endings
   Edge Cases:
   - Deeply nested syntax structures
   - Various Python version grammars

   File: /app/black/src/black/__init__.py:1177-1221

   Input Surface: Python source strings + Mode configuration
   Edge Cases:
   - Multiple formatting passes
   - Idempotence checking
   - AST transformations
   - String normalization edge cases
   - Large or pathological input structures
   Potential Issues: Memory exhaustion, infinite loops, DoS with pathological input

   Input Surface: String literals with prefixes, quotes, escape sequences
   Edge Cases:
   - Quote normalization edge cases
   - Escape sequence handling
