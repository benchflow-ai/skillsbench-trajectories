FUZZING STRATEGY:
- Start with transform_cell() and check_complete() for core parsing
- Test with various IPython special syntax (%, !, ?)
- Include magic command fuzzing
- Test prefilter_line() with edge cases
- Use existing IPython tests as seed corpus
- Monitor for ReDoS in regex patterns
- Test code injection attempts through various paths

ORACLE PROPERTIES:
- Round-trip: Transformed code should be valid Python
- Completeness check: check_complete() correctly identifies incomplete code
- No crashes on arbitrary input
- Magic execution should not escape to outer scope
- Transformations should be deterministic

EDGE CASES TO EMPHASIZE:
- Nested parentheses and brackets
- Unmatched quotes and brackets
- Magic commands with special characters
- Shell escapes with pipes and redirects
- Mixed magic and regular Python code
- Very deep nesting levels
- Control characters in input
