BUILD ERROR ANALYSIS AND FIXES
================================

Project: Google Auto (google/auto)

ORIGINAL BUILD ERRORS:
=====================

ERROR 1: Missing com.sun:tools dependency (PRIMARY ERROR)
- Error: Could not find artifact com.sun:tools:jar:11.0.27 at specified path
  /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar
- Root Cause: The compile-testing library (v0.6, v0.7, v0.8) declares a system dependency
  on com.sun:tools (via systemPath pointing to tools.jar), which doesn't exist in Java 9+.
  The tools.jar was removed in Java 9 and its functionality merged into the JDK modules.
- Affected modules: common, factory, service, value
- Solution: Exclude the com.sun:tools dependency from compile-testing since it's provided
  by the jdk.compiler module in Java 9+

ERROR 2: Missing javax.annotation.Generated class
- Error: cannot find symbol class Generated in package javax.annotation
- Root Cause: The modules use @Generated annotation from javax.annotation but don't
  explicitly depend on it. This annotation is needed but jsr305 doesn't contain it
  in the required form.
- Affected modules: factory, value
- Solution: Add javax.annotation:javax.annotation-api:1.3.2 as a compile dependency

ERROR 3: Transitive dependency version mismatch in integration tests
- Error: MoreObjects class not found in com.google.common.base
- Root Cause: guava-testlib:18.0 was supposed to bring in guava:18.0, but Maven
  was pulling in guava:17.0 instead due to transitive dependency resolution.
  MoreObjects was added in Guava 18.0.
- Affected modules: value/src/it/functional integration test
- Solution: Explicitly declare guava:18.0 as a compile dependency in functional test POM

FIXES APPLIED:
==============

1. Excluded com.sun:tools from compile-testing in all modules:

   - factory/pom.xml: Added exclusion block to compile-testing dependency
   - service/pom.xml: Added exclusion block to compile-testing dependency

2. Added javax.annotation:javax.annotation-api:1.3.2 to:

   - value/pom.xml: New compile-scope dependency

3. Added explicit guava:18.0 dependency to:
   - value/src/it/functional/pom.xml: New compile-scope dependency
