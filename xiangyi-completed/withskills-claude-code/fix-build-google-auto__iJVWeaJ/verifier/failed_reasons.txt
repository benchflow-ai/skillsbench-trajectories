# Build Failure Analysis for google/auto Repository

## Summary

The build fails across all modules (common, factory, service, value) due to Java 9+
compatibility issues:
1. Missing `com.sun:tools:jar` dependency (tools.jar removed in Java 9+)
2. Missing `javax.annotation.Generated` class (removed from Java 9+)

## Environment

- Java Version: OpenJDK 11.0.27
- Repository: google/auto (annotation processing framework)

## Error Messages

### Error 1: tools.jar not found
```
Could not find artifact com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar
```

### Error 2: javax.annotation.Generated not found
```
cannot find symbol
  symbol:   class Generated
  location: package javax.annotation
```

## Root Cause Analysis

### Issue 1: tools.jar Removal
In Java 9+, the `tools.jar` file was removed. It no longer exists as a separate JAR file.
The classes that were in tools.jar are now part of the JDK's module system (specifically
the `jdk.compiler` module).

The `compile-testing` library (versions 0.6, 0.7, 0.8 used in this project) has a
transitive dependency on `com.sun:tools:jar` which expects the `tools.jar` file to
exist at `${java.home}/../lib/tools.jar`.

### Issue 2: javax.annotation.Generated Removal
In Java 9+, the `javax.annotation.Generated` class was moved to the `java.compiler`
module and is no longer available by default. The factory and value modules use
this annotation but don't have the required dependency.

## Affected Files and Fixes Applied

### Fix 1: Update compile-testing dependency (patches 1-4)
Updated the `compile-testing` library to version 0.19 in all module pom.xml files.
Version 0.15+ of compile-testing removed the dependency on `com.sun:tools` and
supports Java 9+.

- common/pom.xml: Changed version 0.7 -> 0.19 (patch_1.diff)
- factory/pom.xml: Changed version 0.8 -> 0.19 (patch_2.diff)
- service/pom.xml: Changed version 0.6 -> 0.19 (patch_3.diff)
- value/pom.xml: Changed version 0.6 -> 0.19 (patch_4.diff)

### Fix 2: Update parent pom.xml (patch 5)
- Changed java.version property from 1.6 to 1.8
- Added Java 9+ profile that activates for JDK 9+ and sets empty toolsjar property

### Fix 3: Add javax.annotation-api dependency (patches 6-7)
Added `javax.annotation:javax.annotation-api:1.3.2` dependency to provide the
`javax.annotation.Generated` class:

- factory/pom.xml: Added javax.annotation-api dependency (patch_6.diff)
- value/pom.xml: Added javax.annotation-api dependency (patch_7.diff)
