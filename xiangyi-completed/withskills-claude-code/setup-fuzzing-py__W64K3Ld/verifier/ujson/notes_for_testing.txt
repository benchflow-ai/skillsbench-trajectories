UJSON FUZZING ANALYSIS - NOTES FOR TESTING

## IMPORTANT FUNCTIONS FOR FUZZING

### Tier 1 - CRITICAL Priority:

1. **JSON_DecodeObject() / decode_string()** - Core JSON string decoding (HIGHEST)
   - File: src/ujson/lib/ultrajsondec.c:790, 362
   - Main public decoder entry point with complex string parsing
   - Handles all JSON types with nested recursion
   - Focus: Escape sequences, Unicode validation, buffer overflow
   - Edge Cases:
     * Unicode escape sequences (\uXXXX, surrogate pairs)
     * UTF-8 multi-byte sequence validation
     * Escape buffer reallocation (lines 386-407)
     * Surrogate pair handling (lines 496-510)
   - Test Inputs:
     * Invalid UTF-8 sequences
     * Incomplete escape sequences
     * Deep nesting up to JSON_MAX_OBJECT_DEPTH (1024)
     * Integer overflow in numeric parsing

2. **decode_numeric()** - Number parsing with overflow detection (CRITICAL)
   - File: src/ujson/lib/ultrajsondec.c:91
   - Parses JSON numbers with type discrimination
   - Complex overflow detection logic
   - Focus: Integer overflow, floating point precision, special values
   - Key Code Paths:
     * Overflow checks at lines 144-157
     * Special values (Infinity, NaN) at lines 103-248
     * Type distinction (int/long/double)
   - Test Inputs:
     * Very large exponents (1e308, 1e309)
     * Boundary values (MAX_INT, MIN_INT)
     * Special values: NaN, Infinity, -0.0
     * Pathological precision values

3. **Buffer_EscapeStringValidated/Unvalidated()** - String escaping (CRITICAL)
   - File: src/ujson/lib/ultrajsonenc.c:302, 191
   - Complex escaping logic with buffer management
   - HTML encoding mode complexity
   - Focus: Buffer expansion, overflow, escape correctness
   - Key Operations:
     * Character classification and escaping
     * Buffer reallocation during escaping
     * HTML mode special characters (<, >, &)
     * Size calculation correctness
   - Test Inputs:
     * Control characters (expand 1 -> 6 bytes)
     * HTML special chars with encoding mode
     * Very long strings requiring reallocation
     * All Unicode characters

### Tier 2 - HIGH Priority:

4. **decode_array() / decode_object()** - Recursive container parsing (HIGH)
   - File: src/ujson/lib/ultrajsondec.c:589, 653
   - Recursive parsing with depth tracking
   - JSON_MAX_OBJECT_DEPTH enforcement (1024)
   - Focus: Depth limit validation, memory allocation
   - Test Inputs:
     * Deeply nested arrays: [[[[...]]]]
     * Deeply nested objects: {{{...}}}
     * Mixed nesting at depth boundaries
     * Error cleanup path validation

5. **JSON_EncodeObject() / Buffer_Realloc()** - Encoding and memory (HIGH)
   - File: src/ujson/lib/ultrajsonenc.c:953, 116
   - Memory allocation and reallocation strategy
   - Size calculation overflow potential
   - Focus: Allocation correctness, buffer doubling
   - Test Inputs:
     * Large Python objects with many strings
     * Various indent values (0-1000)
     * Pre-allocated vs NULL buffer scenarios
