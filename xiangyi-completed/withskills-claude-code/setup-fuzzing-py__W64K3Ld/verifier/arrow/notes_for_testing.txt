## IMPORTANT FUNCTIONS FOR FUZZING

### Top 5 Targets - CRITICAL to HIGH Priority:

1. **DateTimeParser.parse_iso()** - ISO 8601 datetime parsing (CRITICAL)
   - File: arrow/parser.py:252-371
   - Parses ISO 8601-like datetime strings
   - Multi-format fallback strategy (24+ formats)
   - Handles dates, times, timezones, basic/extended formats
   - Entry point for flexible datetime parsing

   Key Implementation:
   - Detects format: space/T divider, timezone markers
   - Complex state machine with multi-format fallback
   - Time component parsing with regex (_TIME_RE pattern)
   - Subsecond handling with various precisions
   - Timezone detection and parsing

   Edge Cases - DATE COMPONENTS:
   - Empty/minimal strings
   - Whitespace handling (spaces, tabs, newlines)
   - Leading/trailing whitespace
   - Multiple whitespace variations
   - Leap years (Feb 29)
   - Month boundaries (Jan 31, Apr 30)
   - Year boundaries (0001, 9999)

   Edge Cases - TIME COMPONENTS:
   - Timezone indicators: Z, +/-HH:MM, named zones
   - Date format variations: dash/slash/dot separators
   - Time with subseconds (various precisions)
   - Microsecond precision (000000-999999)
   - Midnight variations (00:00, 24:00)
   - Seconds boundary (59, 60 for leap seconds)

   Edge Cases - TIMEZONE:
   - UTC variants (utc, UTC, Z)
   - Local timezone
   - ISO offsets (+/-HH:MM, +/-HHMM, +/-HH)
   - Named timezone boundaries
   - Timezone without time
   - Invalid offset values

   Fuzzing Focus:
   - Whitespace normalization path
   - Regex boundary conditions in _TIME_RE
   - Format detection state machine
   - Subsecond rounding edge cases
   - Timezone parsing edge cases
   - Multiple T or space dividers

   Expected Issues:
   - ReDoS in regex patterns
   - Off-by-one in format detection
   - Timezone parsing failures
   - Boundary value handling

2. **ArrowFactory.get()** - Main factory entry point (CRITICAL)
   - File: arrow/factory.py:85-297
   - Signature: get(*args: Any, **kwargs: Any) -> Arrow
   - Primary public API for creating Arrow objects
   - Type-based dispatch on arguments
   - Supports: timestamp, Arrow, datetime, date, str, tuple, etc.

   Key Features:
   - Argument count discrimination (0, 1, 2, 3+)
   - Type-based dispatch for single argument
   - Locale and timezone resolution
   - Format string + datetime string pair support
   - Format list with fallback support

   Supported Input Types:
   1. No arguments: now() or utcnow()
   2. Single timestamp (int/float)
   3. Single ISO string (auto-parsed)
   4. Single datetime object (timezone conversion)
   5. Single date object (with time defaulting)
   6. Single Arrow object (clone/convert)
   7. Format + string pair
   8. ISO calendar tuple (year, week, day)
   9. Decimal numeric types

   Key Parameters:
   - tzinfo: Timezone override
   - locale: Locale specification
   - normalize_whitespace: Whitespace handling flag

   Edge Cases - TYPE CONFUSION:
   - bool vs int (bool is subclass of int)
   - Decimal vs float precision issues
   - None as argument (should error)
   - Custom types implementing __float__
   - Timezone-aware vs naive datetime

   Edge Cases - BOUNDARY VALUES:
   - Timestamp boundaries (Unix epoch edge cases)
   - Very large timestamps (year 9999)
   - Negative timestamps (before epoch)
   - Subsecond precision loss
   - Timezone offset boundaries (-12:00 to +14:00)
   - Daylight saving time transitions

   Edge Cases - FORMAT HANDLING:
   - Empty format string
   - Format string with no datetime
   - Multiple format specifications
   - Format list with no matches
   - Locale + format interaction
   - Whitespace normalization options

   Fuzzing Focus:
   - Type confusion attacks
   - Timestamp boundary values
   - Timezone edge cases
   - Format specification combinations
   - Mode parameter combinations
   - Error path handling

   Edge Cases - PATTERN GENERATION:
   - Escaped content in format

   - Regex compilation errors
   - Missing match groups

   Edge Cases - LOCALE INTERACTION:
   - Month names in different locales
   - Day names in different locales
   - Locale availability edge cases

   Fuzzing Focus:

   - Unix epoch: 0, -1, negative values
