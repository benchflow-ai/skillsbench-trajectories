UltraJSON Library - Functions Under Test for Fuzzing

- Location: /app/ujson/src/ujson/python/JSONtoObj.c (JSONToObj function)

- Fuzz Targets:

PRIORITY 2: decode_numeric()
- Location: /app/ujson/src/ujson/lib/ultrajsondec.c:91-247
- Input Type: String (numeric value in JSON)
- Purpose: Parse integers, floats, NaN, Infinity
- Key Features:
  * Complex integer overflow detection
  * Dual parsing paths (fast int, fallback to double)
  * Handles multiple integer types (int32, int64, uint64)
  * Special value handling (NaN, Infinity, -Infinity)
  * Exponent notation support
- Fuzz Targets:
  * Numbers exceeding 64-bit limits
  * Negative overflow scenarios
  * Decimal point handling in very large numbers
  * Exponent notation edge cases (e.g., 1e999999)
  * Malformed special values with typos
  * Boundary values (INT_MAX, UINT_MAX, INT_MIN)
  * Precision edge cases
  * Sign handling in various formats

PRIORITY 3: decode_string()
- Location: /app/ujson/src/ujson/lib/ultrajsondec.c:362-550+
- Input Type: String (JSON string literal)
- Purpose: Process string literals and unescape sequences
- Key Features:
  * Processes all JSON string literals
  * UTF-8 multi-byte sequence handling
  * Complex escape sequence parsing
  * Unicode surrogates (UTF-16 to UTF-32)
  * Dynamic memory allocation for escape buffer
  * Heap reallocation for large strings
- Fuzz Targets:
  * Invalid UTF-8 sequences
  * Malformed Unicode escapes (\uXXXX)
  * Surrogate pair edge cases (ordering, completeness)
  * Very long strings triggering reallocation
  * Mixed valid/invalid escape combinations
  * Buffer overflow scenarios
  * High Unicode codepoint values
  * Special escape sequences (\n, \t, \r, \\, \", etc.)

SECONDARY TARGETS:
- decode_array(): Deeply nested arrays (up to JSON_MAX_OBJECT_DEPTH=1024)
- decode_object(): Object key validation, nested objects
- decode_any(): JSON type dispatch and routing

ORACLE PROPERTIES:

- Proper error handling for invalid JSON

- Memory safety (no buffer overflows)
- Correct numeric precision
- Proper Unicode handling
