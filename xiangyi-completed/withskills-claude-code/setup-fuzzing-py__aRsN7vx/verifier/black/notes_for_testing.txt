Library Analysis: Black
=======================

Black is an uncompromising Python code formatter. It parses Python source code and reformats it.

Important Files for Fuzzing:
----------------------------

1. src/black/parsing.py (Score: 10/10)
   - lib2to3_parse(): Main parsing entry point
   - parse_ast(): AST parsing with multiple Python versions
   - Heavy parsing logic with multiple grammar attempts
   - Handles ParseError, TokenError, SyntaxError
   - Rationale: Core parsing boundary, handles untrusted source code input

2. src/black/__init__.py (Score: 9/10)
   - format_str(): Main formatting function
   - format_file_contents(): Formats file content
   - Central API for code formatting
   - Rationale: Main entry point, processes user source code

3. src/black/strings.py (Score: 8/10)
   - String normalization and manipulation
   - Handles f-strings, quotes, escaping
   - Rationale: String parsing and transformation logic

4. src/black/handle_ipynb_magics.py (Score: 7/10)
   - Jupyter notebook cell handling
   - mask_cell(), unmask_cell(), validate_cell()
   - Rationale: Handles Jupyter-specific syntax parsing

5. src/black/files.py (Score: 7/10)
   - parse_pyproject_toml(): TOML configuration parsing
   - File discovery and path validation
   - Rationale: Configuration parsing, path handling

Important Functions for Fuzzing:
--------------------------------

1. lib2to3_parse() - src/black/parsing.py:55
   - Accepts: src_txt (str), target_versions (Collection[TargetVersion])
   - Returns: Node (lib2to3 parse tree)
   - High-value target: Parses Python source code using lib2to3
   - Tries multiple grammars (Python 3.0-3.6, 3.7-3.9, 3.10+)
   - Can raise InvalidInput, ParseError, TokenError
   - Complex error handling and grammar selection
   - Existing tests: test_format.py, test_black.py

2. parse_ast() - src/black/parsing.py:137
   - Accepts: src (str)
   - Returns: ast.AST
   - High-value target: Parses Python code into AST
   - Tries multiple Python versions (3.3 through current)
   - Handles type comments
   - Can raise SyntaxError
   - Existing tests: Covered in test_black.py

3. format_str() - src/black/__init__.py
   - Accepts: src_contents (str), mode (Mode)
   - Returns: formatted string
   - High-value target: Main formatting entry point
   - Calls parsing, transformation, and output generation
   - Complex pipeline with AST validation
   - Existing tests: Extensive coverage in test_format.py

4. parse_pyproject_toml() - src/black/files.py
   - Accepts: path_config (Path)
   - Returns: configuration dict
   - High-value target: Parses TOML configuration files
   - JSON decode handling
   - Can raise JSONDecodeError, OSError
   - Existing tests: test_black.py config tests

5. validate_cell() - src/black/handle_ipynb_magics.py
   - Accepts: src (str), mode (Mode)
   - Returns: None (raises on error)
   - Medium-value target: Validates Jupyter cell syntax
   - Handles magic commands
   - Existing tests: test_ipynb.py
