Library Analysis: IPython
=========================

IPython is an interactive Python shell with enhanced features for interactive computing.

Important Files for Fuzzing:
----------------------------

1. IPython/core/inputtransformer2.py (Score: 9/10)
   - Transforms user input before execution
   - Handles IPython magic commands
   - Line-based and cell-based transformations
   - Rationale: Parses untrusted user input with complex transformations

2. IPython/core/compilerop.py (Score: 8/10)
   - Compiles Python code in interactive mode
   - Handles partial code compilation
   - Rationale: Code compilation with special handling

3. IPython/core/interactiveshell.py (Score: 8/10)
   - Main interactive shell implementation
   - run_cell(), run_code() methods
   - Rationale: Central execution engine

4. IPython/core/magic.py (Score: 7/10)
   - Magic command system
   - Parses and executes magic commands
   - Rationale: Command parsing and execution

5. IPython/core/completer.py (Score: 6/10)
   - Tab completion logic
   - Code introspection
   - Rationale: Parses partial code for completion

Important Functions for Fuzzing:
--------------------------------

1. Input transformation functions
   - InputTransformer transformers
   - Accepts: code strings
   - Returns: transformed code
   - High-value: Parses user input with complex rules

2. Code compilation
   - CachingCompiler.compile()
   - Accepts: Python code strings
   - Returns: compiled code objects
   - High-value: Handles partial/incomplete code

3. Magic command parsing
   - Magic command handlers
   - Accepts: command strings
   - Returns: execution results
   - Medium-value: Command parsing logic
