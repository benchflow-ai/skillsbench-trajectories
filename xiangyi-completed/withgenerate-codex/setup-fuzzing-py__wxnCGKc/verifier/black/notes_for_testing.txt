Key targets for fuzzing (black):
- black.format_str(...) / format_file_contents(...) for formatting input code.
- black.parsing.parse_ast(...) for AST parsing edge cases.
- black.reformat_code(...) for reformat pipeline.

Input ideas:
- Random Python snippets with odd indentation, comments, strings, f-strings, and unicode.
- Mix of valid/invalid syntax to exercise error paths (InvalidInput, SyntaxError).
- Small line_length values and toggles for string normalization / preview flags.
