Repository: /home/travis/build/failed/google/auto

Build command that fails:
- mvn -q -DskipTests -f build-pom.xml package

Observed error:
- auto-common fails dependency resolution: "Could not find artifact com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar".

Root cause:
- Test dependency com.google.testing.compile:compile-testing (versions 0.6/0.7/0.8) declares a system-scope dependency on com.sun:tools using tools.jar.
- On JDK 11, tools.jar no longer exists, so Maven fails while resolving test dependencies even with -DskipTests.
- This is a build configuration issue in module POMs, not a code error.

Plan:
- Add an exclusion for com.sun:tools to each module that declares compile-testing (common, factory, service, value).
- Rebuild with mvn -q -DskipTests -f build-pom.xml package to verify dependency resolution passes.
