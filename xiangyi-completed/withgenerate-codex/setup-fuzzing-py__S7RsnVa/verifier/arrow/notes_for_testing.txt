Focus areas (public API + parsers):
- arrow.api.get(...) and arrow.factory.ArrowFactory.get(...) for parsing diverse inputs (strings, datetimes, timestamps, tzinfo).
- arrow.parser.Parser.parse(...) and parse_iso(...) for ISO-like strings and tokenized formats.
- arrow.arrow.Arrow.format(...) and arrow.formatter.Formatter.format(...) for formatting directives.
- arrow.arrow.Arrow.shift(...) and Arrow.replace(...) for date arithmetic and normalization.
- arrow.locales.get_locale(...) / get_locale_by_class_name(...) for locale resolution.

Constraints/expectations:
- ParserError / ParserMatchError and ValueError are expected for invalid formats.
- Some functions accept tzinfo strings; invalid values should raise ParserError.
- Keep input sizes modest to avoid heavy locale parsing costs.
