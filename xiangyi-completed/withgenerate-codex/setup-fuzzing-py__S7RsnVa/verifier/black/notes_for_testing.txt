Focus areas (formatting/parsing):
- black.format_str(...) and black.format_file_contents(...) as main entry points.
- black.parsing.lib2to3_parse(...) and black.parsing.parse_ast(...) for parsing stability.
- black.ranges.parse_line_ranges(...) for range parsing edge cases.

Constraints/expectations:
- black.InvalidInput (and SyntaxError) are expected for malformed code.
- Format calls should be guarded with size limits to avoid pathological inputs.
- Prefer Mode() defaults; vary line length/target versions when possible.
