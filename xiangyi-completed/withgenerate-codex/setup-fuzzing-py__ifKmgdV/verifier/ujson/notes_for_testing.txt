Key entry points / parsing & serialization
- ujson.loads(str|bytes): JSON deserialization.
- ujson.dumps(obj): JSON serialization.
- ujson.decode/encode (if available): lower-level encode/decode helpers.

Fuzzing focus ideas
- Feed random bytes/strings into loads/decodes; tolerate ValueError/TypeError.
- Build small Python objects from fuzz data (ints, floats, lists, dicts, strings) and roundtrip via dumps/loads.

Things to avoid
- Avoid huge recursive objects; keep nesting and size bounded.
