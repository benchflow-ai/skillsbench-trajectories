Key entry points / parsing & formatting
- black.format_str(src, mode=Mode(...)) (src/black/__init__.py): main formatter for Python source strings.
- black.format_file_contents(src, fast, mode) (src/black/__init__.py): formatting content without file IO.
- black.format_cell(src, fast, mode) / format_ipynb_string(...) for notebook-like content.
- black.parsing.parse_ast(src) (src/black/parsing.py): AST parsing used by formatter.
- black.strings.normalize_string_quotes / normalize_fstring_quotes (src/black/strings.py): string normalization.
- black.ranges.parse_line_ranges(line_ranges) (src/black/ranges.py): parsing CLI line range syntax.

Fuzzing focus ideas
- Provide random (possibly invalid) Python code to format_str/format_file_contents; expect exceptions for invalid input.
- Random strings to parse_ast and string normalization helpers.
- Random list of strings for parse_line_ranges.

Things to avoid
- Keep source length bounded to avoid huge formatting times.
