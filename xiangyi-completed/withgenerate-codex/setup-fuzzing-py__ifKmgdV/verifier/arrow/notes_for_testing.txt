Key entry points / parsing & formatting
- arrow.get(...) (arrow/api.py, arrow/factory.py): accepts various date/time inputs (strings, timestamps, datetimes, tzinfo).
- arrow.Arrow.format(fmt) (arrow/arrow.py): formatting with custom tokens.
- arrow.Arrow.shift(...) / replace(...) (arrow/arrow.py): date arithmetic with kwargs.
- arrow.Arrow.span(...) / span_range(...) / range(...) (arrow/arrow.py): range generation & boundaries.
- arrow.parser.parse(...) / parse_iso(...) (arrow/parser.py): string parsing incl. ISO-8601 variants.
- arrow.formatter.format(dt, fmt) (arrow/formatter.py): direct formatting.

Fuzzing focus ideas
- Feed random strings (including invalid/unicode) to parser.parse / parse_iso / arrow.get.
- Feed random format strings to formatter.format / Arrow.format with a fixed datetime.
- Use random kwargs for shift/replace (bounded ranges) to exercise arithmetic.

Things to avoid
- Avoid system timezone dependence; prefer explicit tzinfo (e.g., UTC) when creating base Arrow.
- Avoid extremely large ranges in range/span_range.
