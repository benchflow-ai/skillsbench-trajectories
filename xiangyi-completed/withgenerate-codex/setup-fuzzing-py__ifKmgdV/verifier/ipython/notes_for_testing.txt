Key entry points / parsing & input transforms
- IPython.core.inputtransformer2.TransformerManager.transform_cell(cell) and check_complete(cell): core input transformation logic.
- IPython.core.splitinput.split_user_input(line): parses user input into command + args.
- IPython.core.magic_arguments.parse_argstring(magic_func, argstring): parses magic arguments.
- IPython.core.magic.MagicMixin.parse_options(arg_str, opt_str, *long_opts): option parsing.

Fuzzing focus ideas
- Feed random unicode strings (single/multi-line) into transform_cell/check_complete.
- Feed random lines into split_user_input.
- Feed random arg strings into parse_argstring/parse_options using minimal dummy magic function.

Things to avoid
- Avoid executing code or starting shells; only parsing/transforming APIs.
