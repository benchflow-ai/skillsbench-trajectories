Analysis:
- Running `mvn -f build-pom.xml -DskipTests package` fails during dependency resolution for `com.google.auto:auto-common`.
- The failure is `com.sun:tools:jar:11.0.27` with `systemPath` pointing at `${java.home}/../lib/tools.jar`, which does not exist on JDK 9+ (JDK 11 here).
- The dependency comes transitively from `com.google.testing.compile:compile-testing:0.7` used in test scope across modules.
- This is a build configuration compatibility issue with modern JDKs rather than a code error.

Plan:
- Exclude `com.sun:tools` from the `compile-testing` test dependency in each module that declares it (`common`, `factory`, `service`, `value`).
- Keep existing versions to minimize changes; rely on JDK 11's `javax.tools`/`jdk.compiler` modules for the compiler classes.
- Re-run `mvn -f build-pom.xml -DskipTests package` to verify dependency resolution succeeds.
