Primary targets for fuzzing (input transformation & parsing):
- IPython.core.inputtransformer2.TransformerManager.transform_cell: transforms cell text with magic, system, help syntax.
- TransformerManager.check_complete: completeness checking for multi-line input.
- IPython.core.splitinput.split_user_input: splits user input into pre, line, post sections.
- IPython.utils.text.strip_email_quotes / format_screen: text parsing and formatting utilities.
- IPython.core.magic_arguments.parse_argstring: argument parsing for magic commands.

Fuzz focus:
- Random Unicode cells with prompts, magics (%, %% , !), and line continuations.
- Edge cases: very long lines, mixed newlines, stray backslashes, unmatched brackets.
- Catch expected exceptions (SyntaxError, ValueError, TokenError, RuntimeError) from parsing and transforms.
