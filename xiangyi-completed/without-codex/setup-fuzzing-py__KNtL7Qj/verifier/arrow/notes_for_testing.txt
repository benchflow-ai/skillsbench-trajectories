Primary targets for fuzzing (API/inputs likely to be user-provided):
- arrow.get(...) / arrow.api.get: accepts strings, timestamps, datetimes, timezone strings, and format strings.
- arrow.parser.parse / parse_iso: parsing of ISO-8601 and custom formats.
- Arrow.format / formatter.format: string formatting with format tokens.
- Arrow.shift / Arrow.to / Arrow.humanize / Arrow.dehumanize: timezone conversion and humanization of time deltas.
- Locales: get_locale and get_locale_by_class_name (locale name handling).

Fuzz focus:
- Random Unicode strings and bytes decoded to text.
- A mix of valid and invalid format tokens (e.g., YYYY-MM-DD, X, x, etc.).
- Timezone strings (e.g., 'UTC', 'US/Pacific', '+02:00').
- Ensure we catch expected parsing/validation exceptions (ValueError, TypeError, OverflowError, parser errors).
