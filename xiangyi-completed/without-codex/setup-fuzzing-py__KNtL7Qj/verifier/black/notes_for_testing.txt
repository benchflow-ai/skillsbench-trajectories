Primary targets for fuzzing (text parsing/formatting):
- black.format_str: format arbitrary Python source text.
- black.decode_bytes: decode bytes with encoding/newline detection.
- black.format_file_contents: validate and format file content in one step.
- black.parsing.parse_ast: AST parsing with Black's tokenizer helpers.

Fuzz focus:
- Random Unicode text, including invalid syntax and edge-case whitespace.
- Random bytes for decode_bytes to exercise encoding detection.
- Expect and catch InvalidInput, SyntaxError, TokenError, ValueError, and OverflowError.
