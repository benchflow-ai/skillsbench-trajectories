Primary targets for fuzzing (JSON parser/serializer):
- ujson.loads: parse JSON from str/bytes/bytearray.
- ujson.dumps: serialize Python objects to JSON.

Fuzz focus:
- Random bytes decoded to text for loads.
- Construct random JSON-like objects (dict/list/str/int/float/bool/None) for dumps.
- Expected exceptions: ValueError, OverflowError, TypeError, RecursionError.
