Analysis of likely build failures:
1) Python 3.7/3.8 compatibility: `agentops/worker.py` uses `list[Dict]` for type annotations. Built-in generics require Python 3.9+, but `pyproject.toml` declares `requires-python = ">=3.7"`. This will raise a SyntaxError on import under 3.7/3.8, breaking the build.
2) Session start without prior init: tests call `agentops.start_session(config=...)` without calling `agentops.init()`. When `Client()` is instantiated without an API key, `ConfigurationError` is raised and `__init__` returns early, leaving `_tags_for_future_session` undefined. `start_session` then references `self._tags_for_future_session` when `tags` is None, causing an AttributeError.

Plan:
- Update `agentops/worker.py` to use `typing.List[Dict]` and import `List` to restore compatibility with Python 3.7/3.8.
- Initialize `_tags_for_future_session` (and `config` as None) early in `Client.__init__` so `start_session` can safely use it even if configuration failed due to a missing API key.
