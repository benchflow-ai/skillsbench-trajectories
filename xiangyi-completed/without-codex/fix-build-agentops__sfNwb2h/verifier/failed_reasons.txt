Analysis:
- Editable installs fail because pyproject.toml pins build backend to setuptools>=61, which does not implement PEP 660's build_editable hook. Pip in editable mode errors: "build backend is missing the build_editable hook".
- Importing agentops fails when the optional langchain dependencies are not installed. agentops/__init__.py imports langchain_callback_handler unconditionally, which imports langchain_core, causing ModuleNotFoundError and breaking test collection.

Plan:
1) Update pyproject.toml build-system requirement to setuptools>=64 (or newer) so editable installs succeed.
2) Make langchain handlers optional: guard the import in agentops/__init__.py and provide a clear error or placeholder if langchain isn't installed.
3) Re-run tests to confirm core functionality works without langchain extras.
