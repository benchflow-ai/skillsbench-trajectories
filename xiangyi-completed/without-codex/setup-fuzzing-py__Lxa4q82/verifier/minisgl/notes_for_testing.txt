Targets for fuzzing (serialization, message handling):
- minisgl.message.utils._serialize_any(...) and serialize_type(...) for nested structures.
- minisgl.message.utils._deserialize_any(...) and deserialize_type(...) for type tags.
- Tensor serialization path (1D torch.Tensor -> bytes -> torch.Tensor).

Interesting input dimensions:
- Deeply nested dict/list/tuple structures with mixed scalar types.
- __type__ dicts for Tensor and custom classes.
- Byte buffers and dtype strings for Tensor deserialization.
- Unexpected/invalid __type__ values and missing fields.

Potential error types to treat as expected:
- AssertionError (non-1D tensors), ValueError/TypeError/KeyError for malformed payloads.
