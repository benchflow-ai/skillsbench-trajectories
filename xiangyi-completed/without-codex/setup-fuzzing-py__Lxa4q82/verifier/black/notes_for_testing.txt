Targets for fuzzing (code parsing/formatting paths):
- black.format_str(...) (core formatting path for source code).
- black.format_file_contents(...) and black.decode_bytes(...) for bytes input handling.
- black.format_ipynb_string(...) for notebook JSON input.
- black.parsing.lib2to3_parse(...) and black.parse_ast(...) for parser edge cases.
- black.ranges.parse_line_ranges(...) for line-range parsing.

Interesting input dimensions:
- Random Python snippets, including invalid syntax and indentation.
- Long lines, multiline strings, f-strings, type comments, and escapes.
- Non-UTF8 bytes and unusual newline conventions (CRLF/CR).
- Jupyter notebook JSON payloads with missing/invalid fields.

Potential error types to treat as expected:
- black.InvalidInput, black.NothingChanged, SyntaxError, IndentationError,
  TokenError, ValueError, TypeError, AssertionError.
