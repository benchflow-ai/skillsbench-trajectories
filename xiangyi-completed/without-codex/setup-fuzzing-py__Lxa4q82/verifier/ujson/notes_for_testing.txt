Targets for fuzzing (JSON encoding/decoding):
- ujson.loads(...) for string/bytes JSON parsing.
- ujson.dumps(...) for encoding Python objects.

Interesting input dimensions:
- Invalid JSON: trailing commas, single quotes, unescaped control chars.
- Large numbers, NaN/Infinity, very deep nesting.
- Unicode escapes and surrogate edge cases.

Potential error types to treat as expected:
- ValueError, TypeError, OverflowError for malformed input.
