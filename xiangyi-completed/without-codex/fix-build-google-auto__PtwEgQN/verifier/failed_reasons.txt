Analysis:
- The build fails during `mvn -f build-pom.xml verify` because Maven cannot resolve `com.sun:tools:jar` at `${java.home}/../lib/tools.jar` on JDK 11. That jar was removed after JDK 8, so the system-scope dependency is broken on modern JDKs.
- The failing dependency is pulled in by the `com.google.testing.compile:compile-testing` test dependency (versions 0.6–0.8) which declares a system-scope `com.sun:tools` dependency. This makes the failure a build configuration/dependency issue, not a Java source issue.

Plan:
- Update each `compile-testing` dependency in module POMs (common, factory, service, value) to exclude `com.sun:tools` so Maven does not try to resolve tools.jar on JDK 9+.
- Re-run `mvn -f build-pom.xml verify -Dsource.skip=true -Dmaven.javadoc.skip=true` to confirm the build passes.
