LIBRARY: ujson
PURPOSE: Ultra-fast JSON encoder and decoder - C extension for high-performance JSON processing

KEY FUNCTIONS FOR FUZZING:

1. JSONToObj() / ujson.decode() or ujson.loads() - src/ujson/python/JSONtoObj.c:163-286
   - Input type: str or bytes (JSON data)
   - Expected exceptions: ValueError, JSONDecodeError, UnicodeDecodeError, OverflowError
   - Why fuzz this: PRIMARY ENTRY POINT - parses untrusted JSON input from external sources
   - Coverage: JSON parsing, escape sequence handling, type conversion
   - Test cases: Deeply nested structures (1000+ depth), malformed JSON, extreme numbers
   - Limits: JSON_MAX_RECURSION_DEPTH = 1024, JSON_MAX_STACK_BUFFER_SIZE = 1024

2. decode_string() - src/ujson/lib/ultrajsondec.c:362-587
   - Input type: str portion of JSON (quoted string with escapes)
   - Expected exceptions: ValueError, UnicodeDecodeError
   - Why fuzz this: String escape sequence processing - critical for parsing
   - Coverage: Unicode escapes (\uXXXX), surrogates, UTF-8 validation, buffer management
   - Test cases: Invalid surrogate pairs, incomplete escapes, malformed UTF-8
   - Vulnerabilities: UTF-16 surrogate pair handling, buffer overflow potential

3. decode_numeric() - src/ujson/lib/ultrajsondec.c:91-247
   - Input type: str portion of JSON (number)
   - Expected exceptions: ValueError, OverflowError
   - Why fuzz this: Number parsing with overflow detection
   - Coverage: Integer/float parsing, scientific notation, special values (Inf, NaN)
   - Test cases: 1e308, 1e-308, -0, very long decimals, integer limits
   - Vulnerabilities: Integer overflow/underflow, floating-point edge cases

4. decode_array() - src/ujson/lib/ultrajsondec.c:589-651
   - Input type: JSON array structure
   - Expected exceptions: ValueError, RecursionError (depth limit)
   - Why fuzz this: Array parsing with recursion depth tracking
   - Coverage: Nested arrays, depth limit enforcement, element parsing
   - Test cases: Arrays with 1024+ nesting depth, empty arrays, mixed types
   - Limit: JSON_MAX_OBJECT_DEPTH = 1024

5. decode_object() - src/ujson/lib/ultrajsondec.c:653-745
   - Input type: JSON object structure
   - Expected exceptions: ValueError, RecursionError, KeyError
   - Why fuzz this: Object parsing with key-value validation
   - Coverage: Key-value pairs, recursion depth, type checking
   - Test cases: Duplicate keys, non-string keys, deeply nested objects
   - Limit: JSON_MAX_OBJECT_DEPTH = 1024

6. objToJSON() / ujson.encode() or ujson.dumps() - src/ujson/python/objToJSON.c:660-865
   - Input type: Python object (dict, list, tuple, str, int, float, bool, None)
   - Expected exceptions: TypeError, ValueError, OverflowError
   - Why fuzz this: Serialization of arbitrary Python objects with configuration options
   - Coverage: Type conversion, recursion depth limiting, option handling
   - Test cases: Custom objects, cyclic references, extreme nesting
   - Options to fuzz: ensure_ascii, encode_html_chars, escape_forward_slashes, sort_keys, indent, allow_nan, reject_bytes
   - Limit: recursionMax = 1024

7. JSON_DecodeObject() - src/ujson/lib/ultrajsondec.c:790-834
   - Input type: Raw bytes/string (entire JSON document)
   - Expected exceptions: ValueError, MemoryError
   - Why fuzz this: Core decoder dispatcher and buffer management
   - Coverage: Decoder state initialization, escape buffer allocation, main parsing loop
   - Test cases: Large documents (>10MB), extreme nesting, malformed structure

RELATED FUNCTIONS TO AVOID:
- File I/O operations
- Network operations
- Memory allocation beyond what fuzzer controls

DEPENDENCIES:
- C compiler (for extension)
- setuptools
- wheel (for building)

SETUP NOTES:
- C extension library - requires compilation
- Uses setup.py for building
- Pure C core with Python bindings
- Ultra-fast - can handle millions of parse ops in fuzzing session
- Test configuration in pyproject.toml

PARSING CHARACTERISTICS:
- Strict JSON parsing (RFC 7159)
- IEEE 754 double precision for floats
- UTF-8 validation throughout
- Stack-based recursion tracking
- Streaming not supported - all data processed at once

COMMON EXPECTED EXCEPTIONS:
- ValueError: Invalid JSON format
- JSONDecodeError: Malformed JSON (subclass of ValueError)
- UnicodeDecodeError: Invalid UTF-8 sequences
- OverflowError: Integer too large to convert
- TypeError: Invalid Python type for encoding (objToJSON)

FUZZING STRATEGIES:
1. Deeply nested structures (approach 1024 limit)
2. Unicode edge cases (surrogates, combining characters)
3. Numeric edge cases (very large/small exponents, precision limits)
4. Escape sequence mutations
5. Configuration option combinations
6. Mixed valid/invalid JSON
7. Boundary condition testing
