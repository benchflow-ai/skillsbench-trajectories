VLOOKUP (Vertical Lookup)\n**Purpose**: Search for a value in the leftmost column of a table and return a value from a specified column to the right.\n\n**Syntax**: `=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])`\n\n**Parameters**:\n- `lookup_value`: The value to search for\n- `table_array`: The range containing the data\n- `col_index_num`: The column number to return (1-based)\n- `range_lookup`: FALSE for exact match, TRUE for approximate\n\n**Limitations**:\n- Only searches from left to right\n- Sensitive to column position (must be to the right of lookup column)\n\n### 2.
