# UltraJSON (ujson) Library - Fuzzing Analysis Notes

## Overview
ujson is a fast JSON encoder/decoder written in C.

## Main Entry Points to Fuzz

### 1. ujson.loads(obj) / ujson.decode(obj) - PRIMARY TARGET
Parses JSON string/bytes to Python object.
Input: str, bytes, or bytearray
No keyword arguments accepted.

### 2. ujson.dumps(obj, **kwargs) / ujson.encode(obj, **kwargs)
Encodes Python object to JSON string.
Parameters:
- ensure_ascii: bool (default=True)
- encode_html_chars: bool (default=False)
- escape_forward_slashes: bool (default=True)
- sort_keys: bool (default=False)
- indent: int (default=0)
- allow_nan: bool (default=True)
- reject_bytes: bool (default=True)
- default: callable (optional)
- separators: tuple (optional)

### 3. ujson.load(fp)
Parses JSON from file object.

### 4. ujson.dump(obj, fp, **kwargs)
Encodes to file object.

## Expected Exceptions
- ujson.JSONDecodeError (ValueError subclass):
  - Invalid JSON syntax
  - Unexpected characters
  - Incomplete input
  - Depth exceeded
  - Invalid escape sequences
  - Unterminated strings

- TypeError:
  - Unsupported object types
  - Invalid return from __json__()
  - sort_keys with incompatible keys
  - File without write()

- OverflowError:
  - NaN/Infinity with allow_nan=False
  - Invalid UTF-8 bytes
  - Extremely large integers

- RecursionError: depth exceeded (max 1024)

## Input Types
- String/bytes (JSON for decoder)
- Python primitives: None, bool, int, float, str
- Collections: list, tuple, dict
- Custom objects with __json__() or toDict()

## Constants/Limits
- JSON_MAX_RECURSION_DEPTH: 1024
- JSON_MAX_OBJECT_DEPTH: 1024
- JSON_DOUBLE_MAX_DECIMALS: 15

## Special Values
- NaN, Infinity, -Infinity supported
- null -> None
- true/false -> True/False

## Fuzzing Focus Areas
1. Deeply nested arrays/objects (near 1024 limit)
2. Large strings with special characters
3. Invalid UTF-8 sequences
4. Unicode surrogates and escapes
5. Floating-point edge cases (denormalized, large exponents)
6. Large integers (beyond 64-bit)
7. Incomplete/truncated JSON
8. Trailing data after valid JSON
9. Object keys of non-string types (encoder)
10. Buffer boundary conditions
11. Escape sequence handling
12. Very long strings

## Dependencies
- setuptools >= 42
- C compiler (GCC/Clang/MSVC)
- double-conversion library (bundled)
