# MiniSGL Library - Fuzzing Analysis Notes

## Overview
MiniSGL is a minimal inference engine for large language models.

## Main Entry Points to Fuzz

### 1. deserialize_type(cls_map, data) - HIGH PRIORITY
Location: python/minisgl/message/utils.py
Deserializes dictionaries to Python objects.
Risk: Uses np.frombuffer() for tensors, dynamic type lookup.

### 2. serialize_type(obj)
Location: python/minisgl/message/utils.py
Serializes Python objects to dictionaries.
Risk: Tensor serialization expects 1D tensors only.

### 3. TokenizeManager.tokenize(msgs)
Location: python/minisgl/tokenizer/tokenize.py
Tokenizes text via tokenizer.apply_chat_template() and encode().
Input: TokenizeMsg with text (str or List[Dict[str, str]])

### 4. DetokenizeManager.detokenize(msgs)
Location: python/minisgl/tokenizer/detokenize.py
Converts token IDs back to strings.
Risk: Token ID validation, incomplete UTF-8 handling.

### 5. load_hf_weight(model_path, device)
Location: python/minisgl/models/weight.py
Loads weights from local path or HuggingFace Hub.
Risk: Path handling, glob patterns, safetensors parsing.

### 6. ModelConfig.from_hf(config)
Location: python/minisgl/models/config.py
Extracts configuration from HuggingFace model config.
Risk: Numeric calculations, division operations.

### 7. Scheduler._process_one_msg(msg)
Location: python/minisgl/scheduler/scheduler.py
Processes UserMsg, validates input_ids length.
Risk: Integer overflow in length calculations.

## Expected Exceptions
- ValueError - invalid type names, malformed tensors
- KeyError - missing dictionary keys, tensor keys
- AssertionError - failed assertions
- AttributeError - missing attributes
- IndexError - tensor dimension issues
- RuntimeError - memory issues
- NotImplementedError - unimplemented features
- ZeroDivisionError - calculation errors

## Input Types
- Dictionaries with "__type__" field (serialization)
- torch.Tensor (1D int32 for input_ids)
- Strings (prompts, model paths)
- Chat format: List[Dict[str, str]] with "role"/"content"
- Integers: token IDs, max_tokens, uid

## Fuzzing Focus Areas
1. Serialization with malformed dicts
2. Invalid type names in "__type__" field
3. Corrupted tensor bytes
4. Multi-dimensional tensors (should be 1D)
5. Path traversal in model_path
6. Invalid token IDs (negative, out-of-vocab)
7. Extremely long prompts
8. Invalid chat format dicts
9. Zero/negative values in config
10. Concurrent message processing

## Dependencies
- torch
- transformers >= 4.56.0, <= 4.57.3
- safetensors
- msgpack
- numpy
- fastapi, uvicorn
- pyzmq
