# IPython Library - Fuzzing Analysis Notes

## Overview
IPython is an enhanced interactive Python shell with rich functionality.

## Main Entry Points to Fuzz

### 1. TransformerManager.transform_cell(cell) - PRIMARY TARGET
Location: IPython/core/inputtransformer2.py
Transforms IPython special syntax to Python code.
Input: Raw cell code with %magic, !system, ?help syntax.

### 2. TransformerManager.check_complete(cell)
Location: IPython/core/inputtransformer2.py
Checks if code is complete, incomplete, or invalid.
Returns: ('complete'|'incomplete'|'invalid', indent_spaces|None)

### 3. CachingCompiler.ast_parse(source, filename='<unknown>', symbol='exec')
Location: IPython/core/compilerop.py
Parses code to AST with compiler flags.

### 4. split_user_input(line, pattern)
Location: IPython/core/splitinput.py
Splits line into: (pre_whitespace, escape_char, function_name, rest)
Handles: !, !!, ?, ??, %, %%, ,, ;, /

## Token Transformers (in inputtransformer2.py)
- MagicAssign: a = %magic args -> get_ipython().run_line_magic(...)
- SystemAssign: a = !command -> get_ipython().getoutput(...)
- EscapedCommand: !cmd, %magic, ?obj -> appropriate calls
- HelpEnd: obj? and obj?? -> pinfo magic

## Expected Exceptions
- SyntaxError - invalid Python syntax after transformation
- tokenize.TokenError - malformed tokens
- RuntimeError - transformation loop limit (500)
- OverflowError - integer literals too large
- ValueError - invalid literal format
- TypeError - unexpected type in compilation
- MemoryError - out of memory

## Input Types
- String (cell code with IPython syntax)
- String (magic function arguments)
- String (shell commands)

## Fuzzing Focus Areas
1. Mixed IPython escape sequences (!, %, ?, etc.)
2. Unclosed strings/brackets
3. Deeply nested expressions
4. Backslash line continuation
5. Unicode identifiers
6. Malformed magic names
7. Very long lines
8. Multiple escape characters together
9. Cell magics with complex content
10. Prompt patterns (In [N]:, >>>, etc.)

## Dependencies
- jedi >= 0.18.1
- decorator >= 4.3.2
- prompt_toolkit >= 3.0.41, < 3.1.0
- traitlets >= 5.13.0
