# Arrow Library - Fuzzing Analysis Notes

## Overview
Arrow is a Python date/time library providing human-friendly parsing and manipulation.

## Main Entry Points to Fuzz

### 1. arrow.get() - PRIMARY TARGET
Location: arrow/api.py and arrow/factory.py
Polymorphic function accepting multiple input types:
- String (ISO format): arrow.get("2021-05-15T10:30:00")
- String with format: arrow.get("05/15/2021", "MM/DD/YYYY")
- Timestamps: arrow.get(1234567890.5)
- Timezone expressions: arrow.get("US/Pacific")

### 2. DateTimeParser.parse_iso(datetime_string, normalize_whitespace=False)
Location: arrow/parser.py
Parses ISO 8601-like date/time strings.
Critical for fuzzing - handles untrusted string input.

### 3. DateTimeParser.parse(datetime_string, fmt, normalize_whitespace=False)
Location: arrow/parser.py
Parses datetime strings against format string(s).
Regex-based matching - potential for ReDoS vulnerabilities.

### 4. TzinfoParser.parse(tzinfo_string)
Location: arrow/parser.py
Parses timezone expressions: ISO offsets, timezone names.
Examples: "UTC", "+05:30", "US/Pacific", "local"

## Expected Exceptions
- arrow.parser.ParserError (ValueError subclass) - parsing fails
- arrow.parser.ParserMatchError (ParserError subclass) - format mismatch
- TypeError - invalid argument types
- ValueError - invalid values (e.g., month 13, day 32)
- OverflowError - extremely large timestamps

## Input Types
- Strings (UTF-8): date/time strings, format strings, timezone strings
- Integers/Floats: timestamps
- Tuples: ISO calendar dates

## Fuzzing Focus Areas
1. ISO 8601 parsing with various formats
2. Timezone offset parsing: "+05:30", "-12:00", "Z"
3. Format string parsing with tokens: YYYY, MM, DD, HH, mm, ss
4. Very large/negative timestamps
5. Edge dates: leap years, leap seconds, year boundaries
6. Unicode in date strings
7. Whitespace normalization edge cases

## Dependencies
- python-dateutil >= 2.7.0
- backports.zoneinfo (Python < 3.9)
- tzdata (Python >= 3.9)
