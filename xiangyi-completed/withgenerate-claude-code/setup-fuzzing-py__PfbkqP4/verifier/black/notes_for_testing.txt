# Black Library - Fuzzing Analysis Notes

## Overview
Black is an uncompromising Python code formatter.

## Main Entry Points to Fuzz

### 1. black.format_str(src_contents, *, mode) - PRIMARY TARGET
Location: src/black/__init__.py
Core formatter - formats Python code string.
Parameters:
- src_contents: str - Python source code
- mode: black.Mode() - formatting configuration

### 2. black.format_file_contents(src_contents, *, fast, mode, lines)
Location: src/black/__init__.py
Wrapper with safety checks that calls format_str().

### 3. black.lib2to3_parse(src_txt, target_versions, type_comments)
Location: src/black/parsing.py
Parses Python source to lib2to3 AST.

### 4. black.parse_ast(src, type_comments=False)
Location: src/black/parsing.py
Parses Python source to Python AST.

### 5. black.format_ipynb_string(src_contents, *, fast, mode)
Location: src/black/__init__.py
Formats Jupyter notebook JSON with Python cells.

## Expected Exceptions
- black.parsing.InvalidInput (ValueError subclass) - code fails to parse
- black.parsing.ASTSafetyError - generated code not equivalent
- black.report.NothingChanged (UserWarning subclass) - already formatted
- SyntaxError - invalid Python syntax
- tokenize.TokenError - malformed tokens
- blib2to3.pgen2.parse.ParseError - grammar mismatch
- IndentationError - invalid indentation

## Input Types
- String (Python source code)
- String (JSON for Jupyter notebooks)

## Mode Configuration
- target_versions: set[TargetVersion] - Python version targets
- line_length: int (default 88)
- string_normalization: bool - quote normalization
- is_pyi: bool - stub files
- is_ipynb: bool - Jupyter notebooks
- preview: bool - experimental features

## Fuzzing Focus Areas
1. Malformed Python syntax
2. Deeply nested structures
3. Very long lines
4. Mixed indentation (tabs/spaces)
5. Unicode identifiers
6. Edge cases in string literals
7. Complex f-strings
8. Pattern matching syntax
9. Invalid encodings
10. Jupyter notebook JSON parsing

## Dependencies
- click >= 8.0.0
- mypy_extensions >= 0.4.3
- packaging >= 22.0
- pathspec >= 0.9.0
- platformdirs >= 2
- pytokens >= 0.3.0
- tomli >= 1.1.0 (Python < 3.11)
