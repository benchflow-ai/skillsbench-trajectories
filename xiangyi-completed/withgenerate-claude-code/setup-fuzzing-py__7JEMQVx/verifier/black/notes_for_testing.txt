Library: Black - The Uncompromising Code Formatter
===================================================

Purpose: Python code formatter

Key Modules:
- black.__init__: Main formatting functions
- black.parsing: AST parsing with lib2to3
- black.linegen: Line generation and transformation
- black.mode: Formatting modes and options
- black.comments: Comment handling

Important Functions for Fuzzing:

1. black.format_str()
   - Main function to format Python code strings
   - Takes: src (str), mode (Mode)
   - Parses and reformats Python code
   - High complexity with AST manipulation

2. black.format_file_contents()
   - Formats file contents
   - Takes: src, fast, mode
   - Similar to format_str but with file handling

3. black.parsing.lib2to3_parse()
   - Parses Python code to AST using lib2to3
   - Takes: src_txt (str)
   - Critical parser - good fuzzing target
   - Can raise InvalidInput, ASTSafetyError

4. black.parsing.parse_ast()
   - Parses to standard Python AST
   - Takes: src (str)
   - Alternative parser

5. black.comments.normalize_fmt_off()
   - Handles fmt: off/on comments
   - String processing with regex

6. black.Mode class
   - Configuration for formatting
   - Test with various combinations of options

Primary Fuzzing Targets:
- Python code parsing (valid and invalid syntax)
- Comment processing
- String literal handling
- Format mode configurations
- Edge cases in Python syntax

Expected Exceptions:
- InvalidInput (parsing errors)
- ASTSafetyError (unsafe AST)
- NothingChanged (no changes needed)
- ValueError, TypeError

Input Types to Test:
- Malformed Python code
- Edge case syntax (decorators, f-strings, etc.)
- Very long lines
- Complex nested structures
- Unicode identifiers and strings
- Comments in unusual positions
- Mixed indentation
- Various Python version syntax
