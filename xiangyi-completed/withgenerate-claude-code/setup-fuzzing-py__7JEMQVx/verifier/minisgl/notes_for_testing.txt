Library: Mini-SGLang - Lightweight LLM Inference Framework
============================================================

Purpose: High-performance inference framework for Large Language Models

Key Modules:
- minisgl.core: Core request and sampling parameter classes
- minisgl.engine: Inference engine
- minisgl.kvcache: KV cache management
- minisgl.message: Message handling
- minisgl.utils: Various utilities

Important Functions for Fuzzing:

1. minisgl.core.SamplingParams class
   - Configuration for sampling (temperature, top_k, top_p)
   - Dataclass with validation
   - Test with out-of-range values

2. minisgl.core.Req class
   - Request object with input_ids, cache info
   - Post-init validation (assertions)
   - Test property methods (remain_len, extend_len)

3. minisgl.utils.* utility functions
   - Various helper functions for processing
   - String/data manipulation

4. Message parsing/handling (if accessible)
   - Protocol message handling
   - Serialization/deserialization

Primary Fuzzing Targets:
- SamplingParams initialization and validation
- Req object creation with edge case values
- Tensor operations with unusual shapes/values
- Utility function inputs
- Parameter validation logic

Expected Exceptions:
- AssertionError (validation failures)
- ValueError (invalid parameters)
- TypeError (wrong types)
- RuntimeError (torch operations)

Input Types to Test:
- Invalid temperature values (negative, very large)
- Edge case top_k, top_p values
- Invalid tensor shapes
- Negative lengths/indices
- Very large numbers
- None/null values where not expected

Note: This library uses PyTorch and is GPU-focused. Fuzzing should
focus on CPU-based validation and parameter processing to avoid
GPU dependencies. Mock torch tensors where needed.
