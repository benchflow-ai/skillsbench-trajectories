Library: IPython - Productive Interactive Computing
===================================================

Purpose: Interactive Python shell and kernel

Key Modules:
- IPython.core.completer: Code completion
- IPython.core.inputtransformer: Input transformation
- IPython.core.displayhook: Output formatting
- IPython.core.magic: Magic command system
- IPython.core.prefilter: Pre-process input

Important Functions for Fuzzing:

1. IPython.core.inputtransformer2.TransformerManager.transform_cell()
   - Transforms IPython cell input to valid Python
   - Handles magic commands, shell escapes
   - Takes: cell (str)
   - Complex string transformation logic

2. IPython.core.completer.Completer.complete()
   - Code completion logic
   - Takes: text, line, cursor_pos
   - Parses partial code

3. IPython.core.prefilter.PrefilterManager.prefilter_lines()
   - Pre-processes input lines
   - Handles special IPython syntax
   - Takes: lines (str), continue_prompt

4. IPython.utils.tokenutil functions
   - Token-based utilities
   - Various string parsing helpers

5. IPython.core.magic.Magics command parsing
   - Parses magic commands (%magic, %%cell_magic)
   - String processing with arguments

Primary Fuzzing Targets:
- Input transformation (IPython syntax to Python)
- Magic command parsing
- Code completion logic
- Token parsing
- Shell command handling

Expected Exceptions:
- SyntaxError (invalid Python/IPython syntax)
- ValueError (invalid arguments)
- AttributeError (completion on invalid objects)
- Various transformer-specific exceptions

Input Types to Test:
- IPython magic commands (%timeit, %run, etc.)
- Shell escapes (!command, !!command)
- Mixed IPython and Python syntax
- Malformed magic syntax
- Very long input lines
- Unicode and special characters
- Nested quotes and escapes
- Incomplete code fragments

Note: IPython is complex and stateful. Focus on stateless parsers
and transformers for effective fuzzing.
