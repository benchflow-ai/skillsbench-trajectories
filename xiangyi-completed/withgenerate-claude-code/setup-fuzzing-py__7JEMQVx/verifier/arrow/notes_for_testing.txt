Library: Arrow - Better dates & times for Python
================================================

Purpose: Date/time parsing and manipulation library

Key Modules:
- arrow.parser: DateTimeParser - parses datetime strings
- arrow.factory: Creates Arrow objects from various formats
- arrow.formatter: Formats Arrow objects to strings
- arrow.api: Main API functions like get(), now(), utcnow()

Important Functions for Fuzzing:

1. arrow.parser.DateTimeParser.parse()
   - Parses datetime strings with format strings
   - High complexity with regex parsing
   - Takes: datetime_string, format_string
   - Good target for malformed input testing

2. arrow.get()
   - Main entry point, accepts various input types
   - Can parse strings, timestamps, datetime objects
   - Takes: *args, **kwargs (flexible)
   - Tests type coercion and parsing

3. arrow.parser.DateTimeParser.parse_iso()
   - Parses ISO 8601 datetime strings
   - Handles timezone information
   - Good for testing edge cases in ISO format

4. arrow.Arrow.format()
   - Formats Arrow objects to strings
   - Uses format tokens (YYYY, MM, DD, etc.)
   - Test with unusual format strings

5. arrow.Arrow.humanize()
   - Converts to human-readable relative time
   - Complex string generation logic
   - Test with edge case dates

Primary Fuzzing Targets:
- String parsing functions (parse, parse_iso)
- Format string processing
- Timezone handling
- Relative time calculations

Expected Exceptions:
- ParserError, ParserMatchError (custom)
- ValueError (invalid dates)
- TypeError (wrong types)

Input Types to Test:
- Malformed datetime strings
- Invalid format strings
- Edge case timestamps (negative, very large)
- Various timezone strings
- Unicode and special characters
