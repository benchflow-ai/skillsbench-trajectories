Library: UltraJSON (ujson) - Ultra Fast JSON Encoder/Decoder
==============================================================

Purpose: High-performance JSON encoder/decoder with Python bindings

Key Functions:
- ujson.loads(): Decode JSON string to Python object
- ujson.dumps(): Encode Python object to JSON string
- ujson.encode(): Alias for dumps
- ujson.decode(): Alias for loads

Important Functions for Fuzzing:

1. ujson.loads(s, precise_float=False, reject_bytes=True)
   - Parses JSON string to Python objects
   - Written in C - excellent fuzzing target
   - Can expose buffer overflows, parser bugs
   - Takes: JSON string
   - Returns: Python object (dict, list, str, int, float, bool, None)

2. ujson.dumps(obj, ensure_ascii=True, double_precision=9, encode_html_chars=False,
               escape_forward_slashes=True, sort_keys=False, indent=0)
   - Encodes Python object to JSON string
   - Many options to test
   - Can expose encoding edge cases
   - Takes: Any JSON-serializable Python object

3. ujson.encode() - Same as dumps()

4. ujson.decode() - Same as loads()

Primary Fuzzing Targets:
- JSON parsing (loads/decode)
  * Malformed JSON
  * Deeply nested structures
  * Very long strings/numbers
  * Invalid escape sequences
  * Unicode edge cases
  * Buffer boundary cases

- JSON encoding (dumps/encode)
  * Circular references
  * Very large numbers
  * Special float values (inf, nan)
  * Deep nesting
  * Unicode characters
  * Various Python object types

Expected Exceptions:
- ValueError (invalid JSON)
- TypeError (non-serializable objects)
- OverflowError (numbers too large)
- RecursionError (too deeply nested)

Input Types to Test for loads():
- Malformed JSON strings
- Invalid escape sequences (\x, \u)
- Unterminated strings/arrays/objects
- Invalid numbers (leading zeros, multiple decimals)
- Invalid Unicode surrogate pairs
- Very large numbers
- Deeply nested arrays/objects
- Mixed valid/invalid syntax
- Empty strings
- Very long strings (> 1MB)
- Binary data

Input Types to Test for dumps():
- Nested dicts/lists (depth 100+)
- Very large integers
- Float special values (inf, -inf, nan)
- Unicode strings (emoji, etc.)
- Bytes objects
- Custom objects
- Circular references (should fail)

Note: ujson is a C extension. Fuzzing can potentially find:
- Buffer overflows
- Memory corruption
- Segmentation faults
- Integer overflows
- Parser state machine bugs

This is a HIGH VALUE fuzzing target due to C implementation.
