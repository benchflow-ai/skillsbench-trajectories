Library: ujson (UltraJSON)
Version: dynamic (setuptools_scm)
Purpose: Ultra fast JSON encoder and decoder written in pure C

Main Entry Points:
- ujson.loads(s) - Decode JSON string to Python object
  - HIGHEST PRIORITY FOR FUZZING
  - C extension with potential for buffer issues

- ujson.dumps(obj) - Encode Python object to JSON string
  - Also important for fuzzing

Key Functions for Fuzzing:
1. ujson.loads(s) - JSON decoding
   - Takes JSON string, returns Python object
   - C implementation - important security target
   - Critical for fuzzing

2. ujson.dumps(obj, **kwargs) - JSON encoding
   - encode_html_chars, ensure_ascii, escape_forward_slashes, indent
   - Various encoding options to test

3. ujson.load(fp) - Decode from file
4. ujson.dump(obj, fp) - Encode to file

Input Types:
- String inputs: JSON strings for loads()
- Various Python objects for dumps()
- Encoding options: booleans and integers

Expected Exceptions to Catch:
- ujson.JSONDecodeError - Invalid JSON
- ValueError - Invalid values
- TypeError - Wrong type inputs
- OverflowError - Numeric overflow
- UnicodeDecodeError - Encoding issues

Dependencies:
- None at runtime (C extension)
- Build requires: setuptools, setuptools_scm

Build Note:
ujson is a C extension module. It needs to be built with:
  pip install -e .
This compiles the C code into a .so file.

Fuzzing Strategy:
1. Primary: ujson.loads() with arbitrary string inputs
2. Secondary: ujson.dumps() with various Python objects
3. Include edge cases:
   - Deeply nested structures
   - Very long strings
   - Unicode edge cases
   - Malformed JSON
   - Numeric limits
4. Test encoding options (ensure_ascii, encode_html_chars)
