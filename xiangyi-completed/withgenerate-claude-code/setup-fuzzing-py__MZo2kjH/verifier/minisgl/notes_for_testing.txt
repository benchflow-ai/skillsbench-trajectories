Library: minisgl
Version: 0.1.0
Purpose: Minimal SGL - LLM inference engine components

Main Entry Points:
- minisgl.core - Core data structures (SamplingParams, Req, Batch, Context)
- minisgl.tokenizer - Tokenization utilities

Key Functions for Fuzzing:
1. minisgl.core.SamplingParams - Sampling parameters dataclass
   - temperature, top_k, top_p, max_tokens
   - Data validation targets

2. minisgl.tokenizer.TokenizeManager.tokenize() - Tokenization
   - Processes text inputs via tokenizer
   - NOTE: Requires transformers and model - may be hard to fuzz in isolation

3. minisgl.message - Message processing
   - TokenizeMsg and related structures

Input Types:
- Float inputs: temperature, top_p
- Integer inputs: top_k, max_tokens
- String inputs: text for tokenization

Expected Exceptions to Catch:
- ValueError - Invalid values
- TypeError - Wrong type inputs
- AssertionError - Validation failures

Dependencies (Heavy - may not install easily):
- accelerate
- torch
- transformers>=4.56.0
- flashinfer-python>=0.5.3
- sgl_kernel>=0.3.17.post1

Fuzzing Strategy:
1. Focus on SamplingParams with various numeric inputs
2. Test parameter validation logic
3. Avoid heavy dependencies by focusing on core dataclasses
4. Test property methods (is_greedy, etc.)

NOTE: This library has heavy dependencies (torch, transformers, CUDA-related).
Fuzzing should focus on data validation in core.py rather than
tokenization which requires model loading.
