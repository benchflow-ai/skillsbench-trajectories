Library: arrow
Version: dynamic (from git)
Purpose: Better dates & times for Python - Date/time parsing, manipulation, and formatting

Main Entry Points:
- arrow.get(*args, **kwargs) - Main factory function to parse/create Arrow objects
  - Accepts: strings (ISO 8601), timestamps, datetime objects, date objects
  - Very flexible input parsing - HIGH PRIORITY FOR FUZZING
- arrow.now(tz) - Get current time in timezone
- arrow.utcnow() - Get current UTC time

Key Parsing Functions (High Fuzzing Priority):
1. arrow.factory.ArrowFactory.get() - Main parsing entry point
   - Parses strings with flexible format detection
   - Handles ISO 8601 strings
   - Critical for fuzzing: string inputs with arbitrary formats

2. arrow.parser.DateTimeParser.parse_iso() - ISO format parsing
   - Located in arrow/parser.py
   - Parses ISO 8601 date/time strings
   - High priority target

3. arrow.parser.DateTimeParser.parse() - Format string parsing
   - Parses date strings with format specifiers
   - Takes (string, format) pairs

4. arrow.parser.TzinfoParser.parse() - Timezone parsing
   - Parses timezone expressions

Input Types:
- String inputs: arrow.get("2023-01-01") - ISO strings, custom formats
- Integer/Float inputs: arrow.get(1234567890) - timestamps
- Format strings: arrow.get("2023-01-01", "YYYY-MM-DD")

Expected Exceptions to Catch:
- arrow.parser.ParserError - Invalid parsing input
- ValueError - Invalid values
- TypeError - Wrong type inputs
- OverflowError - Numeric overflow

Dependencies:
- python-dateutil>=2.7.0
- tzdata (for Python 3.9+)

Fuzzing Strategy:
1. Focus on arrow.get() with string inputs (most complex parsing)
2. Test format string parsing with format specifiers
3. Test timezone parsing
4. Include edge cases: empty strings, very long strings, special chars
