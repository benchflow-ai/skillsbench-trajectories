# Build Failure Analysis - google/auto Repository

## Summary

The build is failing due to multiple Java version incompatibility issues. The project was designed for Java 6-8 but is being built with Java 11.

## Issue 1: tools.jar Dependency (FIXED)

### Error Message

```
Could not resolve dependencies for project com.google.auto:auto-common:jar:1.0-SNAPSHOT:
Could not find artifact com.sun:tools:jar:11.0.27 at specified path
/usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar
```

### Root Cause

The `compile-testing` library versions used (0.6, 0.7, 0.8) have a system-scoped dependency on `tools.jar` which was removed in Java 9+.

### Solution

Update `compile-testing` to version 0.19 which supports Java 9+ without requiring tools.jar.

### Files Modified

- common/pom.xml: compile-testing 0.7 -> 0.19 (patch_1.diff)
- service/pom.xml: compile-testing 0.6 -> 0.19 (patch_2.diff)
- value/pom.xml: compile-testing 0.6 -> 0.19 (patch_3.diff)
- factory/pom.xml: compile-testing 0.8 -> 0.19 (patch_4.diff)

## Issue 2: javax.annotation.Generated Not Found (FIXED)

### Error Message

```
cannot find symbol
  symbol:   class Generated
  location: package javax.annotation
```

### Root Cause

In Java 9+, `javax.annotation.Generated` was moved to `javax.annotation.processing.Generated`. The code in factory and value modules references the old location.

### Solution

Add a dependency on `javax.annotation:javax.annotation-api:1.3.2` which provides the old `javax.annotation.Generated` class for backwards compatibility.

### Files Modified

- factory/pom.xml: Add javax.annotation-api dependency (patch_5.diff)
- value/pom.xml: Add javax.annotation-api dependency (patch_6.diff)
