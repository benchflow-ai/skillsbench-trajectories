# Mini-SGLang Library - Fuzzing Notes

## Library Purpose
Mini-SGLang is a lightweight LLM inference framework with advanced optimizations for serving large language models. It provides model loading, inference, and API server functionality.

## Key Components
- minisgl/llm/model.py: LLM model initialization and management
- minisgl/engine/: Request scheduling and inference engine
- minisgl/server/: OpenAI-compatible API server
- minisgl/utils/: Utility functions

## Important Functions to Test

1. minisgl.llm.LLM.__init__() and load()
   - Input type: str (model name/path)
   - Complexity: HIGH
   - Why important: Model loading with path handling, configuration parsing, CUDA initialization
   - Fuzzing strategy: Invalid model paths, malformed configuration, memory pressure

2. minisgl.engine.Engine.generate()
   - Input type: str (prompt), dict (generation parameters)
   - Complexity: HIGH
   - Why important: Core inference engine. Handles token generation, beam search parameters, output formatting.
   - Fuzzing strategy: Invalid prompts, extreme parameter values, edge cases in prompt encoding

3. minisgl.server.start_server()
   - Input type: dict (configuration), str (model name)
   - Complexity: MEDIUM
   - Why important: Server initialization with port handling and request routing
   - Fuzzing strategy: Invalid port numbers, malformed config, concurrent requests

4. Tokenizer functions
   - Input type: str (text to encode/decode)
   - Complexity: MEDIUM
   - Why important: Text encoding/decoding with special tokens. UTF-8 handling.
   - Fuzzing strategy: Invalid UTF-8, long sequences, special token edge cases

## Potential Bug Areas
- Model path parsing and validation
- Configuration file parsing (YAML/JSON)
- Tokenizer edge cases with special characters
- Memory allocation for large batches
- GPU resource management
- Protocol buffer handling for distributed inference
- Unicode normalization in prompts
- Parameter validation bounds

## Testing Strategy
- Provide invalid model paths and configuration
- Test tokenizer with various encodings and special characters
- Test generation parameters at boundaries
- Test with very long prompts and batch sizes
- Provide malformed API requests
