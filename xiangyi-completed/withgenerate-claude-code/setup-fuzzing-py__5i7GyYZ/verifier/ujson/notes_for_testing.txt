# UltraJSON (ujson) - Fuzzing Notes

## Library Purpose
UltraJSON is a ultra-fast JSON encoder and decoder written in C with Python bindings. It provides fast JSON parsing and serialization.

## Key Components
- C extension module (compiled)
- ujson.loads(): JSON string parser (main entry point)
- ujson.dumps(): JSON object encoder
- Python wrapper and helpers

## Important Functions to Test

1. ujson.loads()
   - Input type: str or bytes (JSON string)
   - Complexity: HIGH
   - Why important: Main JSON parser. C implementation with complex parsing state machine. Common source of bugs in JSON parsers.
   - Fuzzing strategy: Malformed JSON, deeply nested structures, large numbers, Unicode characters, edge cases

2. ujson.dumps()
   - Input type: Python objects (dict, list, str, int, float, bool, None)
   - Complexity: MEDIUM
   - Why important: JSON encoder with special character handling. Tests encode_html_chars, ensure_ascii options.
   - Fuzzing strategy: Circular references, special characters, extreme values, custom objects

3. ujson.load() / ujson.dump() (file I/O)
   - Input type: file object + data
   - Complexity: MEDIUM
   - Why important: File-based JSON operations with I/O handling
   - Fuzzing strategy: Corrupted file handles, permission issues, partial reads/writes

## Known Characteristics (from README)
- C-based implementation (high-risk for memory issues)
- In maintenance-only mode due to security concerns
- Unicode handling is critical
- Special focus on buffer overflow prevention needed

## Potential Bug Areas
- Buffer overflows in C code (integer parsing, string allocation)
- Unicode/UTF-8 handling edge cases
- Deeply nested JSON structures (stack overflow)
- Large number parsing (floating point precision issues)
- Control character handling
- Surrogate pair handling in Unicode
- Special characters in HTML encoding mode
- Null byte handling in strings

## Testing Strategy
- Provide deeply nested JSON structures (>1000 levels)
- Test with very large numbers (extreme floats, integers)
- Test Unicode edge cases (surrogate pairs, invalid sequences)
- Provide malformed JSON with missing/extra characters
- Test edge cases in number parsing
- Test with special characters and escape sequences
- Provide empty and minimal JSON documents
