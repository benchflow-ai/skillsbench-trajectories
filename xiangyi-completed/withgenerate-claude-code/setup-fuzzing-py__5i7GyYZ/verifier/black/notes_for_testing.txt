# Black Library - Fuzzing Notes

## Library Purpose
Black is an uncompromising Python code formatter. It takes Python source code and reformats it according to consistent style rules.

## Key Components
- black/__init__.py: Main API (format_str, format_file_in_place, get_grammars)
- black/linegen.py: Line generation logic
- black/lines.py: Line manipulation and analysis
- black/nodes.py: AST node handling

## Important Functions to Test

1. black.format_str()
   - Input type: str (Python source code)
   - Complexity: HIGH
   - Why important: Main entry point for code formatting. Parses and transforms Python AST. Complex string handling with potential parsing issues.
   - Fuzzing strategy: Invalid Python syntax, edge cases in language grammar, very long lines, nested structures

2. black.lib2to3.pytree parsing
   - Input type: str (Python code)
   - Complexity: HIGH
   - Why important: Uses lib2to3 grammar to parse Python code. Grammar handling can have edge cases.
   - Fuzzing strategy: Almost-valid Python, syntax edge cases, unusual whitespace

3. black.normalize()
   - Input type: various AST node types
   - Complexity: MEDIUM
   - Why important: Normalizes AST nodes - logic-heavy with potential for infinite loops or crashes
   - Fuzzing strategy: Deeply nested structures, circular references in AST

4. black.generate_comments()
   - Input type: lib2to3 pytree
   - Complexity: MEDIUM
   - Why important: Comment extraction and handling
   - Fuzzing strategy: Various comment styles and positions

## Potential Bug Areas
- Handling of edge case Python syntax (comprehensions, async/await, walrus operator)
- Comment preservation in unusual positions
- Very deeply nested structures causing stack overflow or infinite loops
- Unicode identifiers and strings
- Edge cases in string literal handling (f-strings, raw strings, triple-quoted)
- Line length calculations with Unicode

## Testing Strategy
- Provide various Python code snippets (valid and almost-valid)
- Test with deeply nested code structures
- Provide unusual but syntactically valid Python constructs
- Test with Unicode identifiers and strings
- Test edge cases in whitespace handling
