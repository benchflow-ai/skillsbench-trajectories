# MiniSGL Library - Notes for Fuzzing

## Library Purpose
MiniSGL is a minimal serving library for large language models, providing attention backends, scheduling, and model serving infrastructure.

## Key Modules
- python/minisgl/core.py: Core data structures (SamplingParams, Req, Batch, Context)
- python/minisgl/tokenizer/: Tokenizer handling
- python/minisgl/message/: Message processing
- python/minisgl/utils/: Utility functions

## High-Value Fuzz Targets

### Target 1: SamplingParams dataclass
- Location: python/minisgl/core.py:15
- Input: temperature, top_k, top_p, max_tokens (numeric values)
- Purpose: Validate sampling parameters
- Expected exceptions: ValueError, TypeError

### Target 2: Message parsing (if available)
- Look in python/minisgl/message/ for message parsing functions
- Input: strings, JSON-like structures
- Purpose: Parse chat messages
- Expected exceptions: ValueError, KeyError

### Target 3: Tokenizer operations (if available)
- Look in python/minisgl/tokenizer/ for tokenization
- Input: strings
- Purpose: Tokenize text input
- Expected exceptions: ValueError

## Fuzzing Strategy
Note: This library has heavy dependencies (torch, transformers, etc.) that may not be installable without CUDA. The fuzz driver should:
1. Focus on pure Python components without GPU dependencies
2. Test SamplingParams validation with edge case values
3. Look for any string parsing or validation code
