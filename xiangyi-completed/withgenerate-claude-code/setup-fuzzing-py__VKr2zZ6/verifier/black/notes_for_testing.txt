# Black Library - Notes for Fuzzing

## Library Purpose
Black is an uncompromising Python code formatter. It reformats Python source code according to a consistent style.

## Key Modules
- src/black/__init__.py: Main entry point with format_str(), format_file_contents()
- src/black/parsing.py: Code parsing utilities (lib2to3_parse)
- src/black/mode.py: Formatting mode/configuration

## High-Value Fuzz Targets

### Target 1: black.format_str(src_contents, mode=black.Mode())
- Location: src/black/__init__.py:1177
- Input: string (Python source code)
- Purpose: Format Python source code string
- Expected exceptions:
  - InvalidInput (syntax errors)
  - TokenizeError
  - IndentationError
  - NothingChanged (not an error)

### Target 2: black.format_file_contents(src_contents, fast=True, mode=Mode())
- Location: src/black/__init__.py:1068
- Input: string (Python source code)
- Purpose: Format file contents with safety checks
- Expected exceptions: NothingChanged, ASTSafetyError, ValueError

### Target 3: lib2to3_parse(src_contents)
- Location: src/black/parsing.py
- Input: string (Python source code)
- Purpose: Parse Python source into AST
- Expected exceptions: InvalidInput

## Fuzzing Strategy
1. Primary target: black.format_str() with random Python-like code
2. Use FuzzedDataProvider to generate varied code snippets
3. Focus on malformed Python syntax and edge cases
4. Use fast=True mode to skip safety checks for performance
