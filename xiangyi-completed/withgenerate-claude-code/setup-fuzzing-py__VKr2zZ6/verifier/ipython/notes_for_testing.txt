# IPython Library - Notes for Fuzzing

## Library Purpose
IPython provides an enhanced interactive Python shell with support for magic commands, system commands, and various input transformations.

## Key Modules
- IPython/core/inputtransformer2.py: Input transformation machinery
- IPython/core/compilerop.py: Code compilation
- IPython/core/interactiveshell.py: Main interactive shell

## High-Value Fuzz Targets

### Target 1: Input Transformers
- Location: IPython/core/inputtransformer2.py
- Classes:
  - PromptStripper: Remove input prompts
  - cell_magic(): Transform cell magic syntax
  - TransformerManager: Manage input transformations
- Input: list of strings (source code lines)
- Expected exceptions: SyntaxError, TokenizeError

### Target 2: TransformerManager.transform_cell(cell)
- Location: IPython/core/inputtransformer2.py
- Input: string (cell content)
- Purpose: Transform IPython syntax to Python
- Expected exceptions: SyntaxError

### Target 3: classic_prompt and ipython_prompt strippers
- Location: IPython/core/inputtransformer2.py:85-112
- Input: list of strings
- Purpose: Strip prompt prefixes from input
- Expected exceptions: None (should be robust)

### Target 4: cell_magic(lines)
- Location: IPython/core/inputtransformer2.py:115
- Input: list of strings starting with %%
- Purpose: Transform cell magic syntax
- Expected exceptions: None

## Fuzzing Strategy
1. Primary target: Input transformation functions
2. Focus on magic command parsing (%%magic, %magic)
3. Test prompt stripping with malformed inputs
4. Generate code-like strings with special IPython syntax
