# Arrow Library - Notes for Fuzzing

## Library Purpose
Arrow is a Python library that provides better dates and times handling, with a focus on parsing and creating human-readable date/time strings.

## Key Modules
- arrow/parser.py: Contains DateTimeParser class for parsing date strings
- arrow/api.py: Main API entry point with `get()` function
- arrow/factory.py: ArrowFactory class
- arrow/arrow.py: Main Arrow class

## High-Value Fuzz Targets

### Target 1: arrow.get(string)
- Location: arrow/api.py and arrow/factory.py
- Input: string (date/time representation)
- Purpose: Parse arbitrary date/time strings into Arrow objects
- Expected exceptions: ParserError, ValueError, TypeError

### Target 2: DateTimeParser.parse_iso(datetime_string)
- Location: arrow/parser.py:252
- Input: string
- Purpose: Parse ISO 8601-like datetime strings
- Expected exceptions: ParserError, ParserMatchError

### Target 3: DateTimeParser.parse(datetime_string, fmt)
- Location: arrow/parser.py:373
- Input: string, format string
- Purpose: Parse datetime string with specific format
- Expected exceptions: ParserError, ParserMatchError

### Target 4: TzinfoParser.parse(tzinfo_string)
- Location: arrow/parser.py:895
- Input: string (timezone representation)
- Purpose: Parse timezone strings
- Expected exceptions: ParserError

## Fuzzing Strategy
1. Primary target: arrow.get() with random string input
2. Focus on parsing edge cases and malformed inputs
3. Test various date/time format strings

## Dependencies
- python-dateutil>=2.7.0
- tzdata (Python 3.9+)
