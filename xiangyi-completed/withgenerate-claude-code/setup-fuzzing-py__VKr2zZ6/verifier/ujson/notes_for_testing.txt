# ujson Library - Notes for Fuzzing

## Library Purpose
ujson (UltraJSON) is an ultra-fast JSON encoder and decoder for Python, implemented as a C extension.

## Key Modules
- ujson C extension: Core JSON encoding/decoding
- The library exposes: ujson.loads(), ujson.dumps(), ujson.encode(), ujson.decode()

## High-Value Fuzz Targets

### Target 1: ujson.loads(json_string) / ujson.decode(json_string)
- Input: bytes or string (JSON data)
- Purpose: Parse JSON string into Python objects
- Expected exceptions: JSONDecodeError, ValueError, TypeError, OverflowError
- HIGHEST PRIORITY - JSON parsing is a classic fuzz target

### Target 2: ujson.dumps(obj) / ujson.encode(obj)
- Input: Python object (dict, list, str, int, float, bool, None)
- Purpose: Serialize Python objects to JSON string
- Expected exceptions: OverflowError, TypeError
- Options: indent, ensure_ascii, encode_html_chars, escape_forward_slashes

### Target 3: ujson.loads with encoding variations
- Input: bytes with various encodings
- Purpose: Test encoding detection/handling
- Expected exceptions: UnicodeDecodeError, JSONDecodeError

## Fuzzing Strategy
1. Primary target: ujson.loads() with random bytes/strings
2. Generate malformed JSON structures
3. Test edge cases: deeply nested objects, large numbers, special characters
4. Test both string and bytes input types
5. Use FuzzedDataProvider for structured input generation

## Note
ujson is a C extension. Crashes in C code are the primary security concern.
Fuzzing should focus on:
- Memory safety issues (buffer overflows, use-after-free)
- Integer overflows in number parsing
- Stack overflows from deeply nested structures

## Dependencies
- No runtime Python dependencies (C extension only)
- Build requires: setuptools-scm
