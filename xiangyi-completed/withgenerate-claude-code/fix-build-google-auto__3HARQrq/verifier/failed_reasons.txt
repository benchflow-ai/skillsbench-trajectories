BUILD ERROR ANALYSIS - Google Auto Service Project
====================================================

PROJECT LOCATION: /home/travis/build/failed/google/auto/service

ERROR MESSAGE:
Could not resolve dependencies for project com.google.auto.service:auto-service:jar:1.0-SNAPSHOT:
Could not find artifact com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar

ROOT CAUSE:
The build fails because Maven is trying to resolve a dependency on com.sun:tools:jar:11.0.27
with a system scope that points to $JAVA_HOME/../lib/tools.jar. However:

1. The Java environment is OpenJDK 11 (openjdk version "11.0.27")
2. In Java 9+, the tools.jar file was removed from the JDK filesystem
3. The tools library was migrated to Java modules (jdk.compiler, jdk.jdi, etc.)
4. The auto-parent POM (version 3) likely contains this problematic dependency definition

ISSUE TYPE: Build Configuration Error

The error is in the inherited build configuration, not the code itself. The parent POM
(com.google.auto:auto-parent:3) defines a system-scoped dependency on tools.jar which
cannot be found in Java 11.

SOLUTION:
Since the auto-service project doesn't appear to directly use com.sun:tools APIs
(based on source code inspection), the solution is to exclude this problematic
dependency from the parent POM inheritance using Maven's dependency exclusion mechanism.

Alternatively, we could update the Maven compiler plugin configuration to handle Java 11
compatibility, but exclusion is the cleanest approach since the tools.jar API is not used.

FIX APPROACH:
Add a dependency exclusion in the pom.xml to prevent the problematic tools.jar dependency
from being resolved. Since the parent POM defines this as a system-scoped dependency, we
need to add it explicitly to the child POM and then exclude it, or configure the build
to skip this specific dependency resolution.

The cleanest fix is to modify the pom.xml to add a dependency section that excludes
the tools.jar artifact that the parent POM may be trying to pull in.
