UJson Library - Notes for Fuzzing

Library: ujson (Ultra-fast JSON encoder/decoder)
Location: /app/ujson
Source: /app/ujson/src/ujson/ (C extension)
Dependencies: setuptools, setuptools_scm (build only)
Build system: setuptools + setuptools_scm

== Key Functions to Fuzz ==

1. ujson.loads(s) / ujson.decode(s)
   - Deserialize JSON string to Python object
   - s: str | bytes | bytearray
   - Raises ujson.JSONDecodeError on invalid JSON
   - CRITICAL fuzzing target - C extension parser

2. ujson.dumps(obj, ...) / ujson.encode(obj, ...)
   - Serialize Python object to JSON string
   - Parameters: ensure_ascii, encode_html_chars, escape_forward_slashes,
     sort_keys, indent, allow_nan, reject_bytes, default, separators
   - CRITICAL fuzzing target - C extension encoder

3. Round-trip testing: loads(dumps(obj)) and dumps(loads(s))
   - Tests consistency between encoder and decoder

== Fuzzing Strategy ==
- Primary target: ujson.loads() with arbitrary bytes/strings - C extension parsing
- Secondary target: ujson.dumps() with structured fuzzed objects
- ujson is a C extension, so it benefits greatly from coverage-guided fuzzing
  (potential memory safety issues in C code)
- Use both ConsumeUnicodeNoSurrogates and ConsumeBytes for input
- Fuzz parameter combinations for dumps (indent, ensure_ascii, etc.)
- Catch JSONDecodeError, ValueError, TypeError, OverflowError, RecursionError
- The library needs to be built (compiled) before fuzzing
