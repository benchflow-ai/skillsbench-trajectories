IPython Library - Notes for Fuzzing

Library: IPython (Productive Interactive Computing)
Location: /app/ipython
Source: /app/ipython/IPython/
Dependencies: decorator, jedi, prompt_toolkit, pygments, stack_data, traitlets, etc. (pyproject.toml)
Build system: setuptools

== Key Functions to Fuzz (pure string processing, no side effects) ==

1. IPython.core.inputtransformer2.TransformerManager().transform_cell(cell)
   - File: /app/ipython/IPython/core/inputtransformer2.py
   - Transforms IPython input cells (handles magics, !, ?, etc.)
   - Takes arbitrary string, returns transformed string
   - Excellent fuzzing target

2. IPython.core.inputtransformer2.make_tokens_by_line(lines)
   - File: /app/ipython/IPython/core/inputtransformer2.py
   - Tokenizes code and groups by line
   - Handles tokenization errors gracefully

3. IPython.utils.tokenutil.token_at_cursor(cell, cursor_pos)
   - File: /app/ipython/IPython/utils/tokenutil.py
   - Finds token at cursor position in code string
   - Pure function, safe for fuzzing

4. IPython.utils.tokenutil.line_at_cursor(cell, cursor_pos)
   - File: /app/ipython/IPython/utils/tokenutil.py
   - Finds line at cursor position

5. IPython.core.splitinput.split_user_input(line, pattern=None)
   - File: /app/ipython/IPython/core/splitinput.py
   - Splits IPython input into components
   - Pure regex-based parsing

== Fuzzing Strategy ==
- Primary target: TransformerManager().transform_cell() - main input pipeline
- Secondary targets: token_at_cursor, split_user_input
- Use FuzzedDataProvider for code strings and cursor positions
- Catch ValueError, TypeError, SyntaxError, TokenError, RecursionError
