MiniSGL Library - Notes for Fuzzing

Library: minisgl (Minimal serving and generation layer for LLMs)
Location: /app/minisgl
Source: /app/minisgl/python/minisgl/
Dependencies: Heavy (torch, transformers, flashinfer, etc.) - will install --no-deps
Build system: setuptools

== Key Functions to Fuzz (NO GPU required) ==

1. minisgl.message.utils.serialize_type(obj) / deserialize_type(cls_map, data)
   - File: /app/minisgl/python/minisgl/message/utils.py
   - Serializes/deserializes Python objects to/from dicts
   - Handles recursive structures, good fuzzing target

2. minisgl.tokenizer.detokenize.find_printable_text(text)
   - File: /app/minisgl/python/minisgl/tokenizer/detokenize.py
   - Finds longest printable substring
   - Handles CJK characters, good string processing target

3. minisgl.tokenizer.detokenize._is_chinese_char(cp)
   - File: /app/minisgl/python/minisgl/tokenizer/detokenize.py
   - Checks if codepoint is CJK character

4. minisgl.utils.misc.div_ceil(a, b) / div_even(a, b)
   - File: /app/minisgl/python/minisgl/utils/misc.py
   - Integer division utilities, boundary cases

5. minisgl.utils.registry.Registry operations
   - File: /app/minisgl/python/minisgl/utils/registry.py
   - String lookup and validation

== Fuzzing Strategy ==
- Since minisgl has heavy GPU dependencies (torch, transformers, sgl_kernel, flashinfer),
  we cannot install the full package. Instead:
  - Install --no-deps and only pip install lightweight deps (msgpack, pyzmq, etc.)
  - Directly import the specific Python modules that don't require GPU
  - Focus on find_printable_text(), _is_chinese_char(), div_ceil(), div_even()
  - Add sys.path manipulation to import from source directly
- Catch ValueError, TypeError, ZeroDivisionError, AssertionError, KeyError
