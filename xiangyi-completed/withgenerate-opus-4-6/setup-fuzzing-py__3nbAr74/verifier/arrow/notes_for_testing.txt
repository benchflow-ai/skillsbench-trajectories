Arrow Library - Notes for Fuzzing

Library: arrow (Better dates & times for Python)
Location: /app/arrow
Source: /app/arrow/arrow/
Dependencies: python-dateutil>=2.7.0, tzdata (pyproject.toml)
Build system: flit_core

== Key Functions to Fuzz ==

1. arrow.parser.DateTimeParser.parse_iso(datetime_string, normalize_whitespace=False)
   - File: /app/arrow/arrow/parser.py
   - Parses ISO 8601-like datetime strings
   - Takes arbitrary string input, good fuzzing target
   - Raises ParserError on invalid input

2. arrow.parser.DateTimeParser.parse(datetime_string, fmt, normalize_whitespace=False)
   - File: /app/arrow/arrow/parser.py
   - Parses datetime strings with custom format
   - Takes string + format string, both are fuzzable

3. arrow.parser.TzinfoParser.parse(tzinfo_string)
   - File: /app/arrow/arrow/parser.py
   - Parses timezone strings (e.g., "+05:30", "US/Pacific", "UTC")
   - Raises ParserError on invalid input

4. arrow.factory.ArrowFactory.get(*args, **kwargs)
   - File: /app/arrow/arrow/factory.py
   - Main entry point, accepts many input types including strings
   - When given a string, calls parse_iso internally

5. arrow.arrow.Arrow.format(fmt, locale)
   - File: /app/arrow/arrow/arrow.py
   - Formats Arrow objects using format strings

== Fuzzing Strategy ==
- Primary target: parse_iso() - complex regex-based parser with many date formats
- Secondary target: parse() with fuzzed format strings
- Use FuzzedDataProvider to generate both datetime strings and format strings
- Catch ParserError, ParserMatchError, ValueError, TypeError, OverflowError, re.error
