Black Library - Notes for Fuzzing

Library: black (The uncompromising code formatter)
Location: /app/black
Source: /app/black/src/black/
Dependencies: click, mypy_extensions, packaging, pathspec, platformdirs, pytokens, tomli (pyproject.toml)
Build system: hatchling

== Key Functions to Fuzz ==

1. black.format_str(src_contents, *, mode, lines=())
   - File: /app/black/src/black/__init__.py
   - Core formatting function, takes Python source code string
   - Returns formatted string
   - mode is a Mode() dataclass
   - Excellent fuzzing target - complex parsing pipeline

2. black.format_file_contents(src_contents, *, fast, mode, lines=())
   - File: /app/black/src/black/__init__.py
   - Higher-level formatting with AST safety checks
   - fast=True skips equivalence checks

3. black.Mode(target_versions=set(), line_length=88, string_normalization=True, ...)
   - File: /app/black/src/black/mode.py
   - Configuration dataclass for formatting
   - Can fuzz line_length and boolean options

4. black.parsing.lib2to3_parse(src_txt, target_versions=())
   - File: /app/black/src/black/parsing.py
   - Low-level parser, tries multiple grammars

== Fuzzing Strategy ==
- Primary target: format_str() with Mode() - takes arbitrary Python source strings
- Catch NothingChanged (from black.report), InvalidInput, all parsing errors
- Use FuzzedDataProvider for source code and mode parameters
- Catch broad exceptions since the formatting pipeline is complex
