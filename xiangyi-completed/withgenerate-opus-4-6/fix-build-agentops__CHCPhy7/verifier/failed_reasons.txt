ERROR 1: ImportError - Unconditional import of optional dependency
----------------------------------------------------------------------
Type: Code Error

File: agentops/__init__.py (line 12)
  from .langchain_callback_handler import LangchainCallbackHandler, AsyncLangchainCallbackHandler

This line unconditionally imports from langchain_callback_handler.py, which in turn
imports from three packages that are OPTIONAL dependencies:

  1. langchain_core (line 5-9 of langchain_callback_handler.py)
     - from langchain_core.agents import AgentFinish, AgentAction
     - from langchain_core.documents import Document
     - from langchain_core.outputs import ChatGenerationChunk, GenerationChunk, LLMResult
     - from langchain_core.messages import BaseMessage

  2. langchain (line 8 of langchain_callback_handler.py)
     - from langchain.callbacks.base import BaseCallbackHandler, AsyncCallbackHandler

  3. tenacity (line 11 of langchain_callback_handler.py)
     - from tenacity import RetryCallState

In pyproject.toml, langchain is declared as an OPTIONAL dependency:
  [project.optional-dependencies]
  langchain = ["langchain>=0.0.354"]

But __init__.py imports from it unconditionally, so `import agentops` fails
with ModuleNotFoundError when langchain_core is not installed.

Impact: ALL 5 test files fail during collection with:
  ModuleNotFoundError: No module named 'langchain_core'

ERROR 2: AttributeError - _tags_for_future_session not always initialized
----------------------------------------------------------------------
Type: Code Error

File: agentops/client.py (lines 76-97)

The `_tags_for_future_session` attribute is only set in the `else` branch when
`auto_start_session=False` (line 97). When `auto_start_session=True` (default),
this attribute is never set. Additionally, if `ConfigurationError` is raised during
config initialization (line 89-90), the method returns early before reaching the
attribute assignment, leaving it uninitialized.

The `start_session()` method (line 251) references `self._tags_for_future_session`
unconditionally via `tags or self._tags_for_future_session`, causing an
AttributeError when the attribute doesn't exist.

Impact: test_events.py::test_record_timestamp and test_session.py::test_session fail.

ERROR 3: Singleton prevents test isolation
----------------------------------------------------------------------
Type: Code Error (Test Infrastructure)

File: agentops/helpers.py (lines 15-23)

The `singleton` decorator caches the first Client instance and always returns it.
When tests run sequentially, the first test creates a Client that persists for all
subsequent tests. Tests that call `agentops.init()` expecting a fresh Client instead
get the stale singleton from a previous test.

Impact: Tests pass individually but fail when run together.
