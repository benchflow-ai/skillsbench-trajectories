BUILD FAILURE ANALYSIS: google/auto
=====================================

Repository: /home/travis/build/failed/google/auto
Build command (from .travis.yml): mvn -B -U -f build-pom.xml verify --fail-at-end

ERRORS FOUND
============

Two categories of errors were identified:

--- ERROR 1: Missing com.sun:tools:jar dependency (Build Configuration) ---

All modules (common, factory, service, value) fail with:
  "Could not find artifact com.sun:tools:jar:11.0.27 at specified path
   /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar"

Root Cause:
  The build environment uses Java 11 (OpenJDK 11.0.27), but the project was designed
  for Java 7/8. Starting with Java 9, tools.jar was removed from the JDK - its classes
  were integrated into the JDK's module system (java.compiler, jdk.compiler modules).

  The transitive dependency chain causing the failure:
    Module POM -> compile-testing (test scope) -> com.sun:tools:jar (system scope)

  Specifically:
    - common/pom.xml uses compile-testing 0.7 -> depends on com.sun:tools
    - service/pom.xml uses compile-testing 0.6 -> depends on com.sun:tools
    - factory/pom.xml uses compile-testing 0.8 -> depends on com.sun:tools
    - value/pom.xml uses compile-testing 0.6 -> depends on com.sun:tools

Fix: Add <exclusions> for com.sun:tools in each module's compile-testing dependency.
  Patches: patch_1.diff, patch_2.diff, patch_3.diff, patch_4.diff

--- ERROR 2: javax.annotation.Generated not found (Source Code) ---

After fixing the dependency issue, three source files fail to compile:
  - factory/src/main/java/.../FactoryWriter.java:39 - cannot find symbol javax.annotation.Generated
  - value/src/main/java/.../AutoAnnotationProcessor.java:36 - cannot find symbol javax.annotation.Generated
  - value/src/main/java/.../AutoValueProcessor.java:51 - cannot find symbol javax.annotation.Generated

Root Cause:
  javax.annotation.Generated was part of the java.xml.ws.annotation module, which was
  deprecated in Java 9 and removed in Java 11 (JEP 320). The replacement class is
  javax.annotation.processing.Generated, available since Java 9.

Fix: Change imports from javax.annotation.Generated to javax.annotation.processing.Generated.
  For FactoryWriter.java, also update the generated code output string.
  Patches: patch_5.diff, patch_6.diff, patch_7.diff
