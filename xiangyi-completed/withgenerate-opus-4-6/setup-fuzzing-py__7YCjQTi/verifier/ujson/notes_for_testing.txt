Library: UltraJSON (ujson)
Description: Ultra-fast JSON encoder and decoder written in C with Python bindings. Drop-in replacement for Python's json module.

Source directory: /app/ujson/src/ujson/ (C source)
Python interface: ujson module (C extension)

Dependencies (from setup.py / pyproject.toml):
- setuptools>=42
- setuptools_scm[toml]>=3.4
- No runtime Python dependencies (pure C extension)
- Bundled: double-conversion C++ library for float parsing

Key Functions for Fuzz Testing:

1. ujson.loads(s: str | bytes | bytearray) -> Any
   - Alias for ujson.decode()
   - Parses JSON string/bytes into Python objects
   - Calls JSON_DecodeObject() in C core
   - PRIMARY FUZZ TARGET - handles arbitrary user input

2. ujson.dumps(obj, **kwargs) -> str
   - Alias for ujson.encode()
   - Serializes Python objects to JSON string
   - Options: ensure_ascii, encode_html_chars, escape_forward_slashes, sort_keys, indent, allow_nan

3. ujson.decode(s: str | bytes | bytearray) -> Any
   - Main C entry point: JSONToObj() in /app/ujson/src/ujson/python/JSONtoObj.c (line 163)
   - Core decoder: JSON_DecodeObject() in /app/ujson/src/ujson/lib/ultrajsondec.c (line 790)

4. ujson.encode(obj, **kwargs) -> str
   - Main C entry point: ObjToJSON() in /app/ujson/src/ujson/python/objToJSON.c
   - Core encoder: JSON_EncodeObject() in /app/ujson/src/ujson/lib/ultrajsonenc.c (line 953)

Critical C parsing paths:
- decode_string(): lines 362-588 in ultrajsondec.c - UTF-8/Unicode/surrogate handling
- decode_numeric(): lines 91-247 in ultrajsondec.c - integer/float overflow
- decode_array(): lines 589-652 - recursive array parsing
- decode_object(): lines 653-746 - recursive object parsing

Limits:
- JSON_MAX_RECURSION_DEPTH = 1024

Exceptions to catch during fuzzing:
- ujson.JSONDecodeError (inherits ValueError)
- ValueError, TypeError, OverflowError
- MemoryError, RecursionError

Fuzzing strategy:
- Primary: Fuzz ujson.loads() with random bytes (accepts str, bytes, bytearray)
- Secondary: Fuzz ujson.dumps() with objects created from random data, then decode the result
- Round-trip: encode then decode to check consistency
- This is a C extension - fuzzing may find memory safety issues
