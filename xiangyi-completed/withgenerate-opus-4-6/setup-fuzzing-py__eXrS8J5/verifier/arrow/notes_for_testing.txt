Arrow Library - Notes for Fuzz Testing
=======================================

Overview:
Arrow is a Python library for creating, manipulating, formatting, and converting
dates, times, and timestamps. It is a drop-in replacement for Python's datetime.

Key modules:
- arrow/arrow.py       : Core Arrow class (datetime wrapper)
- arrow/parser.py      : DateTimeParser - parses datetime strings
- arrow/factory.py     : ArrowFactory - flexible object construction
- arrow/formatter.py   : DateTimeFormatter - formats datetimes to strings
- arrow/util.py        : Utility functions
- arrow/locales.py     : Locale support for 100+ languages

Dependencies (from requirements/requirements.txt):
- python-dateutil>=2.7.0
- tzdata

Functions to fuzz:
------------------

1. arrow.get(*args, **kwargs)  [arrow/api.py / arrow/factory.py]
   - Main entry point for creating Arrow objects
   - Accepts: str, int, float, datetime, date, tuple, etc.
   - Polymorphic - handles many input types
   - Excellent target for string input fuzzing

2. DateTimeParser.parse_iso(datetime_string)  [arrow/parser.py]
   - Parses ISO 8601 datetime strings
   - Uses complex regex matching
   - Handles various date/time formats and separators
   - Primary string parsing target

3. DateTimeParser.parse(string, fmt)  [arrow/parser.py]
   - Parses datetime strings with custom format strings
   - Format token substitution
   - Locale-aware parsing

4. Arrow.dehumanize(input_string, locale)  [arrow/arrow.py]
   - Parses human-readable relative time strings
   - e.g., "2 hours ago", "in 3 days"
   - Natural language processing target

5. Arrow.format(fmt)  [arrow/arrow.py]
   - Format arrow object to string with format string
   - Format string processing

6. arrow.util.is_timestamp(value)  [arrow/util.py]
   - Validates if value is a valid timestamp
   - Type coercion from string to float

7. arrow.util.normalize_timestamp(timestamp)  [arrow/util.py]
   - Normalizes millisecond/microsecond timestamps
   - Numeric edge cases

Fuzz strategy:
- Primary: Feed random strings to arrow.get() and DateTimeParser.parse_iso()
- Secondary: Test format strings with Arrow.format()
- Use FuzzedDataProvider for structured input generation
- Catch: ParserError, ValueError, TypeError, OverflowError
