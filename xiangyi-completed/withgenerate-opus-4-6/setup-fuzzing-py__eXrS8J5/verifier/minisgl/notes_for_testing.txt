MiniSGL Library - Notes for Fuzz Testing
=========================================

Overview:
MiniSGL is a lightweight inference framework for Large Language Models (LLMs).
It's a compact implementation of SGLang (~5,000 lines of Python) designed for
high-performance LLM serving.

Key modules:
- python/minisgl/message/utils.py       : Serialization/deserialization
- python/minisgl/env.py                 : Environment variable parsing
- python/minisgl/tokenizer/detokenize.py: Token-to-text conversion
- python/minisgl/core.py                : Core data structures (Req, Batch, etc.)
- python/minisgl/server/args.py         : Server argument parsing
- python/minisgl/server/api_server.py   : API request models

Dependencies (from pyproject.toml):
- torch
- transformers>=4.56.0,<=4.57.3
- accelerate
- uvicorn
- fastapi
- pyzmq
- msgpack
- prompt_toolkit
- openai
- sgl_kernel>=0.3.17.post1
- flashinfer-python>=0.5.3

Note: Many dependencies require CUDA/GPU. For fuzzing, we'll focus on
pure-Python functions that don't require GPU.

Functions to fuzz:
------------------

1. serialize_type(obj)  [python/minisgl/message/utils.py]
   - Serializes dataclasses and tensors to dict
   - Handles recursive structures
   - Uses type dispatch

2. deserialize_type(data)  [python/minisgl/message/utils.py]
   - Reconstructs objects from dict
   - Uses globals() and dynamic class lookup
   - Potential security concern - key attack surface

3. _PARSE_MEM_BYTES(s)  [python/minisgl/env.py]
   - Parses memory size strings like "1GB", "512MB", "1024"
   - String-to-numeric conversion with units
   - Edge cases with invalid formats

4. find_printable_text(text)  [python/minisgl/tokenizer/detokenize.py]
   - Returns complete words to avoid partial unicode
   - String processing with character detection

5. _is_chinese_char(cp)  [python/minisgl/tokenizer/detokenize.py]
   - Unicode codepoint range checking for CJK characters
   - Boundary value testing

Fuzz strategy:
- Primary: Test serialization/deserialization with random dict structures
- Test _PARSE_MEM_BYTES with random strings
- Test text processing functions with Unicode strings
- Avoid GPU-dependent code paths
- Catch: ValueError, TypeError, KeyError, AttributeError
