UltraJSON (ujson) Library - Notes for Fuzz Testing
===================================================

Overview:
UltraJSON is an ultra-fast JSON encoder and decoder written in pure C with
Python bindings. It's a drop-in replacement for Python's standard json library.

Key modules:
- src/ujson/python/ujson.c      : Python module initialization
- src/ujson/python/JSONtoObj.c   : JSON string -> Python object decoder
- src/ujson/python/objToJSON.c   : Python object -> JSON string encoder
- src/ujson/lib/ultrajsondec.c   : Core JSON decoder (C)
- src/ujson/lib/ultrajsonenc.c   : Core JSON encoder (C)

Dependencies:
- Build: setuptools>=42, setuptools_scm>=3.4
- Runtime: None (pure C extension)

Functions to fuzz:
------------------

1. ujson.loads(s) / ujson.decode(s)
   - Decodes JSON string/bytes to Python object
   - Core C decoder with complex state machine
   - Handles: strings with escapes, numbers, nested structures, unicode
   - Most important fuzz target
   - Known architecture limitations (per README)

2. ujson.dumps(obj) / ujson.encode(obj)
   - Encodes Python object to JSON string
   - Options: ensure_ascii, encode_html_chars, escape_forward_slashes,
     sort_keys, indent, allow_nan, reject_bytes, default, separators
   - Good for roundtrip testing

3. Roundtrip testing: loads(dumps(obj)) and dumps(loads(s))
   - Test consistency between encoder and decoder
   - Verify no data corruption in roundtrip

Key risk areas:
- String escape sequences (especially Unicode surrogates)
- Numeric parsing (integer overflow, float precision)
- Nested structure depth (max recursion depth 1024)
- Invalid UTF-8 sequences
- Control characters
- Buffer management in C code

Fuzz strategy:
- Primary: Feed random bytes/strings to ujson.loads()
- Secondary: Roundtrip test with loads(dumps(loads(input)))
- Test with various encoding options
- Catch: ValueError (JSONDecodeError), OverflowError, TypeError
- Do NOT catch: MemoryError, SystemError, segfaults (these are real bugs)
