Black Library - Notes for Fuzz Testing
======================================

Overview:
Black is "The Uncompromising Code Formatter" for Python. It reformats Python
source code to comply with PEP 8 with deterministic output.

Key modules:
- src/black/__init__.py     : Main API - format_str(), format_file_contents()
- src/black/parsing.py      : lib2to3_parse(), parse_ast() - Python code parsing
- src/black/strings.py      : String normalization functions
- src/black/numerics.py     : Numeric literal normalization
- src/black/mode.py         : Mode configuration dataclass
- src/black/comments.py     : Comment handling
- src/black/linegen.py      : Line generation from AST

Dependencies (from pyproject.toml):
- click>=8.0.0
- mypy_extensions>=0.4.3
- packaging>=22.0
- pathspec>=0.9.0
- platformdirs>=2
- pytokens>=0.3.0

Functions to fuzz:
------------------

1. black.format_str(src_contents, mode)  [src/black/__init__.py]
   - Main public API entry point
   - Takes arbitrary Python source code as string
   - Returns formatted code
   - Most important fuzz target

2. black.parsing.lib2to3_parse(src_txt, target_versions)  [src/black/parsing.py]
   - Parses Python source using lib2to3 grammar
   - Must handle malformed input gracefully
   - Core parsing function

3. black.strings.normalize_string_quotes(s)  [src/black/strings.py]
   - Normalizes string quote style
   - Complex regex and escape handling
   - Edge cases: raw strings, f-strings, triple quotes

4. black.strings.normalize_string_prefix(s)  [src/black/strings.py]
   - Normalizes string prefixes to lowercase
   - Regex pattern matching

5. black.numerics.normalize_numeric_literal(leaf)  [src/black/numerics.py]
   - Normalizes hex, binary, octal, scientific notation
   - Numeric parsing and formatting

6. black.strings.fix_multiline_docstring(docstring, prefix)  [src/black/strings.py]
   - Fixes docstring indentation
   - Tab expansion logic

Fuzz strategy:
- Primary: Feed random Python-like source strings to format_str()
- format_str wraps parsing + formatting in one call
- Use Mode() with default settings
- Catch: InvalidInput, NothingChanged, ValueError, TypeError, TokenError
- The formatter should never crash on any input
