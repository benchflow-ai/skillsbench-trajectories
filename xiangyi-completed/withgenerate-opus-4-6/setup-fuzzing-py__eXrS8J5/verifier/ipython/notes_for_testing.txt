IPython Library - Notes for Fuzz Testing
========================================

Overview:
IPython is a powerful interactive Python shell with rich features including
syntax highlighting, code completion, magic commands, and input transformation.

Key modules:
- IPython/core/splitinput.py         : User input line splitting
- IPython/core/inputtransformer2.py  : Input transformation pipeline
- IPython/utils/text.py              : Text utility functions
- IPython/utils/_process_common.py   : Process utilities (arg_split)
- IPython/utils/tokenutil.py         : Tokenization utilities
- IPython/utils/wildcard.py          : Wildcard pattern matching
- IPython/utils/PyColorize.py        : Syntax highlighting

Dependencies (from pyproject.toml):
- decorator>=4.3.2

Functions to fuzz:
------------------

1. split_user_input(line)  [IPython/core/splitinput.py]
   - Regex-based line splitting into components
   - Handles escape chars, magics, shell commands
   - Good string parsing target

2. TransformerManager.transform_cell(cell)  [IPython/core/inputtransformer2.py]
   - Transforms user cell input through pipeline
   - Handles magics, system commands, help queries
   - Core input processing function

3. arg_split(s, posix, strict)  [IPython/utils/_process_common.py]
   - Splits command-line arguments using shlex
   - Handles quotes, escapes, special characters
   - Has strict/non-strict modes

4. strip_email_quotes(text)  [IPython/utils/text.py]
   - Strips email quote markers (>) from text
   - Multiline text processing

5. EvalFormatter().format(s)  [IPython/utils/text.py]
   - String formatting with field evaluation
   - Parses format strings

6. generate_tokens_catch_errors(readline)  [IPython/utils/tokenutil.py]
   - Tokenizes Python code with error handling
   - Handles malformed code

7. line_at_cursor(text, cursor_pos)  [IPython/utils/tokenutil.py]
   - Finds line at cursor position in multiline text
   - Boundary handling

Fuzz strategy:
- Primary: Feed random strings to split_user_input() and transform_cell()
- Secondary: Test arg_split() with command-line-like strings
- Test text utilities with random Unicode text
- Catch: ValueError, TypeError, IndexError, TokenError, SyntaxError
