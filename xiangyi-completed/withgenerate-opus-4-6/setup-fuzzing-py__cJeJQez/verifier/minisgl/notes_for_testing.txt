Library: Mini-SGLang (minisgl)
Description: Lightweight inference framework for Large Language Models. Provides message serialization, tokenization, and an OpenAI-compatible API server.

Key modules:
- python/minisgl/message/utils.py - Serialization/deserialization of messages
- python/minisgl/tokenizer/detokenize.py - Token ID to text conversion
- python/minisgl/server/args.py - Argument parsing
- python/minisgl/core.py - Core data structures (SamplingParams, Req)

Important functions for fuzz testing:

1. minisgl.message.utils.deserialize_type(cls_map, data)
   - Deserializes JSON dicts to Python objects
   - Recursive deserialization, dynamic class instantiation
   - High priority: processes untrusted structured data

2. minisgl.message.utils.serialize_type(obj)
   - Serializes Python objects including torch.Tensor
   - High priority: roundtrip testing

3. minisgl.tokenizer.detokenize.find_printable_text(text)
   - String slicing with heuristics for CJK characters
   - Medium priority: Unicode edge cases

4. minisgl.tokenizer.detokenize._is_chinese_char(cp)
   - Unicode codepoint validation for CJK characters
   - Lower priority: boundary checking

5. minisgl.server.args.parse_args(args, run_shell)
   - Command-line argument parsing with dtype conversion
   - Medium priority

Note: This library has heavy dependencies (torch, CUDA, transformers, flashinfer, etc.)
that make full installation impractical in a fuzzing environment.

Dependencies:
- torch, transformers>=4.56.0, accelerate, msgpack
- sgl_kernel, flashinfer-python, pyzmq, uvicorn, fastapi
- Many GPU/CUDA dependencies that won't be available

Fuzz strategy:
- Focus on pure Python functions that don't require GPU/CUDA
- Primary targets: message serialization/deserialization utilities
- Also fuzz: find_printable_text, _is_chinese_char for Unicode handling
- Install only minimal deps needed (avoid torch/CUDA)
- Use FuzzedDataProvider to generate structured dicts and Unicode strings
