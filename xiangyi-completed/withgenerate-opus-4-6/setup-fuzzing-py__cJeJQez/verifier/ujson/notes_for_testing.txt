Library: UltraJSON (ujson)
Description: Ultra-fast JSON encoder and decoder written in pure C with Python bindings. Drop-in replacement for Python's json module.

Key modules:
- src/ujson/python/ujson.c - Module initialization, Python API
- src/ujson/python/JSONtoObj.c - JSON parsing/decoding
- src/ujson/python/objToJSON.c - Object serialization/encoding
- src/ujson/lib/ultrajsondec.c - C JSON decoder implementation
- src/ujson/lib/ultrajsonenc.c - C JSON encoder implementation

Important functions for fuzz testing:

1. ujson.loads(s) / ujson.decode(s)
   - Primary JSON decoder - accepts str, bytes, bytearray
   - Calls C decode functions: decode_any -> decode_string, decode_numeric, decode_object, decode_array
   - High priority: primary attack surface for parsing untrusted JSON

2. ujson.dumps(obj) / ujson.encode(obj)
   - JSON encoder - accepts arbitrary Python objects
   - Complex type handling and option processing
   - Medium priority: encoding side

3. ujson.loads() with various options
   - precise_float parameter for float parsing mode
   - Medium priority

4. Internal C functions (reached via loads/dumps):
   - decode_string: Unicode escape handling (\uXXXX), special chars
   - decode_numeric: Integer/float parsing, overflow handling
   - decode_object/decode_array: Recursive parsing with depth limits

Dependencies:
- Build: setuptools>=42, setuptools_scm[toml]>=3.4
- C compiler for building the extension
- No runtime Python dependencies
- Vendored: Google double-conversion library

Fuzz strategy:
- Primary target: ujson.loads() with raw bytes/strings
- Secondary: ujson.dumps() with objects created from decoded JSON
- Roundtrip testing: decode -> encode -> decode
- Also test with bytes input for ujson.loads()
- Catch ValueError, OverflowError, TypeError, RecursionError
- Test edge cases: deep nesting, malformed numerics, invalid escapes, truncated input
- C extension means real crash bugs (segfaults) are possible - these are valuable findings
