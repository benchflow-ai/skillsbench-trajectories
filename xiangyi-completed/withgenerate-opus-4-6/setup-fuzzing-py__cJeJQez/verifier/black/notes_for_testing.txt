Library: Black
Description: The uncompromising Python code formatter. Reformats Python source code deterministically.

Key modules:
- src/black/__init__.py - Main entry point with format_str()
- src/black/parsing.py - lib2to3_parse() and parse_ast() for Python source parsing
- src/black/strings.py - String normalization (quotes, unicode escapes, docstrings)
- src/black/numerics.py - Numeric literal formatting
- src/black/mode.py - Configuration/mode settings
- src/blib2to3/ - Python parser (lib2to3 fork)

Important functions for fuzz testing:

1. black.format_str(src_contents, mode)
   - Main entry point for formatting Python source code
   - Parses code, applies formatting rules, validates AST equivalence
   - High priority: primary public API

2. black.parsing.lib2to3_parse(src_txt, target_versions, is_pyi)
   - Parses Python source strings into lib2to3 AST
   - Tries multiple grammars for different Python versions
   - High priority: core parsing function

3. black.strings.normalize_string_quotes(leaf)
   - Converts quote styles with escape sequence handling
   - Complex regex for unescaped quote detection
   - Medium priority

4. black.strings.normalize_unicode_escape_sequences(leaf)
   - Processes Unicode escapes (\uXXXX, \UXXXXXXXX, \xXX, \N{name})
   - Medium priority

5. black.numerics.normalize_numeric_literal(text)
   - Formats hex, binary, octal, scientific notation, complex numbers
   - Medium priority

6. black.handle_ipynb_magics.mask_cell(src)
   - Masks IPython magic commands before formatting
   - Lower priority

Dependencies:
- click >= 8.0.0
- mypy_extensions >= 0.4.3
- packaging >= 22.0
- pathspec >= 0.9.0
- platformdirs >= 2
- Install via: pip install -e /app/black/

Fuzz strategy:
- Primary target: black.format_str() with random Python-like strings
- Use Mode() with default settings
- Catch expected exceptions from parsing invalid Python code
- The formatter should never crash on any input, only raise clean errors
