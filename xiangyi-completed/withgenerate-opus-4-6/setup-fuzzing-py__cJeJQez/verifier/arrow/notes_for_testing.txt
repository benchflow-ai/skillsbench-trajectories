Library: Arrow
Description: Python library for creating, manipulating, formatting, and converting dates, times, and timestamps.

Key modules:
- arrow/parser.py - DateTimeParser, TzinfoParser for parsing date/time strings
- arrow/factory.py - ArrowFactory for flexible Arrow object creation
- arrow/formatter.py - DateTimeFormatter for formatting Arrow objects
- arrow/arrow.py - Main Arrow class with datetime operations
- arrow/util.py - Utility functions (timestamp normalization, ISO calendar)

Important functions for fuzz testing:

1. arrow.parser.DateTimeParser.parse_iso(datetime_string, normalize_whitespace)
   - Parses ISO 8601 datetime strings
   - Complex regex-based matching, handles multiple date/time formats
   - High priority: main entry point for string parsing

2. arrow.parser.DateTimeParser.parse(datetime_string, fmt, normalize_whitespace)
   - Parses datetime strings with custom format patterns
   - Generates regex from format tokens
   - High priority: format-directed parsing

3. arrow.factory.ArrowFactory.get(*args, **kwargs)
   - Flexible factory accepting str, int, float, datetime, date, tuple, etc.
   - Type-routing and conversion logic
   - High priority: polymorphic input handling

4. arrow.parser.TzinfoParser.parse(tzinfo_string)
   - Parses timezone strings (e.g., 'US/Pacific', '+07:00', 'UTC')
   - Handles ISO offset format, timezone names
   - Medium priority

5. arrow.arrow.Arrow.dehumanize(input_string, locale)
   - Converts humanized time strings back to Arrow objects
   - String deserialization with locale handling
   - Medium priority

6. arrow.util.normalize_timestamp(timestamp)
   - Normalizes millisecond/microsecond timestamps to seconds
   - Boundary validation
   - Lower priority

7. arrow.util.iso_to_gregorian(iso_year, iso_week, iso_day)
   - Converts ISO week dates to Gregorian calendar
   - Boundary validation for week (1-53) and day (1-7)
   - Lower priority

Dependencies:
- python-dateutil >= 2.7.0
- Core requirements in requirements/requirements.txt

Fuzz strategy:
- Primary target: arrow.get() with string inputs - covers both parse_iso and parse with formats
- Secondary: TzinfoParser.parse() for timezone strings
- Use FuzzedDataProvider to generate Unicode strings
- Catch ValueError, TypeError, ParserError as expected exceptions
