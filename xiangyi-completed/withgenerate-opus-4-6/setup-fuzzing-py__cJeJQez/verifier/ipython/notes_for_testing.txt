Library: IPython
Description: Interactive Python shell with magic commands, input transformation, code completion, and rich display.

Key modules:
- IPython/core/inputtransformer2.py - Input transformation engine (magic, shell, help syntax)
- IPython/core/splitinput.py - User input line parsing and classification
- IPython/core/compilerop.py - Code compilation with caching
- IPython/core/completer.py - Tab completion system
- IPython/utils/tokenutil.py - Token generation and manipulation

Important functions for fuzz testing:

1. IPython.core.inputtransformer2.TransformerManager.transform_cell(cell)
   - Main entry point for transforming cell input
   - Applies cleanup, line, and token transformers in sequence
   - Handles magic commands, shell commands, help syntax
   - High priority: primary input processing pipeline

2. IPython.core.inputtransformer2.TransformerManager.check_complete(cell)
   - Validates if code block is syntactically complete
   - Checks brackets, multiline strings, continued lines
   - High priority: complex token analysis

3. IPython.core.splitinput.split_user_input(line)
   - Splits input into (pre_whitespace, escape_char, function_name, rest)
   - Complex regex-based parsing
   - Medium priority

4. IPython.core.inputtransformer2.EscapedCommand.find(tokens_by_line)
   - Finds escaped commands (%, !, ?, /, etc.)
   - Medium priority

5. IPython.core.inputtransformer2.HelpEnd.find(tokens_by_line)
   - Finds help syntax (obj?, obj??)
   - Medium priority

6. IPython.core.inputtransformer2.make_tokens_by_line(lines)
   - Tokenizes code and groups by logical line
   - Complex bracket tracking
   - Medium priority

7. IPython.utils.tokenutil.token_at_cursor(cell, cursor_pos)
   - Gets token at cursor position in multi-line cell
   - Lower priority

Dependencies:
- decorator, jedi>=0.18.1, matplotlib-inline, pexpect>4.3
- prompt_toolkit>=3.0.41, pygments>=2.11.0, stack_data, traitlets>=5.13.0
- Install via: pip install -e /app/ipython/

Fuzz strategy:
- Primary target: TransformerManager.transform_cell() and check_complete()
- Feed random strings that may contain Python code, magic commands, shell escapes
- Catch SyntaxError, ValueError, TokenError, IndentationError as expected
- The transformer should never crash on any user input
