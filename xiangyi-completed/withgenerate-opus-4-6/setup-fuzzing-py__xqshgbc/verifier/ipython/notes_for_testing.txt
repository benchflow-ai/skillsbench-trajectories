IPython Library - Notes for Fuzz Testing
=========================================

Library: IPython (Interactive Python shell)
Location: /app/ipython/IPython/

Key Functions to Fuzz Test:
---------------------------

1. InputTransformer functions (inputtransformer2.py)
   - File: /app/ipython/IPython/core/inputtransformer2.py
   - TransformerManager.transform_cell(cell) -> str
   - Transforms IPython special syntax (%magic, !system, help?) into Python
   - Fuzz with: arbitrary unicode strings simulating IPython input

2. IPCompleter.completions(text, offset)
   - File: /app/ipython/IPython/core/completer.py

   - Fuzz with: arbitrary code strings and offsets

3. CachingCompiler.__call__(source, filename, symbol)
   - File: /app/ipython/IPython/core/compilerop.py
   - Compiles Python source code for interactive use
   - Fuzz with: arbitrary strings as source code

4. pretty(obj, verbose=False, max_width=79) -> str
   - File: /app/ipython/IPython/lib/pretty.py
   - Pretty-prints Python objects
   - Fuzz with: various constructed objects

5. split_user_input(line, pattern) -> tuple
   - File: /app/ipython/IPython/core/splitinput.py
   - Splits user input into magic components
   - Fuzz with: arbitrary line strings

6. leading_empty_lines(lines) / leading_indent(lines)
   - File: /app/ipython/IPython/core/inputtransformer2.py
   - Input preprocessing helpers
   - Fuzz with: arbitrary lists of strings

7. PromptStripper(prompt_re, initial_re)(lines)
   - File: /app/ipython/IPython/core/inputtransformer2.py
   - Strips input prompts from blocks
   - Fuzz with: arbitrary strings with prompt-like patterns
