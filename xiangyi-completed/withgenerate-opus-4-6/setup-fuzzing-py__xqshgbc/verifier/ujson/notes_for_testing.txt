UltraJSON (ujson) Library - Notes for Fuzz Testing
====================================================

Library: UltraJSON (fast JSON encoder/decoder in C)
Location: /app/ujson/

Key Functions to Fuzz Test:
---------------------------

1. ujson.loads(s) -> object  (alias: ujson.decode)
   - File: /app/ujson/src/ujson/python/JSONtoObj.c
   - Parses JSON string/bytes/bytearray to Python object
   - Fuzz with: arbitrary bytes and unicode strings
   - HIGH PRIORITY: C parser, buffer overflow risks

2. ujson.dumps(obj, **kwargs) -> str  (alias: ujson.encode)
   - File: /app/ujson/src/ujson/python/objToJSON.c
   - Converts Python objects to JSON string
   - Options: ensure_ascii, encode_html_chars, escape_forward_slashes,
     sort_keys, indent, allow_nan, reject_bytes, default, separators
   - Fuzz with: nested dicts/lists with random values and option combos

3. ujson.load(fp) -> object
   - File: /app/ujson/src/ujson/python/JSONtoObj.c
   - Reads JSON from file-like object
   - Fuzz with: BytesIO with arbitrary content

4. ujson.dump(obj, fp, **kwargs) -> None
   - File: /app/ujson/src/ujson/python/objToJSON.c
   - Writes JSON to file-like object
   - Fuzz with: random objects + StringIO

5. Roundtrip: loads(dumps(obj)) should equal obj
   - Test encode->decode consistency
   - Fuzz with: generated Python structures

Expected Exceptions (to catch in fuzz driver):
- ujson.JSONDecodeError (subclass of ValueError)
- ValueError
- TypeError
- OverflowError
- RecursionError

Dependencies:
- No runtime dependencies (C extension with bundled double-conversion)
- Build requires: setuptools>=42, setuptools_scm>=3.4
- Needs C compiler for building from source
