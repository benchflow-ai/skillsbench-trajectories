Arrow Library - Notes for Fuzz Testing
=======================================

Library: Arrow (date/time handling for Python)
Location: /app/arrow/arrow/

Key Functions to Fuzz Test:
---------------------------

1. arrow.get(*args, **kwargs) -> Arrow
   - File: /app/arrow/arrow/api.py
   - Main entry point. Accepts strings, timestamps, datetime objects.
   - Fuzz with: arbitrary strings, ints, floats

2. DateTimeParser.parse_iso(datetime_string, normalize_whitespace=False) -> datetime
   - File: /app/arrow/arrow/parser.py
   - Parses ISO 8601 datetime strings
   - Fuzz with: arbitrary unicode strings

3. DateTimeParser.parse(datetime_string, fmt, normalize_whitespace=False) -> datetime
   - File: /app/arrow/arrow/parser.py
   - Parses datetime with custom format strings
   - Fuzz with: arbitrary strings and format tokens

4. TzinfoParser.parse(tzinfo_string) -> tzinfo
   - File: /app/arrow/arrow/parser.py
   - Parses timezone strings
   - Fuzz with: arbitrary strings

5. Arrow.format(fmt, locale) -> str
   - File: /app/arrow/arrow/arrow.py
   - Formats datetime with custom format strings
   - Fuzz with: arbitrary format strings

6. Arrow.dehumanize(input_string, locale) -> Arrow
   - File: /app/arrow/arrow/arrow.py
   - Parses human-readable time expressions like "2 hours ago"
   - Fuzz with: arbitrary unicode strings

7. Arrow.shift(**kwargs) -> Arrow
   - File: /app/arrow/arrow/arrow.py
   - Shifts time by relative amounts
   - Fuzz with: random int/float kwargs for years, months, days, hours, etc.

8. Arrow.fromtimestamp(timestamp, tzinfo) -> Arrow
   - File: /app/arrow/arrow/arrow.py
   - Creates Arrow from numeric timestamp
   - Fuzz with: arbitrary floats and ints

Expected Exceptions (to catch in fuzz driver):
- arrow.parser.ParserError
- arrow.parser.ParserMatchError
- ValueError
- TypeError
- OverflowError
- re.error
- AttributeError

Dependencies:
- python-dateutil >= 2.7.0
- tzdata (for Python >= 3.9)
