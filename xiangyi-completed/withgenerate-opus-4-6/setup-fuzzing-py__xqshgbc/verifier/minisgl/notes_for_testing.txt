MiniSGL Library - Notes for Fuzz Testing
=========================================

Library: Mini-SGLang (LLM inference framework)
Location: /app/minisgl/python/minisgl/

Note: This library requires CUDA/GPU for core inference functionality.
Focus fuzzing on pure-Python components that work without GPU.

Key Functions to Fuzz Test:
---------------------------

1. SamplingParams dataclass
   - File: /app/minisgl/python/minisgl/core.py
   - SamplingParams(temperature, top_k, top_p, ignore_eos, max_tokens)
   - Fuzz with: random float/int values for params, test is_greedy property

2. find_printable_text(text) -> str
   - File: /app/minisgl/python/minisgl/tokenizer/detokenize.py
   - Returns longest printable substring containing entire words
   - Fuzz with: arbitrary unicode strings

3. _is_chinese_char(cp) -> bool
   - File: /app/minisgl/python/minisgl/tokenizer/detokenize.py
   - Checks if a codepoint is a CJK character
   - Fuzz with: arbitrary integer codepoints

4. serialize_type(obj) / deserialize_type(cls_map, data) / _serialize_any(value)
   - File: /app/minisgl/python/minisgl/message/utils.py
   - IPC message serialization/deserialization
   - Fuzz with: arbitrary dicts/lists/values to serialize; arbitrary dicts to deserialize

5. OpenAICompletionRequest (Pydantic model validation)
   - File: /app/minisgl/python/minisgl/server/api_server.py
   - Validates OpenAI API request payloads
   - Fuzz with: arbitrary JSON-like dicts

6. GenerateRequest / Message (Pydantic models)
   - File: /app/minisgl/python/minisgl/server/api_server.py
   - Request validation models
   - Fuzz with: arbitrary strings/dicts

Expected Exceptions (to catch in fuzz driver):
- ValueError
- TypeError
- KeyError
- AttributeError
- OverflowError
- AssertionError (from dataclass __post_init__)
- pydantic.ValidationError

Dependencies (from pyproject.toml):
- torch
- transformers>=4.56.0
- msgpack
- pyzmq
- uvicorn
- fastapi
- pydantic
- numpy
Note: Many GPU-specific deps (sgl_kernel, flashinfer, etc.) cannot install without CUDA.
For fuzzing, install only what's needed for the pure-Python components.
