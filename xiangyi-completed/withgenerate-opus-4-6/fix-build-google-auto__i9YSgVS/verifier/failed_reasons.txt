=== ERROR #1: com.sun:tools:jar dependency resolution failure ===

TYPE: Build configuration (dependency resolution)

All four modules (common, factory, service, value) depend on the
`compile-testing` library (versions 0.6, 0.7, or 0.8) for testing.
All versions of `compile-testing` declare a system-scoped dependency on:

    <dependency>
      <groupId>com.sun</groupId>
      <artifactId>tools</artifactId>
      <version>${java.version}</version>
      <scope>system</scope>
      <systemPath>${toolsjar}</systemPath>
    </dependency>

This references tools.jar which existed in Java 8 and earlier at
$JAVA_HOME/../lib/tools.jar. In Java 9+ (including Java 11 used here),
tools.jar was eliminated as part of Project Jigsaw (module system).

Error message:
  "Could not find artifact com.sun:tools:jar:11.0.27 at specified path
   /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar"

This blocks ALL compilation, causing the entire build to fail.

AFFECTED FILES:
  1. common/pom.xml  - compile-testing 0.7
  2. service/pom.xml - compile-testing 0.6
  3. factory/pom.xml - compile-testing 0.8
  4. value/pom.xml   - compile-testing 0.6

FIX: Add <exclusions> for com.sun:tools to each compile-testing
dependency. On Java 9+, javax.tools.* classes are part of the
java.compiler module and available by default.
