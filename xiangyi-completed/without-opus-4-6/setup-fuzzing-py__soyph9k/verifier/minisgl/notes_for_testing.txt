Mini-SGLang Library - Notes for Fuzzing

Mini-SGLang is a lightweight inference framework for Large Language Models (LLMs).
It features message serialization/deserialization, tokenization, and an OpenAI-compatible API server.

Key fuzzing targets (functions that parse/deserialize input):

1. deserialize_type(cls_map: Dict[str, Type], data: Dict) -> Any
   - Module: minisgl.message.utils (python/minisgl/message/utils.py)
   - Reconstructs Python objects from dictionaries using __type__ field
   - Called by all message decoders

2. _deserialize_any(cls_map: Dict[str, Type], data: Any) -> Any
   - Module: minisgl.message.utils (python/minisgl/message/utils.py)
   - Recursively parses nested structures

3. serialize_type(self) -> Dict
   - Module: minisgl.message.utils (python/minisgl/message/utils.py)
   - Serializes Python dataclasses to dicts

4. find_printable_text(text: str) -> str
   - Module: minisgl.tokenizer.detokenize (python/minisgl/tokenizer/detokenize.py)
   - Unicode parsing with CJK character range detection

5. Message dataclass decoders:
   - BaseTokenizerMsg.decoder(json: Dict) -> BaseTokenizerMsg
   - BaseFrontendMsg.decoder(json: Dict) -> BaseFrontendMsg
   - BaseBackendMsg.decoder(json: Dict) -> BaseBackendMsg
   Module: minisgl.message.{tokenizer,frontend,backend}

6. parse_args(args: List[str]) -> Tuple[ServerArgs, bool]
   - Module: minisgl.server.args (python/minisgl/server/args.py)
   - CLI argument parsing

Dependencies: torch, transformers, accelerate, fastapi, uvicorn, pyzmq, msgpack, openai, prompt_toolkit, sgl_kernel, flashinfer-python
Note: Heavy ML dependencies - fuzzing should focus on serialization/deserialization and text processing utilities that don't require GPU.
