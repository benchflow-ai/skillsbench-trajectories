Black Library - Notes for Fuzzing

Black is the "uncompromising Python code formatter". It parses and reformats Python source code.

Key fuzzing targets (functions that accept string input):

1. black.format_str(src_contents: str, *, mode: Mode) -> str
   - Module: black/__init__.py
   - PRIMARY entry point - reformats Python code string
   - Invokes parser, line generator, and AST safety checks

2. black.format_file_contents(src_contents: str, *, fast: bool, mode: Mode) -> FileContent
   - Module: black/__init__.py
   - Wrapper around format_str with AST equivalence and stability checks

3. black.parsing.lib2to3_parse(src_txt: str, target_versions) -> Node
   - Module: black/parsing.py
   - Parses Python code into lib2to3 parse tree

4. black.parsing.parse_ast(src: str) -> ast.AST
   - Module: black/parsing.py
   - Parses Python string into AST, tries multiple Python version modes

5. black.strings.normalize_string_quotes(s: str) -> str
   - Module: black/strings.py
   - Normalizes quote styles in string literals

6. black.assert_equivalent(src: str, dst: str) -> None
   - Module: black/__init__.py
   - Verifies ASTs are equivalent before/after formatting
