IPython Library - Notes for Fuzzing

IPython is an interactive Python shell with magic commands, input transformers, and code completion.

Key fuzzing targets (functions that accept string input for parsing/transformation):

1. TransformerManager.transform_cell(cell: str) -> str
   - Module: IPython.core.inputtransformer2
   - Main entry point for transforming user input
   - Applies cleanup, line, and token transforms (magic, shell, help syntax)

2. TransformerManager.check_complete(cell: str) -> tuple[str, int|None]
   - Module: IPython.core.inputtransformer2
   - Checks if input cell is complete/incomplete/invalid

3. EscapedCommand.transform(lines) -> list[str]
   - Module: IPython.core.inputtransformer2
   - Transforms %magic, !shell, ?help, /paren, ,quote, ;quote2 syntax

4. split_user_input(line, pattern=None) -> tuple
   - Module: IPython.core.splitinput
   - Splits input line into (indent, escape, function, args) via regex

5. arg_split(s, posix=False, strict=True) -> list[str]
   - Module: IPython.utils._process_common
   - Shell-like argument splitting using shlex

6. CachingCompiler.ast_parse(source, filename, symbol) -> AST
   - Module: IPython.core.compilerop
   - Parses Python code to AST
