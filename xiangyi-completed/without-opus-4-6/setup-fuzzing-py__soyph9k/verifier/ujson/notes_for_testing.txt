UltraJSON (ujson) Library - Notes for Fuzzing

UltraJSON is an ultra-fast JSON encoder and decoder written in C with Python bindings.
Drop-in replacement for Python's json module.

Key fuzzing targets (functions that accept string/bytes input):

1. ujson.loads(s: str | bytes | bytearray) -> Any
   - Module: ujson (C extension)
   - PRIMARY target: Parse JSON string/bytes into Python objects
   - C implementation: JSON_DecodeObject() in ultrajsondec.c
   - Handles escape sequences, unicode, nested structures, number parsing

2. ujson.decode(s) -> Any
   - Alias for loads()

3. ujson.dumps(obj: Any, ensure_ascii=True, encode_html_chars=False, escape_forward_slashes=True, sort_keys=False, indent=0, allow_nan=True, reject_bytes=False, default=None, separators=None) -> str
   - Module: ujson (C extension)
   - Serialize Python objects to JSON string
   - C implementation: JSON_EncodeObject() in ultrajsonenc.c

4. ujson.encode(obj) -> str
   - Alias for dumps()

Key limits:
- JSON_MAX_RECURSION_DEPTH = 1024
- JSON_MAX_OBJECT_DEPTH = 1024
- JSON_DOUBLE_MAX_DECIMALS = 15

Dependencies: None (pure C extension, no Python runtime dependencies)
Build dependencies: setuptools>=42, setuptools_scm[toml]>=3.4
