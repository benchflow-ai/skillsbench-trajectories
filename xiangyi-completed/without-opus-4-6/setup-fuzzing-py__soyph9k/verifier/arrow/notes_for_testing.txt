Arrow Library - Notes for Fuzzing

Arrow is a Python library for intuitive date/time handling. It parses various date/time string formats.

Key fuzzing targets (functions that accept string input and perform complex parsing):

1. arrow.get(*args, **kwargs) -> Arrow
   - Module: arrow.api / arrow.factory.ArrowFactory
   - Main public API entry point, accepts ISO 8601 strings, custom format strings, timestamps
   - Flexible parsing with many code paths

2. DateTimeParser.parse_iso(datetime_string, normalize_whitespace=False) -> datetime
   - Module: arrow.parser (arrow/parser.py)
   - Parses ISO 8601-like datetime strings with various separators
   - Complex regex and token-based parsing

3. DateTimeParser.parse(datetime_string, fmt, normalize_whitespace=False) -> datetime
   - Module: arrow.parser (arrow/parser.py)
   - Parses datetime strings with custom Arrow format tokens
   - Supports format lists (tries multiple formats)

4. TzinfoParser.parse(tzinfo_string) -> dt_tzinfo
   - Module: arrow.parser (arrow/parser.py)
   - Parses timezone strings: "local", "utc", ISO offsets (±HH:MM), named timezones

5. Arrow.dehumanize(input_string, locale="en_us") -> Arrow
   - Module: arrow.arrow (arrow/arrow.py)
   - Parses natural language time expressions like "2 hours ago"

6. Arrow.format(fmt, locale) -> str
   - Module: arrow.arrow (arrow/arrow.py)
   - Format string processing with Arrow tokens (YYYY, MM, DD, etc.)

Dependencies: python-dateutil>=2.7.0, typing_extensions
