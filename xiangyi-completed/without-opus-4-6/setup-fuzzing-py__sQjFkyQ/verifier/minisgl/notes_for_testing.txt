MiniSGL Library - Notes for Fuzz Testing
=========================================

Library Purpose:
MiniSGL (mini-sglang) is a lightweight inference framework for Large Language Models.
It provides high-performance LLM serving with optimizations like Radix Cache,
Chunked Prefill, and Overlap Scheduling.

Key Functions to Fuzz:
1. minisgl.message.utils.deserialize_type(cls_map, data) - Core deserialization engine
   that processes inter-process messages, handles type lookup, numpy arrays, torch tensors
2. minisgl.message.utils._deserialize_any(cls_map, data) - Recursive deserialization of
   arbitrary data structures
3. minisgl.message.frontend.BaseFrontendMsg.decoder(json_dict) - Decodes frontend messages
4. minisgl.message.backend.BaseBackendMsg.decoder(json_dict) - Decodes backend messages
5. minisgl.message.tokenizer.BaseTokenizerMsg.decoder(json_dict) - Decodes tokenizer messages

Fuzzing Strategy:
- Focus on message deserialization functions which accept dict inputs
- Feed malformed dictionaries with invalid type names, corrupt buffers, mismatched dtypes
- Test deserialize_type() with various edge cases
- Note: Heavy GPU dependencies (torch, flashinfer, sgl_kernel) may not be available;
  focus on the message serialization/deserialization layer which is CPU-only

Dependencies (from pyproject.toml):
- msgpack
- torch
- transformers>=4.56.0
- pyzmq
- fastapi
- uvicorn
- accelerate
- Many GPU-specific dependencies (sgl_kernel, flashinfer-python, etc.)

Installation:
  cd /app/minisgl && pip install -e .
  Note: Some GPU dependencies may fail without CUDA. Install what's possible.
