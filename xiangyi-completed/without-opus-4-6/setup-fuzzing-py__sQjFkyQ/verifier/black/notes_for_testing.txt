Black Library - Notes for Fuzz Testing
=======================================

Library Purpose:
Black is the uncompromising Python code formatter. It takes Python source
code as input and reformats it to a consistent style.

Key Functions to Fuzz:
1. black.format_str(src_contents, mode=Mode()) - Main public API for formatting Python code
2. black.parsing.lib2to3_parse(src_txt) - Parses Python source code using lib2to3 parser
3. black.parsing.parse_ast(src) - Parses source code to AST
4. black.decode_bytes(src) - Decodes bytes with encoding detection

Fuzzing Strategy:
- Feed arbitrary strings to black.format_str() which is the main entry point
- The function accepts any string as Python source code and must handle invalid syntax gracefully
- Use black.Mode() as the default mode configuration
- All exceptions from invalid input should be caught (InvalidInput, etc.)
