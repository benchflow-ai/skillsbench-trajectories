ujson Library - Notes for Fuzz Testing
=======================================

Library Purpose:
UltraJSON (ujson) is an ultra-fast JSON encoder and decoder written in C with
Python bindings. Drop-in replacement for Python's json module.

Key Functions to Fuzz:
1. ujson.loads(s) / ujson.decode(s) - Parses JSON string/bytes into Python objects
   This is the PRIMARY fuzzing target - C-level decoder handles string parsing,
   numeric parsing, escape sequences, UTF-8, recursive structures
2. ujson.dumps(obj) / ujson.encode(obj) - Serializes Python objects to JSON string
3. ujson.load(fp) - Loads JSON from file object
4. ujson.dump(obj, fp) - Serializes object to file

Critical C-Level Functions (called via loads):
- decode_string(): Escape sequence handling, UTF-8 processing
- decode_numeric(): Integer overflow detection, 32/64-bit handling
- decodeDouble(): Float parsing via double-conversion library
- decode_array(): Recursive array parsing with depth tracking
- decode_object(): Dict parsing with key validation
- Max recursion depth: 1024

Fuzzing Strategy:
- Feed arbitrary bytes/strings to ujson.loads() - the C decoder is the primary target
- Test malformed JSON, deeply nested structures, large numbers, escape sequences
- Test round-trip: ujson.loads(ujson.dumps(obj)) consistency
- Focus on decoder as it processes untrusted input

Dependencies:
- Build: setuptools>=42, setuptools_scm[toml]>=3.4
- Runtime: none (pure C extension)
- Bundled: double-conversion library

Installation:
  cd /app/ujson && pip install -e .
