IPython Library - Notes for Fuzz Testing
=========================================

Library Purpose:
IPython is a powerful interactive computing environment for Python. It provides
magic commands, system shell integration, special syntax transformations, and
rich completion/introspection.

Key Functions to Fuzz:
1. IPython.core.splitinput.split_user_input(line) - Parses user input into components
   (whitespace, escape chars, function, rest) using regex
2. IPython.core.inputtransformer2.TransformerManager().transform_cell(cell) -
   Transforms IPython-specific syntax (magics, system commands, help) into valid Python
3. IPython.utils._process_common.arg_split(s) - Splits command-line arguments using shlex
4. IPython.utils.tokenutil.token_at_cursor(cell, cursor_pos) - Gets token at cursor position
5. IPython.core.compilerop.CachingCompiler().ast_parse(source) - Parses Python code to AST

Fuzzing Strategy:
- Feed arbitrary strings to split_user_input() which uses complex regex parsing
- Feed arbitrary strings to TransformerManager().transform_cell() which handles
  IPython special syntax (!, !!, ?, ??, %, %%, etc.)
- Feed arbitrary strings to arg_split() which uses shlex tokenization
- All functions should handle malformed input gracefully
