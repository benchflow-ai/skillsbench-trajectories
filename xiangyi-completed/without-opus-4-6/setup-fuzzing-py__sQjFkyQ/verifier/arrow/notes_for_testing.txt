Arrow Library - Notes for Fuzz Testing
=======================================

Library Purpose:
Arrow is a Python library for better date/time manipulation. It provides
timezone-aware datetime operations, ISO 8601 parsing, locale support,
and humanization of dates.

Key Functions to Fuzz:
1. arrow.get(string) - Main public API, parses ISO 8601 strings and various date formats
2. arrow.parser.DateTimeParser.parse_iso(datetime_string) - Parses ISO 8601-like datetime strings
3. arrow.parser.DateTimeParser.parse(datetime_string, fmt) - Parses datetime strings with custom format
4. arrow.parser.TzinfoParser.parse(tzinfo_string) - Parses timezone strings
5. arrow.factory.ArrowFactory.get(*args, **kwargs) - Flexible factory for creating Arrow objects
6. arrow.Arrow.dehumanize(input_string) - Parses human-readable time strings like "2 hours ago"

Fuzzing Strategy:
- Feed arbitrary strings to arrow.get() which handles ISO parsing
- Feed arbitrary strings to DateTimeParser.parse_iso()
- Feed arbitrary strings to TzinfoParser.parse()
- All functions should handle invalid input gracefully without crashing

Dependencies:
- python-dateutil>=2.7.0
- Build system: flit_core>=3.2,<4

Installation:
  cd /app/arrow && pip install -e .
