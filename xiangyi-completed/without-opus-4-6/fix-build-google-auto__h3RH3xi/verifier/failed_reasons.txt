BUILD FAILURE ANALYSIS - google/auto
=====================================

Environment:
- Java: OpenJDK 11.0.27 (JRE only, no javac in Java 11 installation)
- Maven: 3.6.3
- Available JDKs with javac: Java 6 (OpenJDK), Java 7 (OpenJDK, Oracle), Java 8 (Oracle)
  Note: Java 6/7/8 cannot connect to Maven Central due to TLS incompatibility,
  so the build must use Java 11.

Build command: mvn -f build-pom.xml compile

ROOT CAUSE #1: com.sun:tools dependency cannot be resolved on Java 11
------------------------------------------------------------------------
Error message:
  Could not find artifact com.sun:tools:jar:11.0.27 at specified path
  /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar

Explanation:
  In Java 8 and earlier, the JDK shipped a tools.jar containing compiler APIs
  (javax.tools, com.sun.source, etc.). Starting with Java 9+, these classes
  were integrated into the JDK modules (jdk.compiler module) and tools.jar
  was removed.

  The compile-testing library (versions 0.6, 0.7, and 0.8) used by this project
  declares a system-scoped dependency on com.sun:tools using ${toolsjar} property:
    <dependency>
      <groupId>com.sun</groupId>
      <artifactId>tools</artifactId>
      <version>${java.version}</version>
      <scope>system</scope>
      <systemPath>${toolsjar}</systemPath>
    </dependency>

  The parent POM (pom.xml) defines profiles that set ${toolsjar} to
  ${java.home}/../lib/tools.jar, but this file does not exist in Java 11.

  Affected modules:
  - common/pom.xml: compile-testing 0.7 (test scope)
  - factory/pom.xml: compile-testing 0.8 (test scope)
  - service/pom.xml: compile-testing 0.6 (test scope)
  - value/pom.xml: compile-testing 0.6 (test scope)

ROOT CAUSE #2: Java source/target level 1.6 is not supported by Java 11
------------------------------------------------------------------------
  The parent POM sets java.version=1.6 which is used for maven-compiler-plugin
  source and target. Java 11's javac only supports source/target >= 1.7.

  From parent pom.xml:
    <java.version>1.6</java.version>
    ...
    <source>${java.version}</source>
    <target>${java.version}</target>

ROOT CAUSE #3: javax.annotation.Generated not available on Java 11
------------------------------------------------------------------------
  The factory and value modules import javax.annotation.Generated, which was
  part of java.se.ee (removed in Java 11 via JEP 320). This class no longer
  ships with the JDK.

  Affected files:
  - factory/src/main/java/.../processor/FactoryWriter.java (import + usage)
  - value/src/main/java/.../processor/AutoValueProcessor.java (import + usage)
  - value/src/main/java/.../processor/AutoAnnotationProcessor.java (import + usage)

FIX PLAN
========

Fix 1 (patch_1.diff): Update parent pom.xml
  - Change java.version from 1.6 to 1.7 (minimum supported by Java 11 javac)
  - Add a new JDK 9+ profile that maps toolsjar to an existing jar (jrt-fs.jar)
    so the system-scoped dependency resolution doesn't fail

Fix 2 (patch_2.diff): Update common/pom.xml
  - Exclude com.sun:tools from the compile-testing dependency

Fix 3 (patch_3.diff): Update factory/pom.xml
  - Exclude com.sun:tools from the compile-testing dependency
  - Add javax.annotation:javax.annotation-api:1.3.2 dependency to provide
    javax.annotation.Generated class

Fix 4 (patch_4.diff): Update service/pom.xml
  - Exclude com.sun:tools from the compile-testing dependency

Fix 5 (patch_5.diff): Update value/pom.xml
  - Exclude com.sun:tools from the compile-testing dependency
  - Add javax.annotation:javax.annotation-api:1.3.2 dependency to provide
    javax.annotation.Generated class
