ERROR 1: com.sun:tools dependency resolution failure
=====================================================
All four modules fail with the same dependency resolution error:

  "Could not find artifact com.sun:tools:jar:11.0.27 at specified path
   /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar"

This is caused by a Java version incompatibility:
1. The project was designed for Java 6/7/8 (as seen in .travis.yml: oraclejdk7, openjdk7)
2. The current environment runs Java 11 (OpenJDK 11.0.27)
3. In Java 9+, tools.jar was removed (classes moved into jdk.compiler module)

DEPENDENCY CHAIN:
  compile-testing (0.6, 0.7, 0.8)
    -> com.sun:tools:jar:${java.version} (system scope, systemPath=${toolsjar})

  The compile-testing library declares a system-scoped dependency on com.sun:tools
  using ${toolsjar} which resolves to ${java.home}/../lib/tools.jar.
  On Java 11, this file does not exist.

AFFECTED MODULE POM FILES AND THEIR compile-testing VERSIONS:
  - common/pom.xml:  compile-testing 0.7 (test scope)
  - service/pom.xml: compile-testing 0.6 (test scope)
  - factory/pom.xml: compile-testing 0.8 (test scope)
  - value/pom.xml:   compile-testing 0.6 (test scope)

ERROR 2: javax.annotation.Generated class not found
====================================================
After fixing the dependency issue, the factory and value modules fail with:

  "cannot find symbol: class Generated, location: package javax.annotation"

In Java 9+, javax.annotation.Generated was removed from the JDK.
The replacement is javax.annotation.processing.Generated.

AFFECTED SOURCE FILES:
  - factory/src/main/java/com/google/auto/factory/processor/FactoryWriter.java
    Line 39: import javax.annotation.Generated;
    Line 60: .emitImports("javax.annotation.Generated");

  - value/src/main/java/com/google/auto/value/processor/AutoValueProcessor.java
    Line 51: import javax.annotation.Generated;

  - value/src/main/java/com/google/auto/value/processor/AutoAnnotationProcessor.java
    Line 36: import javax.annotation.Generated;

FIX STRATEGY:
=============
1. In the root pom.xml (auto-parent 4-SNAPSHOT), add a JDK 9+ profile that
   sets toolsjar to an existing jar (jrt-fs.jar) to avoid broken systemPath
   resolution. Also update java.version from 1.6 to 1.7.

2. In each module POM that depends on compile-testing, exclude the
   com.sun:tools transitive dependency.

3. Change import javax.annotation.Generated to
   import javax.annotation.processing.Generated in the three affected
   source files. Also update the emitted import string in FactoryWriter.java.
