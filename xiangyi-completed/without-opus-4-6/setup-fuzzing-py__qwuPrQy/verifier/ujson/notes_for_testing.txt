ujson Library - Notes for Fuzz Testing
=======================================

Library: UltraJSON - Ultra fast JSON encoder/decoder (C extension)
Location: /app/ujson/
Dependencies: Build-only (setuptools, setuptools_scm). No runtime deps.
Note: Must be compiled from C source (pip install -e .)

Key Functions to Fuzz:
1. ujson.loads(s: str | bytes | bytearray) -> Any
   - Alias: ujson.decode()
   - C implementation: src/ujson/python/JSONtoObj.c -> JSON_DecodeObject()
   - Core parser: src/ujson/lib/ultrajsondec.c
   - HIGHEST priority - parses arbitrary JSON strings
   - Risk areas: buffer overflows, stack exhaustion (max depth 1024),
     integer overflow, Unicode escape handling

2. ujson.dumps(obj: Any, **options) -> str
   - Alias: ujson.encode()
   - C implementation: src/ujson/python/objToJSON.c -> JSON_EncodeObject()
   - Core encoder: src/ujson/lib/ultrajsonenc.c
   - HIGH priority - encodes arbitrary Python objects
   - Options: ensure_ascii, encode_html_chars, escape_forward_slashes,
     sort_keys, indent, allow_nan, reject_bytes, default, separators

3. Roundtrip testing: ujson.loads(ujson.dumps(obj)) and ujson.dumps(ujson.loads(s))
   - Test encoding/decoding consistency

Edge Cases to Test:
- Maximum depth nesting: "[" * 1024 + "]" * 1024
- Very large numbers: 99999999999999999999999999999999
- Scientific notation: 1e308, 1e-308
- Unicode escape sequences: \uXXXX, surrogate pairs
- Malformed JSON: {,}, [,,], trailing commas
- NaN, Infinity, -Infinity handling

Fuzzing Strategy:
- Use atheris for coverage-guided fuzzing
- Primary target: ujson.loads() with arbitrary bytes/strings
- Secondary: ujson.dumps() with constructed Python objects
- Expected exceptions: ujson.JSONDecodeError, ValueError, OverflowError, TypeError
- The C extension makes this especially valuable for finding memory safety issues
