Black Library - Notes for Fuzz Testing
=======================================

Library: Black - The Uncompromising Python Code Formatter
Location: /app/black/src/black/
Dependencies: click>=8.0.0, mypy_extensions>=0.4.3, packaging>=22.0, pathspec>=0.9.0,
              platformdirs>=2, pytokens>=0.3.0

Key Functions to Fuzz:
1. black.format_str(src_contents: str, *, mode: Mode) -> str
   - File: src/black/__init__.py
   - Main public API for formatting Python code strings
   - HIGHEST priority target - takes arbitrary Python code strings

2. black.parsing.lib2to3_parse(src_txt: str, target_versions: Collection[TargetVersion] = ()) -> Node
   - File: src/black/parsing.py
   - Core parsing using lib2to3 (attempts 3 different grammars)
   - HIGH priority - tests core parsing with multiple grammar fallbacks

3. black.format_file_contents(src_contents: str, *, fast: bool, mode: Mode) -> FileContent
   - File: src/black/__init__.py
   - Reformats file contents, dispatches to format_str()

4. black.strings.normalize_string_quotes(s: str) -> str
   - File: src/black/strings.py
   - Complex regex-based quote transformation

5. black.assert_equivalent(src: str, dst: str) -> None
   - File: src/black/__init__.py
   - Verifies formatted code has same AST as original
   - Used for correctness checking in fuzzer

Fuzzing Strategy:
- Use atheris for coverage-guided fuzzing
- Primary target: format_str() with arbitrary string input and default Mode
- The function should handle invalid Python gracefully (raise InvalidInput)
- Expected exceptions: InvalidInput, NothingChanged, SyntaxError, TokenError, ValueError
- Black already has a fuzz script at scripts/fuzz.py using Hypothesis
