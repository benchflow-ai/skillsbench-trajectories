Mini-SGL Library - Notes for Fuzz Testing
===========================================

Library: Mini-SGLang - Lightweight LLM inference framework
Location: /app/minisgl/python/minisgl/
Dependencies: msgpack, pyzmq, fastapi, uvicorn, prompt_toolkit, pydantic
Note: Heavy deps like torch, transformers, sgl_kernel are NOT needed for message parsing fuzz targets

Key Functions to Fuzz:
1. minisgl.message.utils.deserialize_type(cls_map: Dict[str, Type], data: Dict) -> Any
   - File: python/minisgl/message/utils.py
   - Deserializes arbitrary dicts with type lookup using __type__ field
   - CRITICAL - handles untrusted data

2. minisgl.message.utils.serialize_type(self: Any) -> Dict
   - File: python/minisgl/message/utils.py
   - Converts dataclass instances to JSON-serializable dicts

3. minisgl.tokenizer.detokenize.find_printable_text(text: str) -> str
   - File: python/minisgl/tokenizer/detokenize.py
   - String slicing with Unicode character detection
   - Handles CJK characters

4. minisgl.tokenizer.detokenize._is_chinese_char(cp: int) -> bool
   - File: python/minisgl/tokenizer/detokenize.py
   - Unicode range checking for CJK codepoints

5. minisgl.server.args.parse_args(args: List[str], run_shell: bool = False) -> Tuple
   - File: python/minisgl/server/args.py
   - Parses command-line arguments with type conversions

6. Pydantic models: GenerateRequest, OpenAICompletionRequest
   - File: python/minisgl/server/api_server.py
   - HTTP request validation from JSON

Fuzzing Strategy:
- Use atheris for coverage-guided fuzzing
- Primary targets: deserialize_type() and serialize/deserialize roundtrip
- Also fuzz find_printable_text() and _is_chinese_char() for Unicode handling
- Focus on the message serialization layer since it doesn't need GPU/model
- Expected exceptions: KeyError, TypeError, ValueError, msgpack exceptions
