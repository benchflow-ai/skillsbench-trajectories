Arrow Library - Notes for Fuzz Testing
=======================================

Library: Arrow - Better dates & times for Python
Location: /app/arrow/arrow/
Dependencies: python-dateutil>=2.7.0, types-python-dateutil>=0.1.3

Key Functions to Fuzz:
1. arrow.parser.DateTimeParser.parse_iso(datetime_string: str, normalize_whitespace: bool = False) -> datetime
   - File: arrow/parser.py
   - Parses ISO 8601 and ISO-like datetime strings
   - Complex multi-format fallback logic, many format combinations
   - HIGHEST priority target

2. arrow.parser.DateTimeParser.parse(datetime_string: str, fmt: str, normalize_whitespace: bool = False) -> datetime
   - File: arrow/parser.py
   - Custom format string + input string, regex generation
   - HIGH priority target

3. arrow.parser.TzinfoParser.parse(tzinfo_string: str) -> dt_tzinfo
   - File: arrow/parser.py
   - Parses timezone strings ("UTC", "+05:30", "US/Pacific", etc.)
   - Edge cases in timezone offset parsing

4. arrow.factory.ArrowFactory.get(*args, **kwargs) -> Arrow
   - File: arrow/factory.py
   - Flexible factory that handles multiple input types including strings
   - HIGH priority - main entry point

5. arrow.arrow.Arrow.dehumanize(input_string: str, locale: str = "en_us") -> Arrow
   - File: arrow/arrow.py
   - Parses humanized relative time strings like "2 days ago"
   - Complex locale-based regex matching

Fuzzing Strategy:
- Use atheris for coverage-guided fuzzing
- Primary target: parse_iso() with arbitrary string input
- Secondary: get() which is the main API entry point
- Expected exceptions to catch: ParserError, ParserMatchError, ValueError, OverflowError
