IPython Library - Notes for Fuzz Testing
==========================================

Library: IPython - Interactive Python shell
Location: /app/ipython/IPython/
Dependencies: decorator, jedi>=0.18.1, prompt_toolkit>=3.0.41,<3.1.0,
              pygments>=2.11.0, traitlets>=5.13.0, stack_data>=0.6.0,
              matplotlib-inline, pexpect>4.3, ipython-pygments-lexers

Key Functions to Fuzz:
1. IPython.core.inputtransformer2.TransformerManager.transform_cell(cell: str) -> str
   - File: IPython/core/inputtransformer2.py
   - Main parsing engine - transforms IPython syntax to Python
   - Handles %, %%, !, !!, ?, ??, and other special syntax
   - HIGHEST priority target

2. IPython.core.inputtransformer2.TransformerManager.check_complete(cell: str) -> tuple
   - File: IPython/core/inputtransformer2.py
   - Validates code completeness, returns 'complete'/'incomplete'/'invalid'
   - HIGH priority target

3. IPython.core.splitinput.split_user_input(line: str, pattern=None) -> tuple
   - File: IPython/core/splitinput.py
   - Splits arbitrary line input into (pre, esc, ifun, the_rest)
   - Uses regex for parsing

4. IPython.core.inputtransformer2.make_tokens_by_line(lines: List[str])
   - File: IPython/core/inputtransformer2.py
   - Tokenizes code and groups by logical lines

5. IPython.utils._process_common.arg_split(s: str, posix=False, strict=True) -> List[str]
   - File: IPython/utils/_process_common.py
   - Parses shell-like argument strings using shlex

Fuzzing Strategy:
- Use atheris for coverage-guided fuzzing
- Primary target: TransformerManager.transform_cell() with arbitrary string input
- Also fuzz check_complete() and split_user_input()
- Expected exceptions: SyntaxError, TokenError, ValueError, IndentationError
- Be careful: avoid calling run_cell() as it executes code
