Arrow Library - Notes for Fuzzing

Arrow is a Python library for date/time handling that wraps datetime with a more intuitive API.
It provides extensive string parsing for dates, times, and timezones.

Key functions to fuzz:

1. arrow.get(string) - Main entry point, parses various date/time string formats
   Module: arrow.api / arrow.factory (ArrowFactory.get)
   Input: arbitrary date/time strings, ISO 8601 strings, timestamps

2. DateTimeParser.parse_iso(datetime_string) - ISO 8601 string parsing
   Module: arrow.parser
   Input: ISO 8601 date strings with auto-detection of separators and formats

3. DateTimeParser.parse(datetime_string, fmt) - Custom format string parsing
   Module: arrow.parser
   Input: date strings + format strings with tokens (YYYY, MM, DD, HH, mm, ss, etc.)
   Uses regex-based pattern matching

4. TzinfoParser.parse(tzinfo_string) - Timezone string parsing
   Module: arrow.parser
   Input: timezone expressions like "UTC", "+05:30", "US/Pacific"

5. Arrow.dehumanize(input_string) - Human-readable relative time parsing
   Module: arrow.arrow
   Input: strings like "2 days ago", "in 3 hours"

6. Arrow.format(fmt) - Format string processing
   Module: arrow.arrow
   Input: custom format strings

Dependencies:
- python-dateutil>=2.7.0
- Build: flit_core>=3.2,<4

Package structure: /app/arrow/arrow/ is the main package directory
