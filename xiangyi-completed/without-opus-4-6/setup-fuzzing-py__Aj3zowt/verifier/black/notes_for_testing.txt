Black Library - Notes for Fuzzing

Black is an opinionated Python code formatter. It parses Python source code using
lib2to3 and AST, reformats it, and verifies equivalence.

Key functions to fuzz:

1. black.format_str(src_contents, mode) - Main API, formats Python code strings
   Module: black/__init__.py (in src/black/)
   Input: arbitrary Python source code strings
   This is the primary entry point for formatting.

2. black.format_file_contents(src_contents, fast, mode) - Formats file content
   Module: black/__init__.py (in src/black/)
   Input: file content strings (Python source code)

3. lib2to3_parse(src_txt) - Core parser wrapper
   Module: black/parsing.py (in src/black/)
   Input: Python source code, tries multiple grammars

4. normalize_string_quotes(leaf) - String normalization
   Module: black/strings.py (in src/black/)
   Input: string literals with quotes

5. format_ipynb_string(src_contents, fast, mode) - Jupyter notebook formatting
   Module: black/__init__.py (in src/black/)
   Input: JSON strings (Jupyter notebook format)
