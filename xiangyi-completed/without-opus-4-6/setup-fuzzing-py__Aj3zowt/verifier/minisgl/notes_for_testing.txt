Mini-SGLang Library - Notes for Fuzzing

Mini-SGLang is a lightweight LLM inference framework. It provides tokenization,
detokenization, API serving, and message serialization.

Key functions to fuzz (functions that don't require GPU/model loading):

1. find_printable_text(text) - String extraction for detokenization
   Module: minisgl.tokenizer.detokenize
   Input: text strings, complex string slicing logic

2. _is_chinese_char(cp) - Unicode range checking
   Module: minisgl.tokenizer.detokenize
   Input: Unicode code points

3. _deserialize_any(cls_map, data) - Recursive deserialization
   Module: minisgl.message.utils
   Input: dictionaries/nested data structures
   Risk: type confusion, object injection

4. deserialize_type(cls_map, data) - Object reconstruction from dicts
   Module: minisgl.message.utils
   Input: dictionaries with type information

5. SamplingParams dataclass - Numeric parameter validation
   Module: minisgl.core
   Input: temperature, top_k, top_p, max_tokens values

6. parse_args() - Command-line argument parsing
   Module: minisgl.server.args
   Input: argument strings

Dependencies (from pyproject.toml):
- accelerate, msgpack, torch, transformers>=4.56.0
- pyzmq, uvicorn, fastapi, prompt_toolkit, openai
- sgl_kernel, flashinfer-python, apache-tvm-ffi
Note: Heavy GPU/ML dependencies - fuzzing should target non-GPU functions

Package structure: /app/minisgl/python/minisgl/ is the main package
