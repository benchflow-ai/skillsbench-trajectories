IPython Library - Notes for Fuzzing

IPython is an enhanced interactive Python shell with code transformation,
completion, and execution capabilities.

Key functions to fuzz:

1. split_user_input(line) - Parses user input into components using regex
   Module: IPython.core.splitinput
   Input: arbitrary user input strings
   Returns: tuple of (whitespace, escape_char, function, rest)

2. TransformerManager.transform_cell(cell) - Pre-processes code cells
   Module: IPython.core.inputtransformer2
   Input: code cell strings with potential magic commands, shell escapes

3. TransformerManager.check_complete(cell) - Validates code completeness
   Module: IPython.core.inputtransformer2
   Input: code cell strings

4. IPCompleter.completions(text, cursor_pos) - Code completion
   Module: IPython.core.completer
   Input: partial code strings with cursor position

5. guarded_eval(code, context) - Safe code evaluation
   Module: IPython.core.guarded_eval
   Input: Python expression strings

6. token_at_cursor(cell, cursor_pos) - Token extraction
   Module: IPython.utils.tokenutil
   Input: code string + cursor position

7. cell_magic(lines) - Cell magic command parsing
   Module: IPython.core.inputtransformer2
   Input: lines starting with %%magic
