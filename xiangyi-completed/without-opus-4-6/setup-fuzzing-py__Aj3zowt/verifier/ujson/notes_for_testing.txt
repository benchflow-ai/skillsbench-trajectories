UltraJSON (ujson) Library - Notes for Fuzzing

ujson is an ultra-fast JSON encoder/decoder written in C with Python bindings.
It's in maintenance-only mode due to architectural security concerns.

Key functions to fuzz:

1. ujson.loads(str) / ujson.decode(str) - JSON string to Python object
   Module: ujson (C extension)
   Input: arbitrary JSON strings
   C implementation: python/JSONtoObj.c -> lib/ultrajsondec.c
   This is the PRIMARY fuzzing target.

2. ujson.dumps(obj) / ujson.encode(obj) - Python object to JSON string
   Module: ujson (C extension)
   Input: Python objects (dicts, lists, strings, numbers)
   C implementation: python/objToJSON.c -> lib/ultrajsonenc.c
   Parameters: ensure_ascii, encode_html_chars, escape_forward_slashes,
              sort_keys, indent, allow_nan, reject_bytes, default, separators

3. ujson.load(file) - JSON from file object
   Module: ujson (C extension)
   Input: file-like objects with .read() method

4. ujson.dump(obj, file) - JSON to file object
   Module: ujson (C extension)

Critical fuzzing areas:
- String parsing with escape sequences (\uXXXX, \n, \r, \t)
- Unicode edge cases (surrogates, invalid UTF-8)
- Deeply nested arrays/objects (max depth 1024)
- Large numbers (integer overflow, float precision)
- Stack buffer (1024 bytes for escape sequences)
- Invalid/malformed JSON

Dependencies:
- Build: setuptools>=42, setuptools_scm>=3.4, C++ compiler
- Runtime: none (pure C extension)
- Needs to be compiled: python setup.py build_ext --inplace

Package structure: /app/ujson/src/ujson/ contains C source
The compiled module is ujson (importable after build)
