Arrow Library - Notes for Fuzzing

Library Purpose:
Arrow is a Python library for creating, manipulating, formatting, and converting dates, times, and timestamps. It provides a human-friendly, timezone-aware API as a drop-in replacement for Python's datetime module.

Key Functions for Fuzzing:

1. arrow.get(string_input) / arrow.factory.ArrowFactory.get()
   - Universal date/time parser accepting strings, timestamps, datetimes
   - File: /app/arrow/arrow/factory.py
   - Primary entry point for string parsing

2. arrow.parser.DateTimeParser.parse_iso(datetime_string)
   - Parses ISO 8601 datetime strings without explicit format
   - File: /app/arrow/arrow/parser.py
   - Complex regex-based parsing with auto-detection

3. arrow.parser.DateTimeParser.parse(datetime_string, fmt)
   - Parses datetime strings with format strings
   - File: /app/arrow/arrow/parser.py
   - Dynamically generates regex from format strings

4. arrow.parser.TzinfoParser.parse(tzinfo_string)
   - Parses timezone strings (ISO 8601 offsets, names, "utc", "local")
   - File: /app/arrow/arrow/parser.py

5. arrow.arrow.Arrow.dehumanize(input_string, locale)
   - Parses humanized time expressions ("in 3 days", "2 hours ago")
   - File: /app/arrow/arrow/arrow.py

6. arrow.arrow.Arrow.format(fmt)
   - Formats Arrow object to string using format specifier
   - File: /app/arrow/arrow/arrow.py

Dependencies (from pyproject.toml):
- python-dateutil>=2.7.0
- Build: flit_core >=3.2,<4

Fuzzing Strategy:
- Feed random/malformed strings to arrow.get() and parse_iso()
- Test ISO 8601 variants, malformed dates, invalid separators
- Test extreme timestamps, leap year edge cases
- Test Unicode and special characters
- Test deeply nested or extremely long format strings
