MiniSGL Library - Notes for Fuzzing

Library Purpose:
Mini-SGLang is a lightweight inference framework for Large Language Models (LLMs). It provides an OpenAI-compatible REST API server and interactive shell for LLM inference with ~5000 lines of Python.

Key Functions for Fuzzing:

1. minisgl.server.api_server.OpenAICompletionRequest (Pydantic model)
   - Parses complex OpenAI-compatible chat completion requests
   - File: /app/minisgl/python/minisgl/server/api_server.py
   - Fields: model, prompt, messages, max_tokens, temperature, top_k, top_p, stop, stream

2. minisgl.server.api_server.GenerateRequest (Pydantic model)
   - Parses generate API requests
   - File: /app/minisgl/python/minisgl/server/api_server.py
   - Fields: prompt, max_tokens, ignore_eos

3. minisgl.server.api_server.Message (Pydantic model)
   - Parses chat messages with role and content
   - File: /app/minisgl/python/minisgl/server/api_server.py

4. minisgl.message.utils.deserialize_type(cls_map, data)
   - Deserializes arbitrary Python objects from dictionaries
   - File: /app/minisgl/python/minisgl/message/utils.py
   - Handles __type__ field for dynamic class instantiation
   - Critical: potential type confusion with tensor data

5. minisgl.tokenizer.detokenize.find_printable_text(text)
   - String processing with Unicode/CJK character handling
   - File: /app/minisgl/python/minisgl/tokenizer/detokenize.py

6. minisgl.server.args.parse_args(args)
   - Parses command-line arguments
   - File: /app/minisgl/python/minisgl/server/args.py

Dependencies (from pyproject.toml):
- accelerate
- msgpack
- torch
- transformers>=4.56.0,<=4.57.3
- pyzmq
- uvicorn
- fastapi
- prompt_toolkit
- pydantic (via fastapi)

Note: This library has heavy GPU/CUDA dependencies that make direct function
fuzzing impractical without GPU hardware. Focus on the pure-Python parsing
functions that don't require GPU: Pydantic model validation, argument parsing,
message deserialization, and text processing utilities.

Fuzzing Strategy:
- Fuzz Pydantic model validation with malformed JSON/dict inputs
- Test deserialize_type with crafted type maps and data dicts
- Test find_printable_text with Unicode edge cases
- Test parse_args with edge-case command-line arguments
- Focus on input validation and parsing logic that doesn't require GPU
