UltraJSON (ujson) Library - Notes for Fuzzing

Library Purpose:
UltraJSON is an ultra-fast JSON encoder and decoder written in pure C with Python bindings. It's a drop-in replacement for Python's standard json library with significantly better performance.

Key Functions for Fuzzing:

1. ujson.loads(s) / ujson.decode(s)
   - Parses JSON string/bytes/bytearray into Python objects
   - C implementation: /app/ujson/src/ujson/python/JSONtoObj.c
   - Core parser: /app/ujson/src/ujson/lib/ultrajsondec.c
   - Primary fuzzing target - processes untrusted JSON input

2. ujson.dumps(obj, **kwargs) / ujson.encode(obj, **kwargs)
   - Encodes Python objects to JSON strings
   - C implementation: /app/ujson/src/ujson/python/objToJSON.c
   - Core encoder: /app/ujson/src/ujson/lib/ultrajsonenc.c
   - Options: ensure_ascii, encode_html_chars, escape_forward_slashes, sort_keys, indent, allow_nan, reject_bytes, default, separators

3. ujson.load(fp) - Reads JSON from file-like object
4. ujson.dump(obj, fp) - Writes JSON to file-like object

Critical Internal C Functions:
- decode_string() - Handles Unicode escapes, surrogate pairs, all standard escapes
- decode_numeric() / decodeDouble() - Integer overflow, scientific notation, special values
- decode_array() / decode_object() - Deep nesting (max 1024), memory allocation
- JSON_MAX_OBJECT_DEPTH = 1024 (recursion limit)

Dependencies:
- No runtime dependencies (pure C extension)
- Build: setuptools>=42, setuptools_scm[toml]>=3.4

Fuzzing Strategy:
- Feed random/malformed JSON strings to ujson.loads()
- Test Unicode escape sequences (\uXXXX), surrogate pairs
- Test extreme numeric values, integer overflow, NaN, Infinity
- Test deeply nested arrays/objects (near 1024 depth limit)
- Test malformed escape sequences
- Test extremely long strings
- Roundtrip: ujson.loads(ujson.dumps(obj)) with complex objects
- Test encoding options: ensure_ascii, encode_html_chars, indent
- Test bytes and bytearray inputs
