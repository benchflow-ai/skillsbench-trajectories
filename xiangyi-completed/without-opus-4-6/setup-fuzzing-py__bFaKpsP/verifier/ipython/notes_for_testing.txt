IPython Library - Notes for Fuzzing

Library Purpose:
IPython is a command shell for interactive computing. It processes a superset of Python including magic commands (%), shell escapes (!), help syntax (?), and other special syntax that must be transformed into valid Python before execution.

Key Functions for Fuzzing:

1. IPython.core.inputtransformer2.TransformerManager.transform_cell(cell)
   - Main entry point - transforms IPython syntax to Python
   - File: /app/ipython/IPython/core/inputtransformer2.py
   - Chains all input transformations

2. IPython.core.splitinput.split_user_input(line)
   - Splits input line into escape char, function name, and args
   - File: /app/ipython/IPython/core/splitinput.py
   - Regex-based parsing with multiple escape sequences

3. IPython.core.inputtransformer2.make_tokens_by_line(lines)
   - Tokenizes code and groups tokens by logical line
   - File: /app/ipython/IPython/core/inputtransformer2.py
   - Token-based transformation engine

4. IPython.core.inputtransformer2.EscapedCommand.find/transform
   - Finds and transforms escaped commands (%, !, ??, etc.)
   - File: /app/ipython/IPython/core/inputtransformer2.py

5. IPython.core.inputtransformer2.MagicAssign.find/transform
   - Identifies and transforms magic assignments (a = %foo)
   - File: /app/ipython/IPython/core/inputtransformer2.py

6. IPython.core.inputtransformer2.HelpEnd.find/transform
   - Finds and transforms help syntax (obj?, obj??)
   - File: /app/ipython/IPython/core/inputtransformer2.py

7. IPython.utils._process_common.arg_split(s)
   - Shell-like argument splitting using shlex
   - File: /app/ipython/IPython/utils/_process_common.py

Fuzzing Strategy:
- Feed random/malformed IPython syntax to transform_cell()
- Test magic commands: %magic, %%cellmagic
- Test shell escapes: !cmd, !!cmd, a = !cmd
- Test help syntax: obj?, obj??
- Test escape sequences: , ; / prefixes
- Test continued lines with backslashes
- Test mixed/nested special syntax
- Test Unicode and special characters
