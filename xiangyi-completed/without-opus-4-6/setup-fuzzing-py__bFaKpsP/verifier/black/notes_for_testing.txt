Black Library - Notes for Fuzzing

Library Purpose:
Black is an opinionated Python code formatter. It reformats Python source code by parsing it into an AST (using lib2to3), applying transformations, and producing consistently formatted output while ensuring semantic equivalence.

Key Functions for Fuzzing:

1. black.format_str(src_contents, mode)
   - Main formatting function - formats Python source code strings
   - File: /app/black/src/black/__init__.py
   - Primary entry point for code formatting

2. black.format_file_contents(src_contents, fast, mode)
   - Formats file contents with equivalence checking
   - File: /app/black/src/black/__init__.py

3. black.parsing.lib2to3_parse(src_txt, target_versions)
   - Parses Python source into lib2to3 AST nodes
   - File: /app/black/src/black/parsing.py
   - Core parsing engine with complex grammar

4. black.format_ipynb_string(src_contents, fast, mode)
   - Formats Jupyter Notebook JSON strings
   - File: /app/black/src/black/__init__.py

5. black.strings.normalize_string_quotes(leaf)
   - Normalizes string quote styles
   - File: /app/black/src/black/strings.py

6. black.handle_ipynb_magics.mask_cell(src)
   - Masks IPython magic commands for formatting
   - File: /app/black/src/black/handle_ipynb_magics.py

Fuzzing Strategy:
- Feed random/malformed Python source code to format_str()
- Test deeply nested structures
- Test edge-case Python syntax
- Test Unicode and encoding edge cases
- Test extremely long lines and strings
- Test invalid/partial Python code
