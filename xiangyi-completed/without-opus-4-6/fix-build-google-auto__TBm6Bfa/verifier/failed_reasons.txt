BUILD FAILURE ANALYSIS - google/auto
=====================================

Repository: /home/travis/build/failed/google/auto
Project: Google Auto (annotation processing code generators for Java)
Modules: common (auto-common), service (auto-service), factory (auto-factory), value (auto-value)
Build System: Maven 3.6.3

ENVIRONMENT:
- Maven runs with Java 11 JRE (openjdk 11.0.27)
- Project originally targets Java 1.6 source/target
- tools.jar does NOT exist on Java 11 (removed in Java 9+)

ROOT CAUSES:
============

ERROR 1: com.sun:tools:jar dependency resolution failure
---------------------------------------------------------
All four modules fail with:
  "Could not find artifact com.sun:tools:jar:11.0.27 at specified path
   /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar"

The com.sun:tools:jar dependency comes transitively from the compile-testing
library (versions 0.6, 0.7, 0.8) which declares it as a system-scoped dependency:

  <dependency>
    <groupId>com.sun</groupId>
    <artifactId>tools</artifactId>
    <version>${java.version}</version>
    <scope>system</scope>
    <systemPath>${toolsjar}</systemPath>
  </dependency>

On Java 9+, tools.jar was removed. The compiler API classes were moved into
the java.compiler and jdk.compiler modules built into the JDK.

ERROR 2: javax.annotation.Generated class not found (Java 9+ incompatibility)
------------------------------------------------------------------------------
In Java 9+, javax.annotation.Generated was removed from the JDK and moved to
javax.annotation.processing.Generated. Three source files reference the old class:

- factory/src/main/java/.../FactoryWriter.java (import + string literal)
- value/src/main/java/.../AutoAnnotationProcessor.java (import + usage)
- value/src/main/java/.../AutoValueProcessor.java (import + usage)

ERROR 3: auto-common:1.0-SNAPSHOT not available for auto-value
--------------------------------------------------------------
The value module depends on auto-common:1.0-SNAPSHOT which is not published
to any remote repository. It must be built and installed locally first.

AFFECTED FILES:
===============
1. common/pom.xml - compile-testing:0.7 pulls in com.sun:tools
2. service/pom.xml - compile-testing:0.6 pulls in com.sun:tools
3. factory/pom.xml - compile-testing:0.8 pulls in com.sun:tools
4. factory/.../FactoryWriter.java - uses javax.annotation.Generated
5. value/pom.xml - compile-testing:0.6 pulls in com.sun:tools
6. value/.../AutoAnnotationProcessor.java - uses javax.annotation.Generated
7. value/.../AutoValueProcessor.java - uses javax.annotation.Generated

FIXES APPLIED:
==============

patch_1.diff: Exclude com.sun:tools from compile-testing in common/pom.xml
patch_2.diff: Exclude com.sun:tools from compile-testing in service/pom.xml
patch_3.diff: Exclude com.sun:tools from compile-testing in factory/pom.xml
             + Change javax.annotation.Generated -> javax.annotation.processing.Generated
               in FactoryWriter.java (both import and emitted import string)
patch_4.diff: Exclude com.sun:tools from compile-testing in value/pom.xml
             + Change javax.annotation.Generated -> javax.annotation.processing.Generated
               in AutoAnnotationProcessor.java and AutoValueProcessor.java

BUILD ORDER: common must be built and installed first (mvn install -DskipTests)
before value module can resolve auto-common:1.0-SNAPSHOT.

VERIFICATION: All four modules compile successfully after applying patches.
