ROOT CAUSE
----------
All three failing modules depend on Google's `compile-testing` library (test scope),
which transitively depends on `com.sun:tools:jar` with system scope pointing to
`${java.home}/../lib/tools.jar`.

In Java 8 and earlier, `tools.jar` existed at `$JAVA_HOME/lib/tools.jar` and contained
the Java compiler API (javax.tools.*), annotation processing API, etc.

In Java 9+, `tools.jar` was removed. Its classes were absorbed into the JDK module system
(primarily `java.compiler` and `jdk.compiler` modules). The file simply does not exist.

ERROR MESSAGES:
  - auto-common: Could not find artifact com.sun:tools:jar:11.0.27 at specified path
    /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar
  - auto-factory: Same error
  - auto-service: Same error

DEPENDENCY CHAIN:
  compile-testing:0.6/0.7/0.8 -> com.sun:tools:jar:${java.version}:system
    (systemPath: ${toolsjar} -> ${java.home}/../lib/tools.jar)

Module-specific compile-testing versions:
  - common/pom.xml:  compile-testing 0.7
  - factory/pom.xml: compile-testing 0.8
  - service/pom.xml: compile-testing 0.6
  - value/pom.xml:   compile-testing 0.6

SECONDARY ISSUE
---------------
The parent POM (auto-parent:3, from Maven Central) sets java.version=1.6.
Java 11's javac does NOT support -source 1.6 / -target 1.6 (minimum is 1.7).
This will cause compilation errors once the dependency resolution issue is fixed.

FIX PLAN
--------
1. In each module POM (common, factory, service, value), add an exclusion for
   `com.sun:tools` from the `compile-testing` dependency. On Java 11+, the compiler
   APIs are available through the module system without needing tools.jar.

2. In the parent POM (pom.xml), change java.version from 1.6 to 1.7 so that the
   maven-compiler-plugin uses -source 1.7 -target 1.7, which Java 11 supports.

3. Add a JDK 9+ profile to the parent POM that activates when tools.jar doesn't exist,
   providing an empty/valid toolsjar property to prevent profile resolution issues.

FILES TO MODIFY:
  - pom.xml (parent) - java.version property + JDK 9+ profile
  - common/pom.xml   - exclude com.sun:tools from compile-testing
  - factory/pom.xml  - exclude com.sun:tools from compile-testing
  - service/pom.xml  - exclude com.sun:tools from compile-testing
  - value/pom.xml    - exclude com.sun:tools from compile-testing
