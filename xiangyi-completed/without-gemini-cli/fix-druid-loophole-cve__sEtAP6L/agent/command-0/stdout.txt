1. `JavaScriptParseSpec`
2. `JavaScriptWorkerSelectStrategy`
3. `JavaScriptAggregatorFactory`
4. `JavaScriptPostAggregator`
5. `JavaScriptExtractionFn`
6. `JavaScriptDimFilter`
7. `JavaScriptTieredBrokerSelectorStrategy`

This fix prevents Jackson from matching the empty string `""` or any other JSON property to the `config` parameter, thereby maintaining the security configuration set by the administrator.
