Important functions for testing ipython:
- IPython.core.inputtransformer2.TransformerManager.transform_cell(): This transforms IPython code (including magics) into pure Python. Fuzzing this is useful to find issues in the transformation logic.
- IPython.core.interactiveshell.InteractiveShell.run_cell(): Executes code in the shell. A bit more complex as it might have side effects, but very central.

Fuzzing the input transformer is a safe and effective way to find bugs in IPython's custom syntax handling.
