Important functions for testing ujson:
- ujson.loads(str): Decodes a JSON string into a Python object. This is the primary target for fuzzing as it parses external input.
- ujson.dumps(obj): Encodes a Python object into a JSON string. Fuzzing this with various Python objects (if possible) or checking for consistency with loads is useful.

ujson is written in C, so fuzzing loads() is critical for finding memory safety issues like buffer overflows or use-after-free in the parser.
