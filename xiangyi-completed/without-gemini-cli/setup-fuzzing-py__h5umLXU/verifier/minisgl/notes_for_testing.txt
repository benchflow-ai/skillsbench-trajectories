Important functions for testing minisgl:
- minisgl.message.utils.deserialize_type(cls_map, data): This function deserializes custom types from dictionaries, including Tensors. Fuzzing it with arbitrary dictionaries (potentially from fuzzed JSON) can find issues in type handling, buffer processing, and more.
- minisgl.message.utils.serialize_type(obj): Test the inverse process.

The deserialization logic is particularly interesting because it handles raw buffers for Tensors and dynamically looks up classes in a map.
