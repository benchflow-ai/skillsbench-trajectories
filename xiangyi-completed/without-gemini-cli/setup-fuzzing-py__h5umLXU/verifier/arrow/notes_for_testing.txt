Important functions for testing arrow:
- arrow.get(): This is the main entry point for creating Arrow objects. It accepts strings, integers, floats, and other date/time objects. Fuzzing it with various string formats and edge case timestamps is crucial.
- arrow.Arrow.format(): Test how Arrow objects are formatted back to strings.
- arrow.Arrow.replace(): Test modifying Arrow objects.
- arrow.Arrow.shift(): Test shifting dates/times.

The most interesting for fuzzing is arrow.get(str) because it involves parsing complex and potentially malicious date strings.
