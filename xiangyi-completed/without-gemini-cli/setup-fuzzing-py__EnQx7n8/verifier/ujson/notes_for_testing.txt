UJSON library testing notes:
Important functions:
- ujson.loads(str): Decodes a JSON string.
- ujson.dumps(obj): Encodes a Python object to a JSON string.
- ujson.load(fp): Decodes a JSON file-like object.
- ujson.dump(obj, fp): Encodes a Python object to a JSON file-like object.

Fuzzing strategy:
- Fuzz `ujson.loads()` with various malformed and valid JSON strings.
- Fuzz `ujson.dumps()` with various Python objects (if possible).
