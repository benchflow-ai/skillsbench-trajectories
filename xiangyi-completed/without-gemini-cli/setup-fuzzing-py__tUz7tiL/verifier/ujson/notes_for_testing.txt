Important functions for testing ujson:
1. ujson.loads(string): Parses JSON strings. This is a critical entry point for fuzzing.
2. ujson.dumps(obj): Serializes Python objects to JSON.
3. ujson.load(fp), ujson.dump(obj, fp): File-based variants.

Fuzzing strategy:
- Fuzz ujson.loads with random byte strings.
- Fuzz ujson.dumps with various Python objects (if we can generate them).
- Check for crashes and consistency with the standard json library.
