Library: ipython
Important functions for testing:
- IPython.core.interactiveshell.InteractiveShell.run_cell(raw_cell): This function takes a string of code and executes it in the IPython environment. It involves input transformation, parsing, and execution. Fuzzing this can reveal issues in how IPython handles complex or malformed input.
- IPython.core.inputtransformer2.InputTransformerManager: Handles transformations of IPython-specific syntax (magics, etc.) to standard Python.
