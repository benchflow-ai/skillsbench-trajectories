Library: black
Important functions for testing:
- black.format_str(src_contents, mode): The main function for formatting Python code. It takes source code as a string and a Mode object. Fuzzing this with various (potentially invalid) Python code strings is essential to ensure it doesn't crash and handles errors gracefully.
- black.parsing.lib2to3_parse(): The underlying parser.
- black.parsing.parse_ast(): AST parsing and safety checks.
