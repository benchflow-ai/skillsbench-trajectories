Library: arrow
Important functions for testing:
- arrow.get(): This is the primary entry point for creating Arrow objects. It handles various input types: strings, integers, floats, datetimes, and tuples. It also supports different locales and timezones. Fuzzing this with random strings and different combinations of arguments is highly valuable.
- arrow.parser.DateTimeParser.parse(): Internal parser used by arrow.get().
- Arrow.format(): Formatting Arrow objects back to strings.
