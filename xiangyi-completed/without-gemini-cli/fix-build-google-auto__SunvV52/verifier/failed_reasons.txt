The build fails because the project depends on `tools.jar`, which is not available in JDK 11.
The error message `Could not find artifact com.sun:tools:jar:11.0.27` confirms this.
This dependency is inherited from the parent POM `com.google.auto:auto-parent:3`.
The local `auto-parent` version `4-SNAPSHOT` does not include this dependency.
The fix is to update the parent version in the submodules (`common`, `factory`, `service`, `value`) from `3` to `4-SNAPSHOT` to use the local parent POM which is compatible with the current environment.
