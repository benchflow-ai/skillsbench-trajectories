Important functions for testing arrow:
- arrow.get(*args, **kwargs): The main entry point for creating Arrow objects from various inputs (strings, timestamps, etc.).
- arrow.parser.DateTimeParser.parse(datetime_string, fmt): Parses a datetime string with a specific format.
- arrow.parser.DateTimeParser.parse_iso(datetime_string): Parses ISO 8601 strings.
- arrow.Arrow.format(fmt): Formats an Arrow object into a string.
- arrow.Arrow.shift(**kwargs): Shifts the Arrow object by various time units.
