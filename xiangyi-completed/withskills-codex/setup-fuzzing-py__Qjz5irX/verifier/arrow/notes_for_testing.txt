Targets for fuzzing (arrow):
- arrow.get(): accepts many input types (strings, timestamps, datetime); stresses parser & tz handling.
- arrow.parser.parse()/parse_iso(): date-time parsing with formats & ISO edge cases.
- Arrow.shift()/span()/span_range(): date arithmetic with frames and boundaries.
- Arrow.floor()/ceil(): rounding to frames (day/month/etc.), timezone edge cases.
- Arrow.format(): format tokens and locale/timezone formatting.

Notes:
- Focus on string parsing + formatting cycles; combine get -> shift -> format.
- Expect ValueError/ParserError on invalid inputs; ignore common parse failures.
