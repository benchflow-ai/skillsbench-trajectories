Key functions & inputs to fuzz:
- arrow.get(value, *args, **kwargs): accepts strings, timestamps, datetime/date/time objects, and format strings.
- arrow.parse(date_str, fmt or list of fmts): parses diverse date/time formats.
- arrow.Arrow.fromdatetime / fromtimestamp: conversion paths from numeric + tz info.
- Arrow.format / Arrow.humanize / Arrow.shift / Arrow.floor / Arrow.ceil: string formatting + arithmetic with potentially odd units.
- arrow.now/utcnow with tz strings and tzinfo objects.
Focus on invalid/edge-case date strings, timezone names, offsets, and mixed numeric/str inputs.
