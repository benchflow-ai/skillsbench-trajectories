Key targets for fuzzing (Arrow):
- arrow.get() overloads: parse strings, timestamps (int/float), datetime/date/struct_time inputs.
- Arrow.shift()/replace()/floor()/ceil()/span_range(): exercise date arithmetic and edge cases.
- Arrow.format()/strftime(): format tokens, locale handling.
- arrow.parser.Parser.parse() / parse_iso(): string parsing with timezone offsets.
- Arrow.to() / Arrow.timestamp(): timezone conversions and epoch handling.
- locales.get_locale(): locale name handling (invalid/partial names).
