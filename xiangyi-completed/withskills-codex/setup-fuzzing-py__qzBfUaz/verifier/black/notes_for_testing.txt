Key functions / surfaces to fuzz:
- black.format_str(): formatting arbitrary Python source under FileMode options.
- black.format_file_contents(): source formatting with fast/unsafe guards.
- black.parse_ast(): AST parsing for tricky syntax and error cases.
- black.format_file_in_place(): file I/O + formatting path handling (can be mocked in fuzz).
- FileMode options (line_length, string_normalization, is_pyi, target_version, preview): config-sensitive formatting.
