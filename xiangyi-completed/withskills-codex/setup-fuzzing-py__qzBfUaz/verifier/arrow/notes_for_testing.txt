Key functions / surfaces to fuzz:
- arrow.get() / arrow.api.get(): accepts strings, timestamps, datetime/date objects, and format hints.
- arrow.parser.Parser.parse() / parse_iso(): date/time parsing with format tokens and timezone info.
- Arrow.format(): formatting tokens and locale handling.
- Arrow.shift() / Arrow.replace(): arithmetic and field replacement across DST/timezone boundaries.
- Arrow.humanize() / Arrow.dehumanize(): relative time strings.
- Arrow.range() / Arrow.span()/span_range(): interval generation.
