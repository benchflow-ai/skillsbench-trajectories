- Target: ArrowFactory.get
- File / location: arrow/arrow/factory.py

    - Complexity or path depth: Deep logic for parsing ISO 8601 and custom formats.
    - Current test gaps: Corner cases in complex format strings or invalid ISO strings.
- Callable contract:
    - Required imports: from arrow import ArrowFactory; factory = ArrowFactory()
    - Preconditions: None.
    - Determinism concerns: datetime.now() used if no args, but we can fuzz with fixed args.
    - External dependencies: zoneinfo/backports.zoneinfo.
- Input model:
    - Primary payload type: string (for parsing) or other types.
    - Decoding or parsing steps: DateTimeParser handles string parsing.
    - Constraints to respect: None.
    - Edge classes to emphasize: Malformed ISO 8601, invalid formats, leap years, timezone offsets.
- Oracles:
    - Must-hold properties: Should not crash with ParserError or ParserMatchError (these are expected, but not unhandled exceptions).
    - Acceptable exceptions: ParserError, ParserMatchError, TypeError, ValueError.
    - Suspicious exceptions: RecursionError, MemoryError, or any other unhandled exception.
- Harness plan:
    - Recommended approach: Use atheris to provide random strings to factory.get().
    - Minimal harness signature:
      def TestOneInput(data):
