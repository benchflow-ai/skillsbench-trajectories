# UltraJSON Fuzzing Targets

- Target: `ujson.loads`
- Rationale: High-performance JSON decoder written in C. Prime candidate for memory safety bugs.
- Input model: `str` or `bytes`
- Oracles: No crash.

- Target: `ujson.dumps`
- Rationale: JSON encoder.
- Input model: Arbitrary Python objects.
- Oracles: No crash.
