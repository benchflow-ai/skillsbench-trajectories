**Summary of Changes:**

1.  **Image Layout Shifts (`src/components/ProductCard.tsx`)**:

2.  **Grid Layout Shifts (`src/components/ProductList.tsx`)**:
    *   Replaced the simple "Loading products..." text with a list of `ProductSkeleton` components. This ensures the grid structure is preserved during the loading phase, providing a smooth transition when the content arrives.

3.  **Banner Layout Shifts (`src/components/Banner.tsx`, `src/components/LateBanner.tsx`)**:
    *   Modified both banners to always render their container divs with the designated height (padding), even when data is loading.
    *   Added an invisible placeholder to maintain vertical stability, preventing the page content from jumping down when the banner text loads.

4.  **Font Loading (`src/app/globals.css`)**:
    *   Updated the `@font-face` declaration for 'CustomFont' to include `font-display: swap;`. This prevents the "Flash of Invisible Text" (FOIT) by allowing the browser to show a fallback font immediately if the custom font takes time to load (or fails).
