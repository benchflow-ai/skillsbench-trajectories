Analysis:
The build failure is caused by a compilation error in the `functional` integration test of `auto-value`.
The test class `com.google.auto.value.AutoValueTest` uses `com.google.common.base.MoreObjects`, which was introduced in Guava 18.0.
However, the `functional` integration test's `pom.xml` does not explicitly depend on Guava 18.0. It pulls in Guava 17.0 transitively via `truth:0.25`, because `truth` is declared before `guava-testlib:18.0` in the dependencies list.

Plan:
Update `value/src/it/functional/pom.xml` to include an explicit dependency on `com.google.guava:guava:18.0` in the `test` scope. This will ensure that Guava 18.0 is used during compilation and execution of the integration tests.
