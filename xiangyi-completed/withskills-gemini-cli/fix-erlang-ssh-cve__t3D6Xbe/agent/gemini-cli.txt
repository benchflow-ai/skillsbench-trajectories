If a connection message is received before authentication, the server now disconnects with a protocol error.

The fix is located in the `handle_event/4` function clause that handles `{conn_msg, Msg}`.

```erlang
handle_event(internal, {conn_msg,Msg}, StateName, #data{connection_state = Connection0,
                                                        event_queue = Qev0} = D0) ->
    Role = ?role(StateName),
    Rengotation = renegotiation(StateName),

    case ?CONNECTED(StateName) orelse Rengotation of
        true ->
            %% Process message as before ...
        false ->
            {Shutdown, D} = ?send_disconnect(?SSH_DISCONNECT_PROTOCOL_ERROR,
                                             "Connection message received before authentication",
                                             StateName, D0),
            {stop, Shutdown, D}
    end;
```

This prevents the unauthorized execution of commands via `SSH_MSG_CHANNEL_REQUEST` (exec) and other channel-related operations.
