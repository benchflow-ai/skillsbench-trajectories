### Vulnerability Summary
The vulnerability (CVE-2021-25646) allowed authenticated attackers to execute arbitrary code on the Druid server by bypassing JavaScript security settings. Attackers could provide an empty key `""` in a JSON payload which Jackson would incorrectly match to a parameter annotated with `@JacksonInject`. This allowed attackers to override the `JavaScriptConfig` object, setting its `enabled` property to `true` even if it was globally disabled.

### Fix Details
The fix involves securing all locations where `JavaScriptConfig` is injected using Jackson. In all 7 identified classes, the following changes were applied:
1.  Set `useInput = OptBoolean.FALSE` in the `@JacksonInject` annotation to prevent Jackson from using any JSON input for that parameter.
2.  Added an explicit `@JsonProperty("config")` to ensure the parameter has a name, preventing it from matching the empty key `""` during Jackson's parameter matching process.
