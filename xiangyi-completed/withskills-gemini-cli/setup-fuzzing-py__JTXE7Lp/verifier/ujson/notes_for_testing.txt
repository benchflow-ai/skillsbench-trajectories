    - Constraints to respect: None.

- Oracles:
    - Must-hold properties: Should not crash.
    - Acceptable exceptions: ValueError, TypeError (Python level).
    - Suspicious exceptions: Segfaults (not catchable by Python try/except but atheris/libfuzzer detects them).
    - Crash-only vs correctness-checking: Crash-only.
- Harness plan:
    - Recommended approach: Fuzz ujson.loads(s)
    - Minimal harness signature:
      ```python
      import atheris
      import sys
      
      with atheris.instrument_imports():
          import ujson

      def TestOneInput(data):
          fdp = atheris.FuzzedDataProvider(data)
          s = fdp.ConsumeUnicode(sys.maxsize)
          try:
              ujson.loads(s)
          except (ValueError, TypeError):
              pass

      atheris.Setup(sys.argv, TestOneInput)
      atheris.Fuzz()
      ```

    - Timeouts and resource limits: Standard.
- Risk flags:
    - C extension might crash the process. Atheris handles this well.
