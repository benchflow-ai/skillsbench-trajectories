Focus areas for fuzzing (parsing + formatting Python code):
- black.format_str and black.format_file_contents: arbitrary source text, invalid syntax, encoding edge cases, very long lines, and mixed indentation.
- black.parsing.parse_ast: malformed code, huge expressions, nested parentheses, and unicode escapes.
- black.Mode options: line_length boundaries, string normalization toggles, magic trailing commas.
- Output stability: ensure formatting is deterministic and does not crash on bad input (should raise InvalidInput).
