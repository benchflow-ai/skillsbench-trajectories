Library: UltraJSON - Ultra fast JSON encoder and decoder
Location: /app/ujson

Primary Fuzz Target #1: JSON Deserialization - ujson.loads() / ujson.decode()
- File: /app/ujson/src/ujson/python/JSONtoObj.c (JSONToObj function)
- Python Function Signatures:
  - ujson.loads(s: str | bytes, *, precise_float: bool = False) -> Any
  - ujson.decode(s: str | bytes) -> Any
- C Function: JSOBJ JSON_DecodeObject(JSONObjectDecoder *dec, const char *buffer, size_t cbBuffer)
- Why: Core JSON parsing function using C implementation with complex state machine
- Input Surface: JSON strings/bytes with arbitrary structure
- Boundary Considerations:
  - Buffer overflows in unicode escape handling
  - Recursion depth limits (JSON_MAX_OBJECT_DEPTH = 1024)
  - Numeric parsing edge cases (integer overflow, NaN/Infinity)
  - Unicode escape sequences (\uXXXX, surrogate pairs)
- Current Test Gaps: Malformed unicode escapes, numeric edge cases, deeply nested structures
- Callable Contract:
  - Required imports: import ujson
  - Preconditions: s must be string or bytes
  - Determinism: Fully deterministic
  - External dependencies: C extension module
- Input Model: JSON-formatted strings with variations (valid and invalid)
- Oracles:
  - Must parse valid JSON and return Python object
  - Should raise JSONDecodeError on invalid JSON
  - Should handle numeric boundaries correctly
  - No crashes on malformed unicode escapes
  - Recursion limit should prevent stack overflow
- Harness Plan: Fuzz with random JSON structures, numeric boundaries, deep nesting, bad escapes
- Risk Flags: C extension, buffer handling, recursion depth, numeric parsing complexity
- Next Actions:
  1. Create Python wrapper fuzz harness calling ujson.loads()
  2. Extract seeds from test JSON files
  3. Test numeric boundaries: INT_MAX, INT_MIN, FLOAT_MAX, etc.
  4. Timeout: 5 seconds per input

Setup Notes:
- UltraJSON requires: python3, build tools (gcc, python-dev)
- Installation: pip install ujson (or build from source: cd /app/ujson && pip install -e .)
- C sources: /app/ujson/src/ujson/
- Python wrapper: /app/ujson/src/ujson/python/
- Tests located in: /app/ujson/tests/
- Existing fuzzing: /app/ujson/tests/fuzz.py (already has fuzzing setup)
- Build requirements: setuptools, wheel (for building C extension)

Key Implementation Details:
- JSON_MAX_OBJECT_DEPTH = 1024 (recursion limit for deserialization)
- JSON_MAX_RECURSION_DEPTH = 1024 (recursion limit for serialization)
- C extension requires compilation: python setup.py build_ext --inplace
- Supports Decimal type conversion
- Handles NaN and Infinity (decode) with proper parsing
- Unicode escape handling in decode_unicode_escape() function
