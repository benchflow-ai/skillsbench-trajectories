Black Library - Fuzzing Analysis Notes
=======================================

Library: Black - The uncompromising Python code formatter
Purpose: Python code formatting

Important Functions for Fuzzing:
---------------------------------

1. black.format_str()
   - Main formatting function
   - Accepts Python source code as string
   - High value target (parsing + transformation)

2. black.format_file_contents()
   - File content formatting
   - Handles encoding detection

3. black.parsing.lib2to3_parse()
   - Python AST parsing
   - Core parsing logic
   - Many edge cases in Python syntax

4. black.decode_bytes()
   - Encoding detection and decoding
   - Handles various encodings and newline styles

Testing Strategy:
-----------------
- Fuzz format_str() with random Python code
- Test malformed Python syntax
- Edge cases: empty files, huge files, deeply nested code
- Unicode in strings and comments
- Various Python version syntax
- Invalid encodings
