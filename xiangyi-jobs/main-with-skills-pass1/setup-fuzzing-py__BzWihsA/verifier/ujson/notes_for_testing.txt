UltraJSON (ujson) Library - Fuzzing Analysis Notes
===================================================

Library: UltraJSON - Ultra fast JSON encoder and decoder
Purpose: High-performance JSON parsing

Important Functions for Fuzzing:
---------------------------------

1. ujson.loads()
   - JSON string decoding
   - High value target (parsing untrusted input)
   - Handles various JSON data types

2. ujson.dumps()
   - JSON encoding
   - Object serialization

3. ujson.decode()
   - Alternative decode interface
   - Binary data handling

Testing Strategy:
-----------------
- Fuzz ujson.loads() with random JSON strings
- Test deeply nested structures
- Edge cases: huge numbers, long strings, escaped characters
- Invalid UTF-8 sequences
- Malformed JSON (missing braces, invalid syntax)
- Stack overflow with deep nesting
- Integer overflow with large numbers
