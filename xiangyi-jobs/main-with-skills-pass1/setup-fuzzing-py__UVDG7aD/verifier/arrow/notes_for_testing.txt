# Arrow Library - Fuzz Testing Notes

## Library Overview
Arrow is a Python library for better dates and times. It provides parsing, formatting,
and manipulation of datetime objects with timezone support.

## Important Files for Fuzzing
1. arrow/parser.py - Primary parsing logic (HIGH PRIORITY)
2. arrow/factory.py - Factory methods that call parsers
3. arrow/formatter.py - Datetime formatting
4. arrow/util.py - Utility functions including timestamp normalization

## Key Functions Under Test (FUTs)

### 1. DateTimeParser.parse_iso() [HIGH PRIORITY]
- File: arrow/parser.py:252
- Signature: parse_iso(self, datetime_string: str, normalize_whitespace: bool = False) -> datetime
- Input: ISO 8601-like datetime strings
- Reason: Primary parsing entry point, handles complex format detection, regex-heavy
- Edge cases: malformed dates, invalid separators, timezone edge cases, whitespace handling

### 2. DateTimeParser.parse() [HIGH PRIORITY]
- File: arrow/parser.py:373
- Signature: parse(self, datetime_string: str, fmt: Union[List[str], str], normalize_whitespace: bool = False) -> datetime
- Input: datetime string with format specification
- Reason: Format-based parsing with regex generation, multiple format fallback
- Edge cases: invalid format tokens, mismatched formats, locale-specific parsing

### 3. TzinfoParser.parse() [MEDIUM PRIORITY]
- File: arrow/parser.py:894
- Signature: parse(cls, tzinfo_string: str) -> dt_tzinfo
- Input: Timezone strings (e.g., "UTC", "+05:00", "America/New_York")
- Reason: Timezone parsing with multiple formats supported
- Edge cases: invalid timezone names, malformed offsets

### 4. ArrowFactory.get() [MEDIUM PRIORITY]
- File: arrow/factory.py:85
- Signature: get(self, *args: Any, **kwargs: Any) -> Arrow
- Input: Various inputs (str, int, float, datetime, tuples)
- Reason: Main entry point dispatching to various parsing paths
- Edge cases: Type confusion, timestamp boundaries

### 5. DateTimeFormatter.format() [LOWER PRIORITY]
- File: arrow/formatter.py:37
- Signature: format(cls, dt: datetime, fmt: str) -> str
- Input: Format string
- Reason: Format string parsing with regex
- Edge cases: Malformed format tokens, locale-specific formatting

### 6. normalize_timestamp() [MEDIUM PRIORITY]
- File: arrow/util.py:73
- Signature: normalize_timestamp(timestamp: float) -> float
- Input: Numeric timestamp (seconds, milliseconds, or microseconds)
- Reason: Boundary detection between timestamp formats
- Edge cases: Extreme values, boundary conditions

### 7. iso_to_gregorian() [LOWER PRIORITY]
- File: arrow/util.py:86
- Signature: iso_to_gregorian(iso_year: int, iso_week: int, iso_day: int) -> datetime.date
- Input: ISO calendar components
- Reason: Week-to-date conversion
- Edge cases: Invalid week/day values, year boundaries

## Recommended Fuzzing Targets

### Primary Target: DateTimeParser.parse_iso()
- Accepts arbitrary string input
- Complex parsing logic with multiple regex patterns
- Good for finding edge cases in date/time parsing
- Oracles: No crash, valid datetime or ParserError

### Secondary Target: DateTimeParser.parse()
- Accepts string with format specifier
- Tests format pattern generation and matching
- Oracles: No crash, valid datetime or ParserError

## Harness Strategy
1. Create fuzzer that generates random datetime-like strings
2. Call parse_iso() with fuzzed input
3. Catch expected ParserError exceptions
4. Report crashes or unexpected exceptions
