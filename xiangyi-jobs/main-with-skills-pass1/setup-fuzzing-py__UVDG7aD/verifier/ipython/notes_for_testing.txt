# IPython Library - Fuzz Testing Notes

## Library Overview
IPython is an enhanced interactive Python shell. It provides input transformation,
magic commands, code completion, and guarded evaluation features. The library
processes user input through various transformers before execution.

## Important Files for Fuzzing
1. IPython/core/inputtransformer2.py - Input transformation and parsing
2. IPython/core/guarded_eval.py - Safe evaluation of expressions
3. IPython/core/completer.py - Tab completion logic
4. IPython/core/prefilter.py - Input preprocessing
5. IPython/core/splitinput.py - Input line splitting

## Key Functions Under Test (FUTs)

### 1. guarded_eval() [HIGH PRIORITY]
- File: IPython/core/guarded_eval.py:433
- Signature: guarded_eval(code: str, context: EvaluationContext)
- Input: Code string to evaluate
- Reason: Security-critical function that evaluates code with guards
- Edge cases: Malicious code, nested expressions, edge unicode, injections
- Oracle: Should not allow forbidden operations, no crashes

### 2. TransformerManager.transform_cell() [HIGH PRIORITY]
- File: IPython/core/inputtransformer2.py (search for class)
- Input: Cell content as lines
- Reason: Transforms IPython syntax to valid Python, handles magic commands
- Edge cases: Malformed magic commands, mixed Python/IPython syntax
- Oracle: No crashes, valid transformation

### 3. cell_magic() [MEDIUM PRIORITY]
- File: IPython/core/inputtransformer2.py:115
- Signature: cell_magic(lines)
- Input: Lines starting with %%
- Reason: Parses cell magic syntax
- Edge cases: Malformed cell magics, special characters

### 4. PromptStripper [MEDIUM PRIORITY]
- File: IPython/core/inputtransformer2.py:48
- Input: Lines with prompts (>>> or In [N]:)
- Reason: Strips prompts from input blocks
- Edge cases: Mixed prompts, partial prompts, unicode

### 5. eval_node() [HIGH PRIORITY]
- File: IPython/core/guarded_eval.py
- Input: AST node
- Reason: Evaluates AST nodes with policy enforcement
- Edge cases: Deep AST nesting, complex expressions

### 6. _find_assign_op() [LOWER PRIORITY]
- File: IPython/core/inputtransformer2.py:127
- Signature: _find_assign_op(token_line) -> Optional[int]
- Input: Token line
- Reason: Finds assignment operators for magic command parsing
- Edge cases: Nested brackets, edge tokenization

## Recommended Fuzzing Targets

### Primary Target: guarded_eval()
- Accepts arbitrary code strings
- Security-critical evaluation with policy guards
- Good for testing guard bypass attempts
- Oracles:
  - GuardRejection on forbidden operations
  - No crashes on malformed input
  - No bypass of evaluation policy

### Secondary Target: Input transformers
- Transform IPython-specific syntax to Python
- Handle magic commands, system commands, help queries
- Oracle: No crashes, syntactically valid output when valid input

## Harness Strategy
1. Create fuzzer generating Python/IPython-like code strings
2. Set up EvaluationContext with "limited" or "minimal" policy
3. Call guarded_eval() with fuzzed input
4. Catch expected GuardRejection exceptions
5. Report crashes or security policy bypasses
