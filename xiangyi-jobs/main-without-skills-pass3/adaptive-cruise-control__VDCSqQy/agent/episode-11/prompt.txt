# Adaptive Cruise Control System Report

## System Design

The ACC system is implemented in Python using a modular architecture:
- **pid_controller.py**: Implements a standard PID controller with anti-windup (implicit in implementation via reset) and derivative filtering.
- **acc_system.py**: Contains the  class which manages the control logic. It switches between three modes:
  - **Cruise**: Maintains set speed when no lead vehicle is detected.
  - **Follow**: Maintains a safe following distance based on time headway when a lead vehicle is present.
  - **Emergency**: Applies maximum deceleration if the Time-To-Collision (TTC) falls below a safety threshold.
- **simulation.py**: Runs the closed-loop simulation using real-world sensor data for the lead vehicle's behavior.

The system uses two PID controllers: one for speed control (used in Cruise and as a limit in Follow mode) and one for distance control (used in Follow mode). The final acceleration command is the minimum of the speed and distance controllers, clamped by vehicle physical limits.

## PID Tuning Methodology

Tuning was performed using an automated grid search script () that evaluated different combinations of Kp, Ki, and Kd against performance metrics:
- **Speed Control**: Evaluated on a step response from 0 to 30 m/s. Metrics: Rise time (<10s), Overshoot (<5%), Steady-state error (<0.5 m/s).
- **Distance Control**: Evaluated on a following scenario where the lead vehicle decelerates. Metrics: Distance steady-state error (<2m), Minimum distance (>5m).

### Final Gains
Based on the tuning results saved in :
- **Speed PID**: Kp=1.5, Ki=0.0, Kd=0.0
- **Distance PID**: Kp=0.8, Ki=0.0, Kd=0.0

The tuning process favored Proportional-only control, likely to maximize responsiveness and stability within the allowed error margins without introducing oscillation or overshoot often associated with aggressive integral or derivative terms in this specific discrete-time simulation.
