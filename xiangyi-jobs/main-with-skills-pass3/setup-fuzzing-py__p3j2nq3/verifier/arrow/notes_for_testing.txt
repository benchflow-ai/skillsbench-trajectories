Key functions & surfaces to fuzz:
- arrow.api.get / arrow.factory.ArrowFactory.get: accepts many input types (strings, timestamps, tzinfo); exercise parsing and timezone handling.
- arrow.parser.Parser.parse / parse_iso: ISO-8601 & custom format parsing with edge cases (offsets, fractional seconds, week dates).
- arrow.arrow.Arrow.format / formatter: formatting tokens and locale handling.
- arrow.arrow.Arrow.shift / replace / floor / ceil / span / range: date arithmetic, boundary conditions, DST transitions.
- arrow.arrow.Arrow.humanize / dehumanize: locale-aware human-friendly strings.
Fuzz strategy: generate random strings as candidate datetimes/formats/locales, mix with integers for timestamps/offsets; avoid heavy I/O.
