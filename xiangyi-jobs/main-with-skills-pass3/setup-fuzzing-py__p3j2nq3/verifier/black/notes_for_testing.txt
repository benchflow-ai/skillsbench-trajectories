Key functions & surfaces to fuzz:
- black.format_str / black.format_file_contents: parsing and formatting of Python source; sensitive to edge-case syntax.
- black.parsing.lib2to3_parse / parse_ast: parsing layer over lib2to3/ast.
- black.assert_equivalent / assert_stable: sanity checks on reformatted output.
Fuzz strategy: feed random text as Python source; vary FileMode (line length, string normalization, preview flags). Keep input sizes bounded.
