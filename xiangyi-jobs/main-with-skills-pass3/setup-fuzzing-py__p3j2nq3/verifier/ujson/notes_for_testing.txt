Key functions & surfaces to fuzz:
- ujson.loads: parsing of JSON strings/bytes with edge cases (numbers, escapes, deep nesting).
- ujson.dumps: serialization of Python objects with options (ensure_ascii, escape_forward_slashes, sort_keys).
Fuzz strategy: feed random bytes/strings to loads; construct small random Python objects (dict/list/str/int/float/bool/None) for dumps.
