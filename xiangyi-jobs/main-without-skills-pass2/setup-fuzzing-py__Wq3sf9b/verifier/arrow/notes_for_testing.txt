Key targets for fuzzing (Arrow):
- arrow.get() / arrow.api.get(): accepts many input shapes (strings, timestamps, datetime, date, tuple); exercise parsing and timezone handling.
- arrow.parser.Parser.parse(): ISO-8601-like parsing and custom format tokens; expects exceptions on invalid input.
- arrow.formatter.format(): formats datetime with tokenized format strings.
- Arrow.shift()/replace()/floor()/ceil(): date arithmetic over bounds.
Notes:
- Expect ValueError/TypeError/arrow.parser.ParserError on invalid inputs.
- Use random strings for datetime inputs and format strings; use bounded ints for timestamps.
