Key targets for fuzzing (Black):
- black.format_str(): parse/format arbitrary Python source; sensitive to invalid syntax and edge cases.
- black.format_file_contents(): handles file-level formatting, newline normalization, and pragmas.
- black.parsing.parse_ast(): parses AST with different feature versions.
Notes:
- Expect black.InvalidInput, SyntaxError, or ValueError for invalid source.
- Use FileMode() with default settings; vary target_version flags if possible.
