# Black Library Analysis for Fuzzing

## Library Purpose
Black is the uncompromising Python code formatter that formats Python code to a consistent style.

## Key Functions to Test

### 1. black.format_str() - Main formatting function
- Formats Python source code strings
- Input: Python code string, mode options
- Edge cases: Invalid Python syntax, very long lines, complex expressions

### 2. black.format_file() - File formatting
- Formats Python files in place or returns diff
- Input: file path, mode options

### 3. black.read_pyproject_toml() - Config parsing
- Parses pyproject.toml for Black configuration
- Input: file path
- Edge cases: Malformed TOML, missing sections

### 4. black.get_gitignore() - Gitignore handling
- Parses .gitignore files
- Input: paths
- Edge cases: Malformed patterns, circular references

### 5. black.lib2to3_parse() - AST parsing
- Parses Python code to AST
- Input: Python source code
- Edge cases: Invalid Python syntax, encoding issues

### 6. Mode class - Formatting mode options
- Target Python version
- Line length
- Various formatting flags

## Fuzzing Strategy
- Generate random Python code (valid and invalid syntax)
- Generate edge case inputs: empty strings, very long lines, special characters
- Test with various Mode configurations
- Focus on parser crashes and infinite loops
