# ujson Library Analysis for Fuzzing

## Library Purpose
UltraJSON (ujson) is an ultra-fast JSON encoder/decoder written in C with Python bindings.

## Key Functions to Test

### 1. ujson.dumps() - JSON encoding
- Converts Python objects to JSON strings
- Input: Python objects (dict, list, str, int, float, bool, None)
- Edge cases: Nested structures, unicode, special floats (inf, nan)

### 2. ujson.loads() - JSON decoding
- Parses JSON strings to Python objects
- Input: JSON strings
- Edge cases: Malformed JSON, unicode escape sequences, deep nesting

### 3. ujson.decode() - Alias for loads
- Same as loads

### 4. ujson.encode() - Alias for dumps
- Same as dumps

### 5. ujson.load() - File-based JSON reading
- Reads JSON from file objects
- Edge cases: File encoding, streaming

## Fuzzing Strategy
- Generate random JSON strings (valid and malformed)
- Generate random Python objects for encoding
- Test edge cases: NaN, Infinity, deep nesting, long strings
- Focus on parser buffer overflows and type confusion
