# Notes for Black Library Fuzzing

## Library Description
Black is an opinionated Python code formatter. It formats Python code to follow a consistent style.

## Key Functions for Fuzzing

### 1. black.format_file()
- Location: src/black/__init__.py
- Function: format_file()
- Purpose: Format a single Python file
- Input: Source code string, file path, mode options
- Fuzzing strategy: Various Python code snippets, edge cases

### 2. black.format_str()
- Location: src/black/__init__.py
- Function: format_str()
- Purpose: Format a string of Python code
- Input: Source code string, mode options
- Fuzzing strategy: Various Python code snippets

### 3. black.main() / patched_main()
- Location: src/black/__init__.py
- Function: Entry point for command-line usage
- Fuzzing strategy: File paths, stdin input

### 4. src/black/parsing.py
- Function: lib2to3_parse()
- Purpose: Parse Python source code using lib2to3
- Fuzzing strategy: Various code inputs

### 5. src/black/nodes.py
- Functions for AST node manipulation
- Key functions:
  - is_arith() - Check if node is arithmetic
  - is_simple_expr() - Check if expression is simple
  - is_yield() - Check for yield expressions
  - walk() - Walk AST tree

### 6. src/black/lines.py
- Line class and related functions
- Key functions:
  - Line.__init__()
  - Line.append()
  - Line.prepend()
  - is comment(), is import(), is docstring()

### 7. src/black/linegen.py
- Line generation for formatting
- Key functions: line_generator() main function

### 8. src/black/strings.py
- String formatting functions
- Key functions:
  - format_fstring() - Format f-strings
  - format_walrus() - Format walrus operator
  - remove_u_prefix() - Remove unicode prefixes

### 9. src/black/ranges.py
- Source range tracking
- Key functions:
  - does_overlap() - Check range overlap
  - bracket_split_build() - Bracket-aware splitting

## Input Types to Test
1. Valid Python code: Well-formed syntax
2. Invalid Python code: Syntax errors, partial code
3. Edge cases: Empty strings, very long lines, unicode
4. Mode variations: Different target versions, options
5. shebang lines, encoding declarations
6. Type stub files (.pyi)

## Edge Cases
- Python version-specific syntax
- f-strings with complex expressions
- Parentheses in import statements
- Long lines with various structures
- Comment handling
- Parentheses preservation
- Multi-line expressions
