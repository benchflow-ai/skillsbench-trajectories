# Notes for MiniSGL Library Fuzzing

## Library Description
MiniSGL is a library for inference with Small Language Models (SGL). It appears to be a distributed inference engine.

## Key Functions for Fuzzing

### 1. minisgl.core
- Location: python/minisgl/core.py
- Purpose: Core functionality for distributed inference
- Fuzzing strategy: Test core API functions

### 2. minisgl.env
- Location: python/minisgl/env.py
- Environment configuration
- Fuzzing strategy: Various configuration inputs

### 3. minisgl.message
- Location: python/minisgl/message/
- Message types and handling
- Fuzzing strategy: Message serialization/deserialization

### 4. minisgl.attention
- Location: python/minisgl/attention/
- Attention mechanisms
- Fuzzing strategy: Attention computation

### 5. minisgl.llm
- Location: python/minisgl/llm/
- LLM model handling
- Fuzzing strategy: Model configuration, tokenization

### 6. minisgl.tokenizer
- Location: python/minisgl/tokenizer/
- Tokenization functions
- Fuzzing strategy: Various text inputs

### 7. minisgl.models
- Location: python/minisgl/models/
- Model definitions
- Fuzzing strategy: Model configuration

### 8. minisgl.scheduler
- Location: python/minisgl/scheduler/
- Task scheduling
- Fuzzing strategy: Scheduler inputs

### 9. minisgl.server
- Location: python/minisgl/server/
- Server functionality
- Fuzzing strategy: Server configuration, requests

### 10. minisgl.kvcache
- Location: python/minisgl/kvcache/
- Key-value cache management
- Fuzzing strategy: Cache operations

## Input Types to Test
1. Text inputs: Various string lengths, unicode
2. Configuration: Dictionary configurations
3. Token IDs: Integer sequences
4. Attention masks: Binary/float tensors
5. Messages: JSON-like structures

## Dependencies Note
This library has complex dependencies including:
- torch (PyTorch)
- transformers
- accelerate
- flashinfer-python
- sgl_kernel

Note: Some dependencies may not be available in all environments, which could limit fuzzing.
