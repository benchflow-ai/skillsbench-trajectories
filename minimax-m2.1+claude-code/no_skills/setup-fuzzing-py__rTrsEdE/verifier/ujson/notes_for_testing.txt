# Notes for ujson Library Fuzzing

## Library Description
ujson is a fast JSON encoder/decoder for Python. It's written in C for performance.

## Key Functions for Fuzzing

### 1. ujson.loads() - JSON Decoding
- Location: src/ujson/python/JSONtoObj.c / lib/ultrajsondec.c
- Purpose: Deserialize JSON string to Python objects
- Input: JSON encoded strings (bytes or str)
- Fuzzing strategy: Various JSON strings, edge cases

### 2. ujson.dumps() - JSON Encoding
- Location: src/ujson/python/objToJSON.c / lib/ultrajsonenc.c
- Purpose: Serialize Python objects to JSON string
- Input: Python objects (dict, list, str, int, float, bool, None)
- Fuzzing strategy: Various Python objects, custom objects

### 3. ujson.dump() - JSON File Writing
- Location: src/ujson/python/ujson.c
- Purpose: Write Python objects to JSON file
- Fuzzing strategy: Various objects, file handles

### 4. ujson.load() - JSON File Reading
- Location: src/ujson/python/ujson.c
- Purpose: Read JSON from file
- Fuzzing strategy: Various JSON file contents

### 5. lib/ultrajsondec.c - Decoder
- Key functions:
  - JSON_DecodeStr() - Decode string
  - JSON_Decode() - Main decode function
  - SkipWhitespace() - Handle whitespace
  - DecodeValue() - Parse JSON values
  - DecodeString() - Parse strings
  - DecodeNumber() - Parse numbers
  - DecodeTrue() / DecodeFalse() / DecodeNull()
- Fuzzing strategy: Malformed JSON, edge cases

### 6. lib/ultrajsonenc.c - Encoder
- Key functions:
  - JSON_EncodeStr() - Encode string
  - JSON_Encode() - Main encode function
  - EncodeDict() - Encode dictionaries
  - EncodeList() - Encode lists
  - EncodeNumber() - Encode numbers
  - EncodeString() - Encode string values
- Fuzzing strategy: Various Python objects

## Input Types to Test

### For loads():
1. Valid JSON: Objects, arrays, strings, numbers, booleans, null
2. Invalid JSON: Malformed syntax, trailing commas
3. Edge cases:
   - Empty strings
   - Very long strings
   - Deep nesting
   - Unicode characters (\uXXXX)
   - Escape sequences
   - Control characters
   - Surrogate pairs
   - Special numbers (NaN, Infinity - though ujson may reject these)

### For dumps():
1. Python types: dict, list, tuple, str, int, float, bool, None
2. Nested structures: Deeply nested dicts/lists
3. Unicode strings: Non-ASCII characters
4. Large numbers: Very large/small integers
5. Special floats: Infinity, NaN handling
6. Custom objects: Objects with __dict__ or __json__ method

## Edge Cases for Both
- Maximum recursion depth (deep nesting)
- Maximum string length
- Control characters in strings
- Invalid UTF-8 sequences
- BOM handling
- Numbers at various precision levels
- Object key ordering
- Array index bounds
