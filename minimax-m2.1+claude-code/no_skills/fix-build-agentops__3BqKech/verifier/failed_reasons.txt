# Analysis of Build Errors in AgentOps-AI Repository

## Problem Description
The package fails to build/import due to a missing optional dependency (langchain) being
imported unconditionally at the module level.

## Root Cause
The file `agentops/__init__.py` line 12 has an unconditional import:
```python
from .langchain_callback_handler import LangchainCallbackHandler, AsyncLangchainCallbackHandler
```

This imports `langchain_callback_handler.py`, which has top-level imports from `langchain_core`:
```python
from langchain_core.agents import AgentFinish, AgentAction
from langchain_core.documents import Document
from langchain_core.outputs import ChatGenerationChunk, GenerationChunk, LLMResult
from langchain.callbacks.base import BaseCallbackHandler, AsyncCallbackHandler
from langchain_core.messages import BaseMessage
```

Since langchain is declared as an **optional dependency** in `pyproject.toml`:
```toml
langchain = [
    "langchain>=0.0.354"
]
```

The imports should be conditional to allow the core package to work without langchain installed.

## Errors Encountered
1. `ModuleNotFoundError: No module named 'langchain_core'` when importing agentops
2. All pytest tests fail to collect/run because the test modules also import agentops
3. The package cannot be used in environments without langchain installed

## Fix Required
1. Make the langchain imports conditional in `agentops/__init__.py`
2. Define `LangchainCallbackHandler` and `AsyncLangchainCallbackHandler` as `None` when langchain is not available
3. Update docstrings/optional-dependencies to reflect that the langchain integration is optional
