# Black Library - Functions for Fuzzing Testing

## Library Overview
Black is an uncompromising Python code formatter that follows a strict, opinionated style guide.

## Key Functions to Test

### 1. `black.format_str()` - Main formatting function
- **Purpose**: Format Python source code string
- **Input**: Python source code as string
- **Parameters**:
  - `src_contents`: The Python code to format
  - `mode`: Mode object with formatting options
- **Fuzzing strategy**: Pass random Python code, malformed syntax, edge cases

### 2. `black.format_file_contents()` - Format file contents
- **Purpose**: Format Python code with file path handling
- **Input**: File path and contents
- **Fuzzing**: Various file paths, content types

### 3. `black.check()` - Check if code is properly formatted
- **Purpose**: Return True if code matches Black formatting
- **Fuzzing**: Compare formatted vs unformatted code

### 4. `lib2to3_parse()` - Parse Python code to AST
- **File**: black/parsing.py
- **Purpose**: Safe parsing of Python source code
- **Fuzzing**: Invalid/malformed Python code

### 5. `black.lines()` - Line processing
- **File**: black/lines.py
- **Purpose**: Process and format individual lines
- **Fuzzing**: Various line lengths, edge cases

## Fuzzing Targets
1. Source code formatting - Pass random Python-like strings
2. Syntax edge cases - Unusual indentation, unicode
3. Line length handling - Very long lines
4. Comment handling - Various comment styles
5. String formatting - f-strings, regular strings
6. Parentheses and brackets - Complex nesting

## Edge Cases to Test
- Empty strings
- Very long lines (>10000 chars)
- Invalid Python syntax
- Unicode characters in source
- Mix of tabs and spaces
- Unclosed brackets/quotes
- Binary data in strings
- Zero-width characters
- Very large numbers in source
