# IPython Library - Functions for Fuzzing Testing

## Library Overview
IPython is an interactive Python shell with rich features for computing and data analysis.

## Key Functions to Test

### 1. `IPython.start_ipython()` - Start interactive shell
- **Purpose**: Initialize and start IPython kernel/shell
- **Parameters**:
  - argv: Command line arguments
  - user_ns: User namespace
  - config: Configuration object
- **Fuzzing strategy**: Malformed configuration, invalid arguments

### 2. `IPython.embed()` - Embed IPython shell
- **Purpose**: Embed IPython in running Python code
- **Fuzzing**: Invalid namespace values, custom banner

### 3. `IPython.get_ipython()` - Get current IPython instance
- **Purpose**: Retrieve the active InteractiveShell instance
- **Fuzzing**: Call outside IPython context

### 4. `InteractiveShell` class - Core shell functionality
- **File**: IPython/core/interactiveshell.py
- **Methods**:
  - `run_cell()` - Execute code
  - `run_line_magic()` - Execute magic commands
  - `ev()` - Evaluate expressions
  - `ex()` - Execute Python code

### 5. Input processing
- **File**: IPython/core/inputtransformer.py
- **Purpose**: Process user input before execution
- **Fuzzing**: Malformed input, special characters

## Fuzzing Targets
1. Code execution - Pass arbitrary Python code strings
2. Magic command parsing - Various magic command formats
3. Input transformation - Handle unusual input formats
4. Output formatting - Various output types
5. Configuration handling - Invalid config values

## Edge Cases to Test
- Empty code strings
- Very long code strings
- Invalid Python syntax
- Dangerous code (in controlled environment)
- Unicode and special characters
- Circular imports
- Memory exhaustion cases
- Stack overflow with deep recursion
