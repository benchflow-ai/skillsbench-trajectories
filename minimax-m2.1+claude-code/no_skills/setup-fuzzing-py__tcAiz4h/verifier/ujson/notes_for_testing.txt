# ujson Library - Functions for Fuzzing Testing

## Library Overview
ujson is a fast JSON encoder/decoder for Python, written in C for performance.

## Key Functions to Test

### 1. `ujson.dumps()` - Serialize Python to JSON
- **Purpose**: Convert Python objects to JSON strings
- **Input**: Python objects (dict, list, str, int, float, bool, None)
- **Parameters**:
  - obj: Python object to serialize
  - ensure_ascii: Control ASCII escaping
  - indent: Pretty printing
- **Fuzzing strategy**: Pass various Python objects with edge case values

### 2. `ujson.loads()` - Deserialize JSON to Python
- **Purpose**: Parse JSON strings to Python objects
- **Input**: JSON string
- **Fuzzing**: Malformed JSON, various edge cases

### 3. `ujson.load()` - Read JSON from file
- **Purpose**: Read and parse JSON from file object
- **Fuzzing**: Invalid file content

### 4. `ujson.dump()` - Write Python to JSON file
- **Purpose**: Write Python object to file as JSON
- **Fuzzing**: Invalid file objects, unserializable types

## Fuzzing Targets
1. JSON parsing - Pass malformed JSON strings
2. Encoding - Pass complex Python objects
3. Number handling - Very large numbers, NaN, Infinity
4. String handling - Long strings, unicode, escape sequences
5. Nesting depth - Deeply nested structures
6. Special values - NaN, Infinity, null

## Edge Cases to Test
- Empty strings
- Truncated JSON
- Invalid escape sequences
- Very long strings
- Deeply nested JSON (stack overflow test)
- Numbers beyond float range
- Unicode edge cases (surrogate pairs, etc.)
- Invalid UTF-8 sequences
- Circular references (if not protected)
- Very large integers
