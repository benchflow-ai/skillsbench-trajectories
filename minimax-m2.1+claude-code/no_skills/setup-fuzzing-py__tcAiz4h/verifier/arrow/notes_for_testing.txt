# Arrow Library - Functions for Fuzzing Testing

## Library Overview
Arrow is a Python library for working with dates and times, providing a cleaner, more intelligent API than the built-in datetime module.

## Key Functions to Test

### 1. `arrow.get()` - Main factory method
- **Purpose**: Parse various datetime inputs (strings, timestamps, datetime objects)
- **Input types**:
  - String with datetime format (e.g., "2023-01-01 12:00:00")
  - Unix timestamp (int or float)
  - datetime/date objects
  - ISO 8601 strings
  - Custom format strings with locale
- **Fuzzing strategy**: Pass malformed datetime strings, invalid timestamps, edge case values

### 2. `arrow.utcnow()` - Current UTC time
- **Purpose**: Get current UTC time as Arrow object
- **No input** - low fuzzing priority

### 3. `arrow.now(tz)` - Current time in timezone
- **Purpose**: Get current time in specified timezone
- **Fuzzing**: Invalid timezone expressions

### 4. Parser functions
- **Files**: arrow/parser.py
- **Classes**: DateTimeParser
- **Methods**: parse(), parse流水化(), parse_iso()
- **Fuzzing**: Malformed datetime strings, various locale inputs

### 5. Formatting functions
- **Constants**: FORMAT_RFC3339, FORMAT_RFC2822, FORMAT_ISO, etc.
- **Purpose**: Format Arrow objects to various string representations
- **Fuzzing**: Format with invalid format specifiers

## Fuzzing Targets
1. String parsing - Pass random strings to test parser robustness
2. Timestamp parsing - Invalid integer/float values
3. Locale handling - Various locale codes
4. Timezone parsing - Invalid timezone expressions
5. Format string validation - Invalid format specifiers

## Edge Cases to Test
- Empty strings
- Strings with special characters
- Very long strings
- Invalid date values (e.g., Feb 30)
- Negative timestamps
- Timezones beyond UTC offsets
- Unicode in datetime strings
