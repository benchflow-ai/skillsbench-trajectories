# Black Library - Functions for Fuzzing

## Overview
Black is the uncompromising Python code formatter.

## Key Functions/Modules to Test

### 1. `black.format_str()` - Core formatting function
   - Input: Python source code as string
   - Returns: formatted Python code
   - Parameters: mode (Mode object)
   - Test cases: valid Python, syntax errors, edge cases

### 2. `black.format_file_contents()` - File content formatting
   - Similar to format_str but handles file-level operations
   - Raises NothingChanged for already-formatted code

### 3. `black.format_stdin_to_stdout()` - Stdin formatting
   - Formats code from stdin

### 4. `black.reformat_code()` - Code reformatting
   - Handles write_back options

### 5. `black.lib2to3_parse()` - AST parsing
   - Converts source code to AST
   - Important for error detection

### 6. `black.assert_equivalent()` - AST equivalence check
   - Validates formatted code is semantically equivalent

### 7. `black.assert_stable()` - Stability check
   - Ensures double-formatting produces same result

## Fuzzing Strategy
1. Fuzz `format_str()` with random Python code strings
2. Test with various Mode configurations (line_length, target_versions)
3. Test edge cases: empty strings, invalid syntax, large inputs
4. Test assert_equivalent and assert_stable

## Notes
- Handle NothingChanged exception
- Handle ASTSafetyError for invalid code
- Black requires Python 3.10+
