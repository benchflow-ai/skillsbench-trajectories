# ujson Library - Functions for Fuzzing

## Overview
ujson is a fast JSON encoder/decoder for Python (C extension).

## Key Functions/Modules to Test

### 1. `ujson.loads()` - JSON string to Python object
   - Input: JSON string
   - Returns: Python object (dict, list, str, int, float, bool, None)
   - Test cases: valid JSON, invalid JSON, edge cases

### 2. `ujson.dumps()` - Python object to JSON string
   - Input: Python object
   - Returns: JSON string
   - Parameters: default handler, ensure_ascii, etc.
   - Test cases: various Python types, custom objects

### 3. `ujson.decode()` - Alias for loads
   - Same as loads()

### 4. `ujson.encode()` - Alias for dumps
   - Same as dumps()

### 5. `ujson.objToJSON()` - C-level encoding
   - Low-level encoding function

### 6. `ujson.JSONtoObj()` - C-level decoding
   - Low-level decoding function

## Fuzzing Strategy
1. Fuzz `loads()` with random byte/string inputs
2. Fuzz `dumps()` with random Python objects
3. Test edge cases: deeply nested structures, large numbers, unicode
4. Test error handling for invalid JSON

## Notes
- ujson is a C extension - may need special handling
- Can cause crashes on malformed input
- Good for finding parsing vulnerabilities
