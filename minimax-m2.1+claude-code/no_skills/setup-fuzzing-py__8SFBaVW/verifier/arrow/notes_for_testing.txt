# Arrow Library - Functions for Fuzzing

## Overview
Arrow is a Python library for working with dates and times.

## Key Functions/Modules to Test

### 1. `arrow.get()` - Main parsing function
   - Parses date/time strings in various formats
   - Input: string, can be ISO 8601, relative strings, etc.
   - Test cases: valid dates, invalid dates, edge cases

### 2. `Arrow` class - Core datetime class
   - `arrow.now()` - Current time
   - `arrow.utcnow()` - Current UTC time
   - `Arrow.shift()` - Time shifting
   - `Arrow.format()` - Formatting
   - `Arrow.timestamp` - Unix timestamp

### 3. `arrow.factory.ArrowFactory` - Factory methods
   - `get()`, `now()`, `utcnow()`
   - Various parsing scenarios

### 4. `arrow.parser` - Parsing functionality
   - Date format parsing
   - Timezone parsing
   - ISO 8601 parsing

### 5. `arrow.formatter` - Formatting functions
   - Format strings (FORMAT_* constants)
   - Custom formatting

## Fuzzing Strategy
1. Fuzz `arrow.get()` with random string inputs
2. Test `Arrow` object creation with various inputs
3. Test shift operations with various timedelta values
4. Test format output with various format strings

## Notes
- Handle ParserError exceptions
- Handle timezone-related errors
- Test edge cases like leap years, month boundaries
