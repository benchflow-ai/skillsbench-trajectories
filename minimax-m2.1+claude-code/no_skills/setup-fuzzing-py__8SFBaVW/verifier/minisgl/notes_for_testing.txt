# MiniSGL Library - Functions for Fuzzing

## Overview
MiniSGL is an LLM serving framework (Mini Scale Graph Language?).

## Key Functions/Modules to Test

### 1. `minisgl.core.SamplingParams` - Sampling parameters
   - temperature: float
   - top_k: int
   - top_p: float
   - max_tokens: int
   - is_greedy property

### 2. `minisgl.core.Req` - Request object
   - input_ids: torch.Tensor
   - Various properties and methods

### 3. `minisgl.core.Batch` - Batch processing
   - Request batching
   - Phase management (prefill/decode)

### 4. `minisgl.core.Context` - Global context
   - Context management for LLM inference

### 5. `minisgl.utils` - Utility functions
   - torch_utils, registry, logger, etc.

## Fuzzing Strategy
1. Fuzz SamplingParams with various parameter combinations
2. Test Req object creation with tensors
3. Test Batch operations
4. Test Context management

## Notes
- Requires PyTorch
- Depends on transformers, accelerate
- Heavy ML dependencies
- Not ideal for simple fuzzing
