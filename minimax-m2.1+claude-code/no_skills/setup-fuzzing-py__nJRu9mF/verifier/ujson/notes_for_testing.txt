# ujson Library - Fuzzing Analysis

## Library Description
ujson is a fast JSON encoder/decoder written in Python with C extensions.

## Important Functions for Testing

### Main Functions (in ujson/__init__.py):
1. `ujson.dumps(obj, **kwargs)` - Serialize Python object to JSON string
   - Parameters:
     - obj: Python object to serialize
     - ensure_ascii: bool (default True)
     - indent: int (default 0)
   - Returns: JSON string
   - Raises: TypeError, OverflowError

2. `ujson.loads(s, **kwargs)` - Deserialize JSON string to Python object
   - Parameters:
     - s: JSON string or bytes to parse
     - precise_float: bool (default False)
   - Returns: Python object
   - Raises: ValueError, JSONDecodeError

### Key Encoding/Decoding Functions:
1. `JSONEncoder.encode()` - Core encoding logic
2. `JSONDecoder.decode()` - Core decoding logic

### Dictionary/Object Conversion:
1. `dict_to_obj()` - Convert Python dict to JSON object
2. `obj_to_dict()` - Parse JSON object to Python dict

## Fuzzing Strategy
1. **JSON parsing**: Test `loads()` with malformed JSON
2. **JSON encoding**: Test `dumps()` with complex Python objects
3. **Nested structures**: Test deeply nested JSON
4. **Unicode handling**: Test non-ASCII characters
5. **Numeric edge cases**: Test large numbers, floats, NaN, Infinity

## Key Edge Cases
- Empty strings
- Invalid JSON syntax (missing quotes, brackets)
- Truncated JSON
- Very deep nesting
- Large numbers (overflow)
- Special floats (NaN, Infinity)
- Unicode escape sequences
- Null bytes in strings
- Mixed types in arrays
- Circular references

## Dependencies
- setuptools (build-time)
