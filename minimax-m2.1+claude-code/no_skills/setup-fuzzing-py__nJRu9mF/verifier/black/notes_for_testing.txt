# Black Library - Fuzzing Analysis

## Library Description
Black is an opinionated Python code formatter that reformats Python code to follow a consistent style.

## Important Functions for Testing

### Main Entry Point (in black.__init__.py):
1. `black.format_file_contents(src_contents, *, mode=Mode(), fast=False)` - Format Python code
   - Parameters:
     - src_contents: Python source code as string
     - mode: Mode object with formatting options
     - fast: bool for fast mode
   - Returns: Formatted code string
   - Raises: `NothingChanged`, `ASTSafetyError`, `InvalidInput`

2. `black.format_str(src_contents, *, mode=Mode())` - Format a string

3. `black.fix_code(src_contents, *, mode=Mode())` - Fix code issues

4. `black.fix_file_contents(src, *, mode=Mode())` - Fix file contents

### Mode Configuration:
- `Mode(target_version, is_pyi, magic_trailing_comma, etc.)`
- `TargetVersion` enum (PY310, PY311, etc.)
- `Feature` flags for preview features

### Parser Functions (in black.parsing):
1. `lib2to3_parse(src, accept_empty=False)` - Parse Python source
2. `parse_ast(src)` - Parse AST from source
3. `stringify_ast(node)` - Convert AST to string

## Fuzzing Strategy
1. **Code formatting**: Test `format_file_contents()` with malformed Python code
2. **Syntax validation**: Test with invalid Python syntax
3. **Edge cases**: Test with empty strings, whitespace-only, special characters
4. **Character encoding**: Test with various encodings

## Key Edge Cases
- Empty strings
- Invalid Python syntax
- Syntax that changes after Python version
- Very long lines
- Complex nested structures
- Comments and docstrings
- F-strings with expressions
- Type annotations
