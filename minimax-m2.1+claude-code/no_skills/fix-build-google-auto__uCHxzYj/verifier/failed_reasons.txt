Build Error Analysis and Fix Summary
====================================

Repository: /home/travis/build/failed/google/auto (Auto parent project with submodules)

Root Causes Identified:
-----------------------

1. MISSING MODULES SECTION
   The parent pom.xml at /home/travis/build/failed/google/auto/pom.xml was missing a <modules>
   section, preventing Maven from building the submodules (common, service, factory, value)
   together as a reactor build. This caused the auto-value build to fail because it couldn't
   find the SNAPSHOT dependency com.google.auto:auto-common:1.0-SNAPSHOT.

2. JDK 11+ COMPATIBILITY - tools.jar DEPRECATED
   The compile-testing library versions 0.6, 0.7, and 0.8 used system-scoped dependencies
   on com.sun:tools:jar which points to tools.jar. On JDK 9+, tools.jar was removed from
   the JDK, causing the build to fail with "Could not find artifact com.sun:tools:jar:11.0.27
   at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar"

3. MISSING javax.annotation API
   The javax.annotation.Generated class was removed from the JDK in JDK 9+. Projects that
   used this annotation (like auto-factory and auto-value) failed to compile without the
   external javax.annotation-api dependency.

Fixes Applied:
--------------

1. Added <modules> section to parent pom.xml (google/auto/pom.xml):
   - common
   - service
   - factory
   - value

2. Updated compile-testing dependency versions to 0.18 (JDK 9+ compatible):
   - common/pom.xml: 0.7 -> 0.18
   - service/pom.xml: 0.6 -> 0.18
   - factory/pom.xml: 0.8 -> 0.18
   - value/pom.xml: 0.6 -> 0.18

3. Updated intra-project dependencies to use local SNAPSHOT versions:
   - factory/pom.xml: auto-common 0.5 -> 1.0-SNAPSHOT
   - factory/pom.xml: auto-service 1.0-rc2 -> 1.0-SNAPSHOT
   - service/pom.xml: auto-common 0.3 -> 1.0-SNAPSHOT

4. Added javax.annotation-api dependency (1.3.2) for JDK 9+ compatibility:
   - factory/pom.xml
   - value/pom.xml

Build Result:
-------------
After applying these fixes, the build completes successfully with "BUILD SUCCESS".
