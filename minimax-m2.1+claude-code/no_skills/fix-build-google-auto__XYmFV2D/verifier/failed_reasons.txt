# Build Error Analysis for Google Auto Value Project

## Root Causes Identified

### Issue 1: Missing tools.jar dependency (Java 9+ incompatibility)
The build failed with the error:
```
Could not find artifact com.sun:tools:jar:11.0.27 at specified path /usr/lib/jvm/java-11-openjdk-amd64/../lib/tools.jar
```

**Root Cause:**
- The project was designed for Java 6-8
- The `compile-testing` library (versions 0.6 and 0.7) has a system-scoped dependency on `com.sun:tools:jar` (tools.jar)
- In Java 9+, tools.jar was removed and its classes were incorporated into the JDK itself
- The compile-testing pom.xml has a profile that activates when tools.jar exists, but when it doesn't exist (Java 9+), Maven tries to resolve the dependency from remote repositories

**Solution Applied:**
- Added `<exclusions>` to the `compile-testing` dependency to exclude `com.sun:tools` in both:
  - `/home/travis/build/failed/google/auto/common/pom.xml`
  - `/home/travis/build/failed/google/auto/value/pom.xml`

### Issue 2: Missing javax.annotation.Generated class (Java 9+ incompatibility)
After fixing Issue 1, the build failed with:
```
cannot find symbol: class Generated
  location: package javax.annotation
```

**Root Cause:**
- In Java 9+, the `javax.annotation` package (including `Generated` annotation) was removed from the JDK and moved to a separate module
- The project uses `javax.annotation.Generated` without a dependency on the external artifact

**Solution Applied:**
- Added `javax.annotation:javax.annotation-api:1.3.2` dependency to `/home/travis/build/failed/google/auto/value/pom.xml`

## Summary
The build errors were caused by Java version incompatibility - the project was designed for Java 6-8 but is being built with Java 11. The fixes ensure compatibility with Java 9+ by:
1. Excluding the tools.jar dependency (not needed in Java 9+)
2. Adding the javax.annotation-api dependency (required for Java 9+)
