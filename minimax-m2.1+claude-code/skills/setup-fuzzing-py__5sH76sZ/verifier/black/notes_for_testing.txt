Black Library - Important Functions for Fuzzing
===============================================

Library Description:
- Black is the uncompromising Python code formatter
- Formats Python code to follow a consistent style

Key Functions to Test:

1. Main Formatting Functions:
   - black.format_str() - Primary function to format a string of Python code
     - Takes source code string and Mode configuration
     - Returns formatted string
     - Key parameters: mode (line length, target versions, etc.)

   - format_file_contents() - Format contents of a file
     - Handles both regular Python files and Jupyter notebooks
     - Fast mode skips AST safety checks

   - _format_str_once() - Internal formatting function
     - Performs the actual AST transformation
     - Converts AST to formatted code

2. File Processing:
   - format_file_in_place() - Format file on disk
     - Handles encoding detection
     - Supports diff mode and in-place writes

   - format_stdin_to_stdout() - Format code from stdin
     - Used for piping code through Black

3. Code Parsing:
   - lib2to3_parse() - Parse Python source into AST
     - Critical for detecting Python version features
     - Handles syntax errors gracefully

   - parse_ast() - Parse AST from source
     - Used for equivalence and stability checks

4. AST Processing:
   - get_features_used() - Detect Python features in code
     - Finds f-strings, numeric underscores, type hints, etc.
     - Used for target version detection

   - get_future_imports() - Parse __future__ imports

5. Validation:
   - assert_equivalent() - Ensure source and formatted code are equivalent
   - assert_stable() - Ensure formatted code formats identically on second pass

Fuzzing Strategy:
- Generate random Python code snippets to feed to format_str()
- Test with various Mode configurations (line lengths, Python versions)
- Focus on edge cases: long lines, complex expressions, f-strings
- Test malformed code to ensure proper error handling
- Test Jupyter notebook formatting
