Arrow Library - Important Functions for Fuzzing
================================================

Library Description:
- Arrow is a library for handling dates and times in Python
- Provides a better API than the standard datetime library

Key Functions to Test:

1. Main API Functions:
   - arrow.get() - Primary function for creating Arrow instances from various input types
     - Accepts: strings, datetime objects, timestamps, tuples
     - Multiple overloads for different input combinations
     - Parameters: locale, tzinfo, normalize_whitespace

   - arrow.now() - Creates Arrow instance for current time
     - Optional timezone parameter

   - arrow.utcnow() - Creates Arrow instance for current UTC time

2. Arrow Class Methods:
   - Arrow.fromdatetime() - Creates from datetime object
   - Arrow.fromdate() - Creates from date object
   - Arrow.fromtimestamp() - Creates from timestamp
   - Arrow.strptime() - Creates from formatted string

3. Parsing Functions:
   - Parser.parse() - Internal parsing logic for various date/time formats
   - Supports multiple locale and timezone formats

4. Formatting/Conversion:
   - format() - Format Arrow objects to strings
   - Various built-in format constants (FORMAT_RFC2822, FORMAT_ISO, etc.)
   - humanize() - Human-readable relative time

5. Time Manipulation:
   - replace() - Replace components (year, month, day, etc.)
   - shift() - Relative time shifts (add/subtract time periods)
   - to() - Convert timezone

Fuzzing Strategy:
- Focus on the get() function with various input types (strings, ints, floats)
- Test with malformed date/time strings
- Test edge cases in timezone conversions
- Test format parsing with various format strings
- Test range boundaries for date/time components

Dependencies:
- python-dateutil>=2.7.0
- backports.zoneinfo==0.2.1 (Python <3.9)
- tzdata (Python >=3.9)
