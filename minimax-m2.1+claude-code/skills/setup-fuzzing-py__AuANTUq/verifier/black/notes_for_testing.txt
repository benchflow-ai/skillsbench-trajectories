KEY VULNERABILITY AREAS:
------------------------
- Python AST parsing (lib2to3 and ast modules)
- String normalization and quote handling
- F-string processing and formatting
- Encoding detection and Unicode handling
- Jupyter notebook JSON parsing
- Regex pattern matching and substitution

FUZZING STRATEGIES:
------------------
1. Malformed Python syntax: invalid indentations, incomplete constructs
2. Encoding edge cases: UTF-8 BOM, invalid byte sequences
3. String patterns: nested quotes, escape sequences, Unicode
4. F-string complexity: nested expressions, special characters
5. Notebook corruption: invalid JSON, malformed cell structure
6. Regex injection: crafted patterns causing catastrophic backtracking
7. Mode configurations: extreme values for line length, target versions

- /app/black/src/black/__init__.py - Main API (PRIMARY)
