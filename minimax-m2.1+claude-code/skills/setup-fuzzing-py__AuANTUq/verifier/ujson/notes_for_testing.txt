ujson Library - Analysis for Fuzzing
===================================

Library: ujson (Fast JSON encoder/decoder)
Main Source: /app/ujson/src/ujson/

TIER 1 - Critical Functions (String Parsing & Decoding):
------------------------------------------------------
1. decode_string() - String decoding (ultrajsondec.c:362-587)
   - Fuzz with: invalid UTF-8, malformed escapes, overlong encodings
   - Risks: buffer overflows, invalid surrogates, unterminated escapes
   - PRIORITY: CRITICAL - Ultra-complex string parsing logic

2. JSONToObj() - Main decoding entry (JSONtoObj.c:163)
   - Fuzz with: malformed JSON, invalid structures, edge cases
   - Risks: parser crashes, memory corruption
   - Handles all decoding operations

3. objToJSON() - Main encoding entry (objToJSON.c:660)
   - Fuzz with: complex objects, extreme parameters
   - Risks: parameter validation failures, memory errors
   - Handles: strings, numbers, collections, custom objects

TIER 2 - High Priority (Input Validation & Numbers):
---------------------------------------------------
4. decode_numeric() - Number parsing (ultrajsondec.c:91-246)
   - Fuzz with: very large numbers, overflow boundaries, mixed formats
   - Risks: integer overflow, invalid number formats
   - Parses: int, long, unsigned long, double

5. objToJSON() parameter validation (objToJSON.c:717)
   - Fuzz with: malformed separators tuples, invalid boolean params
   - Risks: validation bypass, parameter confusion
   - Validates: separators (size 2), ensure_ascii, encode_html_chars

6. Object_beginTypeContext() - Type determination (objToJSON.c:340)
   - Fuzz with: unusual object types, custom __json__ methods
   - Risks: type confusion, custom method errors
   - Handles: dicts, lists, tuples, custom objects

7. Dict_convertKey() - Dictionary key conversion (objToJSON.c:212)
   - Fuzz with: non-standard key types, custom __str__ methods
   - Risks: arbitrary code execution via PyObject_Str()
   - Converts: None, bool, string, bytes to dict keys

TIER 3 - Medium Priority (Complex Structures & Buffers):
-----------------------------------------------------
8. decode_array() - Array parsing
   - Fuzz with: deeply nested arrays, mixed types
   - Risks: recursion depth issues, memory exhaustion
   - Handles: [1, 2, 3] structures

9. decode_object() - Object parsing
   - Fuzz with: malformed objects, non-string keys
   - Risks: parser errors, key conversion failures
   - Handles: {"key": "value"} structures

10. Buffer_Realloc() - Dynamic buffer expansion (ultrajsonenc.c:116)
    - Fuzz with: extreme size requests, allocation failures
    - Risks: buffer overflows, memory corruption
    - Manual memory management with pointer arithmetic

11. Buffer_EscapeStringUnvalidated() - String escaping (ultrajsonenc.c:191)
    - Fuzz with: strings with special characters
    - Risks: escape sequence errors
    - Handles: ", \, /, control characters

TIER 4 - Specialized Functions:
----------------------------
12. Object_newIntegerFromString() - Integer from string (JSONtoObj.c:142)
    - Fuzz with: malformed integer strings
    - Risks: manual buffer management errors
    - Allocates buffer and null-terminates

13. decode_array() and decode_object() recursion
    - Fuzz with: deep nesting near JSON_MAX_RECURSION_DEPTH (1024)
    - Risks: stack overflow, infinite recursion
    - NO CYCLIC REFERENCE DETECTION (known limitation)

14. UTF-16 surrogate pair handling
    - Fuzz with: invalid surrogate pairs
    - Risks: Unicode decoding errors
    - Handles \uXXXX and surrogate pairs

15. PyPy buffer protocol handling (JSONtoObj.c:206-211)
    - Fuzz with: PyPy-specific buffer types
    - Risks: PyPy-specific bugs
    - Known PyPy buffer protocol bugs noted

KEY VULNERABILITY AREAS:
------------------------
- String decoding with escape sequences (decode_string)
- Manual buffer management (Buffer_Realloc, escape buffers)
- UTF-8 validation and conversion
- Number parsing with overflow detection
- Dictionary key conversion (PyObject_Str() calls)
- Recursion depth (no cyclic reference detection)
- Parameter validation for encoding functions
- Pointer arithmetic in buffer operations
- TypeContext custom allocation

FUZZING STRATEGIES:
------------------
1. Invalid UTF-8 sequences: malformed multi-byte sequences
2. Malformed escape sequences: \x, \u, incomplete escapes
3. Overlong encodings: UTF-8 encoded beyond minimum length
4. Invalid surrogate pairs: unpaired surrogates, wrong order
5. Extreme nesting: deep arrays/objects near recursion limits
6. Buffer overflows: very long strings, large numbers
7. Parameter confusion: malformed separators tuples
8. Type confusion: unusual object types, custom methods
9. Integer overflow: numbers beyond type limits
10. Null bytes: embedded \x00 in strings
11. Custom serialization: __json__ and toDict methods
12. PyPy edge cases: buffer protocol variations

KNOWN LIMITATIONS:
-----------------
- NO cyclic reference detection (ultrajson.h:47) - Can cause infinite recursion
- JSON_MAX_RECURSION_DEPTH = 1024
- JSON_MAX_OBJECT_DEPTH = 1024
- PyPy-specific buffer protocol bugs (documented in code)

CRITICAL FILES:
---------------
- /app/ujson/src/ujson/ultrajsondec.c - JSON decoding (PRIMARY)
- /app/ujson/src/ujson/ultrajsonenc.c - JSON encoding
- /app/ujson/src/ujson/objToJSON.c - Object to JSON conversion
- /app/ujson/src/ujson/JSONtoObj.c - JSON to object conversion
- /app/ujson/src/ujson/ultrajson.h - Constants and definitions

INPUT SOURCES TO FUZZ:
----------------------
- JSON strings (loads/dumps)
- Python objects (dumps)
- Custom separator parameters
- Very large numbers
- Deeply nested structures
- Invalid UTF-8 sequences
- Malformed escape sequences
- Custom __json__ methods
