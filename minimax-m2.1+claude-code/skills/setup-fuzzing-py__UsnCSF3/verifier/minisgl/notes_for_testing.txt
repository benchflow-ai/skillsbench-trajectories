# MiniSGL Library - Important Functions for Fuzzing

## Library Overview
MiniSGL is a minimal inference engine for Large Language Models.

## Key Functions to Test

### 1. minisgl.core - Core classes
- `SamplingParams`: Sampling parameters (temperature, top_k, top_p)
- `Req`: Request dataclass with tensor operations
- `Batch`: Batch of requests for processing
- `Context`: Context for attention computation

### 2. minisgl.tokenizer - Tokenization
- `tokenize_worker()`: Tokenization worker function
- `Tokenizer`: Tokenizer class for LLMs
- `encode()`: Convert text to tokens
- `decode()`: Convert tokens to text

### 3. minisgl.llm - LLM inference
- `LLM`: Main LLM class
- `generate()`: Generate text from prompts
- `generate_token()`: Generate single token

### 4. minisgl.kvcache - KV Cache management
- `BaseCacheHandle`: Cache handle interface
- `CacheManager`: Manage KV caches

### 5. minisgl.attention - Attention mechanisms
- `BaseAttnBackend`: Attention backend interface
- `AttentionMetadata`: Attention metadata

### 6. minisgl.message - Message handling
- `ChatMessage`: Chat message dataclass
- `ChatTemplate`: Chat template processing

### 7. minisgl.scheduler - Request scheduling
- `Scheduler`: Schedule requests for processing
- `ScheduleResult`: Result of scheduling

## Fuzzing Strategy
- Fuzz `SamplingParams` with various parameter values
- Fuzz tokenizer encode/decode with random text
- Fuzz `Req` tensor operations
- Fuzz message template processing
- Test attention metadata handling
