# Arrow Library - Important Functions for Fuzzing

## Library Overview
Arrow is a Python library for working with dates and times.

## Key Functions to Test

### 1. arrow.get() - Factory method (arrow/api.py:83)
- Main entry point for creating Arrow objects
- Accepts various inputs: datetime, date, int (timestamp), str (date string), tuple
- Parameters: locale, tzinfo, normalize_whitespace
- Tests: Various input formats, timezone parsing, locale handling

### 2. Arrow class methods (arrow/arrow.py)
- `__init__`: Initialize Arrow with year, month, day, hour, minute, second, microsecond, tzinfo
- `fromtimestamp()`: Create from Unix timestamp
- `utcnow()`: Get current UTC time
- `replace()`: Replace time components
- `shift()`: Shift time by delta
- `format()`: Format Arrow to string

### 3. DateTimeParser (arrow/parser.py)
- Main parsing class with format templates
- `parse()`: Parse date strings with format patterns
- `parse_multiformat()`: Try multiple format patterns
- `parse_iso()`: Parse ISO 8601 format
- Supports formats: YYYY-MM-DD, HH:mm:ss, RFC formats, etc.

### 4. ArrowFactory (arrow/factory.py)
- `get()`: Create Arrow from various inputs
- `utcnow()`: Get current UTC time
- `now()`: Get current local time

### 5. Formatting constants (arrow/formatter.py)
- FORMAT_ATOM, FORMAT_RFC3339, FORMAT_RFC2822, etc.
- Various output format strings

## Fuzzing Strategy
- Fuzz `arrow.get()` with random strings (date parsing)
- Fuzz `Arrow()` constructor with random integers
- Fuzz `replace()` and `shift()` methods
- Fuzz locale-dependent parsing
