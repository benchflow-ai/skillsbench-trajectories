# Black Library - Important Functions for Fuzzing

## Library Overview
Black is the uncompromising Python code formatter.

## Key Functions to Test

### 1. black.format_file() - Main formatting entry (black/__init__.py)
- `format_file()`: Format a Python file
- `format_str()`: Format a Python code string
- Parameters: mode (Mode object), fast/exact diff options

### 2. black.format_file_in_place() (black/__init__.py)
- Format a file in-place

### 3. Mode class (black/mode.py)
- TargetVersion: Python version targeting
- Feature flags for various Python features
- Line length configuration

### 4. lib2to3_parse() (black/parsing.py)
- Parse Python source code using lib2to3
- Returns lib2to3 pytree
- Raises ASTSafetyError on invalid code

### 5. LineGenerator and transform_line() (black/linegen.py)
- Generate formatted lines
- Transform individual lines

### 6. parse_pyproject_toml() (black/files.py)
- Parse pyproject.toml configuration
- Extract Black settings

### 7. Path handling functions (black/files.py)
- `find_pyproject_toml()`: Find config file
- `find_project_root()`: Find project root

## Fuzzing Strategy
- Fuzz `format_str()` with random Python code strings
- Fuzz `lib2to3_parse()` with various string inputs
- Test edge cases in parsing and formatting
- Test different Mode configurations
