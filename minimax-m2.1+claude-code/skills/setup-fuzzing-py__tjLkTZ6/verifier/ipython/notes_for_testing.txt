IPython Library - Fuzz Testing Notes
====================================

Library Purpose:
IPython is an interactive shell for Python with advanced features like magic commands,
input transformation, and code execution.

Key Functions to Fuzz:
----------------------

1. TransformerManager() - /app/ipython/IPython/core/inputtransformer2.py
   - Purpose: Manages input transformations for IPython special syntax
   - Input: lines of Python code with IPython magics
   - Fuzz Priority: HIGH
   - Why: Complex regex-based parsing for magic commands and transformations

2. PromptStripper() - /app/ipython/IPython/core/inputtransformer2.py:48
   - Purpose: Strips prompts from code blocks
   - Input: lines with prompts (>>, ..., In[n]:, etc.)
   - Fuzz Priority: MEDIUM
   - Why: Complex prompt pattern matching

3. DataIPython.transform_code() - /app/ipython/IPython/core/inputtransformer2.py
   - Purpose: Transforms IPython-specific code
   - Input: Python code with IPython magics
   - Fuzz Priority: HIGH
   - Why: Handles special IPython syntax and transformations

4. InputSplitter.push() - /app/ipython/IPython/core/splitinput.py
   - Purpose: Splits input into logical lines
   - Input: Lines of Python code
   - Fuzz Priority: MEDIUM
   - Why: Input parsing and splitting logic

Fuzz Strategy:
-------------
- Invalid magic commands
- Malformed IPython syntax
- Very long lines
- Nested magic commands
- Invalid escape sequences
- Unicode in code and comments
- Empty input blocks
- Mixed Python and IPython syntax
- Prompt stripping edge cases

Oracles:
--------
- No crashes or unhandled exceptions
- InvalidInputStream exceptions are acceptable for invalid syntax
- Transformation should preserve code semantics
- Prompt stripping should be accurate
- Magic command parsing should be robust
