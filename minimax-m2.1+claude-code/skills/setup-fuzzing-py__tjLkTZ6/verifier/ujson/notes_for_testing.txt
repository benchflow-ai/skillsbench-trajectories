Ujson Library - Fuzz Testing Notes
==================================

Library Purpose:
Ujson is a fast JSON encoder/decoder for Python written in C.

Key Functions to Fuzz:
----------------------

1. ujson.encode() - C extension in /app/ujson/src/ujson/python/objToJSON.c
   - Purpose: Encode Python objects to JSON strings
   - Input: Python objects (dict, list, str, int, float, bool, None)
   - Fuzz Priority: HIGH
   - Why: Core encoding function, C extension, performance critical

2. ujson.decode() - C extension in /app/ujson/src/ujson/python/JSONtoObj.c
   - Purpose: Decode JSON strings to Python objects
   - Input: JSON strings
   - Fuzz Priority: HIGH
   - Why: Core decoding function, C extension, parsing critical

3. ujson.dumps() - Python wrapper in /app/ujson/src/ujson/python/ujson.c
   - Purpose: Convert Python objects to JSON strings (with options)
   - Input: Python objects + optional parameters
   - Fuzz Priority: HIGH
   - Why: Main API, handles encoding options

4. ujson.loads() - Python wrapper in /app/ujson/src/ujson/python/ujson.c
   - Purpose: Parse JSON strings to Python objects (with options)
   - Input: JSON strings + optional parameters
   - Fuzz Priority: HIGH
   - Why: Main API, handles decoding options

Fuzz Strategy:
-------------
- Malformed JSON (invalid syntax)
- Very large numbers (overflow)
- Deep nesting (stack overflow)
- Very long strings (memory issues)
- Invalid escape sequences
- Unicode edge cases
- Null bytes in strings
- Mixed types in arrays
- Invalid UTF-8 sequences
- Special floating point values (NaN, Infinity)

Oracles:
--------
- No crashes or unhandled exceptions
- ValueError exceptions are acceptable for invalid JSON
- Output should be valid JSON
- Round-trip consistency (encode then decode)
- Match standard json module behavior
- Proper handling of special characters
