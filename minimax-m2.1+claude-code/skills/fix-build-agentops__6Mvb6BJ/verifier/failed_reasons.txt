### Error 1: Package Configuration Issue (CRITICAL)
**File:** pyproject.toml
**Issue:** Package is being built as "UNKNOWN-0.0.0" instead of "agentops-0.1.8"
**Root Cause:** Missing package discovery configuration in pyproject.toml for setuptools
**Impact:** Package cannot be properly built or installed
**Fix Required:** Add [tool.setuptools.packages.find] or [tool.setuptools.package-dir] configuration

---

### Error 2: Langchain Import Path Errors (CRITICAL)
**File:** agentops/langchain_callback_handler.py
**Issues:**
- Line 5-9: Importing from `langchain.*` modules that don't exist in modern langchain
  - Should import from `langchain_core.*` instead
- Line 11: Importing `tenacity` module without proper dependency declaration

**Specific Wrong Imports:**
```python
from langchain.callbacks.base import BaseCallbackHandler, AsyncCallbackHandler  # WRONG
```

**Should Be:**
```python
from langchain_core.callbacks.base import BaseCallbackHandler, AsyncCallbackHandler  # CORRECT
```

**Impact:** Tests fail immediately with ModuleNotFoundError
**Fix Required:** Update all langchain imports to use langchain_core, add tenacity to dependencies

---

### Error 3: Mandatory vs Optional Dependencies (CRITICAL)
**File:** agentops/__init__.py
**Issue:** Line 12 unconditionally imports langchain_callback_handler
**Impact:**
- Makes langchain a required dependency when it should be optional
- Users who don't use langchain features cannot use the library
- Tests fail when langchain dependencies are not installed
**Fix Required:** Make langchain imports conditional using try/except

---

### Error 4: Type Safety Errors (HIGH)
**File:** agentops/client.py
**Issues:**
- Lines 153-154: Dynamically adding attributes to ErrorEvent
  - Sets `trigger_event_id` and `trigger_event_type` which don't exist in class
  - Creates runtime type errors
- Line 250: Passing str | UUID to Session constructor that expects UUID only
- Line 251: Passing potentially non-bool to get_host_env() which expects bool

**Fix Required:**
- Add proper attributes to ErrorEvent dataclass OR use proper typing
- Convert str to UUID when necessary
- Ensure boolean type for opt_out parameter
