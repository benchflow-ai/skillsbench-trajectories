BUILD ERROR ANALYSIS FOR Google Auto Project
=============================================

REPOSITORY: /home/travis/build/failed/google/auto
ERRORS FOUND:
1. ERROR 1 - Missing @Generated Annotation
2. ERROR 2 (FIXED) - Could not find artifact com.sun:tools:jar:11.0.27

ROOT CAUSE ERROR 2:
-------------------
The parent pom.xml (/home/travis/build/failed/google/auto/pom.xml) defines two Maven profiles (default-profile and mac-profile) that attempt to set a `toolsjar` property. The oss-parent POM declares com.sun:tools as a system-scoped dependency with a filesystem path that no longer exists in Java 11+.

In Java 6-8, tools.jar was located at:
  - Linux/Windows: ${java.home}/../lib/tools.jar
  - macOS: ${java.home}/../Classes/classes.jar

In Java 9+, tools.jar was removed. The JDK restructure moved tools into the JDK modules system.

SOLUTION FOR ERROR 2:
- Add a dependencyManagement section to override the tools.jar dependency
- Point to ${java.home}/lib/modules instead of the non-existent tools.jar
- Add JDK version constraints to Maven profiles to prevent Java <9 from using incorrect paths
- Create a java9-plus-profile that doesn't reference tools.jar

ROOT CAUSE ERROR 1:
-------------------
The @Generated annotation is missing from the javax.annotation package. This annotation was part of the Java standard library but has been moved to a separate module/library in Java 9+.

In Java 8, @Generated came from javax.annotation package (from tools.jar).
In Java 9+, the annotation is not automatically available and must be added as an explicit dependency.

AFFECTED FILES:
---------------
1. /home/travis/build/failed/google/auto/pom.xml
   - Needs dependencyManagement section for com.sun:tools
   - Needs JDK version constraints on profiles

2. All modules (common, factory, service, value)
   - Need explicit dependency on javax.annotation for Java 9+ support

SOLUTIONS APPLIED:
------------------
1. Added java9-plus-profile to handle Java 9+ without tools.jar
2. Added JDK version constraints [1.6,9) to legacy profiles
3. Added dependencyManagement to override tools.jar to use ${java.home}/lib/modules
4. Version mismatch fixed: Parent POM version changed from 4-SNAPSHOT to 3 to match module references
5. Need to add explicit javax.annotation dependency to modules for @Generated annotation
