# UltraJSON (ujson) Library - Notes for Fuzz Testing

## Overview
UltraJSON is an ultra-fast JSON encoder and decoder written in C with Python bindings.

## Key Functions for Fuzzing

### 1. ujson.loads()
- Decodes JSON string to Python object
- Main attack surface - parsing untrusted JSON
- C implementation - potential for memory issues

### 2. ujson.dumps()
- Encodes Python object to JSON string
- Options: indent, ensure_ascii, encode_html_chars, escape_forward_slashes
- Can have memory/refcount issues

### 3. ujson.decode() - alias for loads()

### 4. ujson.encode() - alias for dumps()

## Fuzzing Strategy
- Focus on ujson.loads() with malformed JSON strings
- Test edge cases: deeply nested objects, large numbers, unicode
- Test ujson.dumps() with complex Python objects
- Look for crashes, memory leaks, refcount issues
- Reference existing tests/fuzz.py for patterns

## Dependencies
- None (C extension module)
- Requires compilation with setup.py
