# MiniSGL Library - Notes for Fuzz Testing

## Overview
Mini-SGLang is a lightweight LLM inference framework (~5000 lines of Python).

## Key Functions for Fuzzing

### 1. Tokenizer
- Location: python/minisgl/tokenizer/
- Handles text tokenization for LLMs
- Input processing for models

### 2. Message handling
- Location: python/minisgl/message/
- Processes chat messages and prompts

### 3. Engine configuration
- Location: python/minisgl/engine/config.py
- Parses configuration options

### 4. Request handling
- Location: python/minisgl/server/
- HTTP request parsing

## Fuzzing Strategy
- Focus on tokenizer with random text inputs
- Test message formatting functions
- Test configuration parsing
- Test request/response handling

## Dependencies
- torch
- transformers
- numpy
- fastapi (for server)
