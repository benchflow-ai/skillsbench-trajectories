# Black Library - Notes for Fuzz Testing

## Overview
Black is an uncompromising Python code formatter that reformats entire files in place.

## Key Functions for Fuzzing

### 1. black.format_str()
- Location: src/black/__init__.py (line 1177)
- Main entry point for formatting Python source code
- Takes source code string and Mode object
- Returns formatted code string

### 2. black.lib2to3_parse()
- Location: src/black/parsing.py
- Parses Python source code into AST
- Uses lib2to3 grammar

### 3. black.parse_ast()
- Location: src/black/parsing.py  
- Alternative AST parsing function

### 4. blib2to3 parser
- Location: src/blib2to3/
- Low-level Python grammar parser

## Fuzzing Strategy
- Focus on format_str() with random/malformed Python code
- Test edge cases: syntax errors, unicode, very long lines
- Test various Mode configurations
- Look for crashes in the parser

## Dependencies
- click
- mypy_extensions
- pathspec
- platformdirs
- tomli (Python < 3.11)
