# Arrow Library - Notes for Fuzz Testing

## Overview
Arrow is a Python library for creating, manipulating, formatting and converting dates, times and timestamps.

## Key Functions for Fuzzing

### 1. arrow.get() - Primary parsing function
- Location: arrow/factory.py -> ArrowFactory.get()
- Takes various input types: strings, timestamps, datetime objects
- String parsing is the main attack surface for fuzzing
- Can parse ISO 8601 formats and custom formats

### 2. arrow.parser.DateTimeParser.parse()
- Location: arrow/parser.py
- Parses datetime strings with format patterns
- Complex regex-based parsing logic

### 3. arrow.Arrow.shift()
- Manipulates dates with relative offsets

### 4. arrow.Arrow.format()
- Formats Arrow objects to strings

## Fuzzing Strategy
- Focus on arrow.get() with random string inputs
- Test various malformed date/time strings
- Test edge cases: empty strings, very long strings, special characters
- Test format string parsing

- python-dateutil
- typing_extensions (for older Python)
