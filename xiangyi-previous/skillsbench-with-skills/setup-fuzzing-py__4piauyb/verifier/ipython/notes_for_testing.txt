Key functions / areas to fuzz in IPython:
- InputTransformer2.transform_cell(): transforms input code cell with token transformations.
- InputTransformer2.check_complete(): determines if code is complete/incomplete/invalid.
- InteractiveShell.run_cell(): executes transformed code; for fuzzing we can limit to transformation and compilation.
Focus on malformed Python snippets, multiline cells, magic-like syntax, and edge cases in tokenization.
