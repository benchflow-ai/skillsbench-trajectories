================================================================================
                            LIBRARY OVERVIEW
================================================================================

IPython is a powerful interactive computing environment for Python that provides:
- Enhanced interactive Python shell with syntax highlighting
- Magic commands (% and %% prefixes) for special operations
- System shell integration (! and !! prefixes)
- Help system (? and ?? suffixes)
- Tab completion with Jedi integration
- Input transformation and prefiltering
- Guarded evaluation for safe code execution

The library processes user input through multiple transformation stages:
1. Cleanup transforms (prompt stripping, indentation handling)
2. Line transforms (cell magic detection)
3. Token transforms (magic commands, system commands, help queries)
4. Prefiltering (autocall, alias handling)
5. Compilation and execution

Key Dependencies:
- decorator>=4.3.2
- jedi>=0.18.1 (for completion)
- prompt_toolkit>=3.0.41,<3.1.0
- pygments>=2.11.0
- stack_data>=0.6.0
- traitlets>=5.13.0
- pexpect>4.3 (POSIX only)

Python Version: Requires >=3.11

FUT #1: TransformerManager.transform_cell
------------------------------------------------------------------------------
Location: /app/ipython/IPython/core/inputtransformer2.py:635

Function Signature:
    def transform_cell(self, cell: str) -> str

Description:
    Main entry point for transforming IPython cell input into executable
    Python code. Handles magic commands, system calls, help queries, etc.

Why Good Fuzz Target:
    - Processes arbitrary user input strings
    - Contains complex regex and token-based parsing
    - Multiple transformation stages that could have edge cases
    - Core function that all IPython input passes through

Input Type: str (multiline Python/IPython code)

Harnessability: HIGH
    - Stateless function (after TransformerManager instantiation)
    - No side effects during transformation
    - Simple string input/output interface
    - No external dependencies during transformation

Oracles:
    - Should not raise unhandled exceptions on any input
    - Output should be valid Python (parseable by ast.parse)
    - Should complete within reasonable time (no infinite loops)
    - Should not consume excessive memory

Edge Cases to Test:
    - Empty string, whitespace only
    - Very long lines (>10KB)
    - Deeply nested brackets/parens
    - Unclosed strings, brackets
    - Mixed escape sequences (%magic, !shell, ?)
    - Unicode identifiers and strings
    - Null bytes and control characters
    - Backslash continuations at various positions
    - Cell magic (%%magic) with large bodies
    - Combinations: %magic? (magic + help)
    - Invalid escape combinations (%%%, !!!, ???)

================================================================================
                         SEED CORPUS IDEAS
================================================================================

1. Valid Python Code Samples:
   - Simple expressions: "1 + 2", "x = 5"
   - Function definitions
   - Class definitions
   - Comprehensions: "[x for x in range(10)]"
   - Lambda expressions
   - Async/await code
   - f-strings with expressions
   - Match statements (Python 3.10+)

2. IPython Magic Commands:
   - Line magics: "%ls", "%cd /home", "%timeit x+1"
   - Cell magics: "%%writefile test.py\nprint('hello')"
   - Magic with arguments: "%run -t script.py"
   - Magic assignment: "x = %who_ls"
   - Magic + help: "%magic?"

3. System Commands:
   - Simple: "!ls", "!pwd"
   - Capture: "x = !ls -la"
   - SH capture: "!!cat file.txt"
   - With variables: "!echo $PATH"

4. Help Queries:
   - Object help: "foo?", "foo??"
   - Magic help: "%magic?", "%%cell??"
   - Expression help: "os.path.join?"
   - Search: "?*pattern*"

5. Autocall Syntax:
   - Comma quote: ",print hello world"
   - Semicolon quote: ";print hello world"
   - Slash paren: "/print 1 2 3"

6. Edge Case Inputs:
   - Empty: ""
   - Whitespace: "   ", "\t\n"
   - Only special chars: "???", "!!!", "%%%"
   - Very long lines (10KB+)
   - Unicode: "# Comment with emoji"
   - Null bytes: "x = 1\x00y = 2"
   - Mixed encodings

7. Incomplete/Malformed Code:
   - Unclosed parens: "print("
   - Unclosed strings: "x = 'hello"
   - Unclosed brackets: "[1, 2, 3"
   - Dangling operators: "x +"
   - Invalid syntax: "def 123"

8. Prompt Patterns (for stripping):
   - Python: ">>> x = 1"
   - IPython: "In [1]: x = 1"
   - Continuation: "... y = 2"

9. Multiline Constructs:
   - Backslash continuation: "x = 1 +\\"
   - Implicit continuation in parens
   - Cell magics with multiline bodies
   - Functions with docstrings

10. From Test Files:
    - See /app/ipython/tests/test_inputtransformer2.py for examples
    - See /app/ipython/tests/test_splitinput.py for split_user_input cases

Harness Template for transform_cell:
------------------------------------
import atheris
import sys
from IPython.core.inputtransformer2 import TransformerManager

def fuzz_transform_cell(data):
    try:
        cell = data.decode('utf-8', errors='replace')
        tm = TransformerManager()
        result = tm.transform_cell(cell)
    except Exception as e:
        # Log but don't crash - we want to find hangs/crashes, not expected errors
        pass

if __name__ == "__main__":
    atheris.Setup(sys.argv, fuzz_transform_cell)
    atheris.Fuzz()
