Mini-SGLang Library - Lightweight LLM Inference Framework

Key Functions to Test:

1. Server API (server/api_server.py)
   - Request handling for OpenAI-compatible API
   - /v1/completions endpoint
   - /v1/chat/completions endpoint
   - Request validation and parsing
   - Error handling for malformed requests

2. Tokenizer (tokenizer/)
   - tokenize() - Tokenize input text
   - detokenize() - Convert tokens back to text
   - Handle various text encodings
   - Handle special tokens and edge cases

3. Scheduler (scheduler/scheduler.py)
   - Request scheduling logic
   - Batch management
   - Cache management
   - Prefill and decode scheduling

4. Message handling (message/)
   - Request and response message parsing
   - Message validation
   - Handle various message formats

5. Engine (engine/engine.py)
   - Model inference execution
   - Sampling strategies
   - Configuration handling

6. KV Cache (kvcache/)
   - Cache allocation and management
   - Radix cache operations

Fuzzing Strategy:
- Focus on API server with malformed HTTP requests
- Test tokenizer with various Unicode inputs and edge cases
- Test message parsing with invalid JSON and field values
- Test scheduler with edge case request patterns
- Include very long inputs, empty inputs, special characters
- Test with invalid model parameters and configurations
- Test concurrent request handling
