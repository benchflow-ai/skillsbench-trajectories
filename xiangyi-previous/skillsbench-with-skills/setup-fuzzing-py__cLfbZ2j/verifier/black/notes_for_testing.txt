Black Library - Python Code Formatter

Key Functions to Test:

1. format_str() - Main formatting function
   - Format Python source code strings
   - Handle various Python syntax versions
   - Test with different mode options
   - Handle malformed Python code

2. format_file_contents() - Format file contents
   - Format complete Python files
   - Handle encoding issues
   - Test with various newline formats

3. format_cell() - Format Jupyter notebook cells
   - Format individual code cells
   - Handle IPython magics

4. format_ipynb_string() - Format Jupyter notebooks
   - Parse and format entire notebooks
   - Handle notebook metadata

5. decode_bytes() - Decode source bytes
   - Handle various encodings
   - Detect newline formats

6. Parsing functions (parsing.py)
   - lib2to3_parse() - Parse Python code into AST
   - Handle syntax errors gracefully

7. String handling (strings.py)
   - normalize_string_quotes()
   - String prefix handling

Fuzzing Strategy:
- Focus on format_str() with random Python code snippets
- Test with malformed/invalid Python syntax
- Test edge cases in string literals (quotes, escapes, f-strings)
- Test various Python language features (async, walrus operator, etc.)
- Include Unicode and encoding edge cases
- Test with very long lines and deeply nested structures
