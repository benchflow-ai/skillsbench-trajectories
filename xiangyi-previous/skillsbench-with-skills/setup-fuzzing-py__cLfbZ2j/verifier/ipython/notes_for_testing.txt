IPython Library - Interactive Python Shell

Key Functions to Test:

1. Input transformation (inputtransformer2.py)
   - TransformerManager.transform_cell() - Transform IPython input
   - Handle magic commands (%magic, %%magic)
   - Handle shell commands (!command)
   - Handle help syntax (object?)
   - Parse IPython-specific syntax

2. Code completion (completer.py)
   - IPCompleter.completions() - Generate completions
   - Handle various completion contexts
   - Test with malformed input

3. Magic commands (magic.py, magics/)
   - Magic command parsing and execution
   - Line magics and cell magics
   - Test argument parsing

4. Safe evaluation (guarded_eval.py)
   - guarded_eval() - Safely evaluate expressions
   - Handle potentially dangerous code
   - Test with various Python expressions

5. Interactive shell (interactiveshell.py)
   - run_cell() - Execute code cells
   - run_line_magic() - Execute magic commands
   - Handle exceptions and errors

6. Code inspection (oinspect.py)
   - Inspector.info() - Get object information
   - Handle various object types

7. Prefilter (prefilter.py)
   - PrefilterManager.prefilter_lines() - Pre-process input
   - Transform special syntax

Fuzzing Strategy:
- Focus on inputtransformer2 with random IPython syntax
- Test magic command parsing with malformed arguments
- Test guarded_eval with potentially dangerous expressions
- Test completion with various code contexts
- Include edge cases in special syntax (?, !, %, %%)
- Test with Unicode and special characters
- Test nested and complex expressions
