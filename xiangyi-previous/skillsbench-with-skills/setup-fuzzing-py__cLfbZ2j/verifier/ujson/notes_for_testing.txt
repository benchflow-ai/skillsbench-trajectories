UltraJSON (ujson) Library - Fast JSON Encoder/Decoder

Key Functions to Test:

1. ujson.dumps() / ujson.encode() - Encode to JSON string
   - Serialize various Python objects (dict, list, str, int, float, bool, None)
   - Handle nested structures
   - Test with ensure_ascii, encode_html_chars options
   - Test with sort_keys, indent options
   - Test with allow_nan for NaN/Infinity values
   - Test with custom default serializer
   - Test with reject_bytes option

2. ujson.dump() - Encode to file
   - Write JSON to file-like objects
   - Handle encoding options

3. ujson.loads() / ujson.decode() - Decode from JSON string
   - Parse valid JSON strings
   - Handle various JSON types
   - Handle malformed JSON (should raise JSONDecodeError)
   - Test with bytes and bytearray inputs
   - Handle Unicode and escape sequences

4. ujson.load() - Decode from file
   - Read and parse JSON from file-like objects

5. Error handling
   - JSONDecodeError for invalid JSON
   - Handle edge cases and malformed input

Fuzzing Strategy:
- Focus on loads() with random/malformed JSON strings
- Test with deeply nested structures (stack overflow risks)
- Test with very long strings and numbers
- Test with invalid Unicode sequences
- Test with incomplete JSON (truncated input)
- Test dumps() with circular references (if applicable)
- Test with special float values (NaN, Inf, -Inf)
- Test with various escape sequences and special characters
- Test boundary conditions (empty strings, empty objects/arrays)
- Include non-UTF8 byte sequences
