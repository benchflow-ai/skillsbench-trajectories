### Basic Usage
```bash
node gmail-send.js --to "user@example.com" --subject "Hello" --body "Message body"
```

### Advanced Options
```bash
node gmail-send.js \
  --to "user@example.com" \
  --cc "cc@example.com" \
  --bcc "bcc@example.com" \
  --subject "Project Update" \
  --body "The project is complete." \
  --reply-to "reply@example.com"
```

### HTML Email
```bash
node gmail-send.js \
  --to "user@example.com" \
  --subject "Newsletter" \
  --html "<h1>Welcome</h1><p>This is HTML content</p>"
```
