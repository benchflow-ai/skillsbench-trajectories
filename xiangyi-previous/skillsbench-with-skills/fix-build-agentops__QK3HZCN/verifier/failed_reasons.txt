Analysis:
- agentops.init() defaults to auto_start_session=True with tags=None. Client.__init__ only sets _tags_for_future_session when auto_start_session=False, yet start_session() uses tags or self._tags_for_future_session. This means the default init path raises AttributeError before any tests run (ex: tests/test_events.py uses agentops.init(api_key=...) with default auto_start_session True).
- agentops/worker.py uses built-in generics (list[Dict]) which is invalid on Python 3.7/3.8 even though pyproject.toml declares requires-python >=3.7. This causes import-time failures on those runtimes.

Plan:
1) Initialize _tags_for_future_session unconditionally in Client.__init__ and make start_session use a safe fallback (getattr) so auto_start_session works without tags.
2) Replace list[Dict] annotation in Worker with typing.List[Dict] for Python 3.7+ compatibility.
