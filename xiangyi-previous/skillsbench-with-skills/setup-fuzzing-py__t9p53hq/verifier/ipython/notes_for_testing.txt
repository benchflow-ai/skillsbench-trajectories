FUZZ TESTING NOTES FOR IPYTHON LIBRARY
=======================================

TARGET LIBRARY: ipython (interactive Python computing environment)
Main Purpose: Provides interactive Python shell with magic commands, special syntax, and execution management

PRIMARY FUZZ TARGETS:
======================

   - Input: Raw cell string with potential IPython magic/escape sequences
   - Output: Transformed Python code string
   - Why fuzz: Transforms IPython-specific syntax into valid Python
   - Fuzzing focus:
     * Magic command variations: %, %%, !
     * Shell command escapes: !, !!, ?
     * Help syntax: ?, ??
     * Edge cases in magic command names/arguments
     * Mixed escapes and regular code
     * Whitespace handling with escapes
     * Unicode in magic commands/arguments
     * Nested quotes in magic arguments
     * Backslash handling at line boundaries

2. PrefilterManager.prefilter_lines(lines)
   - File: /app/ipython/IPython/core/prefilter.py (line ~350)
   - Input: Raw input lines string
   - Output: Transformed Python code
   - Why fuzz: Dynamic line-by-line transformations
   - Fuzzing focus:
     * Single-line magic commands
     * System commands (!command)
     * Autocall detection edge cases
     * Multiple transformations on same line
     * Comments after special syntax
     * Continuation lines with escapes

IPython SPECIAL SYNTAX ELEMENTS:
================================
Magic Commands:
  - Line magic: %magic_name args
  - Cell magic: %%magic_name args
  - Shell command: !command or !!command
  - Help syntax: ?object or ??object
  - Escape chars: /, , (comma/semicolon for code escapes)

Transformers:
  - MagicAssign: a = %magic → get_ipython().run_line_magic()
  - SystemAssign: a = !cmd → get_ipython().getoutput()
  - EscapedCommand: Handles !, !!, ?, ??
  - HelpEnd: Transforms help syntax

ORACLE PROPERTIES:
===================
1. No panics on any input (especially edge cases)
2. Transformations produce valid Python code
3. Round-trip: transformed code should be syntactically valid
4. Magic command names must match registered magics
5. Escaped sequences should be properly converted
6. Unicode handling in all edge cases
7. Compiler flags handled correctly

SEED CORPUS IDEAS:
===================
- Basic cells: x = 1, print("hello")
- Magic commands: %time x, %%timeit, %cd /path
- Shell commands: !ls, !!pwd, !echo hello
- Help syntax: ?str, ??list, ?len
- Assignments with magic: x = %magic_cmd
- Comments: # comment, % in comments
- Multi-line: def f():\n    pass
- Edge cases: empty lines, only whitespace, only escapes
- Mixed syntax: x = !command  # comment
- Unicode: %magic_命令, x = "日本語"
- Long commands: very long magic/shell arguments
- Invalid escapes: %invalid_magic, ??nonsense

IMPORTANT DETAILS:
===================
- Main entry: InteractiveShell.run_cell()
- Transformer chain defined in inputtransformer2.py
- Prefilter is legacy, still used for single-line handling
- Compiler caches compiled code with unique filenames
- Input history is tracked in HistoryManager
- Max recursion depth depends on Python limits
