Error Analysis:
The test `tests/test_events.py::TestEvents::test_record_timestamp` is failing because the timestamps don't have sufficient precision.

Root Cause:
The `get_ISO_time()` function in `agentops/helpers.py` uses `timespec='milliseconds'` which only provides 3 decimal places of precision (e.g., '2024-05-04T02:36:17.528Z'). When an ActionEvent is instantiated, both `init_timestamp` and `end_timestamp` are set using the same default factory `get_ISO_time()`. If the event is recorded within the same millisecond it was created, both timestamps will be identical.

The test expects that after a 0.15 second sleep between event creation and recording, the timestamps should be different. However, with only millisecond precision, if both operations happen within the same millisecond, the timestamps appear identical.

Fix:
Increase timestamp precision from milliseconds to microseconds by changing `timespec='milliseconds'` to `timespec='microseconds'` in the `get_ISO_time()` function. This will provide 6 decimal places of precision, allowing sub-millisecond differences to be captured.
