Key functions and behaviors to fuzz:
- black.format_str: core formatter for Python source strings; exercises parsing and formatting logic.
- black.format_file_contents: handles input with/without trailing newline, stdin-like content.
- black.files.parse_pyproject_toml: parses config files and validates types/values.
- black.mode.Mode: configuration flags (line length, preview/target versions) that influence formatting.
