UltraJSON (ujson) Library - Fuzzing Analysis Notes

Library: UltraJSON - Ultra fast JSON encoder/decoder
Purpose: High-performance JSON parsing and encoding

IMPORTANT FILES FOR FUZZING:
1. src/ujson/__init__.py - Main API (loads, dumps, etc.)
2. Native C extension - Core JSON parsing (HIGH PRIORITY)

KEY FUNCTIONS FOR FUZZING:

1. ujson.loads(json_string)
   - Parses JSON string to Python objects
   - Input: JSON string (untrusted user input)
   - HIGH-VALUE TARGET: Native C code parsing
   - Potential issues: buffer overflows, integer overflows, stack exhaustion
   - Known vectors: deeply nested JSON, very long strings, large numbers

2. ujson.dumps(obj)
   - Serializes Python objects to JSON string
   - Input: Python objects
   - Potential issues: infinite recursion, circular references
   - Edge cases: special float values, large integers

3. ujson.decode(json_string)
   - Alternative name for loads
   - Same attack surface as loads()

4. ujson.encode(obj)
   - Alternative name for dumps
   - Same attack surface as dumps()

RECOMMENDED FUZZ TARGETS:
1. PRIMARY: ujson.loads(malformed_json_string)
   - Most critical - parses untrusted input in native code
   - Test with: deeply nested arrays/objects, invalid UTF-8, large numbers,
     escape sequences, null bytes, extremely long strings

2. SECONDARY: ujson.dumps(complex_python_object)
   - Test with: circular references, deeply nested structures,
     special numeric values (inf, nan), large objects

TEST COVERAGE GAPS:
- Malformed JSON with various syntax errors
- Deeply nested structures (>1000 levels)
- Very long string values (>1MB)
- Invalid UTF-8 sequences
- Integer overflow cases
- Floating point edge cases (inf, -inf, nan)
- Null bytes in strings
- Invalid escape sequences
- Truncated JSON
- Mixed valid/invalid JSON

FUZZING PRIORITY: HIGHEST
- Native C code makes this the highest priority for fuzzing
- Potential for memory corruption vulnerabilities
- Wide attack surface from untrusted JSON input
