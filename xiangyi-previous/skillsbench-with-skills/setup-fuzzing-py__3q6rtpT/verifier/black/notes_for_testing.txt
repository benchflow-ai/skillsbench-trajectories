Black Library - Fuzzing Analysis Notes

Library: Black - The uncompromising Python code formatter
Purpose: Opinionated Python code formatter

IMPORTANT FILES FOR FUZZING:
1. src/black/parsing.py - Python source parsing (HIGH PRIORITY)
2. src/black/__init__.py - Main formatting functions
3. src/black/linegen.py - Line generation/transformation
4. src/black/handle_ipynb_magics.py - Jupyter notebook handling
5. src/blib2to3/pytree.py - Parse tree manipulation

KEY FUNCTIONS FOR FUZZING:

1. black.format_str(src_contents, mode)
   - Main entry point for formatting Python code strings
   - Input: Python source code as string
   - High-value target: parses and transforms user code
   - Potential issues: AST crashes, infinite loops, memory exhaustion

2. black.parsing.lib2to3_parse(src_txt)
   - Parses Python source into AST
   - Input: Python source string
   - Known to have edge cases with malformed syntax

3. black.format_file_contents(src_contents, fast, mode)
   - Formats file contents with safety checks
   - Handles Jupyter notebooks (JSON parsing)
   - Multiple code paths based on mode

4. black.format_ipynb_string(src_contents, fast, mode)
   - Formats Jupyter notebook JSON
   - Input: JSON string
   - JSON parsing + cell formatting

5. black.decode_bytes(src, mode)
   - Decodes bytes to string with encoding detection
   - Handles CRLF/LF newline detection
   - Tokenization edge cases

RECOMMENDED FUZZ TARGETS:
1. Primary: black.format_str(code_string, mode=black.Mode())
2. Secondary: black.format_ipynb_string(json_string, fast=True, mode=black.Mode())
3. Tertiary: black.parsing.lib2to3_parse(src_string)

TEST COVERAGE GAPS:
- Deeply nested Python syntax
- Malformed source with partial syntax
- Edge case encodings (UTF-16, invalid UTF-8)
- Very long lines
- Mixed newline types
- Invalid Jupyter notebook JSON
