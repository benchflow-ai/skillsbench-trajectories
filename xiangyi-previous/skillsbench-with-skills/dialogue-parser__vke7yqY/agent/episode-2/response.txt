Based on the analysis of the `script.txt` format and the task requirements, I have a plan to implement the parser.

1.  **Parsing Strategy**:
    *   Read the file line by line.
    *   Identify node blocks starting with `[NodeID]`.
    *   Within each block, identify lines as either "Choice" (starting with a number) or "Line" (Speaker: Text).
    *   Extract `from`, `to`, `text`, `speaker` information.
    *   Handle the `->` separator carefully by splitting from the right to handle potential `->` in the text (though unlikely, it's safer).

2.  **Validation**:
    *   Perform a Breadth-First Search (BFS) starting from the first node found in the file.
    *   Identify all reachable nodes.
    *   Filter the parsed nodes and edges to include only those reachable from the start, satisfying the "All nodes must be reachable" constraint.
    *   Allow edges to point to "End" even if "End" is not defined as a node block.

3.  **Output**:
    *   `dialogue.json`: The structured graph.
    *   `dialogue.dot`: The Graphviz representation.

4.  **Implementation**:
    *   I will write the python script `solution.py` which contains the `parse_script` function and the main execution block.
