Ujson Library - Key Functions for Testing

Ujson is an ultra-fast JSON encoder and decoder written in C with Python bindings.

Key Functions to Test:
1. ujson.loads() - Parse JSON string to Python objects
2. ujson.dumps() - Encode Python objects to JSON string
3. ujson.load() - Load JSON from file
4. ujson.dump() - Dump Python objects to file as JSON
5. JSONtoObj.c - JSON parsing implementation
6. objToJSON.c - JSON encoding implementation

Key Parameters and Options:
- encode_html_chars - Escape HTML characters in output
- escape_forward_slashes - Escape forward slashes
- ensure_ascii - Escape non-ASCII characters
- sort_keys - Sort object keys in output
- indent - Pretty-print with indentation
- default - Custom encoder for non-serializable objects
- object_hook - Custom decoder hook for objects
- parse_float - Custom float parser
- parse_int - Custom int parser

Fuzzing Focus Areas:
- Malformed JSON strings (invalid syntax, incomplete structures)
- Deeply nested JSON structures (stack overflow testing)
- Large JSON payloads (memory exhaustion)
- Unicode and escape sequence handling
- Numeric edge cases (very large numbers, NaN, Infinity)
- Circular reference detection
- Custom encoder/decoder hook edge cases
- Empty and null value handling
- Array and object boundary conditions
