Arrow Library - Key Functions for Testing

Arrow is a Python datetime library providing intuitive datetime manipulation.

Key Functions and Classes to Test:
1. Arrow class (__init__, __str__, __repr__) - Core datetime wrapper
2. arrow.now() - Get current time
3. arrow.utcnow() - Get current UTC time
4. arrow.get() - Parse and create Arrow objects from various inputs (strings, timestamps, datetime)
5. Arrow.parse() - Parse datetime strings with various formats
6. Arrow.strftime() - Format datetime to string
7. Arrow.shift() - Shift datetime by time units
8. Arrow.replace() - Replace datetime components
9. Arrow.humanize() - Convert to human-readable relative time
10. Arrow.isoformat() - ISO 8601 formatting
11. Arrow.to() - Convert between timezones
12. Arrow.span() - Get start/end of time periods
13. Factory.get() - Factory method for creating Arrow objects
14. Parser.parse() - Parse various datetime string formats

Fuzzing Focus Areas:
- Parsing arbitrary strings as datetime input
- Timezone conversions and edge cases
- Format string handling
- Datetime arithmetic with extreme values
- Locale-specific parsing
