Minisgl Library - Key Functions for Testing

Minisgl is a lightweight LLM (Large Language Model) inference framework.

Key Functions and Classes to Test:
1. LLM.__init__() - Initialize LLM with model path and parameters
2. LLM.generate() - Generate text from prompts with sampling parameters
3. LLM._tokenize_one() - Tokenize a single prompt (string or token list)
4. LLM.offline_receive_msg() - Receive and process inference requests
5. LLM.offline_send_result() - Process and return inference results
6. SamplingParams class - Sampling configuration (temperature, top_k, top_p)
7. Req class - Individual inference request representation
8. Batch class - Batch of requests for processing
9. Scheduler.run_forever() - Main inference loop
10. Tokenizer.encode() - Encode text to token IDs
11. Tokenizer.decode() - Decode token IDs to text
12. Engine forward pass - Process batches through model
13. Attention backend - Handle attention computation
14. KV Cache management - Cache key-value pairs

Fuzzing Focus Areas:
- Tokenization with various text encodings and edge cases
- Invalid sampling parameters (extreme values, NaN, Inf)
- Batch processing with varying sizes and content
- Token ID sequences with out-of-range values
- Memory management with large batches
- Concurrent request handling
- Error handling for invalid model paths
- Tensor shape mismatches
