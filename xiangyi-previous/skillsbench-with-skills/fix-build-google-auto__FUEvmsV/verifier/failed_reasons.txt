Build fails with mvn -f build-pom.xml verify because Maven cannot resolve com.sun:tools:jar at ${java.home}/../lib/tools.jar on JDK 11 (tools.jar removed). The dependency comes from compile-testing (0.6/0.7) test dependency in module poms. The com.sun:tools dependency is system-scoped and requires tools.jar, which is not present on JDK 9+.

Plan: Update module POMs (common, factory, service, value) to exclude com.sun:tools from compile-testing test dependency. This avoids the tools.jar system dependency on JDK 11. Then rebuild.
