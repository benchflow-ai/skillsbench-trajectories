Arrow Library - Analysis for Fuzzing
====================================

Library: arrow (Date/Time library)
Main Source: /app/arrow/arrow/

PRIORITY 1 - Critical Functions to Fuzz:
-----------------------------------------
1. arrow.get() - Main parsing entry point (api.py:83)
   - Fuzz with: malformed datetime strings, various formats
   - Key targets: string + format pairs, locale parsing

2. DateTimeParser.parse() - Custom format parsing (parser.py:373)
   - Fuzz with: invalid format strings, mismatched tokens
   - Risk: regex errors, token matching failures

3. DateTimeParser.parse_iso() - ISO 8601 parsing (parser.py:252)
   - Fuzz with: malformed ISO strings, invalid separators
   - Risk: timezone format errors, malformed time components

4. Arrow.dehumanize() - Human-readable time parsing (arrow.py:1344)
   - Fuzz with: crafted relative time strings
   - Risk: regex injection vulnerabilities

PRIORITY 2 - Complex Logic:
---------------------------
5. Arrow.shift() - Relative time shifts (arrow.py:996)
   - Fuzz with: overflow values (10^9 years), DST transitions
   - Risk: imaginary times, invalid frame names

6. Arrow.span() / span_range() - Time span calculations (arrow.py:504, 643)
   - Fuzz with: invalid frame parameters, boundary conditions
   - Risk: iteration overflow, timezone edge cases

7. TzinfoParser.parse() - Timezone parsing (parser.py:895)
   - Fuzz with: invalid timezone names, malformed offsets
   - Risk: ZoneInfo lookup failures

PRIORITY 3 - Format String Functions:
-------------------------------------
8. Arrow.format() - String formatting (arrow.py:1105)
   - Fuzz with: invalid format tokens, special characters
   - Risk: format string vulnerabilities

9. DateTimeFormatter.format() - Core formatting (formatter.py:37)
   - Fuzz with: boundary values, timezone edge cases
   - Risk: min/max date handling

KEY VULNERABILITY AREAS:
------------------------
- Parser regex patterns (parser.py - 33KB of complex regex)
- Date arithmetic edge cases (arrow.py - 65KB)
- Timezone conversion logic
- Humanization/dehumanization patterns

FUZZING STRATEGIES:
------------------
1. String fuzzing: Random datetime formats, malformed ISO strings
2. Integer overflow: Extreme date/time/timestamp values
3. Format injection: Special characters in format strings
4. Locale testing: Month/day names in different languages
5. DST testing: Imaginary/non-existent times during transitions
6. Timezone edge cases: Invalid TZ names, offset formats

CRITICAL FILES:
---------------
- /app/arrow/arrow/parser.py - Parsing logic (PRIMARY TARGET)
- /app/arrow/arrow/arrow.py - Core Arrow class
- /app/arrow/arrow/formatter.py - Formatting logic
- /app/arrow/arrow/factory.py - Input handling
