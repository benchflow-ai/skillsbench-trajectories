KEY VULNERABILITY AREAS:
------------------------
- Code execution pipeline (run_cell, ast_parse, transform_cell)
- Input transformation system (escape sequences, magic commands)
- Shell command execution (arg_split, system commands)
- Path handling (expand_user, protect_filename)
- Quote and bracket matching (has_open_quotes, has_sunken_brackets)
- AST manipulation (name mangling, code transformers)
- Display formatting (HTML, JavaScript, Markdown rendering)
- Argument parsing for magic commands

FUZZING STRATEGIES:
------------------
1. Code injection: crafted Python syntax with special characters
2. Escape sequence bypass: %magic, !system command injection
3. Path traversal: crafted paths with .., ~ expansion
4. Shell injection: special shell characters in commands
5. Quote/bracket edge cases: unbalanced, nested, escaped
6. XSS patterns: HTML/JS in display functions
7. Regex bombs: catastrophic backtracking patterns
8. AST corruption: malformed AST nodes
9. Unicode edge cases: encoding issues, normalization
10. Magic command injection: crafted argument patterns
