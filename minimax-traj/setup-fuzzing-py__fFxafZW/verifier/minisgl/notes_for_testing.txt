MiniSGL Library - Functions to Fuzz
====================================

Library Purpose: MiniSGL appears to be a graphics/ML library with attention mechanisms and tensor operations.

Key Classes and Functions for Testing:
--------------------------------------

1. **minisgl.core.SamplingParams** (core.py:14-24)
   - Controls sampling for generation
   - Fields: temperature, top_k, top_p, ignore_eos, max_tokens
   - CRITICAL: Parameter validation for generation

2. **minisgl.core.Req** (core.py:27-66)
   - Request handling class
   - Properties: can_decode(), complete_one(), append_host()
   - Tensor operations and validation
   - CRITICAL: Input tensor validation

3. **minisgl.core.Batch** (core.py:69-95)
   - Batch processing class
   - Handles multiple requests
   - Properties for batch management

4. **minisgl.core.Context** (core.py:98-130)
   - Global context management
   - Methods: set_global_ctx(), get_global_ctx()
   - Manages attention backend and batches

5. **Attention backends** (attention/*.py)
   - Various attention implementation backends
   - CRITICAL: Tensor computations

6. **LLM components** (llm/*.py)
   - Language model components
   - Token processing

Fuzzing Strategy:
-----------------
- Invalid tensor shapes and types
- Extreme values for sampling parameters
- Empty or malformed batches
- Invalid context states
- Unicode in text inputs
- Very long sequences
- Invalid device placements
- Memory exhaustion with large batches

Files to examine: core.py, attention/*.py, llm/*.py, engine/*.py, layers/*.py
