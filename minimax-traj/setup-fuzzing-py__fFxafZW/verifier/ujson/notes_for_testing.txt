UJSON Library - Functions to Fuzz
=================================

Library Purpose: UJSON is a fast JSON encoder and decoder for Python (C extension).

Key Functions for Testing:
--------------------------

1. **ujson.dumps()**
   - JSON encoding (Python object to JSON string)
   - Takes Python objects (dict, list, str, int, float, bool, None)
   - CRITICAL: Most commonly used function

2. **ujson.loads()**
   - JSON decoding (JSON string to Python object)
   - Takes JSON string
   - CRITICAL: Input validation for malformed JSON

3. **ujson.decode()**
   - Low-level JSON decoding
   - Direct parsing interface

4. **objToJSON.c** (python/objToJSON.c)
   - C implementation of JSON encoding
   - Handles various Python types
   - CRITICAL: Buffer overflow, type confusion

5. **JSONtoObj.c** (python/JSONtoObj.c)
   - C implementation of JSON decoding
   - CRITICAL: Malformed JSON handling

Fuzzing Strategy:
-----------------
- Malformed JSON (missing brackets, invalid escape sequences)
- Extremely nested JSON structures
- Very long strings and keys
- Unicode in JSON (various encodings)
- Invalid numbers (NaN, Infinity, very large numbers)
- Type confusion (arrays vs objects)
- Buffer overflow with long inputs
- Null bytes in strings
- Concurrent access patterns

Files to examine: python/ujson.c, python/objToJSON.c, python/JSONtoObj.c, lib/ultrajsonenc.c, lib/ultrajsondec.c
