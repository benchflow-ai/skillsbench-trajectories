Arrow Library - Functions to Fuzz
====================================

Library Purpose: Arrow is a Python library for dates and times that provides an intelligent, smart API for handling dates.

Key Functions for Testing:
---------------------------

1. **arrow.get()** (api.py:83-86)
   - Primary function for parsing various date/time inputs
   - Handles strings, datetime objects, timestamps, tuples
   - Parameters: args (various types), locale, tzinfo, normalize_whitespace
   - CRITICAL: Input validation and parsing edge cases

2. **arrow.Arrow class** (arrow.py)
   - Main class for representing dates/times
   - Key methods: format(), span(), range(), to(), replace()
   - Date arithmetic and manipulation
   - Timezone conversions

3. **arrow.now()** (api.py:101-104)
   - Creates current time with timezone
   - Simple but important for basic functionality

4. **arrow.utcnow()** (api.py:92-95)
   - Creates current UTC time
   - No parameters, straightforward

5. **arrow.factory.ArrowFactory** (factory.py)
   - Factory pattern for creating Arrow instances
   - Handles various input types

Fuzzing Strategy:
-----------------
- Test various string formats for dates (RFC formats, custom formats)
- Invalid date strings, edge case dates
- Timezone strings (valid and invalid)
- Timestamp values (floats, integers)
- Unicode input in date strings
- Very long strings
- Null/empty inputs

Files to examine: arrow.py, api.py, factory.py, parser.py, formatter.py
