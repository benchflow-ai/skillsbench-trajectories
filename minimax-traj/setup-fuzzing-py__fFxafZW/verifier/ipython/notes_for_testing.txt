IPython Library - Functions to Fuzz
====================================

Library Purpose: IPython provides a rich toolkit for interactive computing with Python.

Key Functions for Testing:
--------------------------

1. **IPython.core.interactiveshell.InteractiveShell** (interactiveshell.py)
   - Main shell class for interactive sessions
   - Methods: run_cell(), run_code(), execute()
   - CRITICAL: Code execution and input handling

2. **IPython.core.formatters.FormatterBase** (formatters.py)
   - Base class for output formatters
   - Methods: format(), print_record()
   - Handles various output types

3. **IPython.core.completer.Completer** (completer.py)
   - Code completion functionality
   - Handles various completion contexts
   - CRITICAL: User input for completion

4. **IPython.core.oinspect.inspect_pdb()** (oinspect.py)
   - Object inspection functionality
   - Handles various object types

5. **IPython.core.inputtransformer2** (inputtransformer2.py)
   - Transforms input before execution
   - Handles magic commands, special syntax

6. **IPython.utils.decorators** (util.py)
   - Utility functions for various operations

Fuzzing Strategy:
-----------------
- Malformed Python code snippets
- Invalid magic commands
- Unicode input, special characters
- Very long inputs (code, docstrings)
- Invalid object types for inspection
- Edge cases in code completion
- Malformed IPython-specific syntax
- Nested structures in cell magics

Files to examine: interactiveshell.py, formatters.py, completer.py, oinspect.py, inputtransformer2.py
