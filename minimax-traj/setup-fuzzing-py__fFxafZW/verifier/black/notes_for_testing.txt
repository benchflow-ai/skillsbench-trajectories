Black Library - Functions to Fuzz
==================================

Library Purpose: Black is the uncompromising Python code formatter that formats Python code to follow a consistent style.

Key Functions for Testing:
--------------------------

1. **black.format_str()** (__init__.py:1177-1221)
   - Primary API for formatting Python code strings
   - Takes source code string and Mode object
   - Returns formatted code string
   - CRITICAL: This is the main entry point for fuzzing

2. **black.format_file_contents()** (__init__.py:1068-1093)
   - Formats file contents with safety checks
   - Handles fast mode vs normal mode
   - Validates output equivalence

3. **black._format_str_once()** (__init__.py:1224-1298)
   - Internal formatting function
   - AST parsing and transformation
   - Line generation and formatting

4. **black.main()** (__init__.py:516-730)
   - Command-line interface
   - Handles file processing, configuration
   - Multiple file formatting

5. **black.parse_ast()** (parsing.py)
   - Parses Python code into AST
   - Error handling for invalid syntax
   - CRITICAL: Needs fuzzing for malformed inputs

6. **black.lib2to3_parse()** (parsing.py)
   - Parses source using lib2to3
   - Handles Python syntax variations

Fuzzing Strategy:
-----------------
- Malformed Python code (syntax errors, incomplete code)
- Unicode strings, special characters
- Very long lines, deeply nested structures
- Edge cases in f-strings, comments, docstrings
- Invalid Mode configurations
- Empty files, binary data as input
- Memory exhaustion with large inputs

Files to examine: __init__.py, parsing.py, linegen.py, trans.py, nodes.py
