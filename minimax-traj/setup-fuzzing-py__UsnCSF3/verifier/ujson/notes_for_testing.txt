# ujson Library - Important Functions for Fuzzing

## Library Overview
ujson is a fast JSON encoder/decoder for Python written in C.

## Key Functions to Test

### 1. ujson.loads() - JSON deserialization
- Parse JSON strings to Python objects
- Accepts: str, bytes, bytearray
- Returns: dict, list, str, int, float, bool, None
- Raises: ValueError on invalid JSON

### 2. ujson.dumps() - JSON serialization
- Serialize Python objects to JSON strings
- Accepts: dict, list, str, int, float, bool, None
- Parameters: ensure_ascii, indent, escape_forward_slashes, sort_keys
- Returns: str

### 3. ujson.load() - File-based JSON reading
- Read JSON from file-like object

### 4. ujson.dump() - File-based JSON writing
- Write Python objects to file as JSON

### 5. objToJSON() C function (internal)
- C-level object to JSON conversion

### 6. JSONtoObj() C function (internal)
- C-level JSON parsing

## Fuzzing Strategy
- Fuzz `loads()` with random strings (potential for edge cases in parsing)
- Fuzz `dumps()` with various Python object structures
- Test edge cases: unicode, special characters, deep nesting
- Test integer/float parsing edge cases
- Test object key ordering and escaping

## Note
ujson is a C extension, so fuzzing needs to handle the compiled module properly.
