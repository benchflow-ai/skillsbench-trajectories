UJSON Library - Important Functions for Fuzzing
==============================================

Library Description:
- ujson is a fast JSON encoder/decoder for Python
- Written in C for performance, with Python bindings

Key Functions to Test:

1. Main JSON Functions:
   - ujson.dumps() - Serialize Python object to JSON string
     - Accepts: dict, list, str, int, float, bool, None
     - Parameters: obj, ensure_ascii, indent, separators, sort_keys

   - ujson.loads() - Deserialize JSON string to Python object
     - Parses JSON and returns corresponding Python types
     - Handles various JSON structures

2. File Operations:
   - ujson.dump() - Serialize to file
   - ujson.load() - Deserialize from file

3. String Operations:
   - ujson.dumpb() - Dump to bytes
   - ujson.loadb() - Load from bytes

Fuzzing Strategy:
- Test dumps() with various Python objects:
  - Deeply nested structures
  - Unicode strings and special characters
  - Large numbers (float, int boundaries)
  - Edge cases: empty dict/list, None values
- Test loads() with malformed JSON:
  - Invalid JSON syntax
  - Unexpected tokens
  - Truncated strings
  - Very long strings
- Test with various encoding scenarios
- Test performance with large objects

Dependencies:
- Minimal pure C library with Python bindings
- No external Python dependencies
- Built as C extension module
