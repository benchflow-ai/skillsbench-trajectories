MiniSGL Library - Important Functions for Fuzzing
================================================

Library Description:
- MiniSGL appears to be a machine learning/deep learning library
- Contains layers, utilities, and distributed training features

Key Functions to Test:

1. Core Model Functions:
   - minisgl.core 模块 - Core functionality
     - Model initialization, forward/backward passes
     - Training loops and optimization

2. Layer Implementations:
   - minisgl.layers.linear - Linear/Dense layer operations
   - minisgl.layers.embedding - Embedding layers
   - minisgl.layers.norm - Normalization layers
   - minisgl.layers.rotary - Rotary positional encoding

3. Distributed Training:
   - minisgl.distributed 模块 - Distributed training
     - Multi-GPU/multi-node training utilities
     - Communication primitives

4. Utility Functions:
   - minisgl.utils.misc - General utilities
   - minisgl.utils.torch_utils - PyTorch integration helpers
   - minisgl.utils.hf - HuggingFace integration
   - minisgl.utils.logger - Logging utilities
   - minisgl.utils.mp - Multiprocessing utilities
   - minisgl.utils.arch - Architecture detection

5. Benchmark:
   - minisgl.benchmark - Performance benchmarking tools

Fuzzing Strategy:
- Test layer operations with various tensor shapes
- Test linear layer with different input/output dimensions
- Test embedding with invalid indices
- Test normalization with edge case values (zeros, NaN, inf)
- Test distributed functions with invalid configurations
- Test utility functions with malformed inputs

Dependencies:
- Likely has dependencies on PyTorch/TensorFlow for deep learning
- May depend on HuggingFace transformers
- Communication libraries for distributed training
