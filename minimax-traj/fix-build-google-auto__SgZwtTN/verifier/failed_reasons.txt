# Build Error Analysis for auto-value Java Project

## Summary
The build was failing due to multiple issues related to Java version compatibility and missing dependencies:

### Issue 1: Missing Snapshot Dependency
- **Dependency**: `com.google.auto:auto-common:jar:1.0-SNAPSHOT`
- **Problem**: This snapshot version was no longer available in public repositories
- **Solution**: Updated to released version `1.0`

### Issue 2: Missing tools.jar for Java 11
- **Dependency**: `com.sun:tools:jar:11.0.27`
- **Problem**: The `compile-testing:0.6` library had a system-scoped dependency on `tools.jar`,
  which was removed in Java 9+. Java 11 doesn't have a separate tools.jar file.
- **Solution**: Updated `compile-testing` from `0.6` to `0.18` which supports Java 9+ via
  `--add-exports` flags instead of relying on tools.jar.

### Issue 3: Missing javax.annotation.Generated
- **Dependency**: `javax.annotation:javax.annotation-api`
- **Problem**: `javax.annotation.Generated` was removed from the JDK in Java 9+ and is no longer
  available without an explicit dependency.
- **Solution**: Added `javax.annotation-api:1.3.2` as a compile dependency.

### Additional Fix: Java 9+ Module Configuration
- Added `maven-surefire-plugin` configuration with JVM arguments for Java 9+ module exports
  to allow access to internal JDK compiler APIs.

## Files Modified
1. `/home/travis/build/failed/google/auto/value/pom.xml`:
   - Changed `auto-common` version from `1.0-SNAPSHOT` to `1.0`
   - Changed `compile-testing` version from `0.6` to `0.18`

   - Added `maven-surefire-plugin` with `--add-exports` and `--add-opens` flags

## Build Verification
- `mvn clean compile -DskipTests` now completes successfully
- Only deprecation warnings remain (expected for Java 1.6 source/target on Java 11)
