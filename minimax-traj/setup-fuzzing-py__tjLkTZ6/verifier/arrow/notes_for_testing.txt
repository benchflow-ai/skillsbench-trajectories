Arrow Library - Fuzz Testing Notes
==================================

Library Purpose:
Arrow is a Python library for handling dates and times with a focus on parsing, formatting, and manipulation of datetime objects.

Key Functions to Fuzz:
----------------------

1. DateTimeParser.parse() - /app/arrow/arrow/parser.py:373
   - Purpose: Parse datetime strings using specified format(s)
   - Input: datetime_string (str), fmt (Union[List[str], str])
   - Fuzz Priority: HIGH
   - Why: Complex regex-based parsing with many edge cases, timezone handling

2. DateTimeParser.parse_iso() - /app/arrow/arrow/parser.py:252
   - Purpose: Parse ISO 8601-like datetime strings
   - Input: datetime_string (str), normalize_whitespace (bool)
   - Fuzz Priority: HIGH
   - Why: ISO 8601 parsing is complex with many variants and edge cases

3. ArrowFactory.get() - /app/arrow/arrow/factory.py
   - Purpose: Main API for creating Arrow datetime objects
   - Input: Various formats (Arrow, datetime, date, int, float, str, tuple)
   - Fuzz Priority: HIGH
   - Why: Primary entry point, handles multiple input types

4. TzinfoParser.parse() - /app/arrow/arrow/parser.py:895
   - Purpose: Parse timezone strings
   - Input: tzinfo_string (str)
   - Fuzz Priority: MEDIUM
   - Why: Timezone parsing has many formats and edge cases

Fuzz Strategy:
-------------
- Focus on malformed datetime strings
- Test various ISO 8601 formats
- Boundary testing for dates/times
- Invalid timezone strings
- Unicode and special characters
- Very long strings
- Empty or whitespace strings

Oracles:
--------
- No crashes or unhandled exceptions
- ParserError exceptions are acceptable for invalid input
- Returned datetime objects should be valid
- Timezone-aware vs naive datetime consistency
