Step 1: Analysis of the repository
The build failure is caused by a failing test in 'tests/test_events.py'. The test 'test_record_timestamp' fails because 'init_timestamp' and 'end_timestamp' are equal even after a sleep and a call to 'agentops.record(event)'. This happens because 'agentops.record(event)' returns early if no session is active, skipping the 'end_timestamp' update. The missing session is likely due to the 'Client' being a singleton and not being properly re-initialized between tests after a session has ended.

Step 2: Proposed changes
Modify 'agentops/client.py' to update the 'end_timestamp' of an event before checking if a session is active. This ensures that events are correctly marked as ended in the local state even if they cannot be recorded on the server. This fix also addresses the test failure.

Step 3: Fix implementation
Applied a diff to 'agentops/client.py' moving the timestamp update logic before the session check.
