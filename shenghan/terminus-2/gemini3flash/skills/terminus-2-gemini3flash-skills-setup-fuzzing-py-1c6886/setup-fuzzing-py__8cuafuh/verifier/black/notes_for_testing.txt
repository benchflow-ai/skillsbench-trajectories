Library: black
Functions to test:
1. black.format_str: Formats a string of Python code.
2. black.reformat_code: Reformats a string of Python code given a Mode.
3. black.format_ipynb_string: Formats a Jupyter Notebook string.

Fuzzing Strategy:
Use Atheris to provide random strings of (potentially) Python code to format_str. We want to check for crashes or cases where the formatter produces invalid code that it can't re-parse.
