The build fails because the submodules (common, factory, service, value) depend on 'auto-parent' version 3, which tries to resolve 'tools.jar' from the JDK lib directory. The build environment is running Java 11, which does not have 'tools.jar'.

The root directory contains a 'pom.xml' for 'auto-parent' version '4-SNAPSHOT'. We need to update the submodules to use this local parent version instead of the remote version 3.
