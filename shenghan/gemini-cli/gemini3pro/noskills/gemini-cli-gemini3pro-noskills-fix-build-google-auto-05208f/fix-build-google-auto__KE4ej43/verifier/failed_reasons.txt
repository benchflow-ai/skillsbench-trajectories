The build fails because `auto-common`, `auto-factory`, `auto-service`, and `auto-value` depend on `compile-testing` (versions 0.6, 0.7, 0.8).
These versions of `compile-testing` have a system dependency on `tools.jar` at `${java.home}/../lib/tools.jar`.
On Java 11, `tools.jar` does not exist, causing the build to fail with `Could not find artifact com.sun:tools:jar:11.0.27`.
Additionally, the submodules depend on `auto-parent` version `3`, which should be updated to `4-SNAPSHOT` to match the local workspace configuration.

To fix this:
1. Update the parent version of all submodules to `4-SNAPSHOT`.
2. Add an exclusion for `com.sun:tools` to the `compile-testing` dependency in `common/pom.xml`, `factory/pom.xml`, `service/pom.xml`, and `value/pom.xml`.
