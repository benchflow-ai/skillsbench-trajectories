Fuzzing Target Note

- Target: arrow.get(str)
- File / location: arrow/factory.py -> arrow/parser.py
- Why this target:
    - Input surface: Public API `arrow.get()` accepts strings for ISO parsing.
    - Complexity: Uses regexes and custom parsing logic for various ISO-like formats.
    - Current test gaps: Likely covers standard formats, but edge cases in regexes or weird combinations might be missed.
- Callable contract:
    - Required imports: `import arrow`
    - Preconditions: None.
    - Determinism concerns: `now` is not involved if parsing explicit string.
    - External dependencies: None.
- Input model:
    - Primary payload type: `str` (from `bytes`).
    - Decoding: `data.decode("utf-8", "ignore")` or `atheris.FuzzedDataProvider` to get unicode.
    - Edge classes: Invalid ISO formats, partial strings, huge strings, unicode garbage.
- Oracles:
    - Must-hold properties: Should not crash with unexpected exceptions (only `arrow.parser.ParserError`, `ValueError`, `TypeError`).
    - Suspicious exceptions: `IndexError`, `AttributeError`, `re.error` (if regex is dynamically built from input, though here it seems static).
- Harness plan:
    - `atheris.Setup(sys.argv, TestOneInput)`
    - `TestOneInput(data)`:
        - `fdp = atheris.FuzzedDataProvider(data)`
        - `s = fdp.ConsumeUnicode(sys.maxsize)`
        - `try: arrow.get(s) except (arrow.parser.ParserError, ValueError, TypeError): pass`
- Risk flags:
    - None significant. Pure Python parsing.

    1. Setup env.
    2. Write fuzz.py.
    3. Run.
