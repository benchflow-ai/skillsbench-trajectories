The build fails because the submodules (`auto-common`, `auto-factory`, `auto-service`, `auto-value`) refer to `auto-parent` version 3, which has a dependency on `tools.jar` that is incompatible with the Java 11 environment (where `tools.jar` does not exist).
The root `pom.xml` defines `auto-parent` version 4-SNAPSHOT, which appears to be updated to handle this (or at least doesn't enforce the broken dependency).
The fix is to update the parent version in all submodules' `pom.xml` files from `3` to `4-SNAPSHOT`.
