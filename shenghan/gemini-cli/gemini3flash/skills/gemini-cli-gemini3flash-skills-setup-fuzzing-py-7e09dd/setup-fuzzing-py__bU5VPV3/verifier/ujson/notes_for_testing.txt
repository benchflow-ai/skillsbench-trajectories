Important functions for testing in `ujson`:

1. `ujson.loads(string)`: Decodes a JSON string to a Python object. This is implemented in `JSONtoObj.c`.
2. `ujson.dumps(obj)`: Encodes a Python object to a JSON string. This is implemented in `objToJSON.c`.

Fuzzing Plan:
- Fuzz `ujson.loads()` with random strings.
- Fuzz `ujson.dumps()` with various Python objects if possible, but `loads` is the main target for security/robustness.
