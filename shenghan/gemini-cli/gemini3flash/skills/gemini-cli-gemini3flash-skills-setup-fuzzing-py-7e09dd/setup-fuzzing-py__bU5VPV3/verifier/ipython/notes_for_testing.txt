Important functions for testing in `ipython`:

1. `IPython.core.inputtransformer2.TransformerManager.transform_cell(cell)`: Transforms IPython special syntax to valid Python. This involves complex regex and tokenization.
2. `IPython.core.inputtransformer2.TransformerManager.check_complete(cell)`: Determines if a code block is complete, incomplete, or invalid.
3. `IPython.core.interactiveshell.InteractiveShell.run_cell(raw_cell)`: The high-level entry point for running code in IPython.
