Important functions for testing in `minisgl`:

1. `minisgl.message.utils.deserialize_type(cls_map, data)`: Deserializes a message from a dictionary. This is a common entry point for messages received over the network (ZMQ).
2. `minisgl.message.BaseTokenizerMsg.decoder(json)`: Uses `deserialize_type` to decode tokenizer messages.
3. `minisgl.tokenizer.tokenize.TokenizeManager.tokenize(msgs)`: Processes a list of tokenize messages.
