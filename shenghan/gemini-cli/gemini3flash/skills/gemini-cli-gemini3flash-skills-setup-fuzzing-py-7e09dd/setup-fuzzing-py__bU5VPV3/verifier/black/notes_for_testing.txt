Important functions for testing in `black`:

1. `black.format_str(src_contents, *, mode)`: The main entry point for formatting Python code from a string. This is a very complex function that involves parsing and re-generating code.
2. `black.parsing.lib2to3_parse(src_txt)`: Directly tests the parsing logic.
3. `black.parsing.parse_ast(src)`: Tests AST parsing.
