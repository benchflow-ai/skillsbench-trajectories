Important functions for testing minisgl:
- minisgl.core.SamplingParams: Configuration for sampling, can be fuzzed for edge cases in parameters.
- minisgl.core.Req: Request object for the engine.
- minisgl.tokenizer.tokenize.tokenize(): If it uses a custom tokenizer or wraps one, it's a good target.
- minisgl.engine.engine.Engine.step(): The main execution step.
