## Error 1: tools.jar dependency for Java 11+ (FIXED)
The build initially failed due to a Java 11 incompatibility with the test dependency
com.google.testing.compile. This dependency has a transitive system-scoped dependency
on com.sun:tools (Java compiler tools).

In Java 8 and earlier, tools.jar was available at $JAVA_HOME/../lib/tools.jar.
In Java 9+, tools.jar was removed and its classes are part of the Java modules system.

**Fix Applied**:
1. Added exclusions for com.sun:tools to compile-testing in all four modules:
   - common/pom.xml - Added <exclusion> for com.sun:tools
   - factory/pom.xml - Added <exclusion> for com.sun:tools
   - service/pom.xml - Added <exclusion> for com.sun:tools
   - value/pom.xml - Added <exclusion> for com.sun:tools

2. Removed the tools.jar profile activation conditions from pom.xml:
   - Removed "default-profile" which tried to find ${java.home}/../lib/tools.jar
   - Removed "mac-profile" which tried to find ${java.home}/../Classes/classes.jar
   - These profiles were not applicable to Java 9+ environments

3. Updated all modules to use parent version 4-SNAPSHOT instead of 3:
   - This ensured they use the corrected parent pom with no profiles

## Error 2: Missing javax.annotation.Generated class (FIXED)
After fixing the tools.jar issue, a new compilation error appeared:
- factory/src/main/java/com/google/auto/factory/processor/FactoryWriter.java:39
- value/src/main/java/com/google/auto/value/processor/AutoValueProcessor.java:51
  Cannot find symbol: class Generated, location: package javax.annotation

Root cause: In Java 9+, javax.annotation.Generated is no longer part of the default
classpath. This annotation exists in the java.base module but needs an explicit
dependency to be accessible.

**Fix Applied**:
- Added javax.annotation-api:1.3.2 as a compile-time dependency to:
  * factory/pom.xml
  * value/pom.xml
This provides the missing javax.annotation.Generated class.
