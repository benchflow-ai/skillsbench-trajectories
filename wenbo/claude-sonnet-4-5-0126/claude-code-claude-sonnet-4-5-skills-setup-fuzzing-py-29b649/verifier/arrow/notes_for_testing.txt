==============================================
ARROW LIBRARY - FUZZING TARGET ANALYSIS
==============================================

## LIBRARY OVERVIEW
Arrow is a Python library for better dates and times. It provides parsing, formatting, and manipulation of datetime objects with timezone support. The library handles ISO 8601 and custom format strings.

Dependencies:
- python-dateutil>=2.7.0
- zoneinfo/backports.zoneinfo (for timezone support)
- tzdata (Python 3.9+)

## IMPORTANT FILES (Ranked by fuzzing value)

1. arrow/parser.py (Score: 10/10)
   - Contains DateTimeParser and TzinfoParser classes
   - Handles complex regex-based parsing of datetime strings
   - Multiple input formats (ISO 8601, custom formats, timestamps)
   - High complexity with edge cases
   Indicators: parse, decode, regex, validation, timezone, format handlers

2. arrow/factory.py (Score: 8/10)
   - ArrowFactory.get() method handles multiple input types
   - Dispatches to parser based on input type
   - Type coercion and validation
   Indicators: API exposure, input boundary, type conversion

3. arrow/formatter.py (Score: 6/10)
   - DateTimeFormatter.format() converts datetime to strings
   - Token-based formatting with regex
   - Less critical for security but still valuable
   Indicators: format, encode, template

4. arrow/api.py (Score: 5/10)
   - Public API wrapper functions
   - Delegates to factory methods
   Indicators: Public API exposure

## INFERRED ORACLES

1. No-crash property: Parser should never crash on any string input
   - Applies to: parse(), parse_iso(), TzinfoParser.parse()
   - Either return valid datetime or raise ParserError

2. Round-trip property: format(parse(s, fmt), fmt) should be stable
   - Applies to: parse() + format()
   - Not exact equality due to normalization

3. ISO 8601 consistency: Valid ISO strings should parse consistently
   - Applies to: parse_iso()

4. Timezone offset determinism: Same offset string → same tzinfo
   - Applies to: TzinfoParser.parse()

5. Exception type consistency: Invalid input → ParserError (not other exceptions)
   - Applies to: All parsing functions
