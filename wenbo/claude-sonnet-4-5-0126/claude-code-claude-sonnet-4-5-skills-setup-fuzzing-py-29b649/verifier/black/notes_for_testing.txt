## LIBRARY OVERVIEW
Black is an uncompromising Python code formatter. It parses Python source code using lib2to3, transforms it into an AST, and reformats it according to Black's style rules. The library handles Python 3.10+ code with complex parsing and AST manipulation.

Dependencies:
- click>=8.0.0
- mypy_extensions>=0.4.3
- packaging>=22.0
- pathspec>=0.9.0
- platformdirs>=2
- pytokens>=0.3.0
- tomli>=1.1.0 (Python < 3.11)
- blib2to3 (lib2to3 fork for parsing)

## INFERRED ORACLES

1. No-crash property: Parser should handle any input gracefully
   - Applies to: lib2to3_parse(), parse_ast(), format_str()
   - Either return result or raise expected exceptions

2. Idempotence: format(format(code)) == format(code)
   - Applies to: format_str(), format_file_contents()
   - Critical property for a code formatter

3. AST equivalence: parse(code) ≈ parse(format(code))
   - Applies to: format_file_contents() with safe mode
   - Formatted code should have same semantics

4. Exception type consistency: Invalid input → InvalidInput or SyntaxError
   - Applies to: All parsing functions
   - Should not leak unexpected exceptions

5. Determinism: Same input → same output always
   - Applies to: All formatting functions
