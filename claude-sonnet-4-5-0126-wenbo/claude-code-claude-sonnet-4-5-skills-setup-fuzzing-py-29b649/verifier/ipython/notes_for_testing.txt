## LIBRARY OVERVIEW
IPython is an enhanced interactive Python shell providing powerful features for interactive computing, including rich display system, magic commands, input/output caching, and system shell access.

Dependencies:
- decorator
- jedi (code completion)
- matplotlib-inline
- prompt_toolkit
- pygments (syntax highlighting)
- stack_data
- traitlets

## INFERRED ORACLES

1. No-crash property: Input transformation should never crash
   - Applies to: transform(), completions()
   - Should return result or raise expected exception

2. Valid Python output: Transformed code should be parseable Python
   - Applies to: InputTransformer.transform()
   - Output should compile() successfully or raise SyntaxError

3. Safe completion: Completions should not execute arbitrary code
   - Applies to: IPCompleter
   - No side effects during completion

4. Exception safety: All user input should be handled safely
   - Applies to: run_cell()

==============================================
FUZZING TARGET NOTE #1
==============================================

Target: InputTransformer.transform_cell()
File / location: IPython/core/inputtransformer2.py
Why this target:
  - Input surface: Arbitrary user input strings (code cells)
  - Boundary considerations: Complex regex-based transformations, tokenization
  - Complexity: Handles magic commands, shell escapes, special syntax
  - Current test gaps: Malformed syntax, edge case Unicode, unusual combinations

Callable contract:
  - Required imports: from IPython.core.inputtransformer2 import TransformerManager
  - Preconditions: Input should be string
  - Determinism: Deterministic for given input
  - External dependencies: tokenize module

Input model:
  - Primary payload type: str (Python code cell)
  - Parsing steps: Tokenize → identify special syntax → transform → return
  - Constraints to respect: Must be string
  - Edge classes: Empty strings, special characters, incomplete syntax, magic commands, shell escapes, Unicode edge cases

Oracles:
  - Must-hold properties: No crashes, returns transformed code or raises
  - Acceptable exceptions: SyntaxError, TokenError, IndentationError
  - Suspicious exceptions: ValueError, TypeError, AttributeError, RecursionError
  - Crash-only vs correctness: Crash-only (focus on robustness)

Harness plan:
  - Recommended approach: Create TransformerManager, call transform_cell()
  - Minimal harness signature: TestOneInput(data: bytes) → transform string
  - Seed corpus ideas: Magic commands (%time, %%bash), shell commands (!ls), help syntax (?obj), valid Python code
  - Timeouts: 5 seconds

Risk flags:
  - Native extension: No (pure Python)
  - Potential DoS paths: Regex catastrophic backtracking, deep recursion
  - External I/O: No

Next actions:
  1. Convert fuzzer bytes to string
  2. Create TransformerManager instance
  3. Call transform_cell(string) in try-except
  4. Allow SyntaxError/TokenError, fail on unexpected exceptions
